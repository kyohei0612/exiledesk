# 最終チェック長の猿 (R-18) に必ず触らせる所 — シミュの木の大改装 (シミュ部長 70、11-16 夕)

始め方はどれも同じ: `?page=sim-base` → ベース (例: 手袋 → 巨大なミット) → 完成の MOD の行「付ける ⌄」→「ふつう」で 1 つ以上 → 「決めた (ツリーへ)」→ 窓「どこから始める？」で「これで始める (ツリーへ)」→ スタートの箱の「＋MOD」→ 窓の「決めた (ツリーへ)」→ 箱の下の ＋ で手を置く。完成の MOD 0 のまま「決めた」は「MOD を決めてください」で進めない (正しい)。
1280×800 と 390 (スマホは見るだけ) の両方。英語 (EN) でも 1 回。

## 1. 外れの箱を隠す (idealHide・S-142n・S-191)
- 変成の手の窓で完成形の MOD を ☑ して置く → 結果は当たり 1 + 外れ 2。完成を押す前は外れの箱が出ず「! 未設定 1 つ」
- 当たりの箱を 75% 以上に寄せて「完成」→ 外れの箱が赤い未設定で出る「未設定 2 つ」
- 「保存」→ 名前 → ページを読み直す → 「レシピ ▾」の一覧から開く → 灰色の箱が無く、未設定 2 つのまま
- 見る所: 灰色の箱が出ない・未設定の数と帯の「次へ」が合う

## 2. 兄弟枠と畳み (junkSameHand・hitsSide・linkChipHover・spotNoZoom・chipShrink)
- 変成 → 増強 → 高貴 → カオスを狙い無しで置く (4 段目に 2 つのカオスが並ぶ)。5 段目の外れの左端 / 右端の箱にカオス → 同じ外れの箱に 1 回で同じカオスが入る
- 「→ 同じ枠へ」だけの箱は描かれない (未設定の兄弟がいても畳む)。手の札「カオスオーブ」に乗せる → 「行き先は同じ枠へ (n)」の札・緑の弧・行き先の箱が光る。↩ の札は青
- 縮める (－) → 手の札も木と一緒に小さくなる
- 見る所: 押した箱が 4 段目と同じ中身だと ↩ になり、札は中身の違う箱に付く (わざと、オーナー 11-16「今のまま」)

## 3. 組む順と並べ (buildHitsFirst・pathLeftCol・kidsUnderOwn・handSplit・unsetTopJump)
- 当たりの箱がある木で帯の「! 未設定 n つ ▸ 次へ」を押し続ける → 当たりの道を左から深くが先、外れはその後
- 「完成」・「最終チェック」を押した時、一番進んだ道が左の列に寄る
- 上の帯に赤い「未設定 n つ」は出ない (下の帯だけ)

## 4. 100 人回す (firstTry・walkFast・runNoLines・lowTierBox・goalMetTag・essSameStop・goalRetry・aimFloor)
- 完成と失敗まで決めた木で「100 人回す」→ 結果のまとめの止まりの欄が (a) 予期せぬ狙い MOD / (b) 木の不具合 に分かれる・詳細が開く
- 1 人目の再生が最初から速く流れる・回した後に木に太い線と「n 回」が出ない
- 狙い無しの手で完成形の MOD が付いた箱のカードは「外れ MOD」でなく名前で出る (札は無し)

## 5. フラクチャー (simSureFrac・sureFracAll・fracSplit・fracOneRow・fracSetting・aimGroups)
- 完成形の MOD に ✦ を 1 つ付けて「決めた」→ 窓の見出し「フラクチャー設定」と注意書き 1 か所 → (b) 白から確定フラクチャー → 木の中のフラクチャーで選んだ MOD が必ず固定・費用が使った物全部
- ✦ を 2 つ → 固定した MOD が違う人が別の箱に分かれる・完成形のカードの ✦ の行は 1 行
- 手の窓の狙いが「フラクチャーの候補 / 狙い MOD / 狙い無し」の 3 段。木の中で 2 回目のフラクチャーは棚で灰色 (木は 1 つまで、オーナー 11-16)
- デイリーの確定フラクチャー (DailyFracPick) の費用の文も同じ数え

## 6. 狙いと手の窓 (eleAny・essEleHit・veilPickKeep・handAddAim)
- 完成形に火・冷気・雷の耐性 → 「いずれかの元素耐性」1 行。手の窓で単体の ☑ (いずれかを外した時だけ押せる)、2 つ付く手で「2 個目の MOD も狙う」
- 首飾りなどでエッセンスの耐性を打つ → 値が段以上なら当たり
- 骨の手の窓: 発現 / 狙い無し / 未発現の 3 択、反響はお告げの列から
- 変成・高貴などの手の窓「狙いの MOD を足す」→ MOD の窓で選ぶと ☑ が入る

## 7. 開く・白紙・帯 (oldRecipeView・sharedOpenWait・treeClearArm・resetDim・chaosSkip)
- 共有 URL (#recipe=) を開く → 読み終えるまで「レシピ読み込み中…」、ベース選びへ飛ばない
- 古い版で保存したレシピ (開発の 1440 では作れない = 本番の作りの 1461 で) → 「古いレシピ」の 1 行、100 人回す・最終チェックが止まる、手を触ると今の形で組み直し
- 「白紙」は保存していない木でもいつも 2 回押し・1 つ戻すで戻る
- 完成形の設定を変える確かめの帯の間、ほかが暗くなり押せない
- スタートの手の窓「カオススパムまでスキップ」→ 変成 → 増強 → 王者が狙い無しで置かれる

## 8. チュートリアル (cd98f296d・b92e85ec1)

## 9. 貼り付け (pasteDropOnly)
- シミュとデイリーの「アイテムを貼り付けて取り込む」に創生の樹などドロップ限定の MOD の入った品 → 読めない行にならず取り込まれる

## 10. ジュエル (jewelMagic・E-18b、シミュ部長 71 が足した)
- エミュ (?page=craft) でベースにジュエル (例: ルビー) を選ぶ → 新品がマジック (MOD なし) で出る。棚の変成・錬金は打てない (灰色)、増強などマジックに打つ物は打てる
- シミュの ?page=sim-base でジュエル → 完成の MOD を決めて木へ → スタートの箱がマジック、棚に変成・錬金が無い / 打てない
- 見る所: ジュエル以外 (指輪など) は今までどおりノーマル (白) から

## 11. MOD の表 (tierKeepHeld・modNone・modOneLine、エミュ・シミュ共通)
- エミュで MOD の表のある系統の行を押してティアの表を開く → 棚のカレンシーを別の物に持ち替える → 表が閉じない (同じ系統があれば開いたまま)
- MOD が上限まで付いたレアで高貴を持つ → 空の表でなく「付けられる MOD はありません」(英語 No mods can be added)
- PC 幅 (1280) で長い名前の系統の行 → 1 行で後ろが「…」、乗せると全文、タグは切れない。開いたティアの表の数が見出しと同じ並び (出やすさ・ティア・Lv) で右寄せ、付ける / 選ぶのボタンは文と数の間
- シミュの帯「MOD 一覧」の窓でも同じ表 (上の 3 つ)
- 見る所: 390 で崩れない (はみ出し・重なり)

## 12. 右クリック (noCtxMenu・U-38、Web の全部の画面)
- エミュ・シミュの木・デイリー・レシピの一覧・トップで何も無い所や箱・カードを右クリック → ブラウザのメニュー (コピー・検証など) が出ない
- 文字を打つ欄 (検索・名前・貼り付けの欄)・読むだけの URL の欄・選んだ文字の上で右クリック → メニューが出る (コピー・貼り付けできる)
- エミュでカレンシーを持って右クリック → 持った物を離す (今までどおり、メニューは出ない)
- 見る所: 猿の右クリックで JS エラーが出ない・持った物の離しが壊れていない
