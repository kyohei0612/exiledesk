# ADR 005: ショート (縦 1080x1920) を本編とセットで作る

- 状態: 採用 (2026-09-28)
- 決めた人: kyohei

## 背景

本編と同時にショートも出して、本編へ流したい。ショートは最後まで見られない前提 (kyohei)。
1 本目は「3 秒クイズ」: 「アクト中に使っていいのはどれ？ 錬金術・カオス・神」。

## 決めたこと

- **台本は同じ形** (`VideoScript`) に `layout: "short"` を付ける。結果 JSON・実演 (demos) は本編と共有してよい
- **画面の作り方**: 今の横長 (1920x1080) のフレームを作ってから、縦に組み直す (`render/short_frame.py`)
  - 上: 「本編は関連動画から」の帯を**最初から最後まで**出しっぱなし (途中で離れる人にも見せる) + ショートの題 (`short_title`)
  - 中: 横長フレームのパネル部分 (クラフト画面・クイズのカード) を切り出して拡大。結果の文字 (+ MOD 等) もこの中
  - 下: 立ち絵 2 人 + 大きい字幕 (折り返し)
- **新しい画面 `quiz`**: `choices` (カレンシーキー、2〜4 個) をアイコン + 公式名のカードで並べる。`answer` (正解の番号) で正解を緑に、
  `badges` (カードごとの札、例「使う」「取っておく」) で答え合わせの札を付ける
- **構成の決まり**: 最初の 2 秒で問い (つかみ)、30 秒以内に答えと本編への案内。章カードは出さない
- **検査**: ショートは導入の長さ・聞き役の比率・実践の手の抜けを見ない (文体・語尾・予告禁止・尺は見る)
- **投稿**: 本編を公開 → ショートの説明文に本編の URL、「関連動画」は YouTube Studio で本編を指定 (API に項目が無い)

## 影響

`script/{model,lint}.py`、`render/{scene_panel,short_frame}.py`、`video/{animate,build}.py`

## 追記 (2026-09-30 kyohei)

- **ショートは本編から切り出さず、独立して組み立てる**。同じ実演・画面を使ってもよいが、話の流れはショートの中だけで通るように書く
  (3 本目のショートは本編の流れを縮めたので、選択肢「ずんだもん / おすすめ」なのに答えで「正解は右」と言うずれが出た)
- **クイズの答えは、画面の選択肢と同じ言葉で言う** (「右」「左」ではなく、札に書いてある言葉)
