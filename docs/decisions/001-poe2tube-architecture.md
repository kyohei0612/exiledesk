# ADR-001: POE2Tube 全体設計 — youtube-pipeline の応用で PoE2 解説動画を半自動生成する

- 日付: 2026-09-27
- 状態: 承認 (構想フェーズ、1 分テスト動画で検証中)
- 関連: ExileDesk 側 ADR「クラフトステージ」(別リポジトリ)

## 背景

PoE2 の初心者 (ストーリークリア直後の層) 向けに、クラフト解説とお金稼ぎの動画を
**週 3 本** 出したい。既存の `youtube-pipeline` (ニュース解説の全自動生成) を持っており、
動画化の後半 (音声 → 字幕 → 弾幕 → ffmpeg 合成 → YouTube 投稿) はジャンルに依存しない。
一方、台本生成・背景画像・声はニュース専用なので、ここだけ PoE2 用に作り直す。

## 決定

### 1. 別リポジトリ、youtube-pipeline は部品として import

- 本リポジトリ `POE2Tube` を新設し、`../youtube-pipeline` の部品関数
  (`generate_subtitles` / `generate_danmaku` / `compose_video` / `upload_youtube` 等) を import する。
- `video_pipeline.py` / `daily_runner.py` は **使わない**。ニュース固有の副作用
  (鮮度チェックで停止、タイトル接頭辞、参考ソース URL 注入、`_clean_output` の全消し) を避けるため。
- 理由: 朝 5:00 のニュース本番を壊さない。youtube-pipeline の 300 行ルールにも抵触しない。

### 2. 声は VOICEVOX、キャラは ずんだもん (質問役) × 四国めたん (解説役)

- AquesTalk (ゆっくり声) は収益化に商用ライセンスが要るため不採用。
- VOICEVOX は無料・収益化可。**概要欄に `VOICEVOX:ずんだもん` `VOICEVOX:四国めたん` を必ず入れる**
  (表記なし商用は 1 キャラ 40 万円)。概要欄テンプレートに固定文言として組み込む。
- エンジンは `vv-engine/run.exe --port 50021` を HTTP で叩く (SBV2 と同じ形)。
- 立ち絵は坂本アヒル氏の PSD (動画利用可・商用可・改変可・クレジット任意)。
  `psd-tools` でレイヤー切替 → PNG キャッシュ。口パクは音量 3 段階連動。

### 3. 半自動運用: 指示 → 台本 → OK → 全自動

```
kyohei の指示 (題材)
  → ExileDesk クラフトステージで手順をシミュレート (結果 JSON)
  → Claude が台本 (掛け合い + シーン指示) を書く ※シミュ結果を見てから書く
  → kyohei が OK (レビュー場所は未決: Discord or ローカル)
  → 自動: 図解描画 → VOICEVOX → 字幕 → 合成 → 投稿
```

「声を先に作り、絵をその長さに合わせる」(声先行・絵追従) は youtube-pipeline と同じ原則。
画面録画・GUI 自動操作は **しない**。

### 4. 画面は全部データから描く (実ゲーム画面は使わない)

| シーン | 絵の出どころ |
|---|---|
| 会話 | 立ち絵 2 体 + 背景 + テロップ |
| 積み上げ図解 | 工程 1 → 工程 1+2 → 完成、と工程が積み上がる紙芝居 |
| 実践 | ExileDesk「クラフトステージ」の画面 (JSON 手順で自動再生し撮影) |
| 相場・チャート | ExileDesk のスナップショット → matplotlib |

### 5. 台本の型 (伸びているゆっくり解説のトレース)

導入 30 秒以内 (問いかけ / 意外な事実 / 約束) → 本題は PREP × 3 → まとめ要点 3 つ。
1 分 = 300〜350 字、解説役 3〜5 セリフに聞き役 1〜2、30〜60 秒に 1 回ツッコミ、一文 40 字以内、
語尾固定 (ずんだもん「〜なのだ」、めたん「〜よ / 〜ね」)。

## 影響

- ExileDesk 側に「クラフトステージ」画面と、動画用エクスポート (手順 JSON → 結果 JSON) の出口が必要。
- YouTube は PoE 専用チャンネルを新設し、OAuth は最初から Production 公開にする (Testing の 7 日失効を回避)。
- Claude CLI の使用量をニュース本番 (朝 5:00) と食い合わない時間帯で回す。

## 却下した案

- youtube-pipeline に `--slot poe` を足す: ニュース副作用の分岐が増え god-module 化する。
- 画面録画 (GUI 自動操作): 尺が声と合わない、ExileDesk の改修で壊れる。
- ClipGift で合成: ClipGift は既存動画の切り出し道具で、部品から組む用途ではない。

## 検証済み (2026-09-27)

- VOICEVOX 0.25.2: 1 文 4 秒の合成 2〜4 秒、読みは正確。
- 口パク: PSD レイヤー切替 + RMS 3 段階で 1080p mp4 生成 OK。
