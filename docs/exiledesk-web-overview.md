# ExileDesk (Web 版) の概要 — 外部の評価用

2026-10-15 時点。Path of Exile 2 (以下 PoE2) のクラフトを試せる無料の Web アプリ。開発・運営は個人 1 人 (日本)。
この文書は、別の AI や人に「サービスとしてどうか・何を優先すべきか」を評価してもらうためのまとめ。

- URL: https://exiledesk.com/
- 版: v0.1.514 (Web とデスクトップアプリで共通の版)
- 開発の開始: 2026-05 (アプリ)、Web 版の公開: 2026-10-07 前後、独自ドメインへの移行: 2026-10-11

---

## 1. 何をするサービスか

PoE2 の装備のクラフト (カレンシーを打って MOD を付け外しする) を、ゲーム内のお金を使わずに何度でも試せる「エミュレーター」。

- ベース (指輪・弓・手袋など) を選び、カレンシー (変成・高貴・カオス・消去・神・骨・エッセンス・フラックス・ルーン・お告げ…) を打つと、ゲームと同じ確率で MOD が付く
- 付いた瞬間の確率、1 手戻す、手順の記録、取引所 (公式トレード) で今の MOD を検索するボタン
- 日本語と英語。ゲームの用語はクライアントの日本語・英語の原文

想定する人: PoE2 でクラフトを練習したい人・高いカレンシーを使う前に試したい人・初心者から上級者まで。

## 3. 機能

### 出している物
- **エミュレーター** (メイン): 上の通り。冒涜 (骨 → 発現)・お告げ・エッセンス・ルーン・フラックス・聖別・品質・触媒 まで
- **取引所の検索**: 今のアイテムの MOD で公式トレードを開く (開くだけ。サーバーからトレードの API は叩かない)。「ベース検索含め」のチェックあり
- **ベースの説明のページ** 787 枚 (/bases/、付く MOD・段・出やすさ・暗黙)。検索から来る入口
- **使い方** (/guide)、**お問い合わせ** (/contact)、プライバシーポリシー
- **要望・バグを送る窓**: 画面の状態 (ベース・MOD・手順) が自動で付く。画像も 3 枚まで。直したら次に開いた時に返事が出る
- **相場**: poe2scout から 1 時間に 1 回取り、カレンシーの値段で費用を出す

### 止めている物・外した物
- **シミュレーター** (狙いの MOD まで自動で何千回も回して平均費用を出す): Web は「調整中」で止めている (アプリにはある)
- ヴァールのオーブ (コラプト)・可能性のオーブ: 結果の確率の公開データが無いため棚から外した

### 予定 (ロードマップ、詳細は docs/roadmap-2026-10.md)
1. **掲示板** (次): 1 つのタイムライン・匿名・タグ・投稿の時刻は出さない・レア MOD を引いたら匿名で自動の速報
2. カレンシーの動きを「説明文の分解」で作り直す (ADR-004、例外の書き足しをやめる)
3. クイズ形式のチュートリアル 4 本
4. ジェムコラプトの計算機 (Web)
5. クラフトチャレンジ (毎日のお題・ランキング)
6. 英語版の仕上げ → 英語圏で宣伝 (reddit・配信者)
7. シミュレーターの Web 版を戻す
8. 支援のサブスク (広告を消す + 応援、月 300 / 500 / 1,000 円)

## 4. 技術

| 部分 | 中身 |
|---|---|
| 画面 | Vue 3 + TypeScript + Tailwind、Vite。計算 (確率・シミュレーション) は全部ブラウザ |
| 配信 | Cloudflare Workers の静的な配信 (exiledesk.com)。ページ・絵・ゲームのデータは配信網から |
| サーバー | Cloudflare Workers 1 本 (相場の中継・配信の情報・要望・記録)。KV・D1・Analytics Engine |
| ゲームのデータ | PoE2 のクライアントの表 (MOD・ベース・カレンシーの説明文・日本語訳) から自前で作る。確率の重みは poe2db / Craft of Exile / コミュニティの実測 |
| デスクトップアプリ | 同じ画面を Tauri (Rust) で包んだ物。取引所の自動取得・PoB 連携などアプリだけの機能あり。広告なし |
| テスト | vitest 約 1,100 件 + cargo test。CI で main への push ごとに回す |
| 分析 | 自前の記録 (Analytics Engine、cookie なし・名前なし)。毎朝 9 時に日報を Discord へ |

負荷の考え方: 計算はブラウザ、全員に同じ物は 1 時間に 1 回作って配る。アクセスが集中してもサーバーは落ちにくい。無料枠の上限 (Workers 1 日 10 万回) に当たるのは 1 日 1 万訪問くらいから。

## 5. 正しさの決め方

- MOD・ベースは poe2db、付き方・確率は Craft of Exile、細かい決まりはオーナーがゲームで確認した物を正にする
- テストの期待値は自分の決まりではなく外の正解の写しから作る方針 (移行中)
- 確率の公開データが無い物 (ヴァール・可能性) は入れない

## 6. 収益の計画

- 目標: 月 20 万円
- AdSense: 2026-10-13 に申し込み、審査中。1 訪問 0.25〜0.75 円の見込み → 今の人数だと月数千円
- 広告の置き方: クラフトの画面は右の列に 2 枠、画面を移った時だけ入れ替える (時間では入れ替えない)。スマホは 1 枠
- 時間で入れ替わる広告 (Nitropay): 一度落ちた。1 日 1,000 人を超えたら出し直す
- 支援のサブスク: 広告を消す + 応援 (日本は Stripe、海外は Patreon)。機能を有料と無料に分けない
- アプリには広告を出さない

## 7. 分かっている弱点・課題

- 人の数: 1 日 200 人前後。目標には日本語だけでは足りず、英語圏の人を増やす必要がある
- 検索から来る人がまだ少ない (ベースの説明のページは作ったばかり)
- スマホの人はすぐ帰る (8 割が 1 分未満)。PC の人は長くいる
- 手書きのクラフトの決まり (約 130 個) のうち、根拠の薄い物が約 40 個あった (総点検済み、作り直し予定)
- シミュレーターが Web で止まっている
- セキュリティ: 管理用の合言葉を URL で渡している、Web にセキュリティのヘッダーが無い、部品の古い穴を未確認 (タスク化済み)
- 個人開発なので、リーグ (3〜4 か月ごと) の更新の時に手が回るか

## 8. 評価してほしい点

1. サービスとしての強み・弱み (Craft of Exile・poe2db・Maxroll などと比べて)
2. 人を増やすのに一番効く事は何か (英語圏の宣伝・検索・コンテンツ・SNS)
3. ロードマップの順番は妥当か (掲示板を先にするか、チュートリアルやチャレンジを先にするか)
4. 収益の計画 (月 20 万円) は現実的か、他に良い方法はあるか
5. 初めての人が迷わず使えるか、何が足りないか
6. 1 人で続けるために、やめるべき事・減らすべき事
