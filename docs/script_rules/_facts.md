# PoE2 クラフトの「事実」(台本で断定してよい仕様)

台本の中でゲームの仕様を言い切ってよいのは **この表にある事だけ**。無い事は「〜らしい」も禁止で、書かない。
根拠は ExileDesk のクラフトステージ (計算機と同じ規則、クライアントのデータ) と結果 JSON。
間違いに気づいたら kyohei が直す (2026-09-28 作成)。

## レアリティと枠

| 事実 | 備考 |
|---|---|
| 白 (ノーマル) は MOD 0 個 | |
| 青 (マジック) は MOD 最大 2 個 (プレフィックス 1 + サフィックス 1) | |
| 黄 (レア) は MOD 最大 6 個 (プレフィックス 3 + サフィックス 3) | |
| ティアは T1 が一番強い。数字が大きいほど弱い | アイテムレベルが高いほど強いティアが出うる |
| アイテムレベルは拾った場所 (エリア) の強さで決まる | |
| 強いティアほど、出るのに高いアイテムレベルが要る | 台本では「今のデータだと」を付ける (0.5.0 のデータ、1.0 で変わりうる) |
| 最大マナ・ダメージ系はプレフィックスに多い、耐性・能力値はサフィックスに多い | 「多い」止まり。例外を断定しない |
| 詳しいティア表は poe2db で見られる (読み: ポエツーディービー) | 紹介してよい (kyohei 2026-09-28) |

### 指輪の MOD: ティアごとの必要アイテムレベル (ExileDesk `src/vendor/poe2htc/data/mods.json`、パッチ 0.5.0)

| MOD | T1 の最低 ilvl | ilvl 36 で出る上限 |
|---|---|---|
| 火耐性 | 82 | T5 (36〜) |
| 冷気耐性 / 雷耐性 | 82 | T6 (T5 は 38 / 37〜) |
| 混沌耐性 | 81 | T5 (30〜) |
| 最大ライフ | 54 | T4 (T3 は 38〜) |
| 最大マナ | 75 | T8 |
| 毎秒ライフ回復 | 47 | T2 (35〜) |

## ベース (装備の素体) の入手時期

| ベース | 入手 | 段階 |
|---|---|---|
| ニーモニックリング (Mnemonic Ring) | **創生の木でしか落ちない** (kyohei 2026-09-28)。アクトでは絶対に手に入らない | エンド |
| サファイアの指輪 (Sapphire Ring) | 通常ドロップ。ドロップレベル 12 (クライアントの BaseItemTypes) なのでアクト序盤から拾える。固有効果は冷気耐性 | アクト |

表に無いベースは入手時期を断定しない。アクト中の回ではアクトで拾えるベースを使う (kyohei に確認して表に足す)。

## カレンシーの効果 (PoE2)

| カレンシー | 効果 | 使える対象 |
|---|---|---|
| 変成のオーブ | 白 → 青にして MOD を 1 つ付ける | 白 |
| 増強のオーブ | 青に MOD を 1 つ足す (2 個まで) | 青 (空きがある時) |
| 王者のオーブ | 青 → 黄にして MOD を 1 つ足す | 青 |
| 錬金術のオーブ | 白 → 黄にして MOD を複数付ける | 白 |
| 高貴なオーブ | 黄に MOD を 1 つ足す | 黄 (空きがある時)。6 個埋まったら使えない |
| 消去のオーブ | MOD を 1 つランダムに消す | 青・黄 |
| カオスオーブ | **MOD を 1 つランダムに消して、新しい MOD を 1 つ足す** (PoE1 の「全部振り直し」ではない) | 黄 |
| ヴァールオーブ | コラプトさせる。結果は複数あり運。以後クラフト不可 | 詳細は ExileDesk の apply-vaal.ts (確率は等分の仮定) |
