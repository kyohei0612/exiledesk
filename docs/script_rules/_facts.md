# PoE2 クラフトの「事実」(台本で断定してよい仕様)

台本の中でゲームの仕様を言い切ってよいのは **この表にある事だけ**。無い事は「〜らしい」も禁止で、書かない。
根拠は ExileDesk のクラフトステージ (計算機と同じ規則、クライアントのデータ) と結果 JSON。
間違いに気づいたら kyohei が直す (2026-09-28 作成)。

**出典が食い違った時の優先順位** (kyohei 2026-09-30「ゲームデータ通りかな、最新だからね」):
1. ゲームのデータ (クライアントの値・ゲーム内の説明文。ExileDesk の data-cache / src/i18n)
2. 公式のパッチノート (いつ何が変わったか)
3. PoB の計算 (式の出どころ。手で書いた古い定数が混ざることがある)
4. 攻略サイト・コミュニティ
PoB の値がゲームのデータと違う所は、動画の数字に使う前に ExileDesk で PoB 側をゲームのデータに合わせるか、その数字を使わない。

## カレンシーの効果 (PoE2)

| カレンシー | 効果 | 使える対象 |
|---|---|---|
| 変成のオーブ | 白 → 青にして MOD を 1 つ付ける | 白 |
| 増強のオーブ | 青に MOD を 1 つ足す (2 個まで)。**プレフィックスかサフィックスかは決まっていない、空いている枠に付く** (青はプレ 1 + サフィ 1 なので、片方が埋まっていれば残りの方になる) | 青 (空きがある時) |
| 王者のオーブ | 青 → 黄にして MOD を 1 つ足す | 青 |
| 錬金術のオーブ | 白 → 黄にして MOD を複数付ける | 白 |
| 高貴なオーブ | 黄に MOD を 1 つ足す | 黄 (空きがある時)。6 個埋まったら使えない |
| 消去のオーブ | MOD を 1 つランダムに消す | 青・黄 |
| カオスオーブ | **MOD を 1 つランダムに消して、新しい MOD を 1 つ足す** (PoE1 の「全部振り直し」ではない) | 黄 |
| ヴァールオーブ | コラプトさせる。結果は複数あり運。以後クラフト不可 | 詳細は ExileDesk の apply-vaal.ts (確率は等分の仮定) |

## 耐性・火力の計算 (PoB 0.23.1、ExileDesk 要望 ⑰〜⑳ で確認、2026-09-30)

| 事実 | 備考 |
|---|---|
| 元素耐性の上限は 75% | 攻略記事 (Maxroll 等) と PoB で一致 |
| 元素耐性はアクトが進むとペナルティで下がる: アクト 1 は 0%、アクト 2 から 10% ずつ、エンドゲームで −60% | PoB の resistancePenalty (Act 1〜6 / Endgame)。混沌耐性には付かない |
| 受けるダメージ = 一撃 × (1 − 耐性)。耐性がマイナスだとダメージが増える | 例: 200 の一撃が −20% で 240、75% で 50 |
| クエストの報酬で耐性が上がる: アクト 1 で冷気 +10%、アクト 2 で雷 +10%、アクト 3 で火 +10% | PoB のクエストの表 (ExileDesk の結果 JSON の quests)。どのクエストかの日本語名は未確認なので言わない |
| 敵のアーマーは物理ダメージを軽くする。小さい一撃ほどよく削られる | PoB の式: 軽減 = アーマー ÷ (アーマー + 10 × 一撃の物理)。「普通の敵」のアーマーは PoB の目安の値 (Lv32 で 237) |
| アイスストライクは物理ダメージの 80% を冷気に変換する | ゲーム内の説明文 |
| 武器の「物理ダメージ増加」は武器の物理 (土台) に掛かる。アイスストライクでは冷気に変わる分も増える | PoB の計算で確認 |
| 武器に後から足す火・冷気・雷のダメージは、パッシブ・サポートで冷気だけを伸ばしていなければ同じ扱い (数値の幅が大きい物ほど強い) | PoB の計算 (アイスストライク、元素武装を付けても同じ) |
| DPS = PoB の TotalDPS (命中率・クリティカル込みの 1 秒あたりの当たりのダメージ)。状態異常の継続ダメージは入らない | 動画の前提: パッシブ・アセンダンシー・フラスコ・オーラ無しの素のキャラ |
| MOD の出やすさ (重み、アイテムレベル 33 のクォータースタッフ): プレフィックスは約 9 割がダメージ、サフィックスの当たり (アタックスピード・スキルのレベル・クリティカル) は約 3 割 | ExileDesk の mods.json (0.5.0)。「データの上では」を付けて言う |
| ルーンは防具では耐性 (砂漠 = 火、氷河 = 冷気、嵐 = 雷 の各 +10%)、武器では同じ属性のダメージ追加。はめたら外せないが置き換えはできる | ExileDesk の stage-runes.json とゲーム内の説明文 |
| 解呪: マジック → 変成のシャード、レア → 王者のシャード。サルベージ: ソケット付き → 熟練工のシャード | ExileDesk の実装 (個数は出典が無いので言わない) |

## 防御の仕組み (2026-09-30、ゲームのデータ・公式パッチノート・PoB・コミュニティを突き合わせ、ExileDesk 要望 ㉒)

用語はゲームの公式訳: アーマー / 回避力 (回避率) / **受け流し・受け流し力** (Deflection) / エナジーシールド (ES) / ブロック / ドッジロール / ルーンワード。
数字の出どころは ExileDesk の `src/services/craft-stage/defence-data.json` (ゲームの定数 GameConstants を優先)。

| 事実 | 出どころ・注意 |
|---|---|
| **アーマー**: 物理ダメージの「ヒット」だけを軽減。軽減 = アーマー ÷ (アーマー + 10 × 一撃)。**一撃の 10 倍のアーマーで 50%**、上限 90%。小さい一撃ほどよく軽減し、大きい一撃には弱い。継続ダメージ (出血など) と元素には普段は効かない | 説明文 + 公式 (0.1.1 で係数 12→10) + PoB。「12 倍」は古い情報 |
| **回避力**: ヒットを丸ごと受けない確率。敵が当てる率 = 1 − 0.95 × 回避力 ÷ (回避力 + 4 × 敵の命中力)。回避率の上限 95% (必ず 5% は当たる)。スペル・範囲攻撃にも効く (0.3.0 から)。**ボスの赤く光る技は回避できない** | 公式 0.3.1 / 0.3.0 + ゲームの定数 (上限 95) + PoB。目安: 回避力が命中力の 4 倍で約 47%、12 倍で約 71% |
| 回避が「毎回のサイコロ」か「決まった周期 (エントロピー)」かは **言わない** | 公式にもゲームのデータにも出典が無い (wiki と一部の攻略サイトは周期と書く) |
| **受け流し**: 受け流したヒットのダメージの **40% を防ぐ** (ヒットを消すのではない)。確率は敵の命中力と受け流し力で決まる (0.5.0 の式、上限 95%)。**ボスの赤い技にも効く** (回避との違い)。器用さ系の防具の「回避力の X% と同量の受け流し力」などで得る | ゲームの定数 (40) + 説明文 + 公式 0.5.0 |
| **ES**: ライフより先に削られる。**混沌ダメージは ES を 2 倍削る**。**出血と毒は ES を素通りしてライフに直接**。**最後に ES を失ってから 4 秒後に毎秒 12.5% ずつ戻る** (ライフだけ減った時は待ちがやり直しにならない。ゲームの説明文「再びエナジーシールドを失うとこの遅延はリセット」。poe2wiki の「4 秒ダメージを受けないと」は説明文と違う) | ゲームの定数 + 説明文。出血・毒の素通りは ExileDesk の ES の画面だけで、PoB の数字には入っていない |
| **ライフ**: Lv1 で 28、レベルごとに +12、筋力 1 ごとに +2 | PoB。説明文の「ライフリチャージ」がふだんから働くのか特別な効果の時だけかは分からないので言わない |
| **ブロック**: ブロックしたヒットはダメージを完全に防ぐ (スタンは受ける)。上限 50% (0.3.0 で 75% から)。**ボスの赤い技はブロックできない**。ブロック率は書いてある率そのまま (敵の命中力と関係ない)。盾に付いているブロック率が基本 | 説明文 + 公式 0.3.0 + PoB (CalcDefence の BlockChance に命中力は入らない) |
| **耐性**: 上限 75%、最大耐性でも 90% まで | 説明文 |
| **防具のベース**: 胴の素の値はアクト序盤 (Lv1) とエンド (Lv80) で、アーマー約 11 倍・回避力約 15 倍・ES 約 5.5 倍。アーマー + 回避などの混ざったベースもある | ゲームのデータ (ArmourTypes) |
| 防具の種類と要求能力値: 筋力 = アーマー、器用さ = 回避力、知力 = ES (混ざった物は 2 つの能力値)。防具の値 = (素の値 + 足す MOD) × (1 + 「+◯%」の MOD) × (1 + 品質) → 「+◯%」は素の値に掛け算なので、ベースが古いと伸びない | PoB (Data/Bases/body.lua の req、Classes/Item.lua の防具の計算) |
| **状態異常**: 感電で受けるダメージ +20%。凍結はプレイヤーが受けると 2 秒 (説明文の 4 秒はプレイヤー以外) | ゲームの定数 (PoB の 15% は古い → ExileDesk で 20% に上書き済み) |
| **ルーンワード (0.5.0 で追加)**: ライフが 0 になるダメージを受けた時に 1 残して、ルーンワードが残りを肩代わりする。毎秒 5% 回復 | 説明文 + ゲームの定数。**PoB にはまだ無いので数字は出さない** |
| **ドッジロール**: 「無敵」とは言わない。範囲攻撃は避けられない | 無敵時間の長さは公式・ゲームのデータに出典が無い (攻略サイト同士で食い違う) |
| 受けたダメージが減る順番 (画面の見せ方): 回避 → 受け流し → ブロック → 耐性 → アーマー → ES → ライフ | ExileDesk の view=layers (PoB の計算の順番に合わせた物) |


## エンドのクラフト素材 前編 (2026-10-02、上位オーブ・エッセンス・フラクチャー・カタリスト)

| 事実 | 出典 |
|---|---|
| **上位のオーブ (上級 / 完全)**: 効果はふつうのオーブと同じ。違いは「付く MOD のレベルの下限」で、**それより弱い MOD は付かない**。高貴・王者・カオス: 上級 35 / 完全 50。変成・増強: 上級 55 / 完全 70 | ゲームの説明文 (効果) + PoE2 Wiki (Minimum Modifier Level) + ExileDesk の計算機 (CURRENCY_FLOOR) |
| 下限は「MOD のレベル」(MOD に必要なアイテムレベル)。アイテムレベルが下限より低いと、上位のオーブでも付く MOD が無いことがある → エンドの高いアイテムレベルのベースで使う物 | ExileDesk の計算機 (pool の floor) |
| **エッセンス (レッサー / 名前に何も付かない物 / グレーター)** (名前は「肉体のレッサーエッセンス」「肉体のエッセンス」「肉体のグレーターエッセンス」「肉体のパーフェクトエッセンス」。**「普通のエッセンス」とは言わない**、kyohei 2026-10-02): マジックをレアにして、エッセンスごとに決まった MOD を 1 個付ける。強さの順に付く MOD の数値が上がる。付く MOD は部位で変わる (例: 肉体 = 最大ライフ、宝飾品と防具で数値が違う) | ゲームの説明文 (「保証されたモッドを 1 個含むレアアイテムにアップグレード」) |
| **パーフェクトエッセンス (と、ヒステリー・アビスなどの特殊なエッセンス)**: **レア**に使う。ランダムな MOD を 1 個取り除き、決まった MOD を 1 個足す。**消える MOD は選べない** | ゲームの説明文 |
| **フラクチャーオーブ**: **MOD が 4 個以上のレア**に使う。ランダムな MOD を 1 個フラクチャー (固定) する。固定された MOD は、その後のクラフトで変わらない・消えない。**固定する MOD は選べない**。もうフラクチャーがあるアイテムには使えない | ゲームの説明文 + poe2db |
| **カタリスト**: **指輪・アミュレット**に品質を足す。品質は種類 (ライフ・マナ・防御・物理・火・冷気・雷・混沌・アタック・キャスター・スピード・能力値・ミニオン) に合う MOD だけを強くする。**別の種類のカタリストを使うと、品質はその種類に置き換わる**。「精製された」カタリストはジュエル用 | ゲームの説明文 + poe2db (ブリーチ限定のドロップ) |
| カタリストの品質の上限は 20% (ブリーチリングは上限が高い)。品質 20% で合う MOD の数値が 1.2 倍 (例: ライフ +60 → +72) | コミュニティ + ExileDesk (maxQualityForBase)。**1 個で何 % 上がるかは言わない** (出典が 1〜2% と食い違い、アイテムレベルで変わるとの話もある。ExileDesk は仮に 1.5%) |
| **クラフト MOD は 1 アイテムに 1 つまで** (0.5.0 から)。クラフト MOD = **エッセンス**と**合金**で付く MOD (kyohei 2026-10-02「エッセンスと合金」) → エッセンスか合金を使ったアイテムに、もう 1 つは使えない | Mobalytics (0.5 の変更) + ExileDesk のクラフトステージ (「エッセンスの MOD はアイテムに 1 つまで」で打てない) + kyohei |
| **ブリーチのエッセンス**: レアに使う。ランダムな MOD を 1 個取り除き、宝飾品に「品質の最大値 +20%」を付ける (→ カタリストで品質をふつうより高くできる) | ゲームの説明文 |
| **合金** (ルーンの合金・王権の合金・迅速の合金 など): レアに使う。ランダムな MOD を 1 個取り除き、合金ごとに決まった MOD を足す (パーフェクトエッセンスと同じ動き)。付く MOD は部位で変わる | ゲームの説明文 |
