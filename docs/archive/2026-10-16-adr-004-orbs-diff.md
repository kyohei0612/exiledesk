# ADR-004 の 3・4 段目: オーブ類・エッセンス・品質・触媒・ルーンの打ち比べ (2026-10-16)

[ADR-004](../decisions/004-currency-as-description.md) の 3・4 段目。残りのカレンシーを説明文の分解 (`src/services/craft-stage/spec/`) で書き直し、
今の `applyCurrency` と同じ種で打ち比べた。

**2026-10-16 (夜) に切り替えた**: `applyCurrency` は移し終えた手を `applyBySpec` で打つ。今の関数で打つのは、指名 (pick / remove)・結果の指定・まだ移していない手 (ヴァール・聖別・可能性など)。打ち比べのテストは `{ legacy: true }` で今の関数を呼ぶ。
切り替えで動きが変わった物: アーティフィサーはセプターに使えない (説明文「Martial Weapon, wand, staff or Armour」)・ルーンをはめると予見が消える (「アイテムを変えると消える」)・古代の骨 + 腐食はアイテムレベル 40 未満に使えない・手順 JSON の棚に無い骨 (ジュエルに古代の頭蓋骨) は打てない。触媒の対象にグラスピングメイル (暗黙でカタリストを許すベース) を足した。
冒涜まわり (1・2 段目) は [冒涜まわりの決まりの確認](2026-10-16-adr-004-desecrate-rules.md)。

比べた物: 打てたか・当たり所か・アイテム全部・足し引きした MOD・食ったお告げ・付いた確率・一言 (note)・使った数 (count)・ルーンのはめ方・弾いた一言。

### 新しい作りでの書き方 (例外の if が無くなった所)

- 変成 = レアリティをマジックに + 付ける 1 (空きが無ければ付けずに通す)。王者 = レアに + 付ける 1。錬金 = 全部消す + レアに + 付ける 4。
- 高貴 = 付ける 1 + 「空きがある」制約。大いなる高貴 = 付ける数を 2 に、左右 = 付ける側、触媒 = 重く引いて品質を使い切る (前提「品質がある」)。
- カオス = 消す 1 (上限超えは不成立) + 付ける 1 (付かなくても通す)。削り = 消す物を一番低い MOD レベルに、抹消 = 消す側だけ (付ける側は絞らない)。
- 段の下限は強さごとに 1 つの値 (エンジンの CURRENCY_FLOOR・カオスは 35 / 50) で、用語集 BetterCurrencyMinimumLevel の制約も同じ値から。

## エッセンス (`spec/essence-specs.ts`、`tests/currency-spec-essence.test.ts`)

クライアントの説明文は 2 つだけ: レッサー / 普通 / グレーター = 「マジック → レアにして保証の MOD」、
パーフェクト・ブリーチ・深淵・ヒステリーなど = 「1 つ消して保証の MOD」。エッセンスの鍵 1,500 ほど全部で、段から選んだ説明文がそのエッセンスの説明文と同じかを確かめた。
付く MOD はエンジンのエッセンスの置き場 (クライアントの EssenceMods) から。深淵だけ付くのが「深淵の王の印」(説明文は同じ)。
**合金 (Adaptive Alloy など 13 種) もエッセンスの鍵の表に入っている**: 英語の説明文はパーフェクトと同じ、日本語は別の文なので別の CurrencySpec (ALLOY_SPEC) にした。

|---|---|---|
| 普通 (レッサー / 普通 / グレーター) × ベースの棚 + 別の部位の物 | 59,920 (4,200) | 一言だけ違う物 (下の 3) 以外は全部一致 |
| パーフェクト・ブリーチ・深淵・合金 × 結晶化のお告げ | 58,912 (22,410) | 一言だけ違う物 (下の 2) と、合金 + 結晶化 (下の「結果が違う物」A) 以外は全部一致 |
| 手順の再生 (槍のエッセンスの見本の手順 JSON を含む) | 移した手 2,244 手 | 毎手一致 |

## 品質・触媒・アーティフィサー・ルーン (`spec/other-specs.ts`、`tests/currency-spec-other.test.ts`)

2026-10-16 (2 回目) に確かめた: 説明文の写し (currency-hover-en/ja) と、新旧の打ち比べ (品質 5 種・触媒 13 種 × 手で打つ / 手順の再生の 1 個ずつ・精製された触媒・アーティフィサー・ルーン) は**全部一致** (10 件のテストが通る)。結果が違う物・一言だけ違う物は無し。

| 気をつける事 | 中身 | オーナー確認 |
|---|---|---|
| 触媒の部位 | 新しい作りの対象は説明文どおり「ring or amulet」。main は v0.1.516 でグラスピングメイル (暗黙「Catalysts can be applied to this item」) にも触媒を使えるようにした (ベースの品質とは別の欄)。このブランチを main に合わせる時に、対象に「暗黙でカタリストを許すベース」を足す | 要らない (クライアントの暗黙が根拠) |
| 合金 + 結晶化のお告げ | 上の「結果が違う物」A と同じ。main のクイズの手袋 (適応の合金 + 右側の結晶化) もこの決まりに乗っている | **要る** (A の確認で決まる) |
