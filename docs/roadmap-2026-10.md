## 残っているタスク (2026-10-17 整理)

wiki・攻略サイトへの掲載、配信者、英語圏の宣伝、1.0 の時の動きはオーナーが考えて指示する (タスクにしない)。ユニーク周りは実装しない。

**一緒に作る (これだけ)**
- シミュレーター: 開発版で触ってもらい、使いにくい所・こうしたいを聞いて作る。両側の「どれか」は側ごとに別のシミュレーション (決定済み)。
  - 要望 91ccb2d0 (2026-10-17):「付けた MOD や工程をお気に入りに保存したい」はシミュレーターのレシピ保存で入れる (エミュレーターには足さない、オーナー「UI 的に邪魔、どうせ工程すべて出来上がるまで打っていくから」)。返事済み。ヴァール (コラプト) は入れない (予測不能の動きが作れない、メモ no-vaal-chance)

**チュートリアルの続き** (オーナーのチェックが通ったコースから StageCourses.vue の RELEASED に足して出す)
- エッセンス → 初級 (冒涜・お告げ) → 中級 (カタリスト・液化した感情) → 実践。作りは基本のオーブと同じ (毎回の用意・やさしい箇条書き・次へ)

**オーナーの操作・連絡**
- Search Console にサイトマップ (https://exiledesk.com/sitemap.xml、1,581 URL) を出す
- POE2Tube に MOD 一覧の目印の変更 (mod-add-n / f / d / e) を伝える
- 右の列のチャンネルの出し方の決まり (どのチャンネルを・どの順で・いつ出すか) をオーナーが決める → 決まりに沿って作る (選ぶだけの話ではない)

**時期・結果待ち**
- 10-18: 実際の PV (visit・screen の記録) で広告の見込みを計算し直す (Claude)
- AdSense の結果 → 通ったら広告の枠 (ブランチ ad-preview)・セキュリティのヘッダー (CSP)・ジェムコラプトの Web 版を一緒に

**後で**
- レジェックス (ゲーム内の検索欄に貼る正規表現を作る、poe2.re のような物。2026-10-17 オーナー「ずっと使える」)。自由に条件を選んで文字を出し、ゲームでコピペ。使い道: 商人・スタッシュの装備探し (アクト〜エンド)・ウェイストーン・タブレット・遺物など。文字は日本語のクライアント向け、MOD の文は poe2db に合わせる
