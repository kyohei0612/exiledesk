### オーナーに決めてほしいこと

(各タスクが済んだら足す)

- クイズの手袋: コルの狩りは「外せない・置き換えられない」(クライアントの説明文) ので「途中でアストリッドに交換」はできない。今は 2 ソケット (規格外) にコルの狩り + アストリッド。SaVeQ の動画 (T7R90v2JvFI、字幕で確認) はコルの狩りを使わず、アストリッドを途中で差して最後に別のルーンに替える。どちらの形にするか
- [済] ADR-004 / クイズの手袋: 合金 (適応の合金など) に左右の結晶化のお告げが効くか → オーナーがゲームで確認済み「減る」(効く)
- クイズの指輪: 2 つ目の耐性を冒涜の 2 種耐性で取る形で良いか。アミュレット: 固定 = スピリット・冒涜 = 全てのスキルのレベル・エッセンス = 受けたダメージのライフ回収 で良いか

- ジェムコラプト Web: ①原石から作れないジェム (カルグール系) は 4 つ目の「元のジェム」の値段の欄を出している、3 つだけにするか ②英語の画面の取引所の検索は jp のままか www か ③「やった場合」(回数・予算ごとの赤字の確率) は出していない、要るか

- **段階で増やす** (オーナー「色々結びつけたいけど、最初は書き込みだけで徐々に」):
  1. 最初: ニックネーム + 文字の書き込み + **タグ** (荒らし対策・消す窓口は最初から)
  2. 次: 返信・いいね
  3. その後: エミュレーターの手順 (再生のリンク)・アイテムのカード・画像・チャレンジの結果を貼る
- **タグ** (オーナー「どんな人たちに返信して欲しいか」): 書く時に 1 つ選ぶ。案: 相談 / 自慢 / 初心者に優しく / 上級者に聞きたい。一覧はタグで絞れる
  - 「開発者へ」(Discord に通知・開発者の印) は必要になったら足す (オーナー「掲示板は自分も結構見るし」)。要望・バグの窓は今のまま
- **名前は匿名が基本** (2026-10-14 オーナー「名前とか匿名でいい、連投しても別の人が投稿してる感じ」): 名前を空けたら「名無しのエグザイル」、ニックネームは入れたい人だけ。画面に人ごとの ID は出さない (同じ人の連投が目立たない)。中では端末の番号を持つので、通報・消す・書けなくするはできる
- **自動の札 (当たりの速報)** (2026-10-14 オーナー「カオススパムで特定の MOD 0.1% 以下とか当たったら掲示板に流れるの」): エミュレーターで付いた瞬間の確率が 0.1% 以下の MOD を引いたら、名前を出さずにタイムラインへ「誰かが ◯◯ (ベース) にカオス ◯ 回目で △△ (T1、0.08%) を引きました」。最初の段から入れる (書き込みが少なくても毎日動く)
  - **ベースごとに「クソレア」の線を決める** (2026-10-14 オーナー): 0.1% の一律だと指輪・防具・宝飾品は一生流れない (指輪の一番低い段でも 0.124%、靴・ベルトは 0.2% 前後。両手武器の物理 % の T1 は 0.022%)。
    ベースごとに一番珍しい段の確率から線を引き (データから自動で出して一覧をオーナーが確認)、その線より下の MOD が付いたら流す。目安はどのベースも数千回に 1 回、全体で 1 日 2〜3 件
  - 送るのは端末から (乱数は端末) なので、サーバーで 1 人 1 時間に数件まで・同じ物は重ねない。札は書き込みとは別の見た目にする。流したくない人は設定で止められる

## 支援のサブスク (2026-10-14 オーナー「広告消しが基本、あとは応援代がメイン」)

- 中身: **Web の広告を消す** + 応援 (掲示板に支援者の印・クレジットに名前)。機能を有料で分けることはしない
- 段 (2026-10-14 オーナー OK、Maxroll の B / A / S = 2 / 3 / 5 ドルを参考):

  | 段 | 日本 (Stripe) | 海外 (Patreon) | 中身 |
  |---|---|---|---|
  | 広告なし | 月 300 円 | 2 ドル | 広告を消す |
  | 支援者 | 月 500 円 | 3 ドル | + 掲示板の支援者の印・クレジットに名前 |
  | 応援 | 月 1,000 円 | 5 ドル | 支援者と同じ (応援の気持ち) |

  年払いは 2 か月分お得 (300 円の段なら年 3,000 円)
- 日本の人: 自前の画面 + **Stripe** (決済の画面は Stripe、カードの番号はこちらに来ない。日本のカードで 3.6% くらい)
- 海外の人: 最初は **Patreon** にリンクするだけ。増えたら税金ごと任せられる Paddle などへ
- 要る物: ログイン (**Discord でログイン** が PoE2 の人になじむ。掲示板のニックネーム・支援者の印とつなぐ)、特定商取引法の表記のページ、解約の画面 (Stripe の物に飛ばす)
- 広告を消す特典は AdSense が出てから意味がある → 広告を入れた後に始める

## セキュリティのタスク (2026-10-14 ざっと点検、オーナー「タスクで」)

封印が解けたら先に:
1. [済 2026-10-16、server/live を出した] 管理用の合言葉を URL (`?key=`) からヘッダー `x-exiledesk-key` へ (Cloudflare のログに URL ごと残るおそれ)
2. `pnpm audit` と `cargo audit` で使っている部品の古い穴を確かめる
   - [済 2026-10-16 pnpm] `pnpm audit --prod` はルート・server/live・server/web とも 0 件。開発用の部品 (vitest・vite・vue-tsc・wrangler の下) には高・重大があり、vitest の tinypool (重大) は vitest 4 へのメジャー更新が要る。cargo audit はアプリを当分無視するので後回し
3. [済 2026-10-16] 要望に IP を 90 日残していることがプライバシーポリシーに書いてあるか確かめる → 書いてある (public/privacy.html「要望・バグ…」の節と英語の要約)。
   ただし要望の JSON (IP・ブラウザの種類込み) は Discord にも添付で送っていて、Discord は 90 日で消えない・外部のサービスの一覧に Discord が無い。掲示板の節も削除後のまま残っている (直すかはオーナー)

広告を入れる時に:
4. Web にセキュリティのヘッダー (埋め込みを止める物・CSP。AdSense の読み込み先を許す形で)

その時に:
- 掲示板: 荒らし・違法・個人情報の書き込みへの対応 (通報・消す窓口) は設計どおり最初から
- 支援のサブスク: Discord のログインのセッションをきちんと作る (カードは Stripe 側)
- 画像を後から足す時の本人確認は端末の番号だけ (今は十分、足せるのは画像だけ)
