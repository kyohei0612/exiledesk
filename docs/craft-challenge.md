# クラフトチャレンジ (仮) — 仕様の整理

2026-10-13 から。**金曜までコードは封印**、今週はこの md で決める。書きかけのコードはブランチ `wip/craft-challenge` (main には入れていない)。

## 目的

クラフトは思い立った時に使う物なので、「また来て色々やりたい」と思う理由を作る。
毎日のお題を、ニックネームで競う。クラフトステージとは別のページ (`/challenge`、広告の枠を置ける)。

## 2 つのコース (2026-10-13)

| | 初級者コース | クラフトマスター (上級) |
|---|---|---|
| 打ち方 | エミュレーターで手で 1 回打つ | シミュレーターでレシピ (当たり方ごとの分かれ道) を書く |
| 運 | 残す (乱数はその日全員同じ) | 消す (100 回以上回した平均) |
| お題 | プレ 1・サフィ 1・クラフト MOD 1 (エッセンス・冒涜などのランダムな特別な MOD)・もう 1 つ (プレかサフィのどちらか) | poe.ninja の上位プレイヤーの MOD 群 (最終的な装備を参考に「これを作れ」) |
| 競う物 | 最安 → 最善手 (手数) → 時間 | 平均の費用 (最安) |
| 見せる物 | 上位のダイジェスト再生 (録画モード)、沼カウンター | 上位のレシピ (そのまま教科書になる) |
| 時期 | 先に作る | シミュレーター (クイズのレシピ) を出す時 |

- 初級者は「カオスで何か付いた → それに合わせて次」をその場で判断する。運込みで気軽に遊べる入口。
- 上級は「この当たり方をしたらこのルート」を全部先に書く。オーナー「シミュレーターで作ったら 100 回回せて平均額も出る」。
- 上級のお題の取り方は工夫が要る: Web 版は poe.ninja を直接取らない (サーバーか、置いておく集計の写しから)。アプリの「上位 MOD 一覧」の集計を使えるか。

以下の「決まったこと」〜「画面の流れ」は、特に書いていなければ初級者コースの話。

## 決まったこと

| 項目 | 決めたこと |
|---|---|
| お題 | 毎日 0 時 (JST) に自動で変わる。よく作られるベース 1 つと、狙う MOD 2〜3 個 (段の下限つき)。全員同じ |
| お題を見せる時 | 「挑戦する」を押すまで伏せる。押した瞬間に出て、時間が始まる (下調べ不可、ライブ感) |
| 乱数 | その日は全員同じ。同じ状態で n 手目に同じ手を打てば、誰でも同じ結果 (「カオスで沼るかが人によって違うのは不公平」) |
| 初手 | 狙いの MOD から 1 つ選び、フラクチャー済みのレアで始める (0 手目、数えない) |
| 戻す | 「1 手戻す」は無し。0 手目へのリセットは 3 回まで (フラクチャーも選び直せる、乱数の順番は同じ) |
| 使えない物 | MOD を指名して付ける / 外す、暗黙の数値を手で決める |
| ニックネーム | ログイン無し。このブラウザに覚える。12 字まで、URL は不可 |
| 置き場 | サーバーの D1 (KV は使わない)。負荷は 1 回の挑戦で 3〜4 行書くだけ |
| 時間 | サーバーが始めた時刻を覚えて測る (手元の時計では縮められない) |
| 上位の手順 | 録画モード (16:9) で見せる。今日の分は自分が 1 回達成してから、昨日の分は誰でも |
| 平準化 | しない (運は残す)。「沼ったからやり直す」にならないように |
| スパムの見せ方 | パッと結果と費用を出すのではなく、連打と同じ動き。MOD がルーレットのように高速で切り替わる |
| レシピ部門 (100 回回した平均) | 後で。シミュレーターを出す時に別の部門として |

## 運の扱い (考え方)

運が絡むゲームの日替わりの勝負は、だいたい「**全員同じ種・同じ条件で比べる**」で収めている (日替わりのダンジョン・同じ問題を全員が解くパズルなど)。運そのものは消さず、**全員が同じ運を引く**ので、差が出るのは判断だけ。

このお題も同じ考え方にする。

- n 手目の乱数が決まっているので、沼るかどうかは「どの状態で何を打ったか」で決まる。運ではなく道の選び方。
- 沼った人も、0 手目に戻って別の道を探せる (3 回まで)。
- **最善手を一番早く見つけた人が上手いクラフター**。

## 順位 (案)

オーナー案: **費用 → 最善手 (手数) → 時間** の順で比べる。

- 費用 = 実際に払った合計 (外れた手の分も入る)。安いほど上。
- 費用が同じなら手数が少ない方、それも同じなら速い方。
- 「完全な高貴を 6 回」は手数は少ないが高い。費用が先なので、高いカレンシーで押し切るだけでは勝てない。

## 自動スパム (案)

「当たるまで打つ」のボタン。狙いの MOD が付くか、決めた回数・予算で止まるまで、同じ手を自動で打ち続ける。

- 見た目はルーレット (上の「スパムの見せ方」)。打った回数は工程と沼カウンターに残る。
- 乱数は手ごとに決まっているので、自動でも手で連打しても同じ結果。

## 沼カウンター (案)

1 回の挑戦ごとに数える。自分の分も上位の人の分も見られる。順位の行の横に小さく出し、押すと内訳。

- カオス沼: 進まなかったカオス
- 削減沼: 削減のお告げ付きで外した
- 消去沼: 消去で外したけど進まなかった
- 振り出し: 0 手目へのリセット (手順に残らないので、達成した時に一緒に送る)

## ダイジェスト再生 (案)

手順を全部打ち直したうえで、見せるのは「進んだ手」(狙いが付いた・段が上がった) だけ。

- 外れた手は飛ばして、間に「カオス ×12」のように回数だけ挟む。
- 消去で外して付け直した時は、外した手は見せる。付け直すまでの外れは飛ばして「次で付いた」ように続ける。
- 録画モードの画面で自動で流れる。Web 版でもこの再生だけは開けるようにする (今の録画モードはアプリだけ)。

## 画面の流れ

1. **開く**: 今日のお題は伏せてある。ニックネームと「挑戦する」、挑戦した人数、昨日の上位のダイジェストと沼カウンター、広告の枠。
2. **挑戦する**: お題 (ベース・狙い) が出て時間が始まる。初手のフラクチャーを選ぶ。
3. **打つ**: 上の帯に時間・手数・費用・リセットの残り・狙いのチェック、下はいつものエミュレーター。
4. **0 手目へ**: 確かめの窓。時間は止まらない。
5. **達成**: すぐ記録を送り、順位を出す。今日の上位のダイジェストが見られるようになる。「もう一度」もできる。
6. **やめる**: 記録無し。次は 2 回目扱い。

## まだ決めていないこと (論点)

0. **初級者のお題の細かい所**: 「クラフト MOD」はどれを指すか (エッセンス・冒涜・異界・デリリウムの感情など)。段の下限を付けるか、付けばよいか。
0. **上級のお題の取り方**: poe.ninja の上位の装備から、どの部位・何 MOD を選ぶか。毎日変えるか、週替わりにするか (レシピを書くのに時間がかかる)。

1. **順位は 1 本か 2 本か** (初級者): 「費用 → 手数 → 時間」の 1 本にするか、それとは別に「最速タイム」の順位も残すか (前は 2 本で決めていた)。
2. **何回でも挑戦できるか**: 同じ乱数なので、1 回達成すると答え (上位の手順) を見てまねできる。
   - a. 順位に入るのはその日の最初の挑戦だけ (日替わりのゲームでよくある形)
   - b. 何回でもよい。同じ記録なら先に出した方が上
   - c. 費用・手数は何回でも、タイムだけ最初の挑戦
3. **途中でやめた挑戦**: 2 回目扱いにするか (始め直しでやり直す抜け道を塞ぐ)。
4. **自動スパムの止め方**: 回数・予算・「狙いが 1 つ付いたら」のどれで止めるか、全部選べるか。
5. **ルーレットの速さ**: 1 回あたり何秒か、飛ばせるか (自動スパムで 100 回回る時)。
6. **お題の難しさ**: 狙いの数 (2〜3)・段の下限 (上から 2〜3 番目) で良いか。曜日で難しさを変えるか。
7. **達成できなかった日**: 0 時で切れて記録無しで良いか。
8. **名前**: クラフトチャレンジ (仮)。
9. **X への貼り付け**: 結果の札を最初の版から入れるか。
