# クラフトチャレンジ (仮) — 仕様の整理

2026-10-13 から。書きかけのコードはブランチ `wip/craft-challenge` (main には入れていない)。
時期: **シミュレーターの合格の後に始める** (オーナー 10-19、10-22 に再確認「シミュの後でいい、md だけ整理」)。それまではこの md だけ直す。
(10-13〜16 の「金曜までコードは封印、md で決める」は済み。)

## 目的

クラフトは思い立った時に使う物なので、「また来て色々やりたい」と思う理由を作る。
毎日のお題を、ニックネームで競う。クラフトステージとは別のページ (`/challenge`、広告の枠を置ける)。

- 理由 (オーナー 10-22): 今はコンテンツが少なく、カオスを打って即帰る人が多い (リピート = 2 日以上来た人は 2〜6%)。
- リピート率を上げる本命 (オーナー 10-19「シェアもできるし」)。

## 2 つのコース (2026-10-13、10-22 に直した)

| | 初級者コース (デイリークラフトチャレンジ) | クラフトマスター (上級) |
|---|---|---|
| 打ち方 | エミュレーターで手で 1 回打つ | シミュレーターでレシピ (当たり方ごとの分かれ道) を書く |
| 運 | 残す (乱数はその日全員同じ) | 消す (100 回以上回した平均) |
| お題 | クラフトボックスに入れた完成品 (エミュレーターで作った物) を日替わりで (10-22、下の節) | poe.ninja の上位プレイヤーの MOD 群 (最終的な装備を参考に「これを作れ」) |
| 競う物 | 費用 → 最善手 (手数) → 時間 | 平均の費用 (最安) |
| 見せる物 | 上位のダイジェスト再生 (録画モード)、沼カウンター | 上位のレシピ (そのまま教科書になる) |
| 作るのに要る物 | **シミュレーター無しで作れる** (エミュレーター・乱数・サーバーだけ) | **シミュレーターが要る** |
| 目安の費用 (パー) | 解析君の台本で出せる (お題ごとに最善手の期待値) | 同じ |
| 時期 | 先に作る (シミュレーターの合格の後) | シミュレーターを出した後 |

- 初級者は「カオスで何か付いた → それに合わせて次」をその場で判断する。運込みで気軽に遊べる入口。
- 上級は「この当たり方をしたらこのルート」を全部先に書く。オーナー「シミュレーターで作ったら 100 回回せて平均額も出る」。
- 上級のお題の取り方は工夫が要る: Web 版は poe.ninja を直接取らない (サーバーか、置いておく集計の写しから)。アプリの「上位 MOD 一覧」の集計を使えるか。

以下の「決まったこと」〜「画面の流れ」は、特に書いていなければ初級者コースの話。

## デイリークラフトチャレンジ (オーナー 10-22 の新しい形)

- **お題 = エミュレーターで作った完成品**。「これを作りたい、作れる人募集」の 1 個をクラフトボックス (お題を入れる箱) に入れ、日替わりで 1 つ出して挑戦者に作ってもらう。
- 前の形 (10-13) との違い: 前は「よく作られるベース 1 つ + 狙う MOD 2〜3 個 (段の下限つき)」を**ランダムに組んでいた**。新しい形は**人が作った完成品が元**なので、作れることが分かっていて、狙いに意味がある (実際に欲しい装備)。
- その日の乱数は全員同じ (下の「乱数」「運の扱い」のまま)。
- 順位は費用 → 手数 → 時間 (下の「順位」のまま)。
- シェアはネタバレしない形 (Wordle のように手数・費用・沼だけを見せ、手順は見せない)。10-19 のおすすめで、細かい所は未決。

## 決まったこと

| 項目 | 決めたこと |
|---|---|
| お題 | 毎日 0 時 (JST) に自動で変わる。全員同じ。中身はクラフトボックスの完成品 (10-22。10-13 はベース 1 つ + 狙う MOD 2〜3 個をランダムに組む形だった) |
| お題を見せる時 | 「挑戦する」を押すまで伏せる。押した瞬間に出て、時間が始まる (下調べ不可、ライブ感) |
| 乱数 | その日は全員同じ。同じ状態で n 手目に同じ手を打てば、誰でも同じ結果 (「カオスで沼るかが人によって違うのは不公平」) |
| 初手 | 狙いの MOD から 1 つ選び、フラクチャー済みのレアで始める (0 手目、数えない) |
| 戻す | 「1 手戻す」は無し。0 手目へのリセットは 3 回まで (フラクチャーも選び直せる、乱数の順番は同じ) |
| 使えない物 | MOD を指名して付ける / 外す、暗黙の数値を手で決める |
| ニックネーム | ログイン無し。このブラウザに覚える。12 字まで、URL は不可 |
| 置き場 | サーバーの D1 (KV は使わない)。負荷は 1 回の挑戦で 3〜4 行書くだけ |
| 時間 | サーバーが始めた時刻を覚えて測る (手元の時計では縮められない) |
| 上位の手順 | 録画モード (16:9) で見せる。今日の分は自分が 1 回達成してから、昨日の分は誰でも |
| 平準化 | しない (運は残す)。「沼ったからやり直す」にならないように |
| スパムの見せ方 | パッと結果と費用を出すのではなく、連打と同じ動き。MOD がルーレットのように高速で切り替わる |
| レシピ部門 (100 回回した平均) | 後で。シミュレーターを出す時に別の部門として (= クラフトマスター) |

## 運の扱い (考え方)

運が絡むゲームの日替わりの勝負は、だいたい「**全員同じ種・同じ条件で比べる**」で収めている (日替わりのダンジョン・同じ問題を全員が解くパズルなど)。運そのものは消さず、**全員が同じ運を引く**ので、差が出るのは判断だけ。

このお題も同じ考え方にする。

- n 手目の乱数が決まっているので、沼るかどうかは「どの状態で何を打ったか」で決まる。運ではなく道の選び方。
- 沼った人も、0 手目に戻って別の道を探せる (3 回まで)。
- **最善手を一番早く見つけた人が上手いクラフター**。

## 順位 (案)

オーナー案: **費用 → 最善手 (手数) → 時間** の順で比べる。

- 費用 = 実際に払った合計 (外れた手の分も入る)。安いほど上。
- 費用が同じなら手数が少ない方、それも同じなら速い方。
- 「完全な高貴を 6 回」は手数は少ないが高い。費用が先なので、高いカレンシーで押し切るだけでは勝てない。

## 自動スパム (案)

「当たるまで打つ」のボタン。狙いの MOD が付くか、決めた回数・予算で止まるまで、同じ手を自動で打ち続ける。

- 見た目はルーレット (上の「スパムの見せ方」)。打った回数は工程と沼カウンターに残る。
- 乱数は手ごとに決まっているので、自動でも手で連打しても同じ結果。

## 沼カウンター (必須)

1 回の挑戦ごとに数える。自分の分も上位の人の分も見られる。順位の行の横に小さく出し、押すと内訳。
沼っても最善手の勝負なので失格ではない。その代わり沼は見せて笑いにする (オーナー「沼カウンターは流石にないとダメ」「上位出してあげたら」)。

- **沼ランキング**: その日一番沼った人 (カオス沼・振り出しの回数など) の順位も出す。沼った人が主役になれる枠。

- カオス沼: 進まなかったカオス
- 削減沼: 削減のお告げ付きで外した
- 消去沼: 消去で外したけど進まなかった
- 振り出し: 0 手目へのリセット (手順に残らないので、達成した時に一緒に送る)

## ダイジェスト再生 (案)

手順を全部打ち直したうえで、見せるのは「進んだ手」(狙いが付いた・段が上がった) だけ。

- 外れた手は飛ばして、間に「カオス ×12」のように回数だけ挟む。
- 消去で外して付け直した時は、外した手は見せる。付け直すまでの外れは飛ばして「次で付いた」ように続ける。
- 録画モードの画面で自動で流れる。Web 版でもこの再生だけは開けるようにする (今の録画モードはアプリだけ)。

## 画面の流れ

1. **開く**: 今日のお題は伏せてある。ニックネームと「挑戦する」、挑戦した人数、昨日の上位のダイジェストと沼カウンター、広告の枠。
2. **挑戦する**: お題 (ベース・狙い) が出て時間が始まる。初手のフラクチャーを選ぶ。
3. **打つ**: 上の帯に時間・手数・費用・リセットの残り・狙いのチェック、下はいつものエミュレーター。
4. **0 手目へ**: 確かめの窓。時間は止まらない。
5. **達成**: すぐ記録を送り、順位を出す。今日の上位のダイジェストが見られるようになる。「もう一度」もできる。
6. **やめる**: 記録無し。次は 2 回目扱い。

## 未決 (論点)

10-19 にジン部長が出したおすすめ (オーナーはまだ決めていない。始める時に表で聞き直す) を各行の「おすすめ」に書いた。

- **クラフトボックス (10-22)**: 誰が入れるか (オーナーだけ / 誰でも「作れる人募集」で出せる)、どこから入れるか (エミュレーターの完成品から 1 押し、など)、何個たまったら回すか、同じお題が戻ってくるか。完成品のどの MOD を「狙い」にするか (全部 / 選んだ物だけ、段の下限)。
- **初手のフラクチャー**: 完成品がお題になっても今の「狙いから 1 つ選んでフラクチャー」のままで良いか。
- **ネタバレしないシェア**: 札に出す物 (手数・費用・沼・連続日数)。X のカードはスパムシミュレーターの物を使い回す (おすすめ)。連続日数も足す (おすすめ)。
- **ジュエル**: 初級者のお題から外す案 (重みが平たく候補が多いので狙いが本当に付かない、ガチ運ゲー)。上級か、たまの「沼の日」の特別なお題に回す (おすすめは外す)。
- **初級者のお題の細かい所**: 「クラフト MOD」はどれを指すか (エッセンス・冒涜・異界・デリリウムの感情など。おすすめはエッセンスと冒涜)。段の下限を付けるか、付けばよいか。
- **上級のお題の取り方**: poe.ninja の上位の装備から、どの部位・何 MOD を選ぶか。毎日変えるか、週替わりにするか (レシピを書くのに時間がかかる)。
- **順位は 1 本か 2 本か** (初級者): 「費用 → 手数 → 時間」の 1 本にするか、それとは別に「最速タイム」の順位も残すか (前は 2 本で決めていた)。
- **何回でも挑戦できるか**: 同じ乱数なので、1 回達成すると答え (上位の手順) を見てまねできる。
  - a. 順位に入るのはその日の最初の挑戦だけ (日替わりのゲームでよくある形。おすすめ、2 回目から練習)
  - b. 何回でもよい。同じ記録なら先に出した方が上
  - c. 費用・手数は何回でも、タイムだけ最初の挑戦
- **途中でやめた挑戦**: 2 回目扱いにするか (始め直しでやり直す抜け道を塞ぐ。おすすめは 2 回目扱い)。
- **自動スパムの止め方**: 回数・予算・「狙いが 1 つ付いたら」のどれで止めるか、全部選べるか (おすすめは「1 つ付いたら / 回数」)。
- **ルーレットの速さ**: 1 回あたり何秒か、飛ばせるか (自動スパムで 100 回回る時。おすすめはスパムシミュレーターと同じ加速)。
- **お題の難しさ**: 狙いの数・段の下限で良いか。曜日で難しさを変えるか。パーを出して難しさの目安にするか。
- **達成できなかった日**: 0 時で切れて記録無しで良いか (おすすめは 0 時で切れる)。
- **名前**: クラフトチャレンジ (仮) / デイリークラフトチャレンジ。
