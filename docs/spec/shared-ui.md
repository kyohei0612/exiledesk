## ① この紙の範囲

- **部品**: `src/components/for-share/` (アイテムのカード・MOD 表の土台・棚・上の切り替えタブ・ベース選びの帯) と、Web で使うほかの共通の部品 (`src/components/ui/`・`decor/`・`items/BaseCatalog` など)。
- **決まった挙動**: 枠の外・Esc で取り消す、窓、確かめの 2 回押し、連打の守り、閉じたら前の位置、1 つ戻す、ページの移り方と離れる時の確かめ、説明のカードの出し方 (`src/utils/`・`src/web/`・`src/composables/`)。
- **見た目**: 1 つの枠、ゲームの絵、色、線、字の縮め方・折り方、崩れない作り (`src/style.css`・`src/styles/`)。
- **スマホの並び**、**英語の画面** (`src/i18n/lang.ts`・GLOSSARY)、**スイッチ** (`src/web/release-flags.ts`) の使い方。
- 範囲の外: 結果が変わる物 (付き方・確率・打てるか・名前のデータ) = engine.md、各画面だけの流れ = emu.md・sim-tree.md、出し方・見張りの回し方 = release.md。

## ③ 決まり

### A. 線引き (何を共有にするか)

- **U-01 共有の線**: 共有にするのは、ユーザーがどの画面でも同じと感じる物 (ページの枠 = ヘッダー・上の切り替えタブ・戻る・フッター・広告の枠 / 決まった挙動 / 同じゲームの物を出す部品 = アイテムのカード・MOD 表の土台・棚・ベース選び) だけ。迷えば画面で作り、2 つ目の画面で要った時に共有へ上げる。
  - 有効。出どころ: オーナー 10-23 (メモ org-roles-2026-10-23)。確かめ: 画面 (使う画面の表 docs/org/design/notes/2026-10-23-components-map.md)。
- **U-02 中身はエンジンを呼ぶ**: 共有の部品が見せる中身 (MOD の文・値・段・名前・打てるか) はエンジンの関数を直に呼んで取り、部品の中で作らない (G-06)。
  - 有効。出どころ: オーナー 10-23・10-25 夜 (docs/org/emulator/README.md)。確かめ: 見張り `scripts/check-engine-entry.mjs` (エミュ ⇄ シミュの直の import)、コードを読む。
- **U-03 違いは包む・slot で**: 画面ごとの違い (エミュの持った時の %・次の手で狙う、シミュの狙いにする) は特化部品が props・slot で足し、共有の核に入れない。
  - 有効。出どころ: オーナー 10-23 (「シミュ = % 無し」は % の列でなく「次の手で狙う」ボタンが要らない事、ブラック 8 代目 10-23)。確かめ: 画面 (エミュ・シミュ両方)。
- **U-04 共有を直すのはデザインだけ**: for-share・決まった挙動・見た目の決まりはデザイン部長だけが直す。直す時は両方の画面が落ちない・崩れないことを並べて見る。
  - 有効。出どころ: オーナー 10-23、docs/org/owners.txt。確かめ: 画面 (PC 1660×860・スマホ 375、エミュとシミュで同じ操作)。
- **U-05 要望は全部に効かせる**: 1 つの画面で出た共通の振る舞いの要望は、共通の部品に入れて全部の画面に効かせる。スマホで出た細かい配慮も PC に入れる (スマホだけは固定の帯・縦積みなど使い勝手の分だけ)。
  - 有効。出どころ: オーナー 10-04・10-10 (メモ feedback-global-requests)。確かめ: 画面。

### C. 決まった挙動

- **U-20 枠の外・Esc で選ぶ前に戻す**: 枠の中で選びかけ・持ちかけ・開きかけた物は、枠の外を押すか Esc でクリック前に戻す。確定はボタンを押した時だけ。外を押して閉じた時、その押下は下の物に届けない。例外: エミュの棚の持ち (持った物を離し、押した物にも届ける = 1 回で持ち替え。emu.md M-12)。
  - 有効 (スイッチ dismiss、本番入り)。出どころ: オーナー 10-22 (メモ feedback-click-outside-cancel)、10-19 (swallow-click)。仕組み `utils/use-dismiss.ts`・`utils/swallow-click.ts`。確かめ: 画面 (本物のマウスの台本に「枠の外で元に戻る」)。
- **U-21 Esc は一番後に開いた 1 つだけ**: Esc は積みの一番後ろの 1 つだけ閉じる。窓の中で開いている物 (段の表・説明・段の欄) があればそれを先に閉じ、窓はもう 1 回で閉じる。
  - 有効。出どころ: オーナー 10-23「展開した時の動きをエミュとシミュで一緒に」(notes/2026-10-23-expand-collapse.md)。確かめ: 画面。
- **U-22 開く・畳むは両方の画面で同じ**: ベース選びの部位・MOD 表の段・棚の段の欄は、1 回で開く・もう一度で閉じる・別の物を開くと前を閉じる (1 つだけ)・開いた物が見えるまで送る、をエミュとシミュで揃える (表は notes/2026-10-23-expand-collapse.md)。
  - 有効 (dismiss・monkey1023 と一緒に本番)。出どころ: オーナー 10-23・10-25。確かめ: 画面。
- **U-23 確かめの 2 回押し**: 消す・白に戻すなど戻せない操作は 2 回押しで決める (1 回目で赤いボタン g-btn-red と「もう一度押すと…」)。戻すのは全部の画面で同じ: 時間では戻さず、そのボタンの外を押すか Esc (U-20・21)。外の押下は下の物にも届ける (別の 2 回押しのボタンならそのまま 1 回目になる)。共通の `utils/use-armed.ts` が 1 回目に押したボタンを覚えて受け持つので、使う側は書き足さない (押したボタンが分からない時だけ 3 秒で戻す)。
  - 有効 (スイッチ armAll、オーナー OK 済み 10-28 (スナップ ok-snaps/design-*.png)、本番待ち。閉じている間は 3 秒で戻る、シミュの箱の × だけ armKeep で外・Esc)。出どころ: 動きの揃え 7 (10-10、原点はエミュの「白に戻す」)、オーナー 10-28「ここは統一させたいな。案でおｋ」。確かめ: 画面 (共有メモ local_a9a41698…/design10/u7-check.mjs: 4 秒後も赤・外で戻る・Esc で戻る・2 回で白)。
- **U-24 閉じたら前の位置**: 閉じたら閉じる前の状態・位置に戻す。押した時に画面を勝手に送らない (選んで閉じた時だけ選んだ行を残す)。中身が伸び縮みしても押した物は同じ高さに残す (`utils/keep-place.ts` の keepPlace)。送る時はいつも同じ速さで (glideBy)。
  - 有効。出どころ: 10-07 (メモ feedback-basic-flow)、10-10 (keep-place)。確かめ: 画面。
- **U-25 足したら外す・1 つ戻す**: 足す (＋) があれば外す (×) を同じ所に、選んだ物は後から変えられる、直前の操作は 1 つ戻せる。工程は押せばそこから戻れる。鍵は全部の画面で同じ: 1 つ戻す = Ctrl+Z (エミュは R も)、やり直し = Ctrl+Shift+Z・Ctrl+Y (Mac は Cmd)。エミュのやり直しは戻した手をその結果のまま打ち直し (乱数を引き直さない)、戻した後に打つ・変えると消える。
  - 有効 (エミュのやり直しはスイッチ emuRedo、オーナー OK 済み 10-28 (スナップ ok-snaps/design-*.png)、本番待ち)。出どころ: オーナー 10-05 (メモ feedback-proactive-ui)、10-11「Ctrl+Z はデフォルトみたいな存在だから R でいい」(エミュ)、10-28「統一で」。確かめ: 画面 (design10/u7-check.mjs: Ctrl+Shift+Z・Ctrl+Y で打った後と同じ MOD、R で戻る)。
- **U-31 ホットキーはどこかで知れる**: 画面の鍵 (ホットキー) は全部、画面のどこかで知れるようにする (知らない人がいるので)。見せ方は ⑦ の 2 の案からオーナーが決める。
  - 有効 (見せ方は仮)。出どころ: オーナー 10-28「統一でホットキーはすべてどっかに表示させてあげたいねしらないとかあるだろうから」。確かめ: —。
- **U-26 連打・誤押しの守り**: 窓を閉じた直後・ページを替えた直後の押しは捨てる。説明のカードはマウスが実際に動いて乗った時だけ開く (画面が動いて下に来ただけでは開かない、`utils/pointer-moved.ts`)。指の端末 (hover の無い画面) では乗せて出すカードを出さない。
  - 有効 (monkey1023・firstVisit1024、本番入り)。出どころ: モンキー 10-23・10-24。確かめ: 画面 (本物のマウス 6/6、10-24)。
- **U-27 ページの移り方**: 開き直し・ブクマ・打ち直し = そのページの最初、リロード = 同じページの最初、戻る・記事から戻る・版替わりの自動の読み直し = 前の画面 (`web/page-memo.ts` の cameBack・remember)。シミュは戻るでも空から (cede3e93)。戻る (ブラウザの戻る・進む・記事から戻る) は前に見ていた送りの位置 (スクロール) へも戻す。上の切り替えタブ (エミュレーター・シミュレーター・デイリー・コスメ) を押した時は初めて開いたのと同じ = 一番上から・状態も最初から。
  - 有効 (emuFresh は本番入り。送りの位置はスイッチ backPlace、オーナー OK 済み 10-28 (スナップ ok-snaps/design-*.png)、本番待ち: `web/page.ts` が履歴の番号ごとに位置を覚える、タブは `topOfPage` で一番上、タブで来た直後 2 秒はベース選びの一覧へ送らない `utils/tab-arrive.ts`。オーナー 10-28「エミュレーターとか押したらさ、MODにスクロールされるでしょ。…一番上にそのまま案内させておkだよ」、スナップ ok-snaps/design-tabtop.png)。エミュでベースを選んで戻った時も一番上 (選ばずに戻るは前の位置、StageBasePage。オーナー 10-28「ベース選んだらそこは？」、ブラック 15 の案、design-basepick-top.png)。タブで状態も最初からはまだ (エミュのアイテム・シミュの木は各画面の state、エミュ部長・シミュ部長に頼む)。出どころ: オーナー 10-25 (notes/2026-10-26-design7-handover.md)、10-28「戻るボタンだからね上のエミュとかのタブ押したらリセットだけど初めて訪問しましたみたいなくくりにしたい」。確かめ: 画面 (共有メモ design6-fresh-pages.md の表、design10/u7-check.mjs: エミュ 300 → 使い方 → 戻る 300・進む 173・タブ 0)。
- **U-28 離れる時の確かめ**: 保存していない作りかけ (シミュのツリー) から外へ移る前に聞く。保存の手がある時は「保存して進む / 保存せず進む / やめる」、Esc・×・後ろを押すは「やめる」。戻るも元の位置へ戻してから聞く (`web/page.ts` の setLeaveGuard・`web/LeaveConfirm.vue`)。

## ④ 表示の決まり

### D. 見た目

- **U-40 1 つの枠**: 画面の中身は 1 つの `.g-panel` に入れ、切り替えは `.g-tab` (選んでいる物は .on)。枠の中の区切りは `.g-section`、枠の中の物に枠を重ねて描かない。選べるカードは `g-plain rounded-lg border` で選んだ物だけ accent の縁。
  - 有効。出どころ: オーナー 10-10 夜 (メモ ui-one-frame-rule)、`src/styles/game-ui.css`。確かめ: 画面 (1660 幅)。
- **U-41 ゲームの絵で UI**: 枠・題・ボタン・タブ・アイテムの額はゲームの UI の絵 (game-ui.css の部品)。細い金の線・ただの四角で作らない。字は見出し Yuji Syuku・名前 Zen Antique・本文 Zen Kaku Gothic New。冒涜まわりの窓は `.g-abyss`。
  - 有効。出どころ: オーナー 10-09「めっちゃUIいいやん」・10-17 (メモ game-ui-art-direction)。確かめ: オーナーの目。
- **U-42 縮めてから折る**: 狭い所に入らない文は、まず字を縮めて 1 行 (下限 10px)、下限でも入らなければ語の切れ目で 2 行に折る。数と単位の間で割らない (`utils/fit-text.ts` の v-fit-text)。例外: シミュの箱の中 (modsOnly) の MOD の行は縮めずに札を次の行へ折る。
  - 有効。出どころ: オーナー 10-26 夜 (メモ feedback-shrink-then-wrap)。確かめ: 画面。
- **U-43 崩れない作り**: 長い文を抱える flex・grid の子には `min-w-0`。決め打ちの幅はスマホで max-width:100%。枠線のボタンの自動の絵は `max-width:100%; overflow:hidden`、`text-left` のボタン (一覧の行) には付けない。字は … で切らず、入らなければ折る (U-42。縮めたい所は v-fit-text を付ける)。
  - 有効 (… をやめるのはスイッチ noCut、オーナー OK 済み 10-28 (スナップ ok-snaps/design-*.png)、本番待ち。今の画面に … で切れるボタンが無く前後の絵は無し。閉じている間は 1 行で …)。オーナー 10-28「賛成」。出どころ: 10-13「崩れない設計に」(メモ ui-no-break-rules)。確かめ: 見張り `utils/overflow-guard.ts` (U-44)、画面 (375・414 × 日英)。
- **U-44 開発版は赤い枠**: 開発版では画面の横幅からはみ出した物に赤い枠と console.warn を出す (`window.__overflow()` で一覧)。横に送る箱の中と `[data-overflow-ok]` の中は数えない。
