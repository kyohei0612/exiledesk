## ① この紙の範囲

- **部品**: `src/components/for-share/` (アイテムのカード・MOD 表の土台・棚・上の切り替えタブ・ベース選びの帯) と、Web で使うほかの共通の部品 (`src/components/ui/`・`decor/`・`items/BaseCatalog` など)。

## ③ 決まり

### A. 線引き (何を共有にするか)

- **U-01 共有の線**: 共有にするのは、ユーザーがどの画面でも同じと感じる物 (ページの枠 = ヘッダー・上の切り替えタブ・戻る・フッター・広告の枠 / 決まった挙動 / 同じゲームの物を出す部品 = アイテムのカード・MOD 表の土台・棚・ベース選び) だけ。迷えば画面で作り、2 つ目の画面で要った時に共有へ上げる。
  - 有効。出どころ: オーナー 10-23 (メモ org-roles-2026-10-23)。確かめ: 画面 (使う画面の表 docs/org/design/notes/2026-10-23-components-map.md)。
- **U-02 中身はエンジンを呼ぶ**: 共有の部品が見せる中身 (MOD の文・値・段・名前・打てるか) はエンジンの関数を直に呼んで取り、部品の中で作らない (G-06)。
  - 有効。出どころ: オーナー 10-23・10-25 夜 (docs/org/emulator/README.md)。確かめ: 見張り `scripts/check-engine-entry.mjs` (エミュ ⇄ シミュの直の import)、コードを読む。
- **U-03 違いは包む・slot で**: 画面ごとの違い (エミュの持った時の %・次の手で狙う、シミュの狙いにする) は特化部品が props・slot で足し、共有の核に入れない。
  - 有効。出どころ: オーナー 10-23 (「シミュ = % 無し」は % の列でなく「次の手で狙う」ボタンが要らない事、ブラック 8 代目 10-23)。確かめ: 画面 (エミュ・シミュ両方)。
- **U-04 共有を直すのはデザインだけ**: for-share・決まった挙動・見た目の決まりはデザイン部長だけが直す。直す時は両方の画面が落ちない・崩れないことを並べて見る。
  - 有効。出どころ: オーナー 10-23、docs/org/owners.txt。確かめ: 画面 (PC 1660×860・スマホ 375、エミュとシミュで同じ操作)。
- **U-05 要望は全部に効かせる**: 1 つの画面で出た共通の振る舞いの要望は、共通の部品に入れて全部の画面に効かせる。スマホで出た細かい配慮も PC に入れる (スマホだけは固定の帯・縦積みなど使い勝手の分だけ)。
  - 有効。出どころ: オーナー 10-04・10-10 (メモ feedback-global-requests)。確かめ: 画面。
- **U-05b 要望には作りかけの木を必ず添える**: 要望・バグを送る窓は、どのページから開いても、端末に残っている作りかけのシミュの木 (詰めた code、名前なし = Y-62) を画面の状態 (context.treeDraft) に入れて送る。保存せずに離れた後でも辿れる。置き場は `src/web/feedback-tree.ts` (シミュが木を替えた時に noteTreeDraft で上書き、白紙では消さない)、24 時間より古い木は添えない、60,000 字を超える木は長さだけ。欄 (本文) は本人の文だけ (木の URL は入れない。窓の prefill の口は残すが使わない)。
  - 有効 (v0.1.682 で本番)。出どころ: オーナー 11-08「1おけ」(ブラック 62 経由)。確かめ: 画面 (1451 で金の指輪 → 保存せずエミュ → 要望の窓、送る前の context に木 4,915 字・context 全体 5,639 字、サーバーの上限 96 KB = server/live/src/feedback.ts の MAX_CONTEXT)。
- **U-05c 要望を閉じたら開く前のページへ同じ見え方で戻る**: 要望・バグを送るページは、開く前のページ (木・レシピ・デイリー・見た目・クラフト) を閉じずに上に重ねる。木のページは隠すだけで作り直さない (全体図・動かした位置・倍率・組みかけがそのまま)。隠れている間は木のキー操作 (戻す・やり直し・Ctrl+S など) とスマホの画面固定を止める。戻るボタンの字は開いた元のページの名前 (← ツリーへ戻る / レシピへ / デイリーへ / 見た目へ / クラフトへ)。ページを離れないので保存の確かめは聞かない。置き場は `src/web/page.ts` の openFeedback。
  - 有効 (11-10、v0.1.695 で本番)。出どころ: オーナー 11-10「おすすめでおｋ」(前は閉じるとベース選びへ戻った)。確かめ: 画面 (シミュ部長、本番と同じ作り。390 全体図を拡大で動かす → 要望 → 戻る = 全体図のまま位置と倍率が同じ、1440 ホイールで動かした後も同じ、レシピ・デイリーからも元へ・字も合う。JS エラー 390・1440 とも 0)。
- **U-05d 要望にはデイリーの名前の id と名前を添える**: 要望・バグを送る窓は、端末にデイリーの名前の控えがあれば、その id と名前を画面の状態 (context.daily = { nickId, name }) に入れて送る。運営が要望の人の今日の挑戦を名前を推さずに id で消せるように (D-37h4)。引き継ぎコードは入れない。名前の控えが無ければ null。置き場は `src/web/FeedbackDialog.vue` の contextNow。
  - 有効 (11-10、v0.1.703 で本番)。出どころ: オーナー 11-10「IDで追跡でいいんじゃね」(ブラック 76 経由)。確かめ: 型 0。
