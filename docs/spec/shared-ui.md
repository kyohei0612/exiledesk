## ① この紙の範囲

- **部品**: `src/components/for-share/` (アイテムのカード・MOD 表の土台・棚・上の切り替えタブ・ベース選びの帯) と、Web で使うほかの共通の部品 (`src/components/ui/`・`decor/`・`items/BaseCatalog` など)。
- **決まった挙動**: 枠の外・Esc で取り消す、窓、確かめの 2 回押し、連打の守り、閉じたら前の位置、1 つ戻す、ページの移り方と離れる時の確かめ、説明のカードの出し方 (`src/utils/`・`src/web/`・`src/composables/`)。
- **見た目**: 1 つの枠、ゲームの絵、色、線、字の縮め方・折り方、崩れない作り (`src/style.css`・`src/styles/`)。
- **スマホの並び**、**英語の画面** (`src/i18n/lang.ts`・GLOSSARY)、**スイッチ** (`src/web/release-flags.ts`) の使い方。
- 範囲の外: 結果が変わる物 (付き方・確率・打てるか・名前のデータ) = engine.md、各画面だけの流れ = emu.md・sim-tree.md、出し方・見張りの回し方 = release.md。

## ③ 決まり

### A. 線引き (何を共有にするか)

- **U-01 共有の線**: 共有にするのは、ユーザーがどの画面でも同じと感じる物 (ページの枠 = ヘッダー・上の切り替えタブ・戻る・フッター・広告の枠 / 決まった挙動 / 同じゲームの物を出す部品 = アイテムのカード・MOD 表の土台・棚・ベース選び) だけ。迷えば画面で作り、2 つ目の画面で要った時に共有へ上げる。
  - 有効。出どころ: オーナー 10-23 (メモ org-roles-2026-10-23)。確かめ: 画面 (使う画面の表 docs/org/design/notes/2026-10-23-components-map.md)。
- **U-02 中身はエンジンを呼ぶ**: 共有の部品が見せる中身 (MOD の文・値・段・名前・打てるか) はエンジンの関数を直に呼んで取り、部品の中で作らない (G-06)。
  - 有効。出どころ: オーナー 10-23・10-25 夜 (docs/org/emulator/README.md)。確かめ: 見張り `scripts/check-engine-entry.mjs` (エミュ ⇄ シミュの直の import)、コードを読む。
- **U-03 違いは包む・slot で**: 画面ごとの違い (エミュの持った時の %・次の手で狙う、シミュの狙いにする) は特化部品が props・slot で足し、共有の核に入れない。
  - 有効。出どころ: オーナー 10-23 (「シミュ = % 無し」は % の列でなく「次の手で狙う」ボタンが要らない事、ブラック 8 代目 10-23)。確かめ: 画面 (エミュ・シミュ両方)。
- **U-04 共有を直すのはデザインだけ**: for-share・決まった挙動・見た目の決まりはデザイン部長だけが直す。直す時は両方の画面が落ちない・崩れないことを並べて見る。
  - 有効。出どころ: オーナー 10-23、docs/org/owners.txt。確かめ: 画面 (PC 1660×860・スマホ 375、エミュとシミュで同じ操作)。

- **U-17 チュートリアルの光る道との約束 (画面の側が守る)**: チュートリアルが「流れ以外を灰色・流れを光らせる」形 (tutorial.md T-30) になっても、見た目を作り直す部 (デザイン・シミュ部・エミュ部) とチュートリアルが壊し合わない約束。正はここ 1 か所 (tutorial.md の T-31・T-32 はここを指す)。
  1. **見るのは目印だけ**: チュートリアルが見るのは `data-*` の目印だけ。クラス名・文字・DOM の入れ子・並び順・色は見ない。今だけ文字で探している「完成にする」は目印 (例 `[data-tree-done]`) に置き換え、T-13 の一覧から文字を消す (作る時)。
  2. **目印は押す要素そのもの**: ボタン・行・☑ の label に付ける。包むだけの div や飾りに付けない。目印 + 区別の値 (`data-box-id`・`data-key`・`data-aim`・`data-mod`) で画面の中の 1 つに決まる。
  3. **流れの部品は消さない**: 流れの間は描いておく (`v-if`・`display:none` で消さない。畳む作りなら目印のある見出しを残す)。スクロールの中の部品はチュートリアルが寄せる (固定の帯の下に隠れる時は S-147c と同じ寄せ)。
  4. **重なりの段**: z-index 1000 以上はチュートリアル専用 (幕 1100・光る枠 1200・札 1300)。画面の部品・帯・窓 (ModalShell z-300 / 確かめ z-310) は 1000 未満で、窓も幕の下 (窓の中でも流れの部品だけが穴で明るく、使わない棚などは灰色)。例外はホバーのカード (GameItemCard、HoverStack の `z: 1400 + i`) と乗せて開く説明 (HelpTip の z-[1400]) で、幕より上の 1400 以上に置く (11-03 に 1000 / 80 から移した。オーナー 11-03「ホバーのカードも直して　UIでスナップチェックして」。灰色の所は幕が乗せ・押しを受け止める T-30 の Q7 A ので、出るホバーはいつも流れの物の説明)。画面の側は自分で幕や暗くする層を作らない。
  5. **幕・穴・光る枠はチュートリアルが描く**: 1 か所 (body 直下に Teleport) で描き、画面の部品にクラスや style を足さない。光らせる物の z-index は上げない (石の帯・額は isolation、木は transform で重なりの箱を作るので、上げても幕の上に出ない)。穴と枠は目印の要素の getBoundingClientRect (zoom で割る) から毎コマ取り、`--lit-bleed` の幅だけ広げる。枠の絵が要素の箱の外へ出る部品 (`.g-panel` の外枠 18px・アイテムの額 6px・名前の銘板の羽など) は、その幅を CSS の変数 `--lit-bleed` に書く (飾りが穴の縁で切れて灰色にならない)。
  6. **目印を足す・変える**: 新しい部品が流れに入る時は、作る部が目印を付けて T-13 の一覧に足す。目印の名前を変える・消す・付ける要素を変える commit は、同じ commit で T-13 の一覧とチュートリアルの目印の表 (T-32) を直し、commit の文に「T-13」と書く。
  7. **灰色と光の色はデザインが決める**: 幕は黒 0.6 前後で暗くするだけ (彩度は残す)。光の色と脈は光る枠 `[data-tut-ring]` だけに持たせ、流れの部品そのものの見た目は変えない (U-48 の 6)。動きを減らす人は脈を止める。
  8. **幕は窓に数えない**: 幕に `data-overlay` (U-15・U-81 の Esc の数え) を付けない。Esc・枠の外は今のまま窓だけに効く。
  - 案。出どころ: オーナー 11-03 夜「流れ以外をグレーアウトして流れをすべてライトアップで進める形にするから それに対応させる作りで頼むわ」。チュートリアル部長 (一時) の T-31 (commit 58c9b6ed6) とデザイン部長の案を 1 つにした (11-03、ブラック 37 の頼み)。z の数え方はチュートリアル部長の「1000 以上はチュートリアル専用」を残した (デザイン部長の 幕 900 の案は捨てた)。4 のホバーのカード 1400 以上と 5 の `--lit-bleed` はデザイン部長の足しで、11-03 にブラック 37 が案どおりと決めた。決め: オーナー 11-03「おｋそれで」(見た目全体の OK、ブラック 37 経由)。確かめ: 見張り (T-32 の台本、作る時)。

### C. 決まった挙動

- **U-20 枠の外・Esc で選ぶ前に戻す**: 枠の中で選びかけ・持ちかけ・開きかけた物は、枠の外を押すか Esc でクリック前に戻す。確定はボタンを押した時だけ。外を押して閉じた時、その押下は下の物に届けない。例外: エミュの棚の持ち (持った物を離し、押した物にも届ける = 1 回で持ち替え。emu.md M-12)。
  - 有効 (スイッチ dismiss、本番入り)。出どころ: オーナー 10-22 (メモ feedback-click-outside-cancel)、10-19 (swallow-click)。仕組み `utils/use-dismiss.ts`・`utils/swallow-click.ts`。確かめ: 画面 (本物のマウスの台本に「枠の外で元に戻る」)。
- **U-21 Esc は一番後に開いた 1 つだけ**: Esc は積みの一番後ろの 1 つだけ閉じる。窓の中で開いている物 (段の表・説明・段の欄) があればそれを先に閉じ、窓はもう 1 回で閉じる。
  - 有効。出どころ: オーナー 10-23「展開した時の動きをエミュとシミュで一緒に」(notes/2026-10-23-expand-collapse.md)。確かめ: 画面。
- **U-22 開く・畳むは両方の画面で同じ**: ベース選びの部位・MOD 表の段・棚の段の欄は、1 回で開く・もう一度で閉じる・別の物を開くと前を閉じる (1 つだけ)・開いた物が見えるまで送る、をエミュとシミュで揃える (表は notes/2026-10-23-expand-collapse.md)。
