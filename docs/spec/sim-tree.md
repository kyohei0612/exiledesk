### B. 始まりと ✦

- **S-10 ✦ = 固定してよい印**: 完成の狙いに付ける。付け方は「フラクチャー」ボタンかカードの右クリック (スマホは MOD を押す)。スイッチ clickFracture の下では PC もカードの MOD の行を押すと印を付け外し (右クリックも残す。エミュの M-18 と同じ共通のカード StageItemCard の clickFracture)。 — 有効 (押して付けるのはスイッチ clickFracture、OK 待ち) / オーナー 10-20・10-23・10-28「あとスマホと共有でクリックでもフラクチャーできるようにPCも変えてくれ」(エミュの画面を見て。シミュの完成形も同じ揃え方、メモ「グローバルな依頼は全部に」) / 画面 (dev、完成形のカードの P1 アーマーを押す → ✦ 1、もう一度で 0。スイッチを閉じると押しても 0)
- **S-11 ✦ は何個でも**: 付けてもほかの印は外れない。フラクチャーの手は、どの ✦ が固定されても当たり、✦ の無い MOD が固定されたら外れ。エンジンの固定は 1 アイテム 1 つのまま。 — 有効 (スイッチ fracMulti、オーナー OK 済み 10-28 (スナップ)、本番待ち。前の「1 つだけ」10-26 夜は撤回) / オーナー 10-28「✦ を複数設定してよい」 / 画面
- **S-12 スタートの形は印で決まる**: ✦ あり = ✦ の MOD のどれか 1 つが固定されたレア (外れは木で付ける、START_JUNK 0)。✦ なし = 白 (ノーマル)。スイッチ startCard の下では、PC の木のスタートの箱も結果の箱と同じアイテムカード (レアリティの色の名前の帯・MOD の行、✦ の MOD はフラクチャー) で出す。Lv・✎ の行は上、カードの下に「ベース」・始め方とベースの値段の 1 行・＋MOD、カードを押すと始まりの形の窓 (スマホは前から 1 段目でカード)。 — 有効 (10-23 の「固定 1 + 外れ 3」は撤回。カードはスイッチ startCard、OK 待ち) / オーナー 10-25 (544f1241)・10-28 夜「フラクチャー済みからのやっつがアイテム欄の表示じゃないの違和感ここレアなんかもわからんしスタートもアイテムカードで表示させてくれツリー」 / 画面 (dev、ok-snaps/sim-14-start-card.png: フラクチャー済みから = レアのカード、白から = ノーマルのカード)
- **S-13 始め方の窓 (決めた → ツリーへ)**: (a) フラクチャー済みから / (b) 白から確定フラクチャー / 白ベースから (フラクチャー無し)。違うのは始めの値段だけ。スイッチ fracOne の下では、フラクチャーから始められるのは ✦ がちょうど 1 つの時だけ: ✦ が 2 つ以上なら始まりは白ベースだけ (✦ の印は残し、木の中のフラクチャーの手は S-42・S-43 のまま)。窓は ✦ の一覧と「✦ が 2 つ以上なので白ベースから。フラクチャー済みから始めるなら ✦ を 1 つに」の一言、選ぶ物は無し。スタートの箱の始め方の切り替えも出さない。前の版の ✦ 2 つ以上で「フラクチャー済みから」の木は、開いた時に白ベースから (`start.from` four) に読み替える。 — 有効 (✦ 2 つ以上の扱いはスイッチ fracOne、オーナー OK 済み 10-28 (スナップ)、本番待ち) / オーナー 10-26 夜・10-28「フラクチャー複数選択の時点で白ベースにさせるべきだよね…単発のみフラクチャースタートできるようにさせるか」 / 画面 (dev 1440: ✦ 2 つで窓は白ベースからだけ・始まりは白、✦ を 1 つに戻すとフラクチャー済みからへ戻る (自動で替えた時だけ、`TreeStart.autoWhite`)。印無しの窓は先頭の MOD に ✦ + (a) が既定)
- **S-14 ✦ を付けて始めるのを勧める**: 窓は「フラクチャーから」が上、白ベースは選べるまま一番下に「ふつうは高くつく」の一言。「(おすすめ)」は完成形の設定で ✦ を付けていない時だけ (✦ を付けてある = もう選んでいるので勧めない)。スイッチ fracOne の下では、窓の ✦ は ☑ で選ぶ (いくつでも): ☑ 1 つ = (a) フラクチャー済みから / (b)、☑ 2 つ以上 = その場で「白ベースから」だけの一言 (S-13)、☑ 0 = 白ベースから。既定は印があれば印の MOD 全部、印が無ければ完成の狙いの先頭のフラクチャーできる MOD 1 つ (冒涜の MOD は飛ばす) + (a)。 — 有効 (スイッチ fracMulti・fracOne、オーナー OK 済み 10-28 (スナップ)、本番待ち。☑ に戻したのと「(おすすめ)」の出し分けは 10-28 夜、スナップ sim-03c で確かめ待ち) / オーナー 10-28「フラクチャーせずに開始にするなよとは思う」・10-28「単発のみフラクチャースタートできるようにさせるか」・10-28 夜 (1461 の始め方の窓を見て)「ここは別にフラクチャーしてんだからフラチャーお勧めっておかしいふらくちゃーしてないんだったらわかるけども。 ここは複数選択かってのでチェックボックスに変更」 / 画面
- **S-15 最初の完成形の窓はフラクチャーの設定を答えるまで閉じない** (×・枠の外・Esc では閉じず「決めた (ツリーへ)」だけ)。 — 有効 / オーナー 10-27 夜 (fracFirst) / 画面

### C. 手と結果の箱

- **S-20 打つ手はゲームどおり自由**: 棚・並び・打てない手を出さないのはエミュと同じ (G-03)。ツリーの棚に出さない物: ヒネコラの髪束 (説明も)・聖別・ミラー・神のオーブ・祝福のお告げ・クラフト以外のルーン。錯乱のエッセンスは使えない。 — 有効 / オーナー 10-23・10-24・10-27 / 画面
- **S-21 起こりうる結果を全部箱で出す**: 着いた人のアイテム × その手 (お告げ込み) でエンジンが出しうる結果ごと。お告げで減る・確定なら 1 つ。自動で隠す・外れに入れる物は作らない。まとめる・分けるは人。 — 有効 / オーナー 10-25・10-26「あくまでもツリーは全ての結果を表示して」 / 見張り
- **S-22 ☑ の物だけが当たり**: 手の窓で ☑ (複数可) した MOD ごとに当たりの箱 + 外れ 1 つ (スイッチ junkSide の下では外れは側ごと、S-65)。☑ の無い MOD はそのカレンシーでは外れ MOD (☑ の無い狙いが付いても外れへ、止めない)。 — 有効 (10-27 の (a) は撤回) / オーナー 10-27 朝 (メモ feedback-unchecked-is-junk) / 見張り
- **S-23 手の窓の既定は狙い無し**: 狙い無し = 結果は「打った後」1 つ (完成の狙いが付いた人もここ。スイッチ junkSide の下では側ごと、S-65)。MOD を押すと狙い無しが外れ、全部外すと狙い無しに戻る。 — 有効 (10-26 昼の「候補に全部 ☑」は撤回) / オーナー 10-26 夜「デフォルトは狙い無し」 / 画面
- **S-24 当たりの箱は MOD ごと**: 同じ側でも自動でまとめない。もう持っている狙いがもう一度付く道は数えない。 — 有効 / オーナー 10-26・10-27 夜 (hitNew) / 見張り
- **S-25 当たるまでの手は作らない**: カオススパムオーブの札は無し。当たるまでは「カオス 1 回ずつ + 外れ → 親の箱」で表す。前に保存した当たるまでの手は読めて動き、名前は設定したカレンシー。 — 有効 / オーナー 10-25・10-27 昼 (noSpam) / 画面
- **S-26 特別な手を足さない**: 新しい扱いは、まずふつうのカレンシーの手で表せないか考える。 — 有効 / オーナー 10-27 昼 / —
- **S-27 消去の残したい MOD**: ☑ の MOD が消えた = 狙いが消えた、残った = 外れが消えた (☑ の無い MOD は外れ)。既定は「全部消えてよい」= 消去 1 回ごとの箱を直線に並べる。 — 有効 / オーナー 10-27 / 画面
- **S-28 全部消えてよい消去の直線の止まり**: 同じレアリティ・同じ ✦ の側・同じ外れの数の、手のある箱になった所で止まって ↩ その箱。合う箱が無ければ行き先未定 (MOD 0 のレアを白へ戻さない)。 — 有効 (スイッチ stripRarity・boxShape、オーナー OK 済み 10-28 (スナップ)、本番待ち) / オーナー 10-27・10-28 / 見張り
- **S-29 エッセンスの結果**: 狙いでない MOD が消えた = 当たり、狙いの MOD が消えた = 外れ (割合は MOD の数から)。狙いの付かないエッセンスは「打った後」。エッセンスで付いた狙いも消えたの数えに入る。 — 有効 / オーナー 10-24・10-25 / 見張り
- **S-30 クラフト MOD 2 つ以上**: 行の右の切り替えで「途中で消える / 残る」、残るのはエンジンの上限まで。3 つ以上は全部決めるまで「決めた」を押せない。 — 有効 / 10-27 (rowToggle) / 画面
- **S-31 品質**: 完成形の「品質も狙う」☑ (既定オフ)。オンで品質の帯と完成の判定で品質を見る。上限はエミュと同じ + 途中で付けるブリーチの +20 (付くベースだけ)。11% 以上超える時はブリーチの行を「途中で消える」で出す。品質だけ上げる手の後は通り抜けの箱。 — 有効 / オーナー 10-27 / 画面

### D. 骨 (冒涜)

- **S-32 骨の手の「発現させる」☑**: 既定は無し = 未発現のまま次へ (結果は「未発現の冒涜が付いた」1 つ)。☑ を付けた時点で MOD の窓 (PC は「このベースに付く MOD」の表、スマホは MOD を選ぶ窓) が開き、発現で出うる MOD の段から選ぶ (出ない MOD は灰色)。選ばずに閉じたら ☑ は付かない。発現させる時は狙い無しにしない。 — 有効 (スイッチ boneLater、オーナー OK 済み 10-28 (スナップ)、本番待ち) / オーナー 10-27 夜・10-28 / 画面
- **S-33 置き石**: 完成形に無い MOD も発現で選べる (置き石)。その手の時だけ当たり、以降は冒涜の外れ MOD。 — 有効 (スイッチ boneLater、オーナー OK 済み 10-28 (スナップ)、本番待ち) / オーナー 10-27 夜 / 見張り
