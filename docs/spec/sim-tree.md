## ③ 決まり

**大本 (オーナー 10-29、判定の整理)**: ① 箱の判定は箱に描いている中身 (見本の実物) で決める。道から足していく古い数え (道の当たりの狙いを足す・持って着きうる狙い・形の鍵で先に絞る) は判定に使わない。② 手ごとの特別扱いはしない (フラクチャー・カタリストの結果の除外・カオスの外れを親へ、は消した。中身の判定に任せる)。オーナー「そもそも特別仕様にも対応できるように作らないとダメだから特別扱いなんてのはしたらダメよな」。判定は 2 つだけ (S-50b)。

書き方: **番号 一文** — 状態 / 出どころ / 確かめ方。状態は README.md の 3 の 5 つの型 (有効 / オーナー OK 済み・本番待ち / 仮 (オーナーの OK 待ち) / 未決 / 撤回)。食い違う決まりは、オーナーの言葉の日付が後の方に揃え、古い方は撤回 (M の章) にして新しい番号を指す (10-28 深夜オーナー「新しい奴にそろえるように設計図整理だなしっかり」)。決まりの中の「前は〜」は、なぜ今の形になったかの短い経緯だけ (細かい前 / 後の数は git の履歴と共有メモ)。仮・未決・作りの残りは ⑦ に 1 つにまとめた。

- **S-10b 「付ける」は 1 つ・付け方は 3 つ**: 完成形の設定の MOD 一覧の段の行のボタンは「付ける」1 つ (「狙いにする」「フラクチャー」の 2 つを置き換え)。押すとエミュの「付ける」(M-19) と同じプルダウンで付け方の 3 択 (ふつう・フラクチャー・冒涜) が開き (行の中に横に並べない)、選ぶとその段以上が狙いになる (フラクチャーは ✦ の印も = S-10)。エッセンスは付け方に出さず、エッセンス・合金で付く MOD (クラフト MOD) は「ふつう」で付ける。その付け方で出ない物は灰色で残し、乗せる・押すと訳を一言: ふつう = 冒涜専用 (骨でしか付かない)、フラクチャー = 冒涜の MOD (E-41)、冒涜 = クラフト MOD (骨で付くのは冒涜専用と一般 MOD、E-62)、創生の樹など (カレンシーでは付かない節) はフラクチャー以外が灰色。付けた後のボタンは付け方の名前 (「✓ ふつう」「✦ フラクチャー」「✓ 冒涜」)、押すとプルダウンに 3 択と「外す」。冒涜の印は ✦ と同じく何個でも (S-04 の冒涜 1 つまでは断らない)、クラフト MOD も前から上限で断らない (上限を溢れた分は束、S-30b)。印は付け方の覚え (Aim.via) だけで、木の判定 (当たり・箱の中身・回し) には使わない (フラクチャー以外は狙いが増えるだけ)。行の札も付け方の名前。完成形のカードでは、付け方が冒涜の狙い (冒涜で付けた狙い・冒涜専用 MOD) は 1 つ目から冒涜の行 (`desecrated`) にし、エミュと同じ枠で一番下に並べる (見せるだけ、木の判定は替えない。✦ の印の付いた物は除く。スイッチ goalDesecRow、開発版、オーナーの OK 待ち)。 — 有効 (スイッチ attachWay、v0.1.646 で本番)。前の 4 択 (エッセンスも付け方) は撤回 / オーナー 10-31 決め 15「付けるボタンに統一させようか…できない奴は灰色で」「冒涜もいくつか候補…上限とかなくていいんじゃない…エッセンスも」「フラクチャー以外は…狙いモッドが増えるただそれだけ」・訂正「エッセンスは関係ないね エッセンスは付ける時は複数にまとまるってはなしだよ2個以上は 付け方に表示はしなくていい」・「エミュみたいにつけるって押したら候補出るみたいな挙動を想像してた」 / 画面
