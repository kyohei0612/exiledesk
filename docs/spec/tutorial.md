# 設計図 — チュートリアル・コース (T-xx)

持ち主: シミュ部長 (チュートリアル係)。2026-10-28 に作った。型は `README.md` の「3. 書き方の型」、大本は G-xx。
短い版: 今の決まりの骨組みだけ。細かい手ごとの中身はコードの定義 (`src/services/tutorial/`・`src/services/craft-stage/topic-courses*.ts`) が正。

## ① この紙の範囲

- 持つ物: ヘッダーの「使い方・コツ」のページ (`?page=guide`、コースは `?course=<id>`) のコース (入門〜上級 11 本)、コースの画面の決まり、シミュのツリーのチュートリアル。
- 持たない物: カレンシーの動き → `engine.md`、エミュの画面 → `emu.md` (コースが画面を隠す決まりだけここ)、シミュのツリーの決まり → `sim-tree.md`、出し方 → `release.md`。
- 前の型の ADR-003 (クイズのレシピ) はシミュのツリー (`sim-tree.md`) に置き換え済み。コースの手順を回す型 (`quiz-recipe.ts`) は残る。

## ② 用語

| 言葉 | 意味 | 置き場 |
|---|---|---|
| コース | 1 本の学ぶ流れ (基本のオーブ・エッセンス・冒涜・お告げ・カタリスト・液化した感情・上級 5 本) | `topic-courses*.ts`・`course-release.ts` |

## ③ 決まり

- **T-01 コースの間はチュートリアル専用の画面**: ベースの帯・工程・スパム・次の手で狙う・下の MOD 一覧は出さない。打ったら持った物を離す。判定は `state/tutorial/course-host.ts` 1 か所。 — 有効 / オーナー 10-17 / 画面
- **T-02 手の一覧**: 今の手から上に並べ、済んだ手は ✓ を付けて最後尾。最後までやったら「クリア」の札 (ブラウザにコースの id で残す)。「もう一度」は全部やり直し。 — 有効 / オーナー 10-17 / 画面
- **T-03 説明は省きすぎない**: 今の手の公式の説明と「このステージでの動き」は畳まずに出す。条件 (MOD 4 つ以上など) と「ランダムか」を必ず書く。 — 有効 / オーナー 10-17 / 画面
- **T-04 色でレア度を言う時は必ず添える**: 白 (ノーマル)・青 (マジック)・黄 (レア)。英語も white (Normal)・blue (Magic)・yellow (Rare)。 — 有効 / オーナー 10-17 / 画面
- **T-05 用意は手ごと**: 白に戻す手は使わず、手ごとの用意で「今の手が打てるアイテム」を自動で作る (打てる時は今のアイテムのまま)。 — 有効 / 10-17 夜 / 画面
- **T-06 お告げは先に掛ける**: お告げはカレンシーと別のボタンで先に掛け、掛けるまでカレンシーは押せない。手を移ったらお告げは外す。発現は「MOD を選んで発現」のボタン、未発現が残っている間は手を終えない。 — 有効 / 10-18 / 画面
- **T-07 出すのは合格したコースだけ**: 公開の表の RELEASED。手元の dev だけ全部。 — 有効 / オーナー 10-17〜18 / 画面
- **T-08 名前はエンジン参照** (G-05・E-91)。英語はセット (G-08)。 — 有効 / — / 見張り
- **T-09 シミュのツリーのチュートリアル**: 「不在のアミュレット (フラクチャー済み) から作る」。ベース選びの入口から押す所を光らせて一手ずつ案内。ツリーの目印 (`[data-box-id]`・`[data-tree-next]`・「完成にする」の文字・`[data-tree-hand-card]`・`[data-tree-hand-aim]`・`[data-tree-run]`) を変える時はチュートリアル係に一言。 — 有効 (スイッチ simTutorial、OK 待ち) / オーナー 10-26 夜 / 画面

## ④ 表示の決まり

T-01〜T-04。共通の部品は shared-ui.md。

## ⑤ 不変条件

- 公開の表にあるコースは最後まで打てる (コースの手で「打てない」が出ない)。 — 確かめ: `tests/tutorial/` (オーナーが言った時だけ回す)
- 名前はデータと同じ (T-08)。

## ⑥ 新しいコースを足す手順

1. この紙か (大きい物は) コードの定義に手を書く。2. 開発版の REVIEW に入れてオーナーの OK。3. RELEASED へ (英語もセット)。
