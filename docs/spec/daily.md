- **D-30 木はシミュそのもの**: 箱・手の窓・棚・MOD 一覧の窓・穴チェック・100 人回す・1 つ戻す・線と並べ方・見本はシミュの部品とエンジンをそのまま使う。デイリーの中だけの判定・確率を足さない (G-06・S-110)。MOD 一覧も今のシミュの物。 — オーナー 11-01「チャレンジ場所は勿論シミュでMOD一覧ページも勿論シミュの奴」
- **D-31 違うのは帯と皮だけ**: 下の表 (D-40) の外すものを外し、上の帯をデイリーの物にし、見た目を D-60 にする。 — オーナー 11-01「要はシミュレーターなんだけどUIが違うシミュレーターかな」
- **D-32 時間制限**: スタートから、挑戦のページを開いている時間の合計で 1 時間。ページを閉じる・一覧へ戻ると止まり、戻れば残り時間と木の続きから。木は端末に自動で残す。残りは帯の真ん中に大きく。残り 10 分と 1 分で色が変わる。前の「サーバーの時計でそのまま進む」は撤回。 — オーナー 11-01「スタートボタンから1時間以内作成とかのが燃えるかなって」「時間止めていいよそこまで厳しくしない」
- **D-32b お題はスタートまで伏せる**: スタートを押すまで、一覧・お題のページに出すのはベース名と MOD の数だけ。自分が挑戦を始めた後と、解決一覧に載った物は全部見せる。 — オーナー 11-01「A」
- **D-33 流れ**: ニックネームを決める (D-51、決めていない時だけ) → スタート → (時間が始まる) → フラクチャーを選ぶ (今の DailyStart) → 木 → 穴チェック → 100 人回す → 提出。提出は 1 時間の中で何回でもよく、記録は解決の中で一番安い物。挑戦はお題ごとに 1 回で、時間切れの後は木を見るだけ。 — オーナー 11-01 Q2 = A・Q3 = A
- **D-34 同じ条件で比べる**: 回す種・値段はお題に固定 (D-21、相場は出た朝の写し、Q7 = A)。値段の手入力・ベースの値段は無い。回す人数は 100 (S-70 の RUN_N)。
- **D-35 提出できる条件**: 穴チェック合格 + 100 人回した直後の結果がある。完成率 90% 未満でも提出はできるが「未解決」の記録で順位に載らない。
- **D-36 別の場所の木を持ち込まない**: 挑戦の中はレシピの読み込み・貼り付け・共有 URL を受けない。

## ④ 表示の決まり

- **D-60 皮は 1 か所、1 行で増やす**: 色は `views/daily/skin/skin.ts` の 1 行 (色相・彩度・暗さ・光の強さ・光の色相) から全部決まる。部品に色を直書きせず、`--skin-*` と `--exile-*` を上書きするだけ。字と枠の変数も皮が持つ。皮を足す・丸ごと替えるのに画面の中身を触らない。 — オーナー 11-01「後から死ぬほどＵＩ変えるから対応できるような形で」「色合いはマジで無限に作ってほしいけどな」
- **D-60a 日替わり**: その日の皮は日付で順に回る (`skinOfDay`)。文字の濃さが足りない皮 (本文・薄い字が地に対して 4.5 未満) は回さない (`skinContrast`)。見比べは `?page=daily&q=skins`。
- **D-60c シミュでも読める**: `skinVars` は要素に渡すだけで使えるので、普段のシミュも同じ皮に替えられる。入口はシミュ部長・デザイン部長へ (D-91)。 — オーナー 11-01「シミュレーションもその色合いに変えれるようにしてあげたいな」
- **D-60b 目立たせるのは 1 か所 = 導火線**: 赤い光は残り時間にしか使わない。帯の下の端から端までの細い線が、残り時間の分だけ燃えて縮む。ほかは煤の黒と古い金で静かに。動きはこの線だけで、箱・カードに飾りの動きを足さない (`prefers-reduced-motion` では火の揺れを止める)。
- **D-60d 見た目は一枚の卓**: PC の 1 ページ目は窓いっぱいの `.g-panel` 1 枚 (窓が低い時だけページが伸びる)。題は金の銘板、真ん中に品とスタート、左に順位、右に今週の点、下に今週の棚 7 枠 (今日は持った枠、解決は ✓、これからの日は空き枠) と投稿の口。解決したお題は棚から開く。挑戦は彫像の見出し 2 枚の間に大きな時間、木の周りの道具は石の帯 1 本へ、枠の中の枠を外し右の列は仕切りの絵で分ける。効くのは `daily-skin.css`・`look.css` でデイリーのページの中だけ、普段のシミュは変えない。 — オーナー 11-01「Bだな」
- **D-61 広告**: 一覧・お題・投稿のページは文章のページで両脇の枠 (Y-20)。挑戦のページは操作の画面なので枠なし (WebApp の `textPage` から外す、デザイン部長へ)。
- **D-62 日英**: U-60〜62。用語集に「クラフトボックス」が無いので足す (英語はオーナーに聞く)。
- **D-63 スイッチ**: 全部 `daily` の下。別のスイッチを増やさない。

### G. 型の辞書と毎朝の自動生成 (控えのお題)

- **D-80 型の辞書**: `daily-types.ts`。1 つの型 = 部位のベース・ビルドの系統・必須 MOD・候補 MOD (MOD は行の名前)。オーナーが poe.ninja を人の手で見て、リーグの始めと週に数個足す。足りない分はエミュの記録から候補。ninja は機械で読まない (リサーチ長 11-01)。お題の画面に「poe.ninja の集計」と書かない。 — オーナー 11-01「型+自動生成でおけ、おすすめで」
- **D-81 曜日の難易度**: 月 3 MOD T5 以上 / 火 3・T4 / 水 4・T4 / 木 4・T3 / 金 5・T3 / 土 5・T2 / 日 6・T2。`LEVELS` の 1 行で替えられる。
- **D-82 生成**: `generateTopic` は日付を種にして、最近出た型を避けて型を選び、必須 + 候補からランダムに MOD を選ぶ。同じ日付・同じ辞書なら同じお題。
