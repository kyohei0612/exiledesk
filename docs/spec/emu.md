# 設計図 — エミュの画面 (M-xx)

持ち主: エミュ部長。2026-10-28 に作った (オーナー「大前提、全体及び各項目の設計図がいる。順に決めて全て完了まで」)。
型は `README.md` の「3. 書き方の型」。大本は G-xx (`README.md`)。この紙はエミュの画面 (`src/views/craft-stage/`) の流れ・操作・表示だけを持つ。

## ① この紙の範囲

- 持つ物: エミュの画面の流れ (ベース選び → クラフト台で持って打つ → アイテム・工程・MOD 一覧・次の手で狙う・スパムシミュレーター・シミュレーターへ)、操作 (持つ・手放す・打つ・戻す)、表示 (持った時の色分け・確率の出し方・工程)、品質の帯、エミュのスマホの並び。
- 持たない物 (番号ではなく紙の名前で指す):
  - カレンシー・お告げ・エッセンス・骨の動き、打てるか、確率の計算 (持った時の %・次の手で狙うの aimChain・スパムの 100 人)、MOD の文・値・名前 → `engine.md`。画面はエンジンの関数を呼ぶだけ (G-06)。
  - 共通の部品と決まった挙動 (枠の外・Esc で閉じる、2 回押し、カード・MOD 表の土台・棚の見た目、1 つの枠・ゲームの絵・崩れない作り・縮めてから折る、スマホは省略しない、英語のセット、スイッチの出し方) → `shared-ui.md`。この紙はエミュでの当て方だけを書く。
  - シミュレーター側の受け取り (ツリー・完成の狙い) → `sim-tree.md`。チュートリアルのコースが画面を隠す決まり → `tutorial.md`。
  - 出し方・見張り・モンキー → `release.md`。
  - POE2Tube の再生モード (`?stage-plan=`・`?step=N`・録画) とアプリだけのボタン (手順 JSON・結果 JSON・動画モード) → ADR-001 とメモ poe2tube-handoff (アプリは G-07 で凍結)。

  - 有効。出どころ: オーナー 10-25「emuFresh も本番出して OK」(v0.1.599)。確かめ: 画面 4 通り (todo の記録、スマホの幅は未確認)。

### B. 操作

- **M-10 押して持つ**: 棚の物を押すと持つ (カーソルに絵)。同じ物をもう一度押すと離す。別の物を押すと持ち替え。
  - 有効。出どころ: ADR-001 (オーナー 09-27「操作は Craft of Exile 仕様」)。確かめ: 画面。
- **M-11 アイテムを押して打つ**: 持ったままアイテムのカードを押すと 1 回打つ。持ったままなら続けて押すたびに打つ (連打)。打てない時は打たずに理由を出す (M-41)。
  - 有効。出どころ: ADR-001。確かめ: 画面。
- **M-12 手放す**: Esc・右クリック (クラフト台のどこでも)・棚とアイテムのカードの外を押すと離す。下の帯・窓・MOD 一覧・付けるのプルダウンの中は外に数えない。外を押した時、その押下は押した物にも届く (離して、押した物にも届ける = 1 回で持ち替え・押した先のボタンも効く)。これは U-20 (押下を下に届けない) の例外。次の手で狙うの欄 (行・「回す」) も外に数えるので、「回す」を押すと持っている物は離れる (行を押すと離した後にその行の物を持つ、M-32)。
  - 有効。出どころ: ADR-001 (右クリック / Esc)、オーナー 10-22「キャンセルは枠の外をクリックで」、届ける例外は 10-28「おｋ」(⑦1 への答え)。「回す」で離れるのはモンキー 10-23 の報告 (再現は未確認だった) をコードで見て、この決まりどおりと分かった (10-28、CraftStage.vue の useDismiss の外の数え方)。確かめ: 画面。
- **M-13 お告げ**: 持っている物に掛けられるお告げは棚の中の持っている物の段の下に出し、押して掛ける / 外す。掛けたお告げは棚の題の横に札で出し、札の × でも外せる。お告げは持った物ごとに覚え、持ち替えると前の物の分は外れ、持ち直すと戻る。打って食ったお告げは外れ、1 手戻すと掛け直る。一緒に掛けられない組の扱いは engine.md。
  - 有効。出どころ: オーナー 10-04 (お告げは持った物の下)、10-26 夜「そのオーブが選ばれた時だけ、その設定をオンに」(スイッチ omenPerHeld、v0.1.622 で本番)。確かめ: 画面。
- **M-14 1 手戻す**: 「1 手戻す」・R・Ctrl+Z で直前の手を戻す (鍵の揃え・やり直し Ctrl+Shift+Z / Ctrl+Y は U-25)。入力欄の中・窓が開いている時は効かない。チュートリアルのコースの間は戻さない。まだ打っていない時は始めの MOD を 1 つ外す。戻した後の次の手は新しい乱数 (同じ手を打ち直しても同じ結果にならない)。
  - 有効。出どころ: オーナー 10-11「Ctrl+Z はデフォルトみたいな存在だから R でいい」(Ctrl+Z も残す)、10-05 (メモ feedback-proactive-ui)。確かめ: 画面。
- **M-15 工程の手を押して戻る**: 工程の行を押すとその手を打った直後に戻る。先頭の「始め」は 1 手も打っていない状態 (始めの MOD は残す)。その後に打てば先の手は捨てる。
  - 有効。出どころ: オーナー 10-09「工程クリックしてもそこの工程に戻れない」。確かめ: 画面。
- **M-16 白に戻すは 2 回押し**: 白に戻す (始めの MOD も外す) は 1 手戻すで戻せないので 2 回押しで決める (2 回押しの形・戻し方は U-23)。
  - 有効。出どころ: 10-08 完成判定 (9 手分が確認無しで消えた)。確かめ: 画面。
- **M-17 MOD 一覧の窓**: カードの左上の「MOD 一覧」と Tab (PC だけ) で重ねて開く。大きさは後ろの画面の 75%。Esc・枠の外・×・Tab で閉じ (U-15・U-20)、持っている物はそのまま。ページの下にも同じ一覧を置く。
  - 有効。出どころ: オーナー 10-11「ジャンプしなくていいから MOD 一覧が全て画面に出て」「75%」「スクロールした下に配置してていい」、10-10「アイテムカードの枠左上に MOD 一覧へ」。確かめ: 画面。
- **M-18 カードの MOD の操作**: カードの MOD を押すと MOD 一覧のその行へ飛ぶ (付いている段を囲む)。右クリックでフラクチャー (今の段のまま固定)、フラクチャー済みは右クリックで外す。行の × で外す (費用 0 の手、1 手戻すで戻る)。暗黙の値は ▲▼ で変える (続けて変えた分は 1 手)。
  - 有効。出どころ: オーナー 10-09「MOD 右クリックでフラクチャー化させてあげてもいいかも」、10-18 (外す)。打てるか (レアだけ・1 つまで) は engine.md。確かめ: 画面。
  - 仮 (スイッチ clickFracture、オーナーの OK 待ち): PC もスマホも、持っていない時は MOD を (左) クリック / タップでもフラクチャー (右クリックと同じ手、フラクチャー済みは外す。右クリックも残す)。持っている時のクリックは今どおりアイテムに使う。フラクチャーにできない行 (冒涜・未発現) だけ今どおり MOD 一覧のその行へ飛ぶ。打てない時 (レアでない・もう 1 つある) は理由が出る。下の説明の文は「MOD を押すとフラクチャー · × で外す · R で 1 手戻す」。PC とスマホは同じ関数 (StageItemCard の onFracture、口は clickFracture)。出どころ: オーナー 10-28「あとスマホと共有でクリックでもフラクチャーできるようにPCも変えてくれ」(ブラック 15 代目経由)。確かめ: 画面 (前後のスナップ ok-snaps/emu-clickfrac.png)。
- **M-19 MOD 一覧の「付ける」**: 段の行の「付ける」はプルダウンで付け方 (そのまま / 冒涜 / フラクチャー) を選ぶ。付けられない付け方も灰色で残し、乗せると理由。打つ前は始めの MOD、打ち始めた後は指名の手 (費用 0、1 手戻すで外せる)。
  - 有効。出どころ: オーナー 10-17「付け方を選べるように」、10-18「横に展開は寒い、プルダウンで 3 種類に分けて」「一般 MOD も冒涜で付けれるでしょ」。確かめ: 画面。
- **M-20 MOD 一覧のチェック欄**: 持っている時、行・段にチェックして「どれか 1 つでも付く確率」を出す。行のチェックは付きうる段を全部、段のチェックはその段以上を入れ、外す時はその段だけ外す。持ち替え・離す・打つ・ベースを変えると空に戻す。
  - 有効。出どころ: 要望 c9dee700、オーナー 10-12「カレンシー持ったら MOD の横にチェック欄、キャンセルや付けたらリセット」。確かめ: 画面。
- **M-21 重みを直す 1 行**: MOD 一覧の段の表の上の「重み」を直す 1 行は開発版だけ。直した行は「重みを直した」、推定の重みは「重みは推定」の札 (本番でも出す)。
  - 有効。出どころ: オーナー 10-22「1000 で置いて、修正できるように」、10-18 UI 点検 (札は文字で)。確かめ: 画面 (本番の作りで 1 行が無い)。
- **M-22 使った時の音**: 打つとゲームと同じ音、珍しい段 (M-46) はアイテムフィルターの通知音 6。題の横のボタンで音のオン / オフ (端末に覚える)。
  - 有効。出どころ: 10-16 ゲームと同じ音、オーナー「6 のやつ」(メモ chaos-spam-and-sfx)。確かめ: 画面。

### C. 次の手で狙う

- **M-30 入口と選ぶ窓**: MOD 一覧の段の「次の手で狙う」で選ぶ窓を開く。押した段は最初からチェック済み、6 つまで、1 つでも進める。名前を押すと「T○ 以上」を選べる。決めるまで今の狙いは変えない (やめるで元のまま)。
  - 有効。出どころ: オーナー 10-09「押したらチェックボックスで複数狙えるように別でポップアップだして、選択しなくて単体でも進めるように」、10-16 に 4 → 6 (オーナーのメモ「最高 6 MOD」)。確かめ: 画面。
- **M-31 確率の一覧**: 棚の上に、打ち方 (カレンシー + お告げ) ごとの「当たるまで同じ打ち方を続けた時の確率」を出す。並びは付きやすい順、同じ確率なら付くまでの平均費用 (1 回の値段 ÷ 確率) の安い順。費用は名前の下。0% の行とコラプトさせる物は出さない。上位 5 を出し、残りは畳む。数え方 (当たりの決め・やり直しの費用を足さない) は engine.md。
  - 有効。出どころ: オーナー 10-09「やっぱり付きやすさランキングじゃないとダメ、費用で並べると高貴が絶対上に来る。付きやすさで下に通貨書いてればおｋ」「上位 5 個でいい、あとは畳んどけばええよデフォルトで」。確かめ: 画面。
- **M-32 行を押すと持つ**: 一覧の行を押すとそのカレンシーを持ち、その種類のお告げをその組み合わせに揃える (ほかの種類のお告げは残す)。発現の行はアビスの反響を掛けて発現の欄へ送る。
  - 有効。出どころ: StageAimPanel (10-09)、10-26 夜 (持ってからお告げを揃える順、omenPerHeld)。確かめ: 画面。
- **M-33 回す**: 行の「回す」で今の状態から 10 / 100 / 1,000 回打った時に付いた回数を出す (毎回今の状態から、毎回別の乱数)。どう回した数字かは開いた時だけ 1 行。狙い・アイテムが変わったら結果を消す。
  - 有効。出どころ: オーナー 10-09「ここでも回したいよね、何回やったら何回付くのか」、要望 007801cc「何をどう回した数字か」。確かめ: 画面。
- **M-34 打ったら出し直す**: 打つたびに今の状態で一覧を出し直す (少しずつ、画面を止めない)。スマホでは一覧を画面の同じ高さに残す。
  - 有効。出どころ: StageAimPanel (10-09)、メモ aim-next-move。確かめ: 画面 (スマホで打って一覧の位置)。

- **M-35 見込みの累計 (確率どおりに付いた時の費用)**: 狙いが付いた手は、その手を「付くまでの平均費用」(M-31 の行の数字) で数え、ほかの手は 1 回の値段で数えて、工程の頭から積んだ「見込み」を出す。工程の「累計」(実際に打った分) とは別の数。
  - 仮 (オーナー確認待ち、⑦4)。出どころ: Discord の要望 e6143075 (10-29)「次の手で狙うの選択肢に、確率通りについた時のコストを加算していく仕組みがほしい」「クラフトの流れが一直線の時に、この時のコストは～っていうのが分かって助かる」、オーナー 10-29「1進めて設計から」。作る時はスイッチの下 (U-70〜73、名前は仮に `aimTotal`)。確かめ (作った後): 画面 (手袋で 3 手、狙い → 付く → 次の狙い、行と工程の数字を手で足し算と突き合わせ)。
  - 数え方 (案):
    - 1 手ごとに「見込み」を 1 つ持つ。その手の直前に狙いがあり、打った結果で狙いが全部付き今の MOD が消えていなければ (= aimChain の当たりと同じ決め、engine.md)、打つ直前の一覧でその打ち方の行の「付くまで平均」を見込みにする。それ以外の手 (狙い無し・外れたが残した・確定で付く手・品質の手) は実際の 1 回の値段 (工程の小計と同じ)。
    - 見込みの累計 = 今の工程に残っている手の見込みの和。1 手戻す (M-14)・工程の手を押して戻る (M-15) で戻した手の分は消える (手に付いているので M-90 と同じく打つ前と同じになる)。外れて戻した手の費用は足さない (aimChain の「やり直しの費用は足さない」と同じ考え。外れの分は平均費用の中に入っている)。
    - 値段: 1 回 = カレンシー + 掛けたお告げ (M-31 と同じ相場、高貴建てで持ち、表示通貨で出す)。打った時の値段で持ち、後で相場が変わっても積み直さない。発現 (アビスの反響) の行は今の一覧で 0 なので 0 のまま (⑦4 の ④)。
  - 出し方 (案。A だけ / A + B を ⑦4 で決める):
    - **A 次の手で狙うの行**: 行の下の「付くまで平均 X」の後ろに「ここまで込み Y」(Y = 今の見込みの累計 + X) を足す。並び (M-31) は変えない。
    - **B 工程**: 工程の右の「累計」の下に小さく「見込み Z」を出す (狙いが一度も付いていない間は実際と同じなので出さない)。
  - 英語 (案、U-60〜62・GLOSSARY に足す): 見込み = "Expected"、ここまで込み = "Total if hit"、見込みの累計 (工程) = "Expected total"。
  - 絵 (A):
    ```
    カオスオーブ + 〇〇のお告げ        32.1%
    3.1 回に 1 回 · 1 回 1.2 · 付くまで平均 3.7 · ここまで込み 12.4
    ```
  - engine.md との食い違い (書き出し): ① aimChain は外れたら「今の状態から」やり直すが、実際の game では消えた MOD を作り直す費用が掛かる。見込みはそれを足さないので、外れでアイテムが壊れる流れでは安く出る (要望の「一直線の時」の目安)。② 見込みは画面の数 (エミュだけの扱い) で、エンジンの確率・費用の決まり (E-80〜82) は変えない。計算はエンジンの aimChain の結果を使うだけ (G-06)。
