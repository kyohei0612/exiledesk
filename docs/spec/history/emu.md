# emu.md の経緯の記録

docs/spec/emu.md の項目の経緯 (前の形・壊れていた訳・気付いた道筋) を書く紙。決まりの正は設計図 (emu.md)。

## M-72b 上に貼り付く帯があればカードはその下に止まる (11-12)

- 前の形: スマホで上に止まるアイテムのカード (M-72、v0.1.693) は、どこに置かれても画面の上 0 に止まった。デイリーの投稿の中のエミュ (D-12、v0.1.689) は、エミュの画面の前に「投稿へ戻る / この品で投稿へ」の帯を上に貼り付けて置くので、下へ送るとカードが帯の上に重なり、帯の 2 つのボタンが押せなかった (390 で重なり 91px)。
- 気付いた道筋: 11-12、投稿の中のエミュの見た目の崩れ (D-12c) の直しの絵 (390) を見たブラック 90 が、帯の字がカードの左右に覗いているのに気付いた。崩れの直しの前の絵でも同じだった = 前からの重なり。
- 直し: カードを帯の高さの分だけ下に止める (`use-pin-top.ts`)。スイッチなしの直し。画面で見た物 = 390 で重なり 0・帯の 2 つのボタンが押せる・英語でも同じ・エミュのタブは上 0 のまま。
