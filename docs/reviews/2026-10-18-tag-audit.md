# MOD のタグと poe2db の照合 (2026-10-18)

オーナー「db みてタグフルチェックして相違ないか調べて」。poe2db は 10-18 に取り直した (`node scripts/audit-poe2db.mjs --refresh`)。
照合は `node scripts/audit-poe2db-tags.mjs` (結果は data-cache/poe2db-tag-audit.json)。比べたのは normal / desecrated / essence (+ perfect) の 9,455 段。
こちらのタグは画面に出す物 (displayTags か tags を shownTags に通した物)、冒涜の陣営 (アマナム・ウラマン・カーガル) は別に比べた。
内部用のタグ (elemental_damage・resource・caster_damage など) は画面に出さないので比べていない。

**v0.1.572 で全部 poe2db に合わせた** (オーナー「db に全て合わせてくれ」)。部位ごとに数えると 93 MOD。直しは src/services/htc/poe2db-tag-fixes.json (`node scripts/audit-poe2db-tags.mjs --write` で作り直す)、当てるのは poe2db-tag-fixes.ts。
決まらない物 1 つ: 3 種類の防御の鎧 (str_dex_int) のエッセンスの防御 % は poe2db に 3 種類全部の行が無いので今のまま (アーマー・回避・ES)。
以下は直す前の食い違い (34 種類)。

## 3. こちらにだけ block / flask がある (16 MOD)
poe2db には block と flask のタグ自体が無い (poe2db のタグは 27 種類)。
- block: LocalIncreasedBlockPercentage・PerfectEssence_IncreasedShieldBlockPercentage・冒涜の GainManaOnBlock・MaximumBlockChance・HeavyStunDecayRate・PhysicalDamageTakenAsLightningWhileActiveBlocking・ParriedDebuff × 2・EnergyShieldRechargeRateIfBlockedRecently・AdditionalBlock (スタッフ)
- flask: ベルトの BeltFlaskLifeRecoveryRate・BeltFlaskManaRecoveryRate・BeltIncreasedFlaskChargesGained・BeltReducedFlaskChargesUsed・冒涜の FlaskChargesUsed × 2

## 4. エッセンス (5 MOD)
- Essence_DefencesPercent (鎧): poe2db はベースの防御の種類ごとのタグ (armour / evasion / ES と組み合わせ)、こちらは部位によって 3 つ全部など。突き合わせの取り違えの可能性もあるので要確認
- PerfectEssence_MartialWeaponGainedDamage (弓・クロスボウ・メイス・クォータースタッフ): 火 / 冷気 / 雷 / 物理の版のタグがずれている (elemental だけ・energy_shield など)
- PerfectEssence_ReducedCriticalStrikeDamageTaken・PerfectEssence_Strength・PerfectEssence_IncreasedShieldBlockPercentage: poe2db はタグ無し、こちらは有り
- PerfectEssence_EnergyShieldRegeneration (フォーカス): poe2db は energy_shield、こちらは無し
- PerfectEssence_LightningDamageCanIgnite (タリスマン): poe2db は ailment・elemental・fire、こちらは無し

## 影響
タグはカタリストの品質で伸びる MOD (指輪・アミュレット・ジュエル)、MOD 一覧の札と検索、陣営はお告げに使う。
