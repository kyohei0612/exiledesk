# 手書きのクラフトの決まりの総点検 (2026-10-14)

オーナー「db との調べもせず手書きで決めたルールは全て db やトレードサイト等の情報にのっとって決めて。土台から」。
クラフトステージ・同梱エンジン・計算機の、人が書いた決まり (数値・確率・使える条件・上限・特別扱い) を約 130 個洗い出し、根拠で分けた。

- **A** = クライアントのデータから引いた / オーナーがゲームで確認した
- **B** = poe2db・poe2wiki・Craft of Exile・コミュニティの実測が根拠
- **C** = 根拠が無い・仮・等分

部位の種別の作り替えは [2026-10-13-item-class-audit.md](2026-10-13-item-class-audit.md)。

## 今回確かめて直した物

| 決まり | 確かめた所 | 結果 |
|---|---|---|
| 上級・完全の段の下限 (変成・増強 44 / 70、王者・高貴・カオス 35 / 50) | poe2db の各カレンシーの Minimum Modifier Level | エンジンとステージは合っていた。**計算機だけ変成・増強が 35 / 50 → 44 / 70 に直した**。カオスの 35 / 50 は C → A |
| ガラス職人の玉 (フラスコの品質) | オーナーのゲームでの確認 (1 固定) | **1 / 2 の抽選に入っていた → 1 固定に直した** |
| ネクロマンシーのお告げで側が満杯 | poe2wiki「満杯なら 1 つ消して同じ側に付く」 | 骨は打てるのに一言が「打てない」だった → **「1 つ置き換える」に直した** |
| 勢力のお告げと矢筒 | Craft of Exile のデータ (冒涜の手のお告げに部位の縛り無し) | C → B。文言にも矢筒を入れた |
| アーティフィサーとセプター | Craft of Exile (セプターのベースにソケット 1) | C → B |
| セプターの骨 | poe2wiki「Sceptres do not have exclusive desecrated prefixes or suffixes」 | 専用の冒涜 MOD が無いだけで骨は打てる (候補は普通の MOD)。**10-13 に隠したのを戻した** |
| ヴァールの 4 つの結果を各 1/4、書き換えは 1〜3 回 | コミュニティ (4 つは同じ確率、書き換えはカオスのような物を 1〜3 回) | C → B (ヴァールは棚に無い) |
| 骨の側: 満杯なら消した側、片方だけ空きならそちら | poe2wiki・mobalytics | 合っていた (A/B) |
| 削りのお告げ: 未発現の冒涜も消せる、MOD レベル 1 として数える | poe2wiki | 合っていた |
| 専用の冒涜 MOD は「アイテムレベル 65 以上くらい」から、防具 4 部位には専用のプレが無い | poe2wiki | データと合っていた |
| マジックの枠に暗黙の「±N 個」 | オーナーのゲームでの確認 (不在のアミュレット) | **直した** (v0.1.510) |
| 「兜として得る」ベース (コロナなど) のソケット | オーナー「デフォで必ず 1 個以上」 | **白の時からソケット 1、ルーンは兜 / 手袋 / 靴として** |

## 計算機の画面の不具合 (対象外: アプリの計算機は廃止予定、2026-10-14 オーナー「無視でタスク切っていい」)

- 計算機の冒涜は古い作り (普通 + 冒涜を重みで 3 回別々に引く。専用 MOD の個数の割合を使わない) — step-odds.ts、sim-route-helpers.ts
- 計算機のカタリストはジュエルを数えない — htc/quality.ts
- 計算機のクラフト上限はアストリッドを +1 固定 (ルーンの効果の伸びを見ない) — htc/sockets.ts
