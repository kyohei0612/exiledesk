# 盛った値をそのまま出している所 (S2d) — 案だけ、直すのは J8 の後

オーナー 10-20「MOD の数字は、上乗せを全部抜いた MOD の素の値 (デフォの値) と段で出す」。抜く物 = 品質 (種類つき)・ルーン・ソウルコア・側の効果 (「サフィックスの効果が X% 上昇」) など全部。割り戻しはジン部長がエンジンの入口に 1 か所で作る (J8)、画面はそれを呼ぶだけ。

| 所 | 今の出し方 | 盛った値か | 直し (J8 の後) |
|---|---|---|---|
| ① 貼り付けの結果の MOD の行 (SimPasteRead の `m.text`) | 貼った文のまま (見本 3 の冷気 36〜55 = 品質 (アタックモッド) +50% で盛られた値) | **盛ったまま** | 素の値 + 段 (`m.tier`) で出し、盛った値は小さく添える。行ごとに盛られたかの印は J7 (ジン部長) |
| ① 貼り付けの暗黙の行 | 貼った文のまま | 盛ったまま (品質・コラプトの強まり) | 同上 (暗黙も J8 の割り戻しに入るか、ジン部長に確かめる) |
| ① の品質の ? (S1e) | 「割り戻して段を出している」の断り | — | J8 で素の値を出すなら **外す** |
| ② 狙いの行の文 (use-target-rows の `fillModText(… tierDisplayRanges)`) | 段の幅 (MOD の表の値) | 素の値 | そのまま |
| ② の「貼った値は … で盛られている。段の幅は素の値」(S1e、use-target-share の pastedQuality) | 断りの 1 行 | — | ① で素の値を出せば **外す** |
| ② の %・注記 | 段の割合 | 値ではない | そのまま |
| ② の MOD の一覧 (StageModList、エンジン部の部品) | 段の幅 | 素の値 | そのまま (ルーンを差した時の幅はエンジン部に確かめる) |
| ②-b 整理の名前 (SimTargetSort の nameOf) | 段の幅 | 素の値 | そのまま |
| ③ 貼り付けからの 1 行 (SimStartPick「品質 +50% は持ち越さない」) | 品質の数 | 値ではない | そのまま |
| ④ 順番の表の文 (use-sim-targets の rows `fillModText`) | 段の幅 | 素の値 | そのまま |
| ⑤ アイテムのカード (StageItemCard、エンジン部の部品) | 打った後の値。ルーンを差した白から始める時はルーンの効果の値、品質は始めは 0 | ルーンの効果は盛られた値になりうる | エンジン部の部品なので J8 の時にジン部長と。シミュ側は触らない |
| ⑤ 答えの文 (quiz-text の whenText・StagePatternEditor の `fillModText`) | 「T3+」の段と段の幅 | 素の値 | そのまま |
| ⑥ 結果・費用の内訳 | 費用と回数 | 値ではない | そのまま |

- まとめ: 盛った値をそのまま出しているのは **① 貼り付けの結果 (MOD と暗黙の文)** だけ。② 以降は MOD の表の段の幅で出していて素の値。⑤ のカードはエンジン部の部品で、ルーンの効果の値は J8 の時に確かめる。
- S1e で入れた断り 2 つ (① の品質の ?・② の「段の幅は素の値」) は、① で素の値を出せば要らなくなる → J8 の直しの時に外す。
