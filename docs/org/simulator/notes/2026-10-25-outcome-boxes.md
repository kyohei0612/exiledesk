# 付いている MOD を消す・置き換える手の結果の箱 × エンジン (シミュ 28 本目、10-25 夜)

オーナー 10-25「見直すのはエッセンス系と消去系かな ついてるMODに対しての処理のツリーが微妙な気が」。
アイテムの形 (Lapis Amulet、狙い = プレのスピリット T1・サフィのキャスト T1、始めのアイテムに付けた形) × 手 (お告げあり・なし) で、
木が作る結果の箱 (tree-hand-plan の hitAimsOf → onlyOf → applyPick = 手の窓と同じ) と、エンジンで 400 回打った結果 (tree-sample の playHand = エミュと同じ入口、outcomeOf で分ける) を並べた。
台本は 28 本目の scratchpad の outmatrix.mjs (ONLY=手の名前の一部 で絞る)、結果の写しは共有メモ sim28-outcome-matrix.txt。

## 見つかった食い違いと直し
1. **始めから付いている狙いを木が狙いと数えていない** (全部の手): aimsOf は当たりの箱の札だけで、スタートの「＋ 外れを狙いに差し替える」で付けた狙いが消える結果を「外れが消えた」と数え、「狙いが消えた」の箱も作らなかった (消去・カオスは振り分け先が無く止まる)。→ aimsOf と tree-lost (heldOnPath・aimsMayHold) に始めの狙いを入れた (startGoalAims)。
2. **冒涜 (骨) は起こりうる結果を見ずに手の種類の箱 (当たり・外れ) だった**: 満杯の側に死霊術で打つと 13〜14% 狙いが消えるのに箱が無い。→ 発現で決まる当たり / 外れはそのまま、消える側 (狙いが消えた) は発現の前の stepOutcomes で見て足す。
3. **狙いが全部付いていて外れしか出ない手 (削減のお告げのカオスなど) が手の種類の箱に戻り、起こりえない当たりの箱が出た** → 外れだけの時に手の種類へ戻すのは、まだ付いていない狙いがある時だけ。
4. 冒涜の外れに打つ無限のパーフェクト (B の箱) は前の確かめどおり: サフィが満杯で、エンジンの「付ける側が埋まっていればその側から消す」(spec/parts.ts の sideWhenFull) によりサフィの外れしか消えない = 「打った後」1 つで合っている。サフィに空きがあればスピリットも消える (97 / 200)。

## 直した後
- パーフェクトエッセンス (強化・無限・合金)・消去 (左右のお告げ)・カオス (左右の抹消・削減)・冒涜 (左右の死霊術) × 満杯 / プレに空き / サフィに空き / 両方空き: 木の箱とエンジンの結果の種類が全部合う。
- 残る違い 1 つ: 両方空きのカオスで「外れ」の箱が 400 回では出ない (狙いを消して同じ狙いがまた付くまれな形、エンジンの一覧には有るので箱は正しい)。
- 「打てない」の行 (足す側が埋まっていてお告げの側から消せない・意味の無い死霊術) は、エンジンも同じ理由で打てない。
- 不在のアミュレット B 2 つ: 精査 合格・300 人 完成 300、使った個数は前と同じ (高貴は埋めるだけの B は冒涜の箱に「狙いが消えた」が増えた = 埋める高貴でキャストが付く見本があり、死霊術で消えうる)。
