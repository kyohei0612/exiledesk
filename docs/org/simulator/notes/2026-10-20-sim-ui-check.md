# シミュレーター UI 点検 2026-10-20 (シミュ部長)

開発版 (v0.1.588) を窓なし Chrome 1 タブで、1660×860 と 375×812 (touch) で ① → ⑤ を通しで触った (貼り付けの見本 3 = グラスピングリング・二重コラプト。⑥ は ⑤ の打ち方が空で押せず未確認)。スナップは消した (残していない)。コードは触っていない。
形: 重い順、1 行 1 件 = 【場所】何が困る → 直し方の案 (担当)

1. 【① 貼り付け → ②〜⑤】貼り付けで読んだ「アイテムレベル 82・品質 +50%・二重コラプト・未発現サフィックス」が ③ ⑤ に引き継がれない。③ は 75 (狙いが全部付く最低レベル) に戻り、② の % は「アイテムレベル 86 の時」、⑤ のアイテムカードは「アイテムレベル 75・MOD なし・品質なし」。貼った物と別の物で回すことになる → 貼り付けから始めた時は ilvl・品質・コラプトを持ち越し、② の注記も実際の ilvl で。持ち越せないなら「始めの状態は白ベース」と明記 (シミュ / ジン部長)
2. 【① 貼り付けの結果】読めない行が 3 本 (暗黙「ソケット…手袋」・「ダメージが56%増加する」・「ゴールド 10%」) 。暗黙 MOD に印が無い見本 (見本 3 の特徴) の暗黙・MOD が「読めない」に落ち、理由 (このベースに付く MOD に無い) も利用者に分からない。「T1?」の ? も説明なし → 暗黙はベースの暗黙と照らして「暗黙」として取り込む。? は押すと理由 (シミュ / ジン部長 = 読み)
3. 【④ おすすめの順番】貼り付けた物 (フラクチャー無し) では必ず「出せない (自動の順番はフラクチャー済みから始める時だけ)」。ボタンを押させてから断る。1 本目の「外した時の取り直し (目安) 約 58.3 神」は出るが 2 本目 (品質の最大値) は空欄で意味不明 → 出せない条件なら押す前にボタンを灰色 + 1 行の理由、取り直しの空欄は「—」でなく 0 か「無し」(シミュ / ジン部長 = 自動の範囲)
4. 【④ スマホ】順番の表: 「外した時の取り直し (目安)」の列が幅を食って MOD の文が 5〜6 行に折れ、ドラッグの取っ手が左右に 2 つ、「プレフィックス」が「プレ」に切れる → スマホは 1 行 1 カード (上に文、下に付け方・取り直し)、取っ手は 1 つ (シミュ)
5. 【② 次へ → 付け方の整理】「次へ」を押すと、工程の帯は 2 のまま同じページの中で「付け方が同じ MOD の整理」(全部 / この中のどれか) に変わり、「← 狙う MOD に戻る」「決めた →」が出る。ボタンの名前が「次へ」「決めた」と揃わず、小さな灰色の「全部 (2 つ)」「この中のどれか」が選ぶ札と分からない → 帯に「2-b 付け方の整理」を出す、または ② の下に常に出して「次へ」1 つに、札は選んだ方を濃く (シミュ)。※ 流れの大きな変更なので案だけ。自動/手動の設計の部長と調整
6. 【③ 値段】白ベースの値段を入れないと「次へ」が灰色のまま。理由は右上の小さい文 (分からなければ 0) だけで、入力欄に「値段」の薄い字しか無い。単位の既定が「カオス」なのに ④ の帯・計算は「0 高貴」 → 入力欄の上に「分からなければ 0」を置く、または既定 0 で押せる。単位は表示通貨に合わせる (シミュ)
7. 【スマホ ② 〜 全工程】画面の上 700px くらいが 広告 + ヘッダー + 為替の選択 + アイコンだけの 5 つのボタン (保存・共有・リセット・1 つ戻す・ヘルプ。何のアイコンか分からない) + ベースのカード + 工程の帯で、工程の本体が 1 画面に入らない。工程の帯は横に流れ、4〜6 (灰色) は右に隠れる → 工程の帯と本体を先に、ツールのボタンは 1 つの「…」にまとめるか下へ。リセットは文字付きに (シミュ / 開発 = 共通のヘッダー)
8. 【① PC 1660×860】貼り付けの枠を開くと、結果の「これで始める」がページの下 (943px、画面 860 の外) に出てスクロールしないと見えない。貼ってもボタンが見えず止まったように見える → 結果を貼り付け欄の右に置く、または「これで始める」を枠の上に固定、貼った後に自動で結果へスクロール (シミュ)
9. 【⑤ 打ち方】「答えた 0 / 残り 1」「この時は?」「この答えを使う場面」「見る A/B/ノーマル」「細かい項目 (未発現・冒涜の外れ・固定・ルーン)」と用語が多く、初めて開いた人は何を押すか分からない。⑤ は最初の画面から文字が多い (PC で 1 画面に入らず「回す」ボタンが画面の下端に切れる) → 初期は「手を足す」だけに絞り、場面の札・細かい項目は閉じる (feedback-minimal-text-ui)。「回す」は下に固定 (シミュ)
10. 【⑤ スマホ】「回す」「取引所で見る」「1 人の上限」が最下部で、棚をたくさん持つ間に見失う。手に使う棚 (カレンシー) のボタンは大きいが、設定の文・チェック「パターン 1 答えが無い・回さない」が小さい → 下に固定の帯 (web-phone-layout の決め) に「回す」 (シミュ)
11. 【チュートリアル 段 5 のクラフト手順】コースを始めると上に「次へ →」(灰色) + 4 つの小さいボタンが並び、押す物は下の「ブリーチのエッセンス」(灰色に見える持ち物の絵) だが、「これを使ってみる」の文が箇条 4 つ (T1・上級コースの名前を含む) で長い。押せる物が分からない。進み具合「0 / 3」は一番下で、操作から遠い → 「次に押す物」を光らせる・1 文に、箇条は閉じる、進みを上へ (シミュ)
12. 【② 画面全般】「% = 1 回付く時に、その段以上が出る割合 (アイテムレベル 86 の時…)」の注記が小さな薄い文で、% が何か分からない。貼り付け後の 0.3% は ilvl 82 でも 86 の数 (1 と同じ原因) → 1 と一緒に直す (シミュ)
13. 【使い方・コツのページ】段ごとのコースの説明文が長い (1 つのコースに 60〜100 字、全 12 コース) → 既定は題と手数だけ、説明は ▼ で開く (シミュ = チュートリアル)
