## 開発版を本物のマウスで触って見つけて直した物
- 「100%」を押すと、全体の真ん中 (枝と枝の間の空き所) に出てどこを見ているか分からない → 一望から等倍に戻す時と開いた時は、始まりの箱を上の真ん中に (use-tree-view.ts の resetZoom・goHome)。読み込んだ直後も始まりが右端で切れて出ていた (前からの不具合)。
- 戻り先の札に乗せた時の線: ツリーの外側を大回り → 画面の外へ出て戻り先が分からない → 上の辺へ入れる曲線 → 自分の箱と戻り先を突き抜ける → **箱の横の辺から戻り先の同じ側の横の辺へ、外へふくらむ弧を箱より前に**、で落ち着いた。
- 手の間も箱の × と ＋ が見えて押せそうだった → 隠す。
- メモの窓が右の欄を避けた先で、右下の道具とミニマップに重なった → 道具も避ける。
- ミニマップの地が透けて後ろの箱が見えた → 不透明に。
- 1920 幅 (zoom 1.16) でツリーの枠が画面より高く、ページごと下へ送られた (前からの不具合、100vh が拡大前の高さ) → 高さを zoom で割って出す。
- 整列の説明 (title) が「戻りの矢印は箱の外側」のまま → 今の形に。
