# シミュの死蔵の洗い出し (2026-10-22、係「シミュ；死蔵の洗い出し」)

ツリー特化 (旧 ①〜⑥ の工程ページを消した c16ea55f、クラフト台の中の ①〜④ を外した f5aa9aaa) の後に、どこからも使われなくなった物の一覧。**読んだだけで何も消していない。** 消すのはシミュの物はシミュ部長、共通の物はジン部長、エミュの画面はエミュ部長、auto/ の計算は解析君。

## 見方
- import のグラフを台本で作った: 入口 web.html → src/web/main.ts (Web) / index.html → src/main.ts (アプリ) / scripts・tests の全部。`import … from`・`import()`・`new URL()`・`import.meta.glob<…>()` を読む (WebApp.vue の DailyPage は glob で引いている)。「Web から辿れない」= main.ts から辿れず、台本・テストだけ、またはどこからも。
- export ごとに、他のファイルの中の同じ名前 (単語) を数えた。コメントの中の名前も数えるので、取りこぼし (消せるのに残る) はあっても、消してはいけない物を「消せる」とは言わない側。`self=0` = 自分のファイルの中でも使わない (関数ごと消せる)。
- 文字で引く物: ?page= は src/web/page.ts の applyPage、?sample= は SimTreePage の treeSample、#recipe= は recipe-share の openSharedRecipe (どれもツリーの物で生きている)。
- **mode "sim" は今は止まらない**: 本番 (SIM_LOCKED) は state/craft-stage.ts:151 の watch (flush sync) で hand に戻し、開発版は CraftStage.vue:261 の watch で hand に戻してツリーを開く。だから共通・エミュの画面の `s.mode.value === 'sim'` の枝は全部届かない (ベースのページの「シミュレーター」タブ = ツリーへの入口のボタンだけは生きている)。アプリ (Tauri) も同じ CraftStage を通るので同じ。
- 台本は scratchpad に置いた (リポジトリには入れていない)。同じ事は `pnpm -s exec vue-tsc` では出ない (export の未使用は型チェックで落ちない)。

確か = 使い手が 0 で、消しても型チェックと画面に響かない見込み。要確認 = 持ち主の判断が要る (台本・テストが使う・作り直しで使うかも・前の保存を読む)。
