# ツリーの土台を Vue Flow に入れ替え (2026-10-23、シミュ部長 2 本目)

頼み: オーナー 10-22「Vue Flow を入れて、拡大縮小 (ページの CSS zoom) は中身を読んで合わせて実装」「計算は入れずに動きや表示を完璧に」。合格まで次の段 (100 人回し・全部のベース・保存 / 共有) に進まない。

## 作り
- `@vue-flow/core` 1.48.2 (版を固定、99aeaba0)。背景・ミニマップ・ツールバーは自前 (TreeCanvasTools)。
- **ページの zoom との合わせ方**: ツリーの枠 (`[data-tree-canvas]`) に `zoom: 1/Z` を掛けて打ち消し、枠の中を実質 1 倍に。Vue Flow の倍率は Z 倍で持つ (画面の「100%」= Vue Flow の zoom Z、use-tree-flow.ts)。Vue Flow 1.48.2 の `pointer()`・`getEventPosition()` を読み、枠の getBoundingClientRect とマウスの clientX がどちらも拡大後のピクセルである事を確かめた上で。
- **Vue Flow に任せる**: 空き所の引っ張り (画面の送り)・ふつうのホイール (縦に送る、Shift で横)・Ctrl + ホイール (マウスの所を軸に拡大縮小)・箱を押した判定 (node-click)・空き所を押す (pane-click)。
- **自前のまま**: 箱の引っ張り (use-gesture.ts。Vue Flow の nodeDragThreshold は遊びの 5px 分を動きから抜くので、マウスより遅れた)、＋の押す / 長押し、メモの窓、ミニマップ、戻りの札。
- **線・打つ手の札・引っ張る線・戻りの弧**は Vue Flow の `zoom-pane` (倍率と移動が掛かる層) に描く。線は z-index −1 で箱の後ろ。
- 箱 (TreeBox) は Vue Flow の独自の箱 (`#node-box`)。中のボタンは `nodrag`。`nopan` は付けない (付けると箱の上のホイールで画面が送られなかった)。
- 全体表示は自前 (右下の道具の幅 250px を空けて収める。fitView では右下の箱がミニマップの下に隠れた)。開いた時・一望から 100% は始まりの箱を上の真ん中に。
- 消した物: use-tree-view.ts (自前のスクロールと scale)。

## 残り
- 共通の部品 src/utils/overflow-guard.ts (ジン部長): transform で送った Vue Flow の層を「はみ出し」と数え、開発版でツリーに赤い枠が出る。祖先に `[data-overflow-ok]` がある物を数えない 1 行を頼んだ (ツリーの枠には付けてある)。
- 解析君の `back: "match"` (形の合う箱へ)・`"restart"` (作り直し) を画面で選べるようにする (合格の後)。

## オーナーに触ってもらう時の確かめる点
1. 開いた時: 始まりの箱が上の真ん中・ページが下にはみ出さない。
2. 空き所を引く → 画面がマウスに付いてくる。ふつうのホイール → 縦に送る (Shift で横)。Ctrl + ホイール → マウスの所を軸に拡大縮小 (ブラウザの拡大は起きない)。
3. 箱を押す → 右に試し打ちの欄。空き所を押す → 欄が閉じる。
4. 箱を引く → マウスと同じだけ動く (押しただけでは動かない)。1 つ戻す / Ctrl+Z で戻る。
5. 下の＋を押す → 打つ手の棚。長押しで引っ張る → 曲線がマウスに付く・重なった箱が光る・箱の上で離すとつながる (窓は出ない)・何も無い所で離すと何も起きない。
6. 箱の下の「↩ 戻り先」に乗せる → 弧と戻り先が光る。押す → 戻り先へ寄る。
7. 右下: 選択 / 手 (手の時はどこを引いても画面が動き、箱のボタンが隠れる)・全体表示 (右下の道具に箱が隠れない)・− 倍率 ＋・ミニマップ (押す / 引くとそこへ)。「1」で全体表示。
8. 75% 未満は見るだけ (左上に札、箱を押すとそこへ寄る)。75〜99% でも押せる物は 24px 以上。
9. メモの窓: 題の帯・見た目の上の枠で動く、端と角で大きさ、ダブルクリック / 最大化ボタン / Esc で最大化と戻す、最大化中に題を引くと元の大きさでマウスに付く、閉じる。右の欄・右下の道具を避ける。
10. 幅を変えても (ブラウザのズーム 125% を含む) 上の全部がずれない。
