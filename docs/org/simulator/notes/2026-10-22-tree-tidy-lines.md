# ツリーの整列の定義と＋の引っ張り (2026-10-22、シミュ部長 2 本目)

頼み (オーナー 10-22、ブラック経由): ①「整列でこのざま? クソ汚い。整列の定義を詰めて」(戻りの矢印 5 本がツリーの外側を四角く回って枠のように囲み、色の違う曲線が手の札に何本も集まる)。②「＋を引っ張った線が直線すぎてキモい」・何も無い所で離したらやめる・箱の上で離したらつなぐ (打つ手の窓は出さない)・重なった箱を光らせる。
直す前と後: 共有メモ tree-tidy2-before.png・tree-tidy2-after.png (同じ木: 始まり → カオス → 当たり 4 + 狙いが消えた + 外れ、戻り 5 本)。

## 整列の定義 (今の形)
1. 進む線 (親 → 子) は普通の木の図の直角の線: 親の下から 1 本下りる (途中に手の札) → 子の段の 18px 上で横の棒 → 子の上の辺へ下ろす。扇の曲線は無し。
2. 親は一番左と一番右の子の真ん中 (兄弟の並びの中心が親とそろう)。子は部分木の幅を先に測って詰めて並べる (間 28px、外れは一番右)。段の間は 210px (手の札と横の棒が重ならない広さ、前は 190)。
3. 戻りの矢印は既定では引かない。箱の下の札「↩ 戻り先」に乗せた時だけ、箱の下 → ツリーの外側 → 戻り先の横の辺の線を 1 本出し、戻り先が光る。押すとそこへ寄る。
4. 線の色は 進む = 灰・外れ / 消えた = 赤系・戻り (乗せた時と引っ張る時だけ) = 水色 の 3 つ。

## ＋の引っ張り
- 引っ張る線はベジェの曲線でマウスに付いてくる、箱より前に描く。
- 箱の上で離す = つなぐ (下の＋ = その箱へ戻る、打つ手の窓は出さない / 横の＋ = 新しい当たりを足してその箱へつなぐ。新しい当たりは MOD が要るので MOD の欄は開く)。何も無い所で離す = やめる (何も変わらない)。前の「空き所で離すとそこに箱を置く」(placeOuts) は消した。
- 引っ張っている間、重なった箱が光る。

## 確かめた物
- 画面 (窓なし Chrome 1660×860): 同じ木で整列 → 直角の木の形 (スナップ)。札に乗せる (devtools の hover) → 戻り先が光り外側を回る線が 1 本。＋の引っ張り: 途中の曲線がマウスに付いてくる (スナップ) / 何も無い所で離す → ツリーの保存が前と同じ・窓なし / devtools の drag で始まりの箱へ → 戻りがつながり窓なし / 狙いが消えたの箱に重ねる → その箱が光る → 離すとつながる。引っ張りの途中の様子は pointer の事を台本で送った (drag の道具は途中で止められない)。
- 数え (台本、SVG の線と箱の四角): オーナーと同じ木 7 箱で 交差 0・箱を通る線 0・外側を回る線 0・曲線 0・兄弟のずれ 0・出ている戻りの線 0。1 段深い木 14 箱でも全部 0 (直す途中で兄弟のずれ 2 が出たので 2 の形に直した)。
- 見張りのテスト・外の正解は無し。型チェックと入口の見張り (増えた所なし) は通った。
