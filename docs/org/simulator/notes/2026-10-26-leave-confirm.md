# 作りかけの木を失う入り口と確かめ (2026-10-26 シミュ部長 29)

オーナー 10-26「シミュレーターからエミュクリックしたら保存聞かれなくね」「基本ツリーから離れる時だね、他のページ行っちゃうときが特にかな あとツリー消す作業とかもろもろ」「保存しますかって聞かれたら保存でおｋ」。モンキー 6 の穴探し (docs/org/monkey/notes/2026-10-26-monkey-spec.md) の 4 件も。

## 決め
- 作りかけ = 開いているレシピがあればそれと違う、無ければ完成の狙いか手 (箱 2 つ以上) がある (tree-save.ts の unsaved)。前は「箱 2 つ以上」だけで、ベースと狙いを決めて手がまだの木は聞かずに消えた (本番 v0.1.606 で再現、オーナーの場面)
- 確かめは全部同じ窓 (src/web/LeaveConfirm、デザイン部長 a7bb8565・84d5d0cf) の 3 択: 保存して進む (名前は聞かず自動の名前、開いていたレシピは上書き = tree-save.ts の quickSave) / 保存せず進む / やめる。ページを移る時は setLeaveGuard の save、移らない操作は askLeave
- 聞かない: 保存済みのまま・白紙 (ベースだけ)・新しいタブで今の木が残る時
- 保存したレシピへ戻る: 離れる・閉じる時に開いていたレシピをこのタブの間だけ覚え (sessionStorage)、ツリーのページへ戻る・読み直すとそれを開き直す (tree-save の rememberResume / takeResume)。持ち越さない決め (10-24 夜) とは別 (保存済みのレシピを開くだけ、保存していない木は白紙から)
