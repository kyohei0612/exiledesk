## 手順 (箱の並び)
**B (動画の主の手順)**: カオスを当たるまでスピリット T1 (MOD 4 つのまま) → 右側の消去でサフィの外れを消す (✦ は消えない) → 冒涜 (保存された鎖骨 + 反響) でキャスト T1、外れは光 + 消去で冒涜を消して打ち直す → ルーンワード + 左側の結晶化 = **50/50** (スピリットか外れが消える) → 勝ち = 完成。
負け (プレ = 外れ + ルーンワード、サフィ = ✦ + 冒涜のキャスト) → 光 + 消去でキャストを消す (冒涜は 1 つまでなので、キャストを消さないと付け直せない) → カオスを当たるまでスピリット → 分かれ目:
ルーンワードが残った = 冒涜でキャスト → 完成 / プレがスピリットだけ + サフィに外れ = A の流れ (右側の結晶化でルーンワード → 冒涜でキャスト) / それ以外 = B の形に戻って 50/50 をもう一度。

**A**: 左側の消去でプレの外れを 1 つ消す (MOD 3 つ) → カオスを当たるまでスピリット T1 → 分かれ目: プレがスピリットだけ + サフィに外れ = ルーンワード + 右側の結晶化 (サフィの外れを消す、確定) → 冒涜でキャスト T1 (外れは光 + 消去) → 完成 /
それ以外 (プレ = スピリット + 外れ、サフィ = ✦ だけ) は B と同じ 50/50 の道 (負けの戻りも同じ)。
- 頼みの A は「ルーンワード → 最後に冒涜でキャスト」。不在のアミュレットはプレ 2 なので、プレがスピリット + 外れで満杯の時は右側の結晶化が打てない (「足す側が埋まっているので、お告げの側からは消せない」)。そのため A の前に左側の消去で枠を空けた。それでもカオスでプレに外れが来た人 (約 2 割) は 50/50 になる

## 組めなかった手・シミュの足りない所
1. **反響で何度も選び直す冒涜 (動画の「heart of the well trick」)**: 木の冒涜は 1 回 = 骨 1 + 反響 1、外れたら光 + 消去で消して打ち直すしかない。動画は 1 つの冒涜を反響だけで何十回も選び直す (骨・光を使わない)。この差で費用が 6〜8 倍違う。手としてあれば一番効く
2. 右側の死霊術: プレが満杯の時は「今は意味なし」で掛けられない (冒涜はサフィにしか付かないので要らない)。木では素の骨 + 反響。動画の主は掛けている (費用は少し増えるだけ)
3. 品質 40 (動画は最初にカタリストで品質 40、キャストの値を上げるため): 段 (T1) には関係ないので木に入れていない。カタリストの費用は数字に入っていない
4. 50/50 の負けの戻り: 冒涜は 1 つまでなので「スピリットを付け直す」には先にキャストを光で消すしかない (猿の灰色も「冒涜の MOD はアイテムに 1 つまで」)。それで A の流れ (カオス → 分かれ目) にした。キャストを残して左側の高貴でスピリットを狙う別の戻りは組んでいない
5. 手のある当たりの箱の後に分かれ目 (行は「それ以外」だけ) を挟んだ: 当たりの箱に直接手を付けると、着いた形 (狙いの側の外れ) が道と違う時に tree-run の settle が深い所の外れの箱へ移し、止まった (B で 99 人)。画面で組む人も同じ所でつまずく
6. 負けの後の光 + 消去は見本では結果が 1 通り (狙いが消えた) になるが、まれに外れが消えた形でも着く (プレがスピリットだけで負けた人、100 人中 1 人止まった) ので結果の箱を 2 つ置いた。B のカオスの後にサフィが ✦ だけの人 (MOD 3 つ) もまれにいて、消去を飛ばす行を足した
7. 残りの止まり: B の 1000 人で 2 人 (b6、冒涜の外れの光 + 消去の結果が「狙いが消えた」)。木では直していない
8. ルーンワードを合流させた: ルーンワードが残った形の完成の箱を別に作ると、道に「狙いが消えた」が 2 つ挟まり、精査が「狙いが 2 つしか揃わない完成」と言う (実物は 3 つ揃う)。A の流れの冒涜の箱へ戻して穴 0 にした
