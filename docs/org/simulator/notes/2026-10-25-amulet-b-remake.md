オーナー「これを元に新しいレシピ作り直して今あるアミュレットのBを 全然UI違うから あと最初だけどMOD２つ付けるルートじゃなくて１MOD付けてカオススパムを軸として」→「1 でいい、エッセンスで回すとこ残して なんかめっちゃ通貨かかってる報告あったから」。分かれ道の箱は入れない (オーナー「分かれ道設定もないでしょ今」)。

- 不在のアミュレットはプレフィックス 2 つまで (完成 = プレ スピリット・ルーンの守り、サフィ ✦ 呪文レベル・キャスト)。
- 台本: 27 本目の scratchpad の newb.mjs (手順の表 plan-*.json で組んで精査と 300 人)。

## 組めた形 (I、共有 URL は共有メモ sim27-recipe-b-new-url.md)

## 無限のエッセンスで回す形 (シミュ 28 本目、10-25 夜) = 組めない
- J の鍵 essence:perfect:Amulets/PerfectEssence_PercentageDexterity は、エンジンのデータ (src/services/htc/essence-keys.json) では「無限のパーフェクトエッセンス」(Perfect Essence of the Infinite、名前は items-ja-poe2db)。付くのは筋力・器用さ・知性の付いていない系統から等しく 1 つ (apply-essence の pickInfinite)。27 本目の「器用さのエッセンス」は MOD の id で書いただけで、もう無限で試していた。
- アミュレットの無限はパーフェクトだけ (レッサー・普通・グレーターの鍵は無い。あってもマジックにだけ打てる)。ルーンの守りは「ルーンの合金」(Runic Alloy、合金 = パーフェクトと同じ手)。
- 止まる理由: 無限のパーフェクトエッセンスも合金もクラフト MOD で、上限は 1 つ (spec/judge の craftedSlot、アストリッドの創造性で増える)。ルーンの守りが付いた後の冒涜の外れには打てず、無限を先にすると最後の合金が打てない。

## お告げ無しで組む (シミュ 28 本目、10-25 夜、オーナー「お告げ使わんやろBは」) = 上限で止まる人が多く組めない
- 古い B (23 本目の URL) もお告げ無しではない: 冒涜 + 右側の死霊術 + 深淵の残響、外れは無限のパーフェクト + 右側の結晶化 か 光 + 消去、合金 + 左側の結晶化。
- 合金 (ルーンの守り) の決まり (エンジン): ✦ だけには打てない (消せる MOD 0 のレアだけ消さずに付く)、打つと ✦ 以外から等しく 1 つ消す、クラフト MOD 1 つまでなので付いた後は打ち直せない。→ 先に打つ (高貴 1 つ → 合金でそれを消す) か、最後に 1 つ足してから打つ (1/3〜1/2)。
- 高い所はスピリット T1・キャスト T1 の付きにくさ。手元 1440 の DIAG (10 人、箱に着いた回数) で: お告げ無しの冒涜でキャスト 663 回中 7 回、高貴でキャスト 573 回中 8 回・スピリット 1013 回中 4 回、片方を持ってカオスでもう片方 1160 回中 5 回。外れを消去・カオスで消すと半分は持っていた方が消え、カオス 400 回ほどのスピリット集めに戻る。
