# 不在のアミュレット B の作り直し (シミュ 27 本目、10-25)

オーナー「これを元に新しいレシピ作り直して今あるアミュレットのBを 全然UI違うから あと最初だけどMOD２つ付けるルートじゃなくて１MOD付けてカオススパムを軸として」→「1 でいい、エッセンスで回すとこ残して なんかめっちゃ通貨かかってる報告あったから」。分かれ道の箱は入れない (オーナー「分かれ道設定もないでしょ今」)。

- 元: 23 本目の共有 URL (共有メモ sim23-recipe-b-url.md)。✦ 呪文レベル → 高貴 3 回で外れを埋める → カオス当たるまで (スピリット) → 分かれ目 → 冒涜 + 右側の死霊術 + 深淵の残響 (キャスト)、外れは完全なエッセンス (器用さ) + 右側の結晶化 か 光 + 消去 → 完全なエッセンス (ルーンの守り) + 左側の結晶化。
- 不在のアミュレットはプレフィックス 2 つまで (完成 = プレ スピリット・ルーンの守り、サフィ ✦ 呪文レベル・キャスト)。
- 台本: 27 本目の scratchpad の newb.mjs (手順の表 plan-*.json で組んで精査と 300 人)。

## 組めた形 (I、共有 URL は共有メモ sim27-recipe-b-new-url.md)
start (✦) 高貴 [スピリット・キャスト] → 外れ・キャストが先 = カオス 1 回ずつ (2 MOD なので外せるのは 1 つだけ、自動の矢印でくり返し) → スピリット (✦ + スピリット) に右側の高貴 (狙い無し) → 完全なエッセンス (ルーンの守り) + 右側の結晶化 (消せるサフィは足した 1 つだけ) → 冒涜 + 深淵の残響 [キャスト] → 完成。冒涜の外れは光のお告げ + 消去 → 冒涜の箱へ。
精査 合格、300 人 完成 298・平均 393.9 神 (中央 322)。内訳: 光のお告げ 31.5 個 × 10.59 = 333.5 神 / カオス 384 個 × 0.1 = 38 神 / 消去 9.4 / 冒涜 7.2 / 残響 2.3 / ほか 1 未満。

## 比べた形 (どれも同じ始め・同じスピリット・ルーンの守りまで)
