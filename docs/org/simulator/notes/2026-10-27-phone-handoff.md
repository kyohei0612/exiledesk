# シミュのスマホ版 — 引き継ぎ (10-26 夜〜10-27、係「シミュ；スマホ版」)

宛先はブラック 13 代目。オーナーの頼みは全部 push 済みで、まだ本番には出していない (オーナーが手元の固定版 1461 でまとめて確かめる)。

## 今の形 (767px 以下 = スマホの形。指の端末かどうかでなく画面の幅で決める)
- 画面 src/views/simulator/phone/。中身 (打つ・確率・当たり・まとめ) はエンジンと tree の関数を直に呼ぶ。自前で式を書かない。
- **ツリーとして見せる**: 見出しは「n 段目 · 〜」(段は PC と同じ tree-fail の stepOf)。質問の言い方 (「何を打つ?」「どうする?」) はしない。
- **上の帯**: 名前・保存・レシピ・メモ・白紙は平たいボタン (TreeRecipeBar の flat と slot after)。その下に「‹ 1 つ前 · n 段目 / 全 m 段 · 未定 k · 先へ ›」(見た段の行き来。「全体を見る」と PhoneRoutes は消した)。
- **足りない所**: 組んでいる途中は出さない。「テストで回す」を押した後、木の形 (use-tree-check の routeKeyOf) がそのままの間だけ、「足りない所 n 件」か「✓ 合格」(未定が残れば「✓ 止まる所なし · 未定 n」)。testedKey は use-phone-quiz。
- **手のある箱**: 「○○を選択」の枠 (押すとカレンシーの選択) と「打つ手を替える」のボタン。下の帯は「次へ」= その手の結果へ。
- **結果は 1 つずつ 1 画面**: 外れ → 狙いが消えた → 当たりの順 (outsOf)。「結果 k / n」、下の帯「次へ (k / n)」= その結果を既定の答え (外れは再度挑戦、当たりは次の手) で決めて次へ。番号は PhoneTreePage の outStep を props で PhoneAsk に渡す。
- **結果の行**: 頭は「外れた場合」「狙いが消えた場合」「当たった場合」と何が起きたかの 1 行。確率はスマホでは出さない。中身はアイテムの枠だけ。下に答えを文で出す (「この場合は○○をもう一度打つ (n 段目へ戻る) (既定)」)。「答えを変える」のボタンで、下から選びの窓 (次の手を決める・再度挑戦・完成・戻り先を全体図で選ぶ・まとめる / 分ける)。
- **外れの箱で打つ前と同じ手** (同じカレンシーとお告げ) を選んだら、箱を作らず打つ前の箱へ戻すのと同じ (PhoneTreePage の pickHand の頭、sameHand)。
- **手の選び** (共用の TreeHandShelf の、スマホの時だけの分かれ):
  - 1 段目は棚。持つと下の帯に札の名前と説明、「キャンセル / 狙いを選ぶ ›」(今の手を直す時は「狙いを再度選ぶ ›」)。
  - 2 段目「当たりにする MOD」は手の窓の中に重ねる。body へ出すと、手の窓の外の押しになって閉じた。
  - 持った時の送りは、お告げの欄 (無ければ持った札) の下の端が帯の 12px 上で止まる。
  - 今の手の下に箱がある時は、別の札を持った瞬間・狙いを変えた瞬間に「この手以降は削除されます」。
- **完成形と全体図**: 表には出さず、下の帯の 1 行「完成形と全体図 開く ▴」の重ね窓 (PhoneOverview)。上が完成形 (アイテムの枠・ベース / MOD)、下が全体図 (箱は幅 64px まで、大きい時は色の見方)。戻り先を選ぶ時は全体図だけを大きく出し、戻れる箱が光る。押すと箱の窓 (中身・この箱から次に打つ・ここへ戻る)。普段の箱の窓は閉じるだけ。
- そのほか:
  - 白紙 (PC と同じ)、ツリーのメモ・箱のメモ (PhoneMemo、箱の窓)。
  - 押す所は 40px 以上、カードは画面の幅いっぱい。
  - スマホの貼り付けの札は、読めなかった行がある時だけ 1 行 (TreePasteNote)。
  - 完成の MOD のカードは、スマホの形なら押して ✦ (1 つだけ、use-tap-fracture)。

## 終わっていない物・決めてほしい物
- PC に揃えるか (シミュ 32 に知らせ済み): 「この手以降は削除されます」の警告と「外れの箱で同じ手 = 戻る」は、スマホだけ。
- 「足りない所 n 件」が出る形 (穴のある木) は、画面で見ていない (見本に穴が無かった)。
- お告げの無い札を持った時の送り (持った札を帯の上に合わせる) は、画面で見ていない。
- 320×640 では、持った札と 2 段になるお告げの欄の両方は入りきらない (札を残して止まる)。

## 気を付ける事 (作り方)
- **手元の dev サーバーの食い違い**: 同じファイル (use-phone-quiz.ts) が 2 つ別々に読み込まれ、共有の値 (sheet・outStep) がずれることがあった。押しても何も起きない時は `touch src/views/simulator/phone/use-phone-quiz.ts` で揃う。コードの不具合ではない。
- **共用のファイルを一時的に HEAD の形へ戻して前の絵を撮らない**: 10-27 に TreeHandShelf でシミュ 32 の書きかけを上書きして消した。前の絵は直す前に撮る。
- 台本は係の scratchpad (lib.mjs = 窓なし Chrome 9393)。指の押しは scrollIntoView の後に位置を測り直してから送る (送りの途中で押すと別のボタンに当たった)。
