## 0. 芯 (決まっている事)
- 箱 = 打つ手 (カレンシー + お告げ、カタリストで品質を上げてから打つ等のセット)。箱から「付いた結果」ごとに枝が出る。ツリー 1 枚で始まりから完成まで回せる。
- 各箱に「100 人回した時にここを何人が通るか・ここまでの平均費用」。作り直しの方が安い箱に ⚠。
- **組む順番は当たりの道が先、外れの道は後** (オーナー 1)。**外れの MOD は 1 本に束ねる**: 枝は「付いた狙いごと + 外れ 1 本」(オーナー 2)。外れの先でもまた分岐を組め、戻り先は既にある箱を矢印で指せる (オーナー 3)。
- 最善手の自動の探しはしない (10-21)。正解の分からない数字は既定値 + 直せる (10-22、エンジンの stageTuning をそのまま読む)。打つ処理は全部エンジンの入口 (engine.ts の `startFrom`・`applyCurrency`)。

- **箱**: 上に打つ手 (アイコン + 短い名前)、下に「通った人数・ここまでの平均費用」、小さく「この箱で付いている狙い」の札 (R C …)。⚠ は 4 の決まりで出す。
- **枝**: 箱の右から出る太い線 (2px 以上の実線。点線・1px 線は使わない、feedback-no-flicker-lines)。枝の上に「付いた: レアリティ」「外れ」「外れが消えた」「狙いが消えた」と通った割合。当たりは金、外れは赤み、戻りの矢印は箱の左に回り込む曲線。
- **まだ決めていない枝**は箱の右に灰色の短い「＋」で出る。その枝に来た人は止まり、箱に「ここで止まった 37 人」。当たりの道だけ組んだ時点で、外れの所に人が溜まって見える = 次に組む所が分かる (オーナー 1 の順番が画面で自然に進む)。
- 動かし方: 箱はドラッグで動かす、画面はドラッグ (空き所) で動かし、ホイールで寄る。Ctrl+Z で 1 つ戻す (feedback-proactive-ui)。
- 上の帯: 道の名前・人数・打ち止め・全体の数字・保存・共有・「300 人で回す」。決まり (打ち止め・数え方) は帯の ? で文で出す (feedback-show-sim-rules)。
- 文字は最低限。説明は既定で閉じる。1 画面 = 1 つの .g-panel (ui-one-frame-rule)。

## 2. 組み方の手順 (使う人)
1. **始まりの箱**を押す → 右の欄でベース・アイテムレベル・始めの MOD (フラクチャー)・始めの費用・**狙い** (MOD と段。今の ② の狙いの行を使い回し) を決める。貼り付けで始める事もできる (今の SimPasteRead)。
2. 箱の「＋」→ 打つ手を選ぶ (今の SimMethodPop。打てない手は灰色 + 理由)。新しい箱ができ、**枝の芽が自動で並ぶ**: 「付いた: (まだ付いていない狙い 1 つずつ)」+「外れ」。消去の箱なら「外れが消えた」+「狙いが消えた」。
3. まず「付いた: X」の芽から次の箱を足していく (当たりの道)。狙いが全部そろう枝は自動で **完成** に繋がる (組まなくてよい)。
4. 次に外れの芽を組む。芽の「＋」で新しい箱、芽の先を既にある箱へドラッグで戻りの矢印、または 1 押しの既定:
   - 「同じ箱をもう一度」(カオスの外れ → カオス)
   - 「すぐ消去」(消去の箱を作り、その枝を 外れが消えた → 1 つ前へ / 狙いが消えた → 形の合う箱へ にしておく。金の指輪の C の形)
   - 「作り直し」(始まりへ、始めの費用を払う)
5. 数字は組むたびに裏で 100 人回し直して出る (4)。⚠ や「止まった人」を見ながら直す。

## 3. 枝の分け方 (条件の扱い)
箱の手を打つ前と後で「付いている狙い」を比べて、**上から順に最初に当てはまった枝**へ進む。付いているか = 狙いの MOD (どれか) が狙いの段以上である事。フラクチャーの MOD は外れに数えない。狙いの系統が低い段で付いたら外れ (台本の blocked も外れで扱える)。

| 順 | 起きた事 | 枝 |
|---|---|---|
| 1 | 狙いが全部そろった | 完成 (いつも自動。芽は出さない) |
| 2 | 打てなかった (エンジンが断った。側が埋まっている等) | 止まる。箱に「打てない: 理由」と人数 (エンジンの reason をそのまま) |
| 3 | 新しく付いた狙いがある | 「付いた: X」。**同時に 2 つ以上付いたら、枝の並びで上にある方** (偉大のお告げ等で要る時だけ「2 つ付いた」の芽を足せる) |
| 4 | 狙いが消えた (新しく付いた物は無い) | 「狙いが消えた」(既定の先は 形の合う箱へ) |
| 5 | 外れが減った | 「外れが消えた」 |
| 6 | それ以外 (外れが付いた・入れ替わった・何も変わらない) | 「外れ」 |
- **箱の形**: 当たりの道の上の箱は、始まりから通った「付いた: X」から「ここに来た時に付いている狙い」が決まる (エディターが計算して箱に持つ、使う人は書かない)。外れの枝で作った箱は親と同じ形。
- **形の合う箱へ** (戻り先の 1 つ): 今付いている狙いと同じ形の箱のうち、始まりに一番近い当たりの道の箱へ飛ぶ。台本の「状態で次の手を決める」と同じ動きになるのはここ (消去で何が消えても、残った狙いに合う箱へ戻る)。合う箱が無い = 止まる (箱に「迷子 n 人」)。
- **形のずれ**: 枝の先の箱の形と今の形が違う (カオスが狙いを 1 つ消して別の狙いを付けた等) 時は、形の合う箱へ自動で直して進み、その枝に「ずれ n 人」を小さく出す (組み違いが見える。止めはしない)。
- **分かれ目の箱 (打たない箱)**: 打つ前に状態で分けたい時だけ使う、ひし形の箱。条件は前の案の 5 種 (狙いの数・狙い X がある / 無い / 低い段で埋まり・外れの数・側の空き・狙いの外の MOD がある) + いつも。マナ系の指輪のエッセンス (「非固定が外れ 1 つ → 素で打つ / それ以外 → 餌 + 左側の結晶化」) と、配信者の靴の「紋章が残っているか」で要る。**最初の 1 歩には入れない** (5 の 2 番)。

## 4. 簡易計算 (100 人)
- 裏のワーカーでエンジンを使って 100 人をツリーどおりに打つ (前の案と同じ「回す」、計算の式は持たない)。組み替えるたび 0.5 秒待ってから回し直し、回している間は前の数字を薄くして「計算中」。新しく組み替えたら前の計算は捨てる。
- 時間の見込み: 台本を Node で 100 人 1.4〜4 秒 (ES の手袋 1.4・金の指輪 2.4・マナ系の指輪 4.0、2026-10-22 に測った、束ねる時間込み)。ブラウザはまだ測っていない。
- **打ち止め**: 1 人 2000 神 (既定、帯で直せる) か 20,000 手。超えた人は未完成で使った分は入る。作り直しの回数の上限は既定なし (直せる)。
- 箱ごとの数字:
  - **通った人数**: 1 回でもここに来た人 (100 人中)。2 回目からは「1 人あたり n 回」を小さく。
  - **ここまでの平均費用**: 初めてここに来た時の使った額の平均 (来た人だけ)。
  - **ここからの残り** (右の欄): ここに来るたびの「その時の額 → 完成 (か打ち止め) の額」の差の平均。
  - **⚠ 作り直しの方が安い**: ここからの残り > 始めの費用 + 全体の 1 個あたり の箱 (配信者の「ここは 1 からやり直した方が得」)。
- 全体の数字: **1 個あたり = 全員が使った合計 ÷ 完成した数** (解析君のノートと同じ数え方)、完成率・中央・90%・±95% の幅。外れ値は切らない (帯の切り替えで「上下 3 人を外す」)。
- 「300 人で回す」ボタンで確かめの数字 (100 人の幅が 1 割を超える時に 1 行で勧める)。比べたい道は保存して 2 本並べる (横に 2 枚のツリーではなく、数字の表で並べる。2 弾目)。

- `on`: `got` (付いた、key)・`got2` (2 つ付いた)・`lost` (狙いが消えた)・`junkGone` (外れが消えた)・`junk` (外れ)。分かれ目の箱は `"kind": "split"` で `branches: [{ "if": [条件], "to" }]` + 最後に条件なし。
- `to`: 箱の id / `"match"` (形の合う箱へ) / `"restart"` (作り直し) / `null` (まだ)。完成は書かない (いつも自動)。

## 9. 作る順番

4. 組む操作: 芽から箱を足す・戻りの矢印をドラッグで・既定の 1 押し 3 つ・箱を消す・Ctrl+Z。始まりの箱の右の欄 (ベース・狙い・貼り付け)。
5. 保存・共有 (?page=recipes を新しい JSON に)、300 人、比べる。
