# ツリーの画面の押しにくい所の洗い出し (2026-10-22、シミュ部長)

頼み: オーナー 10-22「今のツリーの UI、スナップで使いづらいクリックになっている所を探して。完成ボタンにプラスマークが被っていたりする」(ブラック経由)。
やり方: 窓なし Chrome 1 つ (1660×860) で 10 箱の木 (始まり → カオス → 当たり 3 + 狙いが消えた + 外れ、レアリティの下に触媒の高貴 → キャスピ (完成) + 外れ → 消去) を台本で組み、押せる物 (ボタン・チェック・選ぶ欄) の四角を台本で比べて数えた。
数えた物: 24px 未満の物、押せる物どうしの重なり (4px² 超)、箱どうし・手の札と箱の重なり、押せる物の真ん中で一番上に別の物がある (隠れ)。ツリー・右の欄の枠の外へはみ出して切れている所は数えない (見えない・押せない)。
場面: ふつう / ツリーを四隅と途中へ送った所 / 全画面 / 一望 / 右の欄 (試し打ち・持った時・打つ手・MOD を選ぶ)。台本は scratchpad の tree-build.js・tree-audit.js (台本の置き場は残さない、要る時はこの節の決まりで書き直す)。

## 直す前 (ふつうの表示) → 直した後
| どこ | 何が起きる | 直し方 | 後 |
|---|---|---|---|
| 当たりの箱の「完成にする」と下の＋ (2 か所) | ＋が完成ボタンの右半分に被り、完成を押すと次の手の欄が開く | 下の＋を箱の外 (下 6px 空けた所) へ。箱に手が付くと＋は消えるので手の札とも重ならない | 0 |
| 当たりの箱の MOD の札と横の＋ (4 か所) | 札の右端を押すと当たりが増える | 札の幅を＋の分 (14px) 短く | 0 |
| 当たりの × (3 か所) | 14×17px で押しにくい | 24×24px の押し所 | 0 |
| ↩ 戻る (3 か所)・完成にする・戻りの × | 高さ 17px | 高さ 24px | 0 |
| MOD の札・フラクチャーの札 (5 か所) | 高さ 17px | 高さ 24px (箱を 104 → 112px に) | 0 |
| 矢印の上の手の札 | 高さ 22px | 高さ 26px | 0 |
| 打つ手の欄の触媒・削減のチェック | 13×13px | 行ごと押せる (高さ 28px) | 0 |
| 箱を押す / ドラッグ | 2px 動くとドラッグ扱いで、押した (試し打ちが開く) つもりが箱が少し動く | 5px までは押した扱い | 3px のぶれで欄が開き箱は動かない |
| 一望 | 縮めた箱のボタン (17px 以下) がそのまま押せる・MOD の札を押すと MOD の欄が開く | 一望の間は箱のボタン・手の札を出さない / 押せない。箱を押すと一望を閉じてその箱を真ん中へ | 押せる物 4 (帯だけ)、0 |
| 右の欄を開いた時 | 右の方の箱を押すと、その箱が欄の陰 (ツリーの枠の外) に隠れたまま | 欄を開いたら、選んだ箱をツリーの枠の中へ送る (枠の中だけ。ページは送らない) | 箱が枠の中・ページの位置そのまま |

数え (直した後): ふつう 0 (押せる物 28)、四隅と途中へ送った 5 か所 0、全画面 0 (31)、一望 0 (4)、試し打ち 0 (31)、持った時 0 (34)、打つ手 0 (38〜42)、MOD を選ぶ 0 (43〜52)。直す前は ふつうで 小さい 11・重なり 6。

## 残った物 (直していない)
- 戻りの矢印が箱の下をくぐって見える (例: 狙いが消えた → 始まり)。押すのには影響しない (矢印は箱の下に描き、押せない) が、木が大きいと線が読みにくい。直すなら矢印の通り道を箱の外へ回す (案、オーナーに聞く)。
- 始まりの箱を真ん中に置くので、右に広い木は右端の箱が枠の外から始まる (送れば見える)。一望・空き所のドラッグで届く。
- 箱の並びは手を足した時だけ並べ直す (後から足した当たりの箱は隣と重ならない間隔だが、手で動かした箱とは重なりうる。重なりの数えは 0 だった)。
