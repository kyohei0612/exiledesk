# ブリーチの指輪 (Breach Ring) と 金の指輪 (Gold Ring) で、品質で伸びる値と「耐性 T1 × 2 + ライフ T1」を揃える費用 (解析係、2026-10-31)

頼み: 記事編集長、ブログ breach-ring (11-12)。記事はまだ書かない。数字の元だけ。

## 1. 形
- ベース (どれも ilvl 82、ベースの代金は 0。取引所のベースの値段の差は見ていない):
  - **ブリーチの指輪** (Breach Ring、Lv40、暗黙「品質の最大値 +20%」= `local_maximum_quality_+ 20`) → 品質の上限 **40%**。
  - **洗練されたブリーチリング** (Refined Breach Ring、items-ja-client の名前。poe2db の日本語名は無し。暗黙 +25%) → 上限 **45%**。版は**ある**。
  - **金の指輪** (Gold Ring、Lv40、暗黙 レアリティ 6–15% = タグ drop でどのカタリストでも伸びない) → 上限 20%。
- 上限はエンジンの `maxQualityOf` (`catalysing-setup.ts maxQualityForBase` = 20 + 20 / + 25) で 40 / 45 / 20 と出た。暗黙の文を二重に足していない (60 にはならない)。
- **3 つとも MOD の置き場・段・重み・枠が全く同じ** (31 系統・重み 161,600・プレ 3 / サフィ 3。PROBE で系統・段・重みの並びを文字列で比べて一致)。違うのは品質の上限だけ。
- 狙い:
  - t1 (頼みの形): サフィ = **火・冷気・雷の単体耐性 T1 (41–45%、MOD Lv 82) を 2 つ** (元素は何でも) / プレ = **最大ライフ T1 (+100–119、MOD Lv 54)**。
  - t2 (比べ用に緩めた形): 耐性 **T2 以上** (36% 以上) を 2 つ + ライフ **T2 以上** (+85 以上)。ブリーチ 40% の T2 が金 20% の T1 と同じ幅になる (下の表) ので回した。
  - 同じ系統の低い段は外れ。ほかの MOD は何でもよい。
- 値段: `data-cache/boot/boot-2026-10-22.json` (自分のサーバーの /boot.json の写し、2026-10-22T04:00Z、Forbidden Rites、高貴建て。神 = 781.93 高貴)。錬金 3.5・カオス 79.5・消去 324.3・上級の高貴 15.8・左側の高貴のお告げ 90.1・右側の高貴のお告げ 32.8・触媒の高貴のお告げ 41.0・ゾフのカタリスト 16.7・エシュ 18.2・トゥル 18.4・肉体 9.1・チャユラ 7.2・ブリーチのエッセンス 775.8。
- 台本: `scripts/analysis/breach-ring-ev.mjs`。打つのは全部エンジンの入口 (applyCurrency)、台本は次の手を決めるだけ。値の表は `TABLE=1`、1 回の割合・品質の消え方は `PROBE=1`、狙いの切り替えは `AIM=t2`、カタリスト 1 個 +1% は `ONE=1`。

## 2. どのカタリストが効くか (エンジンのデータ、13 種を全部 40% で掛けて boostedMod が伸ばすか)
| MOD (指輪) | タグ | 伸ばすカタリスト |
|---|---|---|
| 火耐性 | fire・elemental・resistance ほか | **ゾフのカタリスト** だけ |
| 冷気耐性 | cold ほか | **トゥルのカタリスト** だけ |
| 雷耐性 | lightning ほか | **エシュのカタリスト** だけ |
| 混沌耐性 | chaos ほか | **チャユラのカタリスト** だけ |
| 全元素耐性 | fire・cold・lightning 全部 | ゾフ・トゥル・エシュ のどれでも |
| 最大ライフ | life・resource | 肉体のカタリスト |
| 最大マナ | mana・resource | 神経のカタリスト |
| キャストスピード | caster・speed | 歯擦音・軽快 |
| 知性 (能力値) | attribute | 適応のカタリスト |
| レアリティ (サフィ・プレ・金の指輪の暗黙) | drop | **無し** (品質では伸びない) |

- **「耐性」のカタリストは無い**。耐性はその元素のカタリストで伸びる。`resistance` のタグはあるがカタリストの種類 (catalysts.json の 13 個) に無い。
- **品質の種類は 1 つだけ** (E-71、種類を変えると 0 から)。だから**火耐性 + 冷気耐性 の指輪では、品質 40% でも伸びるのは片方だけ**。耐性 2 つ + ライフ の指輪で品質が乗るのは 3 つのうち 1 つ。両方の単体耐性が伸びる組は無い (全元素耐性 + 単体耐性 1 つ なら 1 つのカタリストで 2 つとも伸びる)。

### ブリーチ 40% の段 ↔ 金の指輪の何段目か (幅の重なり)
| MOD | ブリーチ T1 @40% | ブリーチ T2 @40% | ブリーチ T3 @40% |
|---|---|---|---|
| 単体耐性 | 57–63 = 金 20% の T1 (49–54) **より上** | 50–56 ≒ **金 20% の T1** (49–54) | 43–49 = 金 20% の T2〜T1 / 金 0% の T1 |
| 混沌耐性 | 33–37 = 金 20% T1 (28–32) より上 | 28–32 = **金 20% の T1 と同じ幅** | 22–26 = 金 20% の T2〜T3 |
| 全元素耐性 | 21–22 = 金 20% T1 (18–19) より上 | 16–19 = 金 20% の T1〜T2 | 12–15 |
| 最大ライフ | 140–166 = 金 20% T1 (120–142) とほぼ重ならず上 | 119–138 ≒ **金 20% の T1** (120–142) | 98–117 = 金 20% の T2〜T3 |

- 言い方: **「品質 40% のブリーチの指輪の T2 は、品質 20% の金の指輪の T1 とほぼ同じ値」**。単体耐性の T1 は 57–63 で、金の指輪ではどの段・品質でも届かない (金の上限は 54)。
- ただしこれは**カタリストを入れた 1 つの MOD だけ**の話。

## 4. 品質を上げる費用・品質が消える手 (エンジンの決まり)
- カタリスト 1 個 = **+1% か +2% (等分)** (other-specs.ts の CATALYST の owner 欄、オーナー 10-17「1% から 2% の完全ランダムで手動で」)。上限で止まる (上限なら打てない)。
- 品質 0 → 上限 (エンジンで 2 万回):
| | 平均の個数 | ゾフ | エシュ | トゥル | 肉体 | 1 個 +1% なら |
|---|---:|---:|---:|---:|---:|---:|
| 金の指輪 (20%) | 13.5 個 | 0.29 神 | 0.32 | 0.32 | 0.16 | 20 個 (ゾフ 0.43 神) |
| ブリーチの指輪 (40%) | 26.9 個 | **0.57 神** | 0.63 | 0.63 | 0.31 | 40 個 (ゾフ 0.85 神) |
| 洗練されたブリーチリング (45%) | 30.2 個 | 0.65 神 | 0.71 | 0.71 | 0.35 | 45 個 (0.96 神) |
- **品質が消える・消えない** (品質 40% の火の指輪にエンジンで打った): カオス・消去・高貴・上級の高貴 + 右側の高貴・神のオーブ → **40% のまま**。**触媒の高貴のお告げを掛けた高貴 → 0%** (`parts.ts` の「触媒の高貴は品質を使い切る」)。**別の種類のカタリスト (トゥル) → 0 から積み直しで 1%** (E-71)。
  - 設計図で決まっているのは E-71 (種類を変えると 0 から) と E-32 (触媒の高貴の倍率)。「カオス・消去・高貴では消えない」は**設計図に行が無く、エンジンの動き** (お告げ以外の手は品質に触らない)。
- 数えの扱い: exalt・chaos の打ち方は品質 0 のまま作って、**最後に仕上げで上限まで載せる** (費用に入れた)。cat の打ち方は触媒の高貴のたびに 0 → 上限を買い直す (費用に入れた) + 最後に仕上げ。

## 6. 打ち方 (状態だけで決まる。どのベースにも同じ決まり)
| 名前 | 手 |
|---|---|
| exalt | 錬金 → ライフが無くプレに空き → 左側の高貴のお告げ + 上級の高貴 / 耐性が 2 つ無くサフィに空き → 右側の高貴のお告げ + 上級の高貴 / 空きが無い → 消去 (お告げ無し)。最後に仕上げの品質 |
| cat | exalt と同じ順で、高貴のたびにカタリストで品質を上限まで上げて 触媒の高貴のお告げ を重ねる (ライフ = 肉体、耐性 = まだ系統が空いている元素のうち一番安い ゾフ < エシュ < トゥル)。最後に仕上げの品質 |

仕上げ = 持っている耐性の元素のうち一番安いカタリストで上限まで (金 20% / ブリーチ 40% / 洗練 45%)。

## 8. 気付き
- **作る費用はベースでほとんど変わらない**。置き場が全く同じなので、品質を使わない打ち方 (exalt・chaos) は同じ乱数で同じ手数、差は仕上げのカタリスト代 (ブリーチ +0.3 神) だけ。触媒の高貴を使う打ち方でもブリーチが 6% 安いだけ (倍率 7.4 倍 vs 5 倍の得を、カタリストが 2 倍要る分がほぼ食う。1 個 +1% で数えると同じ)。
- **ブリーチの指輪の得は「値」**: 伸ばした MOD 1 つが 金の指輪の 1 段上と同じになる (T2 @40% ≒ 金 T1 @20%)。単体耐性 T1 @40% の 57–63 は 金の指輪では出ない値。
- **品質で伸びるのは 1 種類だけ**。耐性 2 つ + ライフの指輪では、品質 40% でも伸びるのは 3 つのうち 1 つ。
- **狙いを T2 に落とすと 6 分の 1** (cat で 360 → 59 神)。ブリーチなら T2 でも伸ばした耐性は金の T1 以上。記事の芯にするならここ。
- 一番安いのは cat (触媒の高貴)。exalt (お告げの高貴だけ) は t1 で約 4 倍・t2 で約 3.4 倍。chaos は使えない。
- 品質の上げ直しを嫌うなら exalt の後に仕上げ 1 回でよい (品質はカオス・消去・高貴では消えない)。cat では高貴のたびに品質が 0 になり、ブリーチは 1 回 0.3〜0.6 神ずつ (肉体〜トゥル) の買い直し。
- 金の指輪を 40% にする手 (ブリーチのエッセンス 775.8 高貴 ≒ 1 神、「品質の最大値 +20%」= `Rings/PerfectEssence_LocalMaximumQuality`) はプレの枠を 1 つ使う (gold-ring-suffix-ev.mjs の Q=40 の扱い)。ブリーチの指輪は暗黙なので枠を使わない。この比べは回していない。

## 9. 確かめた物 / 弱い所
- **エンジンだけ、外の正解なし**: 費用・手数・1 回の割合・品質の消え方 (カオス・消去・高貴で消えない) 全部。値の表は `quality.ts displayedValue` の手の式と照らした (同じエンジンの中の照らし)。
- 外の正解があるもの: 切り捨て (E-72、オーナーの実物 10-18)、カタリスト 1 個 +1〜2% (オーナー 10-17)、触媒の高貴の倍率 40% = 7.4 倍は CoE の式で、reddit の実測 (品質 40%、100 個中 77 個 = 7.63 倍、95% 区間 5.01〜13.17、`catalysing-multiplier.ts`) の中。
- 段の幅 (耐性 T1 41–45 Lv82・ライフ T1 100–119 Lv54・混沌 T1 24–27) はエンジンのデータ (`loadPatch`) のまま。poe2db とは照らしていない。
- ブリーチの指輪・洗練されたブリーチリングの ilvl 82 は仮定 (ブリーチで落ちる物のレベルは見ていない)。ベースの代金は 0。
- 洗練されたブリーチリングの日本語名は items-ja-client.json の「洗練されたブリーチリング」(poe2db の日本語名は無い)。ブリーチの指輪・金の指輪は両方に名前あり。
- 打ち方は素直な形 (消去にお告げ無し)。左側 / 右側の消去のお告げ (13〜21 神) やフラクチャー、エッセンスは試していない。t1 の 360 神の 4 割は消去で狙いを消し直している分なので、上手な人はもっと安い。
- chaos は 200 人 × seed 1 だけ。
