# 金の指輪のサフィックスの途中の形から、どの次の手が安いか (解析君 2 本目、2026-10-22)

頼み: ブラック 4 代目 (オーナー 10-22 のスナップ「この状態でももう最初からにした方が良いの?」「2 MOD 狙い・1 外れの時、見本の木が初めから戻っている」)。オーナーの直の指示: 冒涜は外す・プレフィックスは計算しない・サフィックス 3 つ (レアリティ T1・キャストスピード T2 以上・全耐性 T2 以上) が揃うまで。
台本 `HAVE=C|RC|RA|CA JUNKT=T3 FIRST=a,b,b2,c,w,fresh node scripts/analysis/gold-ring-midway-ev.mjs [N] [SEED]`。打つのは全部エンジンの入口。

## 形と手
- 指輪: 金の指輪 ilvl 82、プレフィックスはスペルダメージ 33% (T2) のフラクチャーだけ。外れのサフィックスは器用 (T3 = MOD レベル 55、比べに T6 = 22)。
- 1 手目だけ替えて、2 手目からは見本の木と同じ打ち方 C (狙い 0 → カオス、外れ → すぐ素の消去、レアリティが無い → 右側の高貴 + 上級、ある → カタリスト 20% + 触媒の高貴 + 右側の高貴 + 完全)。
- 1 手目: b2 = 素の消去 (木の外れの箱の手)・b = 右側の消去のお告げ + 消去・a = カオス (木の「始めに戻る」)・c = 右側の高貴 + 上級で先に足す (空きがある時)・w = 削減 + カオス・fresh = 新しいベースで見本の始まりから (ベース代は入れない)。
- 値段: 自分のサーバーの /boot.json (2026-10-22 に取得、中の時刻 2026-10-21T17:00:49Z、神 = 807.07 高貴)。消去 347.4・右側の消去のお告げ 10,673.1・削減 11,035.0・カオス 82.0 高貴ほか。

## 1. スナップの形: キャストスピード T2 + 外れ 1 (1 万人、seed 1 / 2)
| 1 手目 | 1 個あたり |
|---|---:|
| 素の消去 (木の jC の手) | 200.3 / 197.0 神 |
| 右側の高貴で 3 つ目を先に | 200.4 / 197.3 |
| カオスで始めに戻る | 200.7 / 197.3 |
| 新しいベースで見本の始めから | 200.4 / 197.3 |
| 右側の消去 + 消去 | 213.5 / 210.2 |
- 右側の消去以外は同じ (差 0.5 神以内)。キャストを 1 つ持っている得はカオス数回分しか無い。右側の消去は、プレフィックスに外せる物が無いので消える候補が素の消去と同じで、お告げ代 (13.2 神) だけ損。

## 2. 狙い 2 つ + 外れ 1 つ (サフィックス満杯) (5,000 人 × seed 1 / 2 の平均、幅 ±5 神)
| 狙い 2 つ | 素の消去 | 始めに戻る (カオス) | 右側の消去 + 消去 | 削減 + カオス (外れ T3 = Lv55 / T6 = Lv22) |
|---|---:|---:|---:|---:|
| レアリティ + キャスト | **185.8** | 188.8 | 199.0 | 212.6 / 185.7 |
| レアリティ + 全耐性 | **178.2** | 183.4 | 191.4 | 212.0 / **169.3** |
| キャスト + 全耐性 | **196.1** | 196.9 | 209.3 | 212.0 / 206.9 |
- 素の消去が一番安いか同じ。木が今「始めに戻る」になっているのは +1〜5 神の損 (シミュ部長 8 本目に送った)。
- 削減 + カオスは外れの MOD レベルが狙い (レアリティ T1 = 40・キャスト T2 = 51・全耐性 T2 = 54) より低い時だけ外れを消せる。外れ T6 (22) でレアリティ + 全耐性の時だけ −9 神。
- 種どうしは同じ乱数の並びを使うので、手の間の差は表の幅より確か (seed 1 と 2 で向きが全部同じ)。

## 3. 見本の木を今の相場で丸ごと (冒涜無し、3,000 人 × seed 1 / 2)
- 1 個 689.8 / 695.2 神 = サフィックス側 221.3 / 221.1 + プレフィックス側 468.6 / 474.2 (プレフィックスはオーナーが計算しないと言ったので参考)。打ち方 C の台本 (上の fresh、197〜200) と木のサフィックス側 (221) の差は、木の作り (カタリストの通り抜けの箱・始めに戻る) による。

## 気付き
- 狙い 2 つから始めても見本の始めから (197 神) と 10〜20 神しか違わない = 今の打ち方 C は、消去で狙いを消してカオスに戻る繰り返しが費用の大半。どの形でも一番安い次の手を全体の収支で選ぶ計算 (動的計画法) は gold-ring-suffix-dp.mjs で組んでいる (計算とエンジンの食い違いを直している途中)。
