## 2. 形
- ベース: 聖なるフォーカス、ilvl 82、ベースの代金は 0 (取引所のベースの値段の差は見ていない)。
- 狙い (プレ 2 + サフィ 1):
  - **プレ = ES% 増加 T2 以上** (`Foci/LocalEnergyShieldPercent` の上 2 段: 80–91% (MOD レベル 60、重み 1000) / 92–100% (65、1000))
  - **プレ = ES の足し算 T2 以上** (`Foci/LocalEnergyShield` の上 2 段: +74–80 (65、1000) / +81–90 (70、1000))
  - **サフィ = キャストスピード 25% 以上** (`Foci/IncreasedCastSpeed` の上 2 段: 25–28% (60、1000) / 29–32% (70、500)。または **敏速のグレーターエッセンス** の 25–28% (`Foci/Essence_IncreasedCastSpeed` の Greater)・**超越の合金** の 26–31% + 元素ダメージの 7–11% を追加の冷気ダメージとして得る (`Foci/PerfectEssence_IncreasedCastSpeed`、MOD レベル 65))
  - 同じ系統の低い段は外れ。ほかの MOD は何でもよい。
- 選んだ訳:
  - フォーカスの ES 系のプレは 3 つ (足し算 `BaseLocalDefences`・増加% `DefencesPercent`・ES% + マナ `BaseLocalDefencesAndMana`) で、系統が別なので 3 つとも同時に付く。数値が一番伸びるのは 足し算 T1 (+81–90) と 増加% T1 (92–100%)。ES% + マナ は一番上でも 39–42% なので、2 つの狙いからは外した (3 つ目のプレに乗ればおまけ)。
  - T2 以上にしたのは、上級の高貴の下限 (35) でも段の重みが 1000 ずつで、T1 だけにすると重みが半分になり「狙いの物が付かない」話ばかりになるため。
  - サフィはフォーカスで全てのスペル +# が **+2 まで** (`Foci/GlobalIncreaseSpellSkillGemLevel`、+1 重み 500 / +2 重み 250) しか無く、狙う物として弱い。キャストスピードはエッセンス (グレーター) と合金で確定させられるので、記事の芯の「打ち方」が作れる。
- 値段: `data-cache/boot/boot-2026-10-22.json` (自分のサーバーの /boot.json の写し、**2026-10-22T04:00Z**、Forbidden Rites、高貴建て。神 = 781.93 高貴)。錬金術のオーブ 3.5・変成のオーブ 2.9・カオスオーブ 79.5・消去のオーブ 324.3・高貴なオーブ (上級) 15.8・左側の高貴なお告げ 90.1・右側の高貴なお告げ 32.8・右側の結晶化のお告げ 305.8・**超越の合金 223.9**・**敏速のグレーターエッセンス 30.1**・鎧鍛冶の端材 9.2 (高貴)。
- 台本: `node scripts/analysis/sacred-focus-ev.mjs [N] [SEED] [打ち方] [ベース]` (ベース = sacred / tasalian / rsacred / rtasalian)、1 回の割合とフォーカス 4 つの比べは `PROBE=1 node scripts/analysis/sacred-focus-ev.mjs [K] [SEED]`、ES の比べは `ES=1 node scripts/analysis/sacred-focus-ev.mjs [N] [SEED]`。打つのは全部エンジンの入口 (applyCurrency)、台本は次の手を決めるだけ。打ち止め無し (1 人 200 万手まで)。

## 3. 打ち方 (状態だけで決まる)
| 名前 | 手 |
|---|---|
| chaos | 錬金術のオーブ → カオスオーブだけ |
| exalt | 錬金 → 欠けた狙いの側に空き → その側のお告げ (左側 = プレ / 右側 = サフィ) + 高貴なオーブ (上級)。プレを先。空きが無い → 消去のオーブ (お告げ無し) |
| alloy | 錬金 → キャストが無い → **超越の合金** (E-51: サフィが満杯ならサフィから 1 つ消して付く。満杯でなく ES の狙いを持っていてサフィに MOD があれば **右側の結晶化のお告げ** を掛けてサフィから消す)。キャストがあって ES が欠けている → プレに空きがあれば 左側の高貴なお告げ + 高貴なオーブ (上級)、満杯なら消去のオーブ。消去がキャストを消したら、また合金 |
| **gess** | 白 → 変成のオーブ → **敏速のグレーターエッセンス** (マジック → レア、キャスト 25–28% 確定)。あとは alloy と同じ (キャストが消えたら超越の合金で戻す) |

- 使えない物・回していない物:
  - **ES のエッセンスはフォーカスに無い** (essence-keys.json の Foci にあるのは 敏速 (キャスト)・断熱 / 解凍 / 接地 / 破滅 (耐性)・探求 (スペルのクリティカル)・魔法 (スペルダメージ)・肉体のレッサー (ライフ)・パーフェクトの 敏速 (マナコスト効率)・アビス、合金の 超越 (キャスト + 冷気)・プリズム・王権 (ルーンワード%)・迅速 (トーテム))。ES を確定させる手は無い。
  - **防御のカタリストはフォーカスに使えない** (E-71: カタリストは指輪・アミュレット・ジュエルだけ)。
  - **フラクチャーオーブ** (8,921 高貴 = 11.4 神) は回していない。gess の 1 個あたり (17.6 神) の 3 分の 2 になり、守れるのは 4 つ以上の MOD のうちランダムな 1 つ。gess で狙いが消える回数は ES% 2.0 回・足し算 1.7 回だけ (費用の芯は「ES を引く」方) なので、守っても割に合わない。
  - 左側 / 右側の消去のお告げ (1 万高貴超 = 13〜21 神) も同じ理由で回していない。
  - 敏速のパーフェクトエッセンス はマナコスト効率 18–20% でキャストではない。

## 6. 完成した時の ES (聖なる vs タサリオ)
式 (エンジンの表示 `src/services/craft-stage/stage-props.ts` の `numbersOf` = 画面の `propRows` と同じ):
**ES = (素の ES + 足し算) × (1 + 増加% の合計 / 100) × (1 + 品質 / 100)**
(増加% の合計 = ES% + ES% とマナ + ほかの ES を含む増加。2 つのベースで MOD が同じなら、差は「素の ES の差 10 × (1 + 増加%) × (1 + 品質)」だけ)

狙いの段の端で (MOD は ES 足し算と ES% の 2 つだけ):
| | 品質 0%: 聖なる / タサリオ | 品質 20%: 聖なる / タサリオ |
|---|---:|---:|
| ES の MOD 無し | 81 / 91 | 97 / 109 |
| 狙いの下限 (+74・80%) | 279 / 297 | 335 / 356 |
| T1 の真ん中 (+85・96%) | **325 / 345** | **390 / 414** |
| T1 の上限 (+90・100%) | 342 / 362 | 410 / 434 |

alloy で作った完成品 2,000 個 (seed 1) を、同じ MOD のままベースだけ載せ替えた比べ:
| | 聖なる 平均 (最小〜最大) | タサリオ 平均 (最小〜最大) | 差 |
|---|---|---|---|
| 品質 0% | 322.9 (279〜411) | 342.8 (297〜436) | +19.9 (+6.2%) |
| 品質 20% | 387.5 (335〜494) | 411.4 (356〜523) | **+23.9 (+6.2%)** |

- 最大が上がっているのは、3 つ目のプレに ES% + マナ (最大 +42%) が乗った物 (2,000 個中 463 個 = 23%)。
- ルーンフォージの版 (pob-item-bases.json の値を同じ式で、T1 の真ん中 +85・96%): ルーンフォージの聖なる (68 + 85) × 1.96 = 300 (品質 20% で 360) + ルーンワード 53、ルーンフォージのタサリオ (36 + 85) × 1.96 = 237 (品質 20% で 285) + ルーンワード 181。
- **費用は 2 つで同じ** (エンジンの候補が同じ・同じ seed で数字が小数まで同じ)。差は ES だけで、その差は品質 20% の完成品で約 24 (6%)。

## 7. 気付き
- **敏速のグレーターエッセンス (0.04 神) でキャストを確定させ、残りを「左側の高貴 + 上級、満杯なら消去」で ES 2 つを引く** のが一番安い。1 個 17.6 神、中央 12 神、50 神あれば 94%。exalt の約 1/7、カオスだけの約 1/55。
  - 費用の 65% は消去 (11.5 / 17.6 神)。残りの難しさは「ES 2 つを T2 以上で引く」所 (上級の高貴で ES の片方が 5 回に 1 回、2 つ目は 9 回に 1 回)。
  - キャストは 1 人 7 回消えるが、超越の合金 1 個 0.29 神で戻る (7 回で 2 神)。守るより打ち直す方が安い (ルーニックフォークの記事と同じ形)。
  - gess と alloy の差は 1 神ほど (6%)。変成 → グレーターエッセンスで始めると MOD が 2〜3 つのレアになり、プレに空きが多い分だけ消去が少し減る。記事では「エッセンスでも合金でも、キャストを先に確定させる」とまとめてよい。
- **右側の結晶化のお告げは要らない**: 合金を打つ時は、たいてい消去でキャストが消えた直後でサフィが空なので、ES の狙いは消えない。
- exalt の重さは消去がお告げ無しなこと: ES% 12 回・足し算 10 回・キャスト 6 回を消している。費用の 81% が消去。
- **聖なるかタサリオかでクラフトの費用は変わらない**。ES の差は素の 10 が増加% で約 2 倍になって品質 0 で +20、品質 20% で +24 (6%)。要求 Lv80・知性 115 を満たせるならタサリオ、満たせない間は聖なる。
- 品質 20% は 鎧鍛冶の端材 平均 13.6 個 (0.16 神) で ES が 2 割増え (聖なる 325 → 390)、ベースを聖なるからタサリオに替える差 (+20) より大きい。

## 8. 確かめた物 / 弱い所
- **エンジンだけ、外の正解なし** (Craft of Exile・poe2db と照らしていない)。重みはエンジンの data.mods (poe2db 由来) のまま。敏速のグレーターエッセンスが「フォーカスでキャスト 25–28%」、超越の合金が「キャスト 26–31% + 冷気 7–11%」は essence-keys.json (同梱 poe2htc の essences.json) と data.mods で見ただけ。記事に出す前に poe2db のエッセンス・合金のページで照らしたい。
- **品質の掛け方はエンジンの式 (増加% と品質を別に掛ける) のまま**。ゲーム (PoB2) で品質が増加% に足される形なら、T1 の真ん中・品質 20% は 聖なる (81 + 85) × 2.16 = 359 / タサリオ 380 で、上の表 (390 / 414) より 1 割ほど低い。差 (タサリオ − 聖なる) は どちらの式でも 20 前後。記事に品質 20% の数字を出すなら、ゲームか PoB2 で 1 つ照らしたい。
- 素の ES 81 / 91 は stage-bases.json・extra-bases.json・pob-item-bases.json の 3 か所で一致 (どれも外のデータの写し、ゲームの画面とは照らしていない)。
- 値段は 10-22 の 1 時点。敏速のグレーターエッセンス 30.1 高貴・超越の合金 223.9 高貴が 10 倍になっても gess の費用は +20 神ほど (合金 6.9 個 × 2.9 神 = 19.7 神 + エッセンス 0.35 神)。費用の芯は消去 (324 高貴) の値段。ベース (聖なる / タサリオ) の取引所の値段は入れていない。
- 打ち方は状態だけで決めた簡単な決まりで、最善手 (DP) ではない。例: 消去の前に左側の高貴を重ねる順、ES の片方を持った後に左側の消去のお告げを使う、などは試していない。
- ES% + マナ (`LocalIncreasedEnergyShieldAndMana`) は狙いに数えていない (3 つ目のプレに乗れば ES は上がる。完成品の 23%)。
- フォーカスの ES の増加が「ルーンワード」にも効くかはエンジンに無い (ルーンフォージの版のルーンワードは足していない)。
