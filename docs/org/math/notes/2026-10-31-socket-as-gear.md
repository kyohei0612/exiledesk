# はめた物が手袋 / 兜 / 靴として効く宝飾品にルーンをはめると、抽選は変わるか (2026-10-31、解析係)

頼み: 記事編集長、ブログ候補 7 (グラスピング・コロナ) の書けるかの確かめ。

台本: `node scripts/analysis/socket-as-gear-probe.mjs 3000 1` (エンジンの入口 engine.ts の startFrom・applyCurrency・candidates・effectiveCls を使う。入口の TS は台本が一時フォルダに書いて束ねる)。

## 結論 (先に)

- **エンジンでは、グラスピングリングにコルの狩りをはめても、マークスマンの MOD は抽選に混ざらない** (高貴 3,000 回で 0 回、候補の重みもはめる前と同じ)。手袋 (サイレーンスケイル) では混ざる (候補の重みのうちプレ 11.16%・サフィ 17.01%、高貴 3,000 回で 15.70%)。
- コロナアミュレット + ヴォラナの虐殺 (兜・バーサーキング)、ストーキングベルト + ウートレドの星読み (靴・時間術) も同じで、**はまる・文は出るが、抽選は変わらない**。
- ただしこれは**エンジンの作りの都合**で、ゲームの決まりとして確かめた物ではない。ゲームのデータ (RePoE) ではマークスマンの MOD の出る条件はタグ `marksman` だけで、部位の縛りが無い。グラスピングリングが「手袋として」コルの狩りの効き目 (= marksman のタグ) を得るなら、**ゲームでは指輪にもマークスマンの MOD が出る見込みがある**。外の正解 (実物・トレード・poe2db の表) は見つからなかった。
- 記事の見立て: **(c) エンジンと外の正解が合わない (合うかどうか分からない) → 今は書かない**。抽選の部分を抜いた「効き目だけ」の (b) は書けるが、「指輪にマークスマンは出ない」とも「出る」とも書けないので、記事の芯 (コルの狩りの記事との対) が作れない。

## 1. グラスピングリング + コルの狩り

| | グラスピングリング (Rings) | サイレーンスケイルの手袋 (Gloves) |
|---|---|---|
| 暗黙 | This item gains bonuses from Socketed Items as though it was Gloves | — |
| 白の時のソケット (`baseSocketsOf`) | 1 | — |
| ルーンを見る部位 (`runeCategoryOf`) | Gloves | Gloves |
| `pools.rune` のルーン | **無し** | kolrs-hunt, katlas-gloom |
| コルの狩りをはめる (`startFrom` の runes) | 通る。効き目の文「Can roll Marksman modifiers」(部位 Gloves) | 通る |
| はめた後のプレの候補 | 13 系統・重み 69,500、特殊 MOD 0 (はめる前と同じ) | 13 系統・重み 71,700、特殊 MOD 3 系統・8,000 (**11.16%**) |
| はめた後のサフィの候補 | 18 系統・重み 92,100、特殊 MOD 0 (はめる前と同じ) | 26 系統・重み 97,000、特殊 MOD 9 系統・16,500 (**17.01%**) |
| 白のレアに高貴 1 回 × 3,000 | 特殊 MOD 0 回 | 471 回 (15.70%) |

手袋に混ざる物 (重み、出どころは `htc/rune-weights.json` = CoE beta の実測、E-03): プレ = 投射物ダメージ 3000・投射物速度 3000・呪いの効果 2000。サフィ = 追加の投射物の確率 3000・クリティカルヒット率 2500・分岐 2000・マークの持続 2000・マークの使用速度 2000・貫通の確率 1500・地形からの連鎖 1500・マークのスキルのレベル 1000・投射物スキルのレベル 1000。記事 kolrs-hunt-gloves と、2026-10-21-es-gloves-ev.md の追記 2 と同じ物。

### 指輪で混ざらない所 (コード)

- `src/vendor/poe2htc/engine/runes.ts` の `poolsWithRunes`: 混ぜる MOD は `base.pools.rune[id]` だけで、「Presence IS the fit test」(上流の `apply_runes.mjs` が、ルーンの部位 = `categories: ['Gloves']` のベースにだけ書く)。指輪の行 (Rings) には `pools.rune` が無いので、何もしない。
- 同じ所の `limitsWithRunes`・`runesFor` も `base.category` (Rings) で見るので、コルの狩りは指輪に「合わない」扱い。
- 一方、クラフトステージの `src/services/craft-stage/stage-runes.ts` の `runeCategoryOf` / `socketAsOf` は暗黙の文を読んで「手袋」として扱い、`applyRune` ははめさせ、効き目の文も出す。`stage-core.ts` の `effectiveCls` → `withRunes` で ID (kolrs-hunt) は渡るが、上の理由で置き場は変わらない。
- **食い違い (不具合らしき物、直していない)**: ステージは「はまった・Can roll Marksman modifiers」と見せるのに、抽選は何も変わらない。ゲームで出るならエンジンが足りない、出ないなら効き目の文を出すのが誤解のもと。どちらかを決めるのは外の正解が要る。設計図 (engine.md) に「手袋 / 兜として効く」宝飾品のルーンの決まりの行は無い (E-13 はグラスピングメイルの暗黙のタグの話で、ソケットの話ではない)。

## 2. コロナアミュレット (兜として効く)

- 白の時のソケット 1、ルーンを見る部位 Helmets、`pools.rune` 無し。
- ヴォラナの虐殺 (兜、「Can roll Berserking modifiers」) ははまるが、候補 (プレ 12 系統 72,200 / サフィ 21 系統 101,450) は変わらず、高貴 3,000 回で特殊 MOD 0 回。
- ストーキングベルト (靴として効く) + ウートレドの星読みも同じ (はまる、抽選は変わらない)。
- **兜側で抽選を変える物は、ヴォラナの虐殺 1 つだけ** (エンジンの RUNES のうち兜で効く「Can roll ◯◯」)。兜で効き目のある物は 121 個 (ルーン 88・魂の核 26・アイドル 7) あるが、ほかは全部キャラクターへの効き目で、クラフトの決まりは変えない (runes.ts の頭の注: 313 個の中で MOD に関わるのは 12 個)。手袋側はコルの狩り・カトラの陰鬱の 2 つ、靴側はウートレドの星読み 1 つ。
- 枠を変える物: セールの凱旋 (サフィ +1) とアストリッドの創造性 (クラフト MOD +1) は「全ての装備品」なので、エンジンでは指輪・アミュレットにもそのまま効く (グラスピングリング・コロナアミュレットとも、セールでサフィの枠 3 → 4)。これもエンジンだけ (宝飾品にはめた実物の確かめは無い)。

**ここまでで「エンジンだけ」の物**: 指輪・アミュレット・ベルトにルーンをはめても抽選が変わらないこと、セール・アストリッドが宝飾品に効くこと。

## 4. 記事にできるか

- 見立ては **(c)**: エンジンは「混ざらない」、ゲームのデータの読み (タグだけで出る) は「混ざりうる」で、外の正解が無い。このまま書くと、どちらに書いても間違いの恐れがある。
- 書くなら先に要る物: オーナーにゲームで 1 回確かめてもらう (グラスピングリングにコルの狩りをはめ、高貴を数回 or 冒涜の発現で、マークスマンの MOD が出るか)、またはトレードで「グラスピングリング + 投射物スキルのレベル / 地形からの連鎖」が出品されているかを見る。出るなら、エンジンの `pools.rune` を「手袋として効く」ベースにも作る直しが要り (エミュレーター部の仕事、設計図に先に書く G-20)、その後は (a) 手袋と指輪の費用の比べが数えられる (指輪はカタリストでマークスマンの MOD を伸ばせる、の切り口もある)。出ないなら、ステージが効き目の文を出す所を直し、記事は (b)「はめて効く物の一覧」になる。
