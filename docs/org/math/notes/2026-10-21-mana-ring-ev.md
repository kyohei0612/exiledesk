# マナ系の金の指輪の期待値 (打ち方 C、エンジンで回した、2026-10-21)

頼み: サム開発部長 (オーナー OK 済み)。材料 docs/org/research/notes/2026-10-21-mana-ring-mods.md (223f97f8)。前の金の指輪 = 2026-10-21-gold-ring-suffix-ev.md。
台本 `scripts/analysis/mana-ring-ev.mjs` (入口の束は前と同じ `_gold-ring-entry.ts`)。数字は全部 **エンジン (applyCurrency) で打った結果**。台本が決めるのは次の手だけ。

## 結論
- **どちらも現実的でない**。エッセンス後 (1) = 1 個あたり **1991 神**・完成 64% (打ち止め 2000 神)。エッセンス先 (2) = 1 個あたり **4942 神**・完成 33%。完成した人だけの平均は 865 神 / 936 神。
- 安いのはエッセンス後 (1)。(2) はカオスを打てず (最大マナ % が唯一の非固定の MOD なので、カオスで必ず消える)、サフィックスを全部完全の高貴で作るうえ、消去のたびに最大マナ % も巻き込む (1 人 67 回消えた)。
- 費用の元は **サフィックスの 3 つ** (特に全耐性 T1 が 1 回 7.1%、マナ回復 T1 が 9.8%)。完全の高貴 1 個 2.9 神を 1 人 128〜143 個使う (完全の高貴だけで 376〜418 神) のと、キャストスピードを狙うたびに軽快のカタリスト 20 個 (4.4 神) を入れ直す分 (228〜391 神) が大きい。外れ → 消去で他の狙いも消え、狙いが全部消えた回数は 1 人 40〜45 回。
- 金の指輪 (レアリティ版 220 神・単体耐性版 111 神) と比べ、狙いが 1 つ増え (プレ 2 つ)、サフィックスが全部 T1 寄り (全耐性 T1・マナ回復 T1) になった分で一桁上がった。

## 始まりと狙い
- 金の指輪 ilvl 82 のレア。プレフィックスにスペルのマナコスト効率 T1/6 (計算高い、`Rings/Special_genesis_tree_caster_SpellManaCostEfficiency`、レベル 77) をフラクチャー。創生の樹の MOD で重み 0 なので、前と同じく stage-core の makeStageMod で置いた。+ 上級の高貴 1 個の乱数の MOD (動画 ④a の 2 MOD の形)。フラクチャーまでと始めの高貴は費用 0。
- 狙い P: 最大マナ (4–6)% (精神のパーフェクトエッセンス、`Rings/PerfectEssence_MaximumManaIncreasePercent`) / 最大マナ T1/12 (藍色をした、レベル 75)。S: キャストスピード T2 以上 / 全ての元素耐性 T1/5 (レベル 68) / マナ自動回復レート T1/6 (涅槃の、レベル 79)。

## 打ち方 (台本の nextMove)
| 状態 | 手 |
|---|---|
| (2 だけ) 最大マナ % が無い | 何より先にエッセンス (下の「エッセンスの手」) |
| 狙いが 1 つも無い | カオス (1 だけ。2 は最大マナ % があるので来ない) |
| 狙いでないサフィックスがある (狙いの系統の低い段も) | 消去 (お告げ無し) |
| サフィックスの狙いが欠けている | キャストスピード → 全耐性 → マナ回復 の順に、カタリスト 20 個 (品質 20%) + 触媒の高貴 + 右側の高貴 + 完全の高貴 |
| サフィックスが揃い、最大マナ % が無い (1) | エッセンスの手 |
| 狙いでないプレフィックスがある | 消去 |
| 最大マナ T1 が無い | 神経のカタリスト 20 個 + 触媒の高貴 + 左側の高貴 + 完全の高貴 |
- カタリスト: キャストスピード = 軽快 (152.34 高貴)、全耐性 = トゥル (冷気、元素で一番安い 13.66。全耐性のタグに fire・cold・lightning があるので効く。エンジンで確かめた)、マナ回復・最大マナ = 神経 (12.10)。
- **エッセンスの手**: 非固定の MOD が外れ 1 つだけなら、お告げ無しで精神のパーフェクトエッセンス (それが消えて最大マナ % が入る)。それ以外は 左側の結晶化 + 精神のパーフェクトエッセンス (プレフィックスだけ消える)。消してよいプレフィックス (固定でも最大マナ T1 でもない物) が無ければ、先に餌を 左側の高貴 + 上級の高貴で付ける。
- **消去と最大マナ %**: 消去は非固定の MOD から等しく 1 つ消すので、最大マナ % も同じ割合で消える。消えたら上の表のとおり入れ直す (1 はサフィックスが揃ってから、2 はすぐ)。エッセンスは 1 つまでなので、最大マナ % がある間は入れ直せない (エンジンが断る。ゲームどおり)。
- 素の右側の高貴 (上級) は今回使わない (狙いが全部カタリストで重く引ける)。上級の高貴は餌と始めの 1 個だけ。

## エンジンに無い手
- 無かった。精神のパーフェクトエッセンス (`essence:perfect:Rings/PerfectEssence_MaximumManaIncreasePercent`、お告げ無しでも左側の結晶化付きでも)・神経のカタリスト (`catalyst_mana`)・左側の高貴 + 触媒の高貴は全部打てた。
- 入口に無い物は前と同じ: 重み 0 の創生の樹の MOD (今回はスペルのマナコスト効率) を始めの形に置く手段。

## 確かめた物
- エンジンで回した: 上の表は全部。
- 外の正解: MOD の名・段・レベル、エッセンス・カタリストの効果は poe2db (リサーチ長の材料)。期待値そのものを CoE と突き合わせてはいない。
- 画面: 見ていない。

## 読み方を決めた所 (ぶれる所)
- サフィックスを狙う順は頼みの並び (キャストスピード → 全耐性 → マナ回復)。順を変えた比べはしていない。
- (2) の最初のエッセンスは、始めの 2 MOD (フラクチャー + 乱数 1 つ) にお告げ無しで打つ (乱数の 1 つが消える)。
- 最大マナ % を消去で失った後に最大マナ T1 しか非固定のプレフィックスが無い時は、餌を足してから左側の結晶化 (最大マナ T1 が消える確率は 1/2)。
