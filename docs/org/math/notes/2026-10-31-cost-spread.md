# 1 人ごとの費用の分かれ方 (計算係、2026-10-31)

## 頼み
ブログ記事「クラフトの費用と運」(src/data/blog/crafting-cost-variance.ja.md) に、この記事だけの新しい数字を足す。1 人ずつの費用 (神) がどう分かれるかをエンジンで数えて残す。例は今までの記録の 2 つ (金の指輪 = 2026-10-22-gold-ring-midway.md の fresh、靴 = 2026-10-23-boots-res.md)。

## 台本
`[EX=A,B] [BUDGET=2000] node scripts/analysis/cost-spread.mjs [N=10000] [SEED_A=1] [SEED_B=7]` (1 万人 × 2 例で 155 秒)。
- 打つのは全部エンジンの入口 (applyCurrency)。台本は次の手を決めるだけ。手の決め方は gold-ring-midway-ev.mjs (fresh + 打ち方 C) と boots-res-ev.mjs (POLICY=full) の写しで、乱数の引き方まで同じ。
- 集計: 完成した人の費用を並べて分位を取る (`_ev-common.mjs` の q と同じ取り方)。「予算の中で完成」は、完成していて費用が予算以下の人 ÷ 全員。帯は完成した人の中の割合。

## 場面
- 例 A: 金の指輪 ilvl 82、プレフィックスはスペルダメージ T2 のフラクチャー + 高貴 1 個 (費用 0) から、サフィックス 3 つ (レアリティ T1・キャストスピード T2 以上・全耐性 T2 以上) まで。打ち方 C (狙い 0 → カオス、外れ → すぐ素の消去、レアリティが無い → 右側の高貴 + 上級、ある → カタリスト 20% + 触媒の高貴 + 右側の高貴 + 完全)。値段 /boot.json 2026-10-21T17:00Z (神 = 807.07 高貴)。1 万人・種 1。
- 例 B: ドレイクスキンブーツ ilvl 82、移動速度 T1 フラクチャー + 上級の高貴 1 個 (費用 0) から、火・冷気・雷の耐性 T1 のどれか 2 つまで。POLICY=full (狙い 0 → カオス、外れのサフィックス 2 つで埋まった → 消去、ほか → 右側の高貴 + 上級)。値段 /boot.json 2026-10-20 16:00Z (神 = 696.93 高貴)。1 万人・種 7。
- 打ち止めはどちらも 2,000 神 (元の台本と同じ)。ベース代は入れない。

## 記録との突き合わせ
- 例 A の平均 200.38 神 = 2026-10-22-gold-ring-midway.md の fresh・種 1 (200.4 神) と同じ (同じ手の決め方・同じ種・同じ値段なので 1 人ずつまで同じ)。
- 例 B の平均 29.86 (±0.60)・中央 20.4・90% 69.8 = 2026-10-23-boots-res.md の台本 1 万人 seed 7 と同じ。
- どちらも元の台本の写しを別の台本で回して同じ数字が出た、というだけ。外の正解 (ゲーム内の実測) は無く、エンジンの見張りにしかならない。

## 言える事
- 品も値段も 7 倍違う 2 つの例で、平均に対する分かれ方はほぼ同じ形: 半分の人は平均の約 0.7 倍まで、4 人に 1 人は 0.3 倍まで、10 人に 1 人は 2.2〜2.3 倍以上、100 人に 1 人は 4.5 倍前後。
- 平均の額を予算にしても完成するのは約 63%。9 割の人が予算の中で完成するには平均の 2 倍強、95% なら約 3 倍が要る。
- 平均より安く済む人が 63% いる (平均は高くついた少数に引っ張られる)。平均の 3 倍以上払う人は 20 人に 1 人くらい。
- どちらも「狙いが全部消えてカオスからやり直す」が費用の大半の打ち方で、1 回ごとの当たりの割合が一定に近いので、待ち時間の形 (幾何分布に近い、標準偏差 ≒ 平均) になる。記事では「この 2 つの例では」として出す。

## 言えない事
- ゲーム内の実測は無い。合っているのは同じエンジンの別の台本どうしだけ。
- 打ち方・品・値段が変われば形も変わる (例: 打ち止めがある時、カタリストのように決まった額の手が多い時は右の裾が短くなるはず。数えていない)。
- 分位は 1 万人の並べた値なので、99% や一番高い人は種でぶれる (種は 1 つずつしか回していない)。
