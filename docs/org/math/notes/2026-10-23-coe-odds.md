# 1 手の確率を Craft of Exile 自身の計算と突き合わせた (解析君、2026-10-23、11/10 までの ④)

外の正解との突き合わせはこれが初めて。台本 `node scripts/analysis/check-coe-odds.mjs 50000` (7 秒)。
- **CoE 側**: 手元の写し (data-cache/coe-beta-package_poe2.js 10-16・coe-beta-data.json 10-09・coe-beta-english.json) を Node の vm で読み込み (`scripts/analysis/_coe-load.cjs`。vm の箱に require・fs・process は渡さない、ブラウザの物は何もしない代わりで埋める)。GameItem (金の指輪 = CoE の id 2592、ilvl 82) に MOD を足し、`GameEmulator.exaltedParams` (お告げ・最低モッドレベル・触媒の品質) → `ModsManager.getFilteredModPool` で「その時点で付きうる段と重み」を取り、狙いの段の重み ÷ 合計 = 正確な割合 (CoE の rollRandomAffix がこの重みで引く)。CoE のコードそのものを動かした (式を写したのではない)。
- **エンジン側**: 同じアイテムを startFrom で作り、applyCurrency (本物の打つ処理) で 50,000 回打って数えた割合 (95% の幅つき)。

- **15 通りすべてで、エンジンの割合が CoE の正確な割合の 95% の幅の中**。ずれの % が大きく見える行 (+6.3% など) は割合が小さく、5 万回の幅 (±0.1% 前後) の中。
- これで外の正解 (CoE) と合ったと言えるのは: 指輪のサフィックスの置き場と重み、右側の高貴のお告げ、通常 / 上級 / 完全の最低モッドレベル (35 / 50)、完全でも下限に届かない系統は一番上の段が残る扱い (レアリティ T1 = レベル 40 が完全で 3.3%)、触媒の高貴の倍率 (品質 20% で ×5)、付いている系統が置き場から外れる扱い。
- 言えない事: ゲーム内の実測と合うか (CoE とエンジンが同じ前提を持っているだけかもしれない。重みの出どころは同じ系統: poe2db・Krakenbul)。カオス・消去・冒涜・エッセンスはまだ比べていない (CoE は冒涜を計算しない)。
