## 1 割を超える食い違いの元 (どこの数え方か)
- **① 狙い 0 + 外れ → 始めの手 (5 本)**: 狙いが 0 の形は始まりの箱と同じ形に数えられる (tree-run の形の箱 / match は狙いの数で見る) ので、外れが付いたままでも始めに戻って高貴を打つ。始め → 外れ (消去 1 回) → 外れが消えた → 始め の輪で、外れが 2 つになると 1 つ残ったまま高貴を続け、狙いが付いても外れと同居して次の消去で 50% 失う。ring-annul は始めの箱に 1 人 237 回、始め → 外れの箱が 216 回。
  - 確かめ: 字のとおりを「狙い 0 の時は直前の高貴で外れが付いた時だけ消去 1 回、ほかは高貴」(木の真似、`MIMIC=1`) にすると、5 本とも木と 0〜3% (ring-annul 133.32 / 133.32・124.58 / 124.58、gloves-rune 101.75 / 101.81、body-sinistral 30.21 / 30.21、amulet-catalyst 3,297 / 3,258、gloves-perfect 11,652 / 12,007)。外れが消えた・狙いが消えたの戻りを「形の合う箱へ」に替えても (`FIX=lost`) 数字は同じ (狙い 0 の形の合う箱が始め)。
  - = tree-run の回し方は木のとおり正しく、高いのは木の形。画面では「狙い 0 で外れがある時は消去」を組めない (始めの箱の中を外れの有無で分けられない)。直し方の案 (シミュ部長・オーナー): 始めの箱も「外れがある時はその外れの箱へ」(形の合う箱の見方に外れの有無を足す) か、始めの手の前に分かれ目を置けるようにする。
- **② amulet-spam-split**: #3 (aimHeld が系統で合わせ、スペルスキルのレベルの狙いにミニオン・投射物・近接のレベルが当たる) で 29〜34% が止まり、止まった人の費用も 1 個あたりに入るので高い。
- **③ body-essence**: #5。字のとおり (エッセンスの MOD を残す MOD として外れから外す) なら 1 個 約 62 神・完成 100% (パーフェクトエッセンスは値段 0)。
