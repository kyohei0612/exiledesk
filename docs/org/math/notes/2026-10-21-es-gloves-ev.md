# ES の手袋のプレフィックス 3 つの期待値 (金の指輪の C を左右逆に、エンジンで回した、2026-10-21)

頼み: サム開発部長 (オーナー 10-21「プレフィックスのみまず揃えて、例の作り方で」)。リサーチ長の確かめ (docs/org/research/notes/2026-10-21-es-gloves-mods.md) は待たずに、MOD の名はエンジンのデータで決めた (届いたら突き合わせ)。
台本 `scripts/analysis/es-gloves-ev.mjs` (入口の束 `_gold-ring-entry.ts`、ベースの一覧を見るため htcBaseInfo を足した)。数字は全部 **エンジン (applyCurrency) で打った結果**。

## 結論
- **左側の高貴 + 上級の高貴が一番安い: 1 個 105 神 (±11)・完成 100%**。完全の高貴は 201 神、通常の高貴は 423 神 (完成 99.7%)。
- **手袋ではカタリストも触媒の高貴も使えない** (エンジンが断る:「カタリストは指輪・アミュレットだけ」。ゲームのカタリストの説明文「指輪またはアミュレットに追加する」どおり)。頼みの「カタリスト 20 個 + 触媒の高貴 + 完全の高貴」は打てないので、素の左側の高貴で通常 / 上級 / 完全を比べた。エンジンに足す手ではない (ゲームに無い)。
- 上級が勝つ理由: 完全の高貴は 1 個 2.9 神で、当たりの上がり方 (高貴 65 → 45 個) が値段に見合わない。通常の高貴は最低 MOD レベルが無く、低い段の外れ → 消去 → 狙いが全部消えてカオスに戻るのが 1 人 111 回に膨らむ。

## ベースと始まり
- ベース: **サイレーンスケイルの手袋** (Sirenscale Gloves、ES 54・必要レベル 80)。知性の手袋 (Gloves_int) のうち、ilvl 82 で一番 ES が高い普通のベース (次はヴァールの手袋 ES 51・レベル 75。ルーンフォージ / ルーンマスターの物は除いた)。
- サフィックスに **投射物スキルのレベル +2** (`Gloves_int/Rune_marksman_IncreaseSocketedGemLevel__projectile_skill_gem_level` の 2 段目、MOD レベル 65) をフラクチャー。普通の置き場に無く (創生の樹の物)、startFrom が断るので、前と同じく makeStageMod で置いた。+ 上級の高貴 1 個の乱数の MOD (動画 ④a の 2 MOD の形)。フラクチャーまでと始めの高貴は費用 0。
- 狙い (プレフィックス、全部 T2 以上): 最大 ES (ローカル固定、`LocalEnergyShield`、7 段、T2 = レベル 46) / ES 増加 % (`LocalEnergyShieldPercent`、7 段、T2 = レベル 60) / 最大マナ (`IncreasedMana`、9 段、T2 = レベル 54)。ES + ライフの混ざった物 (`LocalIncreasedEnergyShieldAndLife`) は外れ扱い。サフィックスは何でもよい。

## 打ち方 (金の指輪の C を左右逆に)
| 状態 | 手 |
|---|---|
| 狙いが 1 つも無い | カオス |
| 外れのプレフィックス (狙いの系統の低い段も) がある | 消去 (お告げ無し) |
| 狙いが足りない | 左側の高貴のお告げ + 高貴 (通常 / 上級 / 完全) |
- **消去とサフィックス**: 300 人 × 3 通りで、消去がサフィックスに当たった事は **0 回**。カオスの間は MOD が 2 つ (フラクチャー + 1 つ) で、カオスが入れ替えるのはその 1 つだけ。狙いのプレフィックスが付いた時点で非固定のサフィックスは無く、その後は左側の高貴しか打たないので、サフィックスは最後まで投射物 +2 だけ (完成時の非固定のサフィックス 0 個)。もし始めに非固定のサフィックスが付いた形から始めると、消去がそれに当たって外れのプレフィックスが残る分だけ消去が増える (今回の形では起きない)。

## 追記 3: サフィックス (サム 10-21、オーナー「プレが消えたら 1 回で 100 神飛ぶ。普通の消去で行くか、お告げを付けた消去か」)
形: コルの狩りだけ差す (セールの凱旋は無し = サフィックス 3 枠)。始め = プレフィックス 3 つ (ES 固定・ES%・最大マナ、T2 で置いた) + 投射物 +2 (F)。プレフィックスの 194 神は下の表に入れず、合計の列で足した。
- X = クリティカルヒット率 T2+ (マークスマン `Rune_marksman_CriticalStrikeChanceIncrease`、3 段) + クリティカルダメージボーナス T2+ (`CriticalStrikeMultiplier`、5 段。T2 = レベル 45 で重み 500、T1 = レベル 59 で 250)。
- Y = クリダメ T2+ + アーケインサージ (冒涜の `ArcaneSurgeOnCrit`)。冒涜は保存された肋骨 (6.75 高貴)。手袋の冒涜のサフィックスは 15 種で、エンジンの重みは全部 2500 (頼みの「全部同じ」と同じ)。プレフィックスが 3 つ埋まった時だけ打つので、未発現の枠はサフィックスに入る。発現は 3 つの候補にアーケインサージがあればそれを選び、無ければ 1 番 (外れ → 消去)。
- 足すのは右側の高貴 + 上級。カオスは使わない (プレフィックスも消すため)。
- (a) 素の消去: 非固定の 5 つ (プレ 3・サフィ外れ・サフィの狙い) から等しく 1 つ。プレフィックスに当たったら、消えた狙いを左側の高貴 + 上級で作り直し、外れのプレフィックスも素の消去 (全部込み)。

- (a) が悪い理由: 外れを素で消すと 5 つのうち 3 つがプレフィックスで、消えたプレフィックスの作り直しは 1 回 6〜7% しか当たらない。作り直しの外れを消す消去がまた別のプレフィックスに当たる、と連鎖して、消えたプレの狙いが 1 人 130〜280 回。オーナーの「プレが消えたら 1 回で 100 神飛ぶ」のとおり。

- Y が X より安いのは、クリ率 (2.5%) の代わりのアーケインサージが冒涜 1 回 6.75 高貴 + 発現で 7.4% 当たり、外れのサフィックスを消す回数が減るため。
- 頼みの形 (右側の高貴 + 上級で狙う) のままでは、サフィックスはこの手袋の費用の大半になる。他の付け方 (エッセンス・カタリストの無い手袋で重みの低い MOD を狙う道) は今回比べていない。

## 追記 4: サフィックスは Y だけ (オーナー 10-21「クリ率消して 3 MOD でおｋ」) + 冒涜の発現と外れの消し方
狙い = 投射物 +2 (F) + クリダメ T2+ + アーケインサージ (冒涜)。上の X の行は残すだけ (もう回さない)。
**冒涜の抽選 (エンジンの発現の手をそのまま使った)**
- 冒涜の置き場はリサーチ長 4f5fb8f8 と同じ 15 種 (エンジンも 15 種、全部サフィックス・重み 2500 で同じ)。アーケインサージはクルガルの 1 種。
- 発現は **3 つの候補から 1 つ選ぶ**。3 つのうち冒涜専用の MOD は 1 個 (480/563)・2 個 (78/563)・3 個 (5/563) で、残りは普通のサフィックスの MOD (普通の重み)。同じ系統は 2 つ出ない (エンジンの drawOffers、CoE の getRevealPicks と同じ)。深淵の反響のお告げ (61.60 高貴) を掛けると、もう 1 組の 3 つから選べる (引き直し 1 回)。
- アーケインサージが 3 つの候補に出る割合 = **7.40%** (エンジンで 5,000 回)。素の 1/15 = 6.7% ではなく、候補に出る割合で数えた (専用 MOD が平均 1.16 個なので 1/15 より少し上)。
