## 不具合 (重い順、新しい物)

### 1. どのベースを選んでも「金の指輪 Lv 82」になる (5 種 5 回中 5 回、100 手の 5 匹とも)
- 手順: ?page=sim-base → 部位 → ベースの札 (サファイアの指輪・ルビーの指輪・バイオスタティックリング・不在のアミュレット・頑丈なハンマー) → sim-mods へ進む。
- 実際: sim-mods の上の「1 ベース」が「金の指輪」。決めた (ツリーへ) の後、ツリーのスタート・左の「0 完成形の設定」も「金の指輪 Lv 82 適正」。sim-mods の一覧は選んだベースの物が出ている (サファイアの指輪の文字も画面にある)。sim-mods で付けた狙いはツリーで「完成の狙いがまだ無い」(2 完成の MOD 0)。
- 期待: 選んだベースでツリーが始まり、狙いも引き継がれる。
- 影響: シミュレーターで金の指輪以外が組めない。100 人の数・費用が全部金の指輪のまま。
- 再現: repro-c.mjs・repro-d.mjs (`CDP_PORT=9335 node repro-c.mjs`)。

### 2. 狙いが無い時のスタートの ＋ で開く「スタート」の窓が閉じない (3 回中 3 回、100 手で 5 匹中 3 匹が 60〜80 手閉じ込められた)
- 手順: 1 の形 (狙い 0) でツリーへ → スタートの箱の中の ＋ (「次に打つ手を足す…」) を押す。
- 実際: 「スタート / 白 (ノーマル) から始める… / 0 完成形の設定で印を変える → / 決めた (ツリーへ)」の窓が出て、右上の ×「ツリーへ戻る (Esc / 枠の外を押す)」・Esc・「決めた (ツリーへ)」・枠の外のどれを押しても閉じない。読み直す (?page=sim-tree を開き直す) と閉じる。JS のエラーは無し。
- 影響: 初めての人は読み直す以外に抜けられない。保存・レシピのボタンも窓の下で押せない (棚好き・取り消し好き・ツリー替えの猿はレシピの確かめまで行けなかった)。
- 再現: repro-b.mjs。

### 3. 保存したレシピが戻らない (3 回中 3 回)
- 手順: ツリーで錬金術 1 手 (箱 2 つ) → 保存 (「『金の指輪 10/25 21:05』で保存しました」) → レシピ ▾ → URL をコピー (「今の木の URL をコピーしました (開いた人はこの木で始まる)」) → 白紙に戻す → もう一度押すと白紙に戻す → レシピ ▾ → 一覧の「金の指輪 10/25 …」を押す / URL を「共有されたレシピの URL を貼る」に貼って「開く」。
- 実際: どちらもスタートだけのまま (錬金術の箱が戻らない)。一覧の札の下は「ベースなし」、頭の印は「空」。写した URL (web.html#recipe=…) を保存なしの新しいタブで開くと ?page=sim-base に着き、木はスタートだけ。
- 期待: 保存した時の木 (箱 2 つ) が戻る。URL を開いた人もその木で始まる。
- 1 と同じ時に出たので、1 が直った後にもう一度見る。

## 迷った所・見た目
- 「白紙に戻す」は 1 回目で「もう一度押すと白紙に戻す」に変わる (2 度押し)。猿は 1 回目で効かないと思った (仕様どおり、数えない)。
- 左の「0 完成形の設定」の札の右上の「MOD」タブが札の題の上に半分重なる (1660×860)。
- 100 手の「効かない」(押しても画面の文が変わらない) の多い物: sim-base の「指輪 Lv 1」「たたむ」「on」(チェック)・sim-mods の「決めた (ツリーへ)」(12 回、まじめ)。sim-mods の決めたは 2 の窓の後ろにある時の数を含むので、重さは決めない。
