## 不具合・食い違い (重い順)

### 1. 消去の後の箱「外れが消えた」に自動の「↩ 始めに戻る」が付く (6 本中 6 本)
- 手順: 指輪 → 狙いを 1 つ → スタートに変成のオーブ (狙い無し) → 「打った後」の箱に消去のオーブ + 右側の消去のお告げ。または スタートにブリーチのエッセンス → 消去のオーブ。
- 実際: 結果の箱は「外れが消えた / 外れの MOD が消えた ↩ 始めに戻る」1 つだけで、自動の矢印でスタートへ戻される。＋ が無くその箱から先へ手を足せない。
- テストで回す (穴 5): スタートで「ノーマルのアイテムにだけ使える (5 人中 3 人)」「30 人中 9 人止まる: ノーマルのアイテムにだけ使える」= 戻った人はマジック (MOD 0 個) で、スタート (白) と同じ形ではない。
- 期待: マジックで MOD 0 の形は白のスタートと別の箱 (自動の矢印を付けない、または付けるなら同じ形の箱へ)。
- 影響: 変成 → 消去 → 変成 / 増強 のような道が組めない。初めての人は「なぜ ＋ が無いのか」で止まる。
- 回: r6-b m-2・m-3・m-4、r6-c m-3・m-4 (+ r6-a の消去なしは関係なし)。

### 2. 打てない人が次の箱へ進んでいる (お告げつき消去) (2 本中 2 本、テストの一覧の文)
- 手順: 1 と同じ (変成 → 消去 + 右側の消去のお告げ)。
- 実際: テストの一覧に「消去の箱: この箱に着いた状態では手が打てない (5 人中 2 人): お告げの側に外せる MOD が無い」とあるのに、30 人の方では「スタートで 30 人中 21 人止まる: プレフィックスが満杯 (外れ 1: 雷ダメージが24%増加する (T2))で着き」= プレフィックスを持ったまま (消去が効かずに) スタートまで来た人が 21 人。
- 期待: 右側のお告げでプレフィックス 1 つの人は消去の箱で止まる (スタートには来ない)。
- 回: r6-b m-3・m-4、r6-c m-3・m-4 (同じ形)。

### 3. 穴の一覧の理由が実際と違う (錬金術の外れを始めに戻した木) (3 本中 3 本)
- 手順: スタートに錬金術 (狙い ☑) → 外れの葉を「↩ 既にある箱へ戻す」→ スタート (または帯の「↩ 始めに戻る」)。
- 実際: スタートに「回すと 30 人中 28〜30 人がここで止まる: サフィックスが満杯 (外れ 3: …)で着き、この手が打てない。この手の前に外れを消す手 (消去 + 満杯の側のお告げ) が要る」と「この箱に着いた状態では手が打てない (5 人中 5 人): ノーマルかマジックのアイテムにだけ使える」が並ぶ。
- 期待: 打てない理由はレア (錬金術はノーマル・マジックだけ)。「消去 + お告げが要る」は直しても打てないので、初めての人が誤った手を足す。
- 回: r6-a m-0、r6-b m-0・m-1、r6-c m-0 (錬金術の外れ → 始め)。エッセンスの猿 r6-c m-2 も同じ形 (変成の外れ → 始め、「サフィックスが満杯 (外れ 1)」と「ノーマルのアイテムにだけ」)。

### 4. sim-mods で冒涜の MOD に「フラクチャー」が押せる (2 本中 2 本)
- 手順: sim-mods で「ウラマン…」「アマナム…」の行 (冒涜の MOD) を開いて「フラクチャー」→ 決めた → 「フラクチャー済みから」。
- 実際: 押せてツリーへ進み、テストで「始まりの形が作れない: 冒涜の MOD はフラクチャーできない」(r6-b m-2)。「フラクチャー前から」を選ぶと穴に出ず、左の MOD に「+ ✦ T1 レムナントは…」が残る (r6-c m-4)。
- 期待: sim-mods の時点で冒涜の MOD の「フラクチャー」は押せない (理由の title つき)。

### 5. 見た目: 左の「完成形の設定」の札が細い (10 本中 10 本、画面 1660×860)
- ベース名「サファイアの指」が右の「ベース」ボタンの下に切れる。MOD の文が細い列に 5〜6 行で折れる (「物理アタッ / クダメージ / の7.45% / をライフと / してリーチ / する」)。

## 迷った所 (不具合でない・軽い)
- sim-mods の一覧の上の方に冒涜の MOD (アマナム・クルガル・ウラマンの頭) が並ぶ。初めての人がそれを狙いにすると、錬金術・変成の窓に狙いのチェックが出ず「狙い無し」だけになる (r6-b の 5 本中 3 本)。
- 「100 人回す」は穴があっても・完成の箱が無くても押せる (横の文は「100 人: 1 個 — 神 · 完成 —%」)。押すと何が起きるかは見ていない。
- 自動の矢印の札「↩ 狙い同じ外れ (狙い無し)」の行き先の箱は「外れ 当たり以外が付いた」で、札と箱の文が違い、どこへ戻るか読みにくい。
- 長い冒涜の行 (「アマナム直近パワーチャージを消費していれば… / … / …」3 行) は猿が押せなかった (台本の探し方の疑いあり、1 回だけ数えない)。

## レシピ
- 「保存」→「『サファイアの指輪 10/25 20:39』で保存しました (名前を押すと変えられる)」。「レシピ ▾」に「保存したレシピから開く」の一覧 (名前・狙いの数・✦・時刻)・開く・別名で保存・URL をコピー・レシピの一覧へ。10 本とも出た。
- 「開く」「URL をコピー」で戻せるかは、画面が変わったので見ていない (残り)。

## 台本の残り (不具合ではない)
- エッセンスの札「全 3 段」は押すと段の選びが出るが、台本が段を選べず「使っても手にならない」(r6-c m-2 で 5 回)。
- 木の結果の箱 (bbd56d66) と エンジン: 錬金術 (狙いあり) = 当たり + 外れ、カオスの当たるまで = 当たり + 外れ、変成 (狙い無し) = 打った後 1 つ、消去 + お告げ = 外れが消えた 1 つ。照らしの台本は戻りのある木の箱ごとの割合を比べないので、エンジンと照らせたのは合格した 1 本の完成・個数だけ。
