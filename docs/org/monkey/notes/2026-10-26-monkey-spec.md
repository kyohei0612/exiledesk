# 細かい仕様の穴を探す猿 2 匹 (隊長 6 本目、10-26 未明)

オーナー「ツリー作業じゃなくてそういう細かい仕様のダメなところ見つけるサル2匹30手」(ブラック経由、決まり 14 の例外)。
- 行き先: 手元 dev サーバー 1440 (v0.1.606)。猿 A = PC 1660×860、猿 B = 375×812。窓なし Chrome 9335 (止めた・profile と絵を消した)。回す間はシミュ 29 に src の保存を止めてもらった。
- 形: 場面ごとに新しいタブ (保存も別) で「作りかけの木」(サファイアの指輪・スタート + 錬金術の手 1 つ・名前なし = 保存していない) を作り直し、離れる操作と選ぶ操作だけを数えた (木を作る手は数えない)。
- 手の数: A 38 手・B 22 手 (2 匹で 60 手。A が 8 手多かった)。JS のエラー 0 (375 幅で `[Vue Flow]: Viewport not initialized yet.` の警告だけ毎回)。
- 台本: 共有メモ local_cbd85ab5…/monkey-scripts/ の spec30.mjs (`CDP_PORT=9335 node spec30.mjs <出力> A|B|A2|B2`)。出力 s4/ (A)・s6/ (B)・s7/ (A2・B2)。前の monkey-scripts (local_52fe22f9…) は消えていたので、lib2.mjs・ui-lib.mjs を 10-25 朝の写しから作り直した。

## 不具合・穴 (重い順)

### 1. 貼り付け (Ctrl+V) が保存を聞かずに作りかけの木を置き換える (2 回中 2 回、PC と 375 幅)
- 手順: 作りかけの木 (名前なし、保存していない) → ツリーの画面で Ctrl+V (クリップボードに指輪の文: `アイテムクラス: 指輪 / レアリティ: レア / ドゥーム ループ / ルビーの指輪 / … 最大ライフ +60`)。
- 実際: 3 択が出ずに ?page=sim-mods へ移り、ベースがルビーの指輪になる。作りかけの木は消える (PC は箱 1 つ、375 幅は答えた手が 0)。
- 期待: ほかの入り口と同じく「保存して進む / 保存せず進む / やめる」。

### 2. 離れて戻ると作りかけの木に戻れない (PC、2 回中 2 回)
- 手順: 作りかけの木 → ヘッダーの「使い方・コツ」→ 3 択で「保存して進む」(または「保存せず進む」) → ブラウザの戻る。
- 実際: ?page=sim-base に着き、木はスタートだけ。上の「3 ツリー」を押してもツリーへ進まない。「保存して進む」の時はレシピの一覧に入っている (「サファイアの指輪 10/26 00:13 · 狙い 1」) ので、一覧から開けば戻る。
- 期待 (迷う所): 戻ったら続きの木 (少なくとも保存した物) が出る。375 幅は戻る → 進むで木が戻った (下)。

### 3. 保存した後の読み直しで木が消える (PC、1 回)
- 手順: 作りかけの木 → Ctrl+S (「『サファイアの指輪 10/26 00:13』で保存しました」= Ctrl+S は効く) → 読み直し。
- 実際: ?page=sim-base に着き、木はスタートだけ、「3 ツリー」でも進まない。保存していない時の読み直しはブラウザの「離れますか」(beforeunload) が出て止まる (PC)。375 幅は保存していない読み直しで木がそのまま残った。
- 期待: 保存した木は読み直しても開いたまま (または PC と 375 幅で同じ動き)。

### 4. 白紙に戻すは 3 択でない (PC、1 回)
- 手順: 作りかけの木 → 白紙に戻す → 「もう一度押すと白紙に戻す」。
- 実際: 保存を聞かずに木がスタートだけになる (名前なしのまま)。2 度押しの確かめはある。
- 期待 (決めごと): ほかの入り口と揃えて「保存して…」を出すか、今の 2 度押しで良いかはシミュ部長の判断。

## 聞いた入り口 (3 択「保存して進む / 保存せず進む / やめる」+ 右上の閉じる)
- PC: 上のタブ「エミュレーター」(既知の「エミュへ出る時は聞かない」は今は聞く)・ヘッダー「使い方・コツ」。やめる・Esc・枠の外はどれもツリーのまま木も名前も残る。
- 375 幅: ヘッダー「使い方・コツ」・上のタブ「デイリー」。やめるでツリーのまま。
- ベースを替える (1 ベース → ルビーの指輪): 別の 3 択「ルビーの指輪 の白紙から組み直します。今の木 (箱 1 個) が消えます。… (1 つ戻すで戻せます)」+「保存して替える / 保存せず替える / やめる」。
- 保存していない読み直し (PC): ブラウザの「離れますか」。

## 迷った所・見ていない物
- 保存の 2 度押し: 2 回目で名前の欄に入り (名前を書き換える形)、2 つ目の保存はされない (トーストは 1 回)。仕様どおりに見える。
- 375 幅: 「ブログ」は押しても離れなかった (台本の探し方の疑い、数えない)。ブラウザの戻るは 2 完成の MOD へ (聞かない)、進むで木が戻る。
- 375 幅に木のタブ (ツリー①②・新しいツリー) は無い。PC のタブの × は台本が押せず見ていない (× はタブの横にある)。
- 作りかけのままレシピの一覧の札を開く: 台本で手が足せず「作りかけ」にならなかったので見ていない。
- 375 幅の「人気のベース」の札 (金の指輪 など) の中に部位名「指輪」が書いてあり、部位の「指輪」と取り違えやすい (猿が 3 回押し間違えた)。
