# PC の猿 3 匹 (指輪・セプター・ジュエル、エミュ 30 手 + ツリー 10 手、10-27、隊長 9 本目)

オーナー 10-27「暇だしサルに PC 版触らせてみるか。3 匹で指輪・セプター・ジュエルで、ツリーも込みの UI/UX・ツリーの挙動チェック。30 手で頼む、ツリーの方は 10 手に一旦」。

## 何をしたか
- 場所: オーナーの確認用の固定の開発版 http://dev.exiledesk.localhost:1461/ (v0.1.625)。PC 1660×860。窓なし Chrome 1 つ (9336、自分のプロファイル)、3 匹は順に。各猿の始めに localStorage を消して最初から。
- エミュ 30 手は台本 (種つき乱数): カレンシーを持ってアイテムを押す・持ったまま連打・お告げ・エッセンス (段の小窓で段も選ぶ)・1 手戻す・R・Ctrl+Z・白に戻す (2 度押し)・Esc・枠の外・MOD の右クリック・×・見えているボタン適当・ホイール・アイテムの右クリック。毎手エラー・アイテムの文・横のはみ出し・NaN 等を記録。
- ツリー 10 手は 1 手ずつ手で (見て次を決める)。毎手の後に重なり (docs/org/monkey/overlap.mjs) と枠からのはみ出しを数えた。
- 台本: 共有メモ local_526b63a7…/monkey9-scripts/ (emu30.mjs・d.mjs の daemon・go.sh・q.mjs)。
- **JS のエラー 0、固まる 0** (3 匹のエミュ 90 手・ツリー約 30 手とも)。

### 外した物 (道具のせい)
- 猿 1 のツリーの途中まで、エミュの台本が切れた時に画面の大きさの指定が外れ、実は 1644×765 で動いていた (絵は 1660×860 で撮れていた)。このせいで「始め方の窓で 1 つ下の丸が選ばれる」「整列で 3 箱でも下が切れる」「スタートの札が枠の上で切れる」に見えた物は、1660×860 に直して出ないことを確かめたので外した。下の一覧は全部 1660×860 で出た物。
- 次の隊長へ: 別の台本で同じタブにつないで切ると Emulation の指定が消える。切った後は daemon で `{"dev":"PC"}` をかけ直す。

## 猿ごとの手の流れ
### 猿 1 指輪 (ニーモニックリング、種 11)
- エミュ: 変成 (上級) → 王者を持って枠外 → 破滅のエッセンス (通常) → Ctrl+Z → × で外す → 神 → 祝福のお告げ + 神 → 解凍のレッサーエッセンス → 消去 → 1 手戻す → R → 白に戻す (2 度押し、0 手へ) → 変成 → 連打 (効かず、正しい) → ▼ → R → 白に戻す → ヒネコラの髪束 → Ctrl+Z … 最後は白・0 手。エラー 0。
- シミュへ: 狙い 0 の白で「完成の MOD」→ 決めた → (始め方の窓は出ず) ツリー。＋ → 錬金術 → 「＋ 打った後」の札を押す → ＋ → カオス + 左側の抹消のお告げ → 整列 → テストで回す → 100 人回す (足りない所の窓) → 保存 → URL をコピー。
### 猿 2 セプター (憤怒のセプター、種 22)
- エミュ: 変成 → Ctrl+Z → スルードの力 → Ctrl+Z → 変成 → 王者 → MOD を右クリック (フラクチャー) → カオス → 神 → 1 手戻す → ヒネコラ → 高貴 (上級) → カオス (上級) 連打 など。最後は S5 フラクチャー + S1・S3 のレア、10 手。エラー 0。
- シミュへ: 狙い 3 つで取り込み → 決めた → 始め方の窓 (フラクチャーから: クリティカルダメージを選ぶ → (a) フラクチャー済みから) → ＋ → 高貴 + 右側の高貴なお告げ + 狙い 2 つ → 当たり 2 + 外れの 3 箱 → 箱の「まとめる」→ 真ん中の箱 → 帯の「まとめる」→ 外れの ↩ → 「↩ 1 段目へ戻る」→ 整列 → 完成 → 100 人回す (スタートの足りない所で止まる、案内あり)。
### 猿 3 ジュエル (サファイア、種 33)

## 見つけた物 (重い順)
数: 壊れ 3 (押しても何も起きない 1・値の食い違い 2) / 迷い 4 / 見た目 7。

### 1. [見た目] レシピ ▾ の中身が右の列からはみ出して切れる (「開く」が見えない)
- 手順: ツリーで右の列の「レシピ ▾」を押す (3 匹とも同じ)。
- 期待: 開いた中身が列の中に収まる。実際: 「共有されたレシピの URL を貼る」の欄・「開く」・「レシピの一覧へ」が列の右の端 (x 1605 あたり) で切れ、「開く」は見えず、「レシピの一覧へ」は「レシ」だけ。保存したレシピの 2 行目も「…」。
- 絵: monkey9-scep-1-recipe-cut.png (共有メモ local_526b63a7…)。

### 2. [壊れ] 足りない所がある木で「テストで回す」を押しても何も起きない
- 手順: 足りない所が 1 つ以上ある木 (猿 1: 2 件、猿 3: 3 件) で「テストで回す」。
- 期待: 回る (止まる所まで) か、「100 人回す」と同じく足りない所の窓を出す。実際: 画面の文も要素の数も押す前と同じで、何も出ない (2 回とも)。「100 人回す」は足りない所の窓を出す。

### 3. [迷い] エミュでフラクチャーした MOD が、シミュの始め方の窓に引き継がれない
- 手順: エミュで MOD を右クリックしてフラクチャー → 「シミュレーターへ」→ 決めた。
- 期待: 「フラクチャーから」でその MOD が選ばれている (エミュの形のまま始まる)。実際: 既定は「白ベースから (フラクチャー無し)」で、どの MOD もフラクチャーの印が付いていない (右のカードにも ✦ が無い)。セプター (S5 クリティカルダメージ) とジュエル (S1 冷気耐性の最大値) の 2 回とも。

### 4. [迷い] 外れの箱の ↩ で、戻せる先が 1 つも無いのに理由が出ない
- 手順: 猿 3: 白 → 変成 → 外れ (マジック) の箱の ↩。
- 実際: スタートの箱も帯の「↩ 1 段目へ戻る」も灰色で押しても何も起きず、帯の「戻り先の箱を押す (Esc でやめる)」のまま。マジックを白へは戻せないので選べないのは正しいが、なぜ全部押せないのかが出ない。Esc で抜けられる。
- 絵: monkey9-jewel-2-return-none.png (灰色のスタートの上に浮きカードもかぶっている)。

### 5. [見た目] 箱の浮きカード (アイテムの絵) が隣の箱にかぶる — まとめる・横の ＋ の時に押したい箱を隠す
- 手順: 猿 2: 箱の「まとめる」を押す (まとめ先を選ぶ中)。猿 3: 横の ＋ で箱を足した直後。
- 実際: 押した箱の浮きカードが右隣の箱の上に出て、まとめ先に選べる真ん中の箱を 247×210 px 隠した (重なりの式で 10 件)。猿 3 でも新しい箱の浮きカードが左隣の箱に 246×106 px。端の見えている所を押せば選べた。
- 絵: monkey9-scep-2-merge-hover.png。

### 6. [見た目] 横の ＋ で箱を足すと、左右の箱が枠の外へはみ出す (自動で寄らない)
- 手順: 猿 3: 当たり 2 + 外れの段で、真ん中の箱の横の ＋ → MOD を選ぶ。
- 実際: 4 箱になり、左の箱は x −30、外れの箱は右の枠 (1350) の外まで (1426)。5 箱中 3 つが枠の外 (上のスタートも)。整列で全部収まった。
- 絵: monkey9-jewel-1-side-plus-cut.png。

### 7. [見た目] 白紙 → 戻す で、整列した並びが崩れ 100% に戻って左右がはみ出す
- 手順: 猿 3: 整列した木 (75%) → 白紙 → 保存せず進む → 戻す。
- 実際: 木は戻るが倍率が 100% になり、左端と右端の箱が枠の外 (x −26・右 1421)。白紙の前は 5 箱とも枠の中。

### 8. [壊れ・値] 同じフラクチャー済みのスタートから出た箱で、フラクチャーの値が箱ごとに違う
- 手順: 猿 2: フラクチャー済みから (✦ T5 以上 クリティカルダメージ 15-19%) → 高貴 → 当たり / 外れの箱。
- 実際: 外れの箱は「S4 … 22% フラクチャー」、まとめた当たりの箱は「S5 … 19% フラクチャー」(戻り先を付けた後に 22% → 19% に変わった)。フラクチャーした MOD は 1 本の流れで同じ値のはず。

### 9. [壊れ・値] 暗黙の値が、完成形の設定と手の窓のカードで違う
- 手順: 猿 1: エミュで神のオーブを使い暗黙が「最大マナが5%」→ シミュへ → ツリーの ＋。
- 実際: 完成形の設定とスタートは「最大マナが5%増加する」、手の窓のカードは「最大マナが4%増加する」。

### 10. [迷い] 手の窓の棚に神のオーブが無い (エミュのレアの棚にはある)
- 猿 1: レアの箱の ＋ の棚は 13 個 (高貴・カオス・消去・フラックス・鎖骨・エッセンス)。同じレアのエミュの棚には神のオーブ・フラクチャーオーブ・ヒネコラもある。わざとならよいが、エミュから来た人は「神が無い」で迷う。

### 11. [迷い] 箱の上の札「＋ 打った後」は ＋ が付いているが押しても何も起きない
- 猿 1: 狙い無しの箱の上の「＋ 打った後」を押す → 見た目の変化なし (ボタンではなく札)。横の ＋ (当たりを横に足す) は箱の右の縁の丸で、別の物。

### 12. [見た目] 手の窓の狙いの行が「…」で切れる
- 猿 2: 高貴を持った時の狙いの 2 行目「T1 サフィ プレイヤーの存在下にいる味方はキャストスピードが(17-20)%増加…」。1660 の幅で左の欄に収まらず、折り返さずに切れる。

### 13. [見た目] 「URL をコピー」の知らせが「…」で切れる
- 「今の木の短い URL をコピーしました (開いた人はこの木で始まる)」が 248 px の帯に 370 px で、「(開…」まで。

### 14. [見た目] スタートの箱でフラクチャーの文が ＋MOD のボタンの下にもぐる (75%)
- 猿 2: 整列 (75%) の後、スタートの「✦ T5 以上 プレイヤーの存在下にいる」が「＋MOD」の左の端で切れる (100% では「…」付きで収まる)。
