オーナー「UI設計上おかしい導線とか親切じゃないところをめどに」(ブラック経由、2 匹 × 30 手)。
- 行き先: 手元 dev サーバー 1440 (v0.1.606 + シミュ 29 の e6084ec6・d7344710 = 離れる時の 3 択の後)。猿 A = PC 1660×860 (29 手)、猿 B = 375×812 (29 手)。窓なし Chrome 9335 (止めて返した)。JS のエラー 0。
- 形: 初めての人の流れ (上のタブ シミュレーター → 指輪 → サファイアの指輪 → MOD を狙い → 決めた → 手を 1 つ → テスト → 100 人 → 結果 → 保存・名前 → レシピの一覧 → 戻る → 1 つ戻す・やり直し → エミュへ出て戻る) を 1 手ずつ撮り、絵を見て迷う所を書いた。
- 台本: 共有メモ local_cbd85ab5…/monkey-scripts/ の ux30.mjs (`CDP_PORT=9335 node ux30.mjs <出力> A|B`)。出力 u2/ (u1/ は直しの前の回、PC の結果は u2 と同じ)。
- 書き方: どこで / 何をしようとして / どう迷ったか / 案 (1 行)。

## PC (猿 A)

1. **2 完成の MOD に着いた時、上が見えない** — どこで: ベースの札を押した直後。何を: 何を選ぶ画面かを見る。迷い: 途中まで送られた形で開き、題と手順の帯が見えない。左のプレフィックスの列は見出しの下が空で、行が上の帯の下に隠れる。案: 着いた時は一番上から見せる。
2. **狙いにした MOD が、手の窓では外れている** — どこで: スタートの ＋ → 錬金術のオーブを持った窓。何を: 2 で選んだ「混沌耐性 T1」を狙って打つ。迷い: 「当たりの箱にする MOD ☐ T1 サフィ 混沌耐性」「☑ 狙い無し」で開き、そのまま使うと結果は「打った後」1 つ (当たり・外れに分かれない)。「当たりの箱にする MOD」も分かりにくい。案: 狙える手は狙いに ☑ を入れて開く。言い方は「狙う MOD」。
3. **始めたばかりで赤い「!」と「穴 2」** — どこで: 決めた直後のツリー。迷い: スタートが赤い枠で「!」、上に赤い「穴 2」。開くと「完成の箱が無い」。壊れた・間違えたに見える。「穴」の意味も分からない。案: 始めたばかりは赤でなく案内 (「次は ＋ で手を足す」)、「穴」は「足りない所」。
4. **＋ が 2 種類、↩ に説明なし** — どこで: ツリーの箱。迷い: スタートの箱の中の右の小さな「＋」と、手の箱の下の丸い「⊕」がある。手の箱の中の小さな「↩」は文字なし。案: 手を足す ＋ は 1 つの形に、↩ には文字か上に乗せた時の説明。
5. **「100 人回す」で穴の一覧が開くだけ** — どこで: 穴がある木で「100 人回す」。迷い: 回らず、穴の一覧が開き直すだけで「穴を直すと回せる」の言葉が無い (「閉じる」は効く。前の記録の「閉じても残る」は 100 人回すで開き直していた)。上の「4 結果」も灰色で押しても何も起きない。案: 一覧の頭に「穴を直すと 100 人回せます」。
6. **穴の一覧が木にかぶる** — どこで: 「穴 2 ▾」で開く一覧。迷い: 完成形の札とスタートの箱の上にかぶり、直したい箱が見えない。案: 一覧を木の外に出すか、木をよけて開く。
7. **名前を変えても「保存しました」が前の名前のまま** — どこで: 保存 → 名前を押して「サファイア練習」に変えた後。迷い: 帯は「『サファイアの指輪 10/26 00:31』で保存しました (名前を押すと変えられる)」のまま。新しい名前で残ったか分からない。帯が木のタブの列 (ツリー① / 新しいツリー / コピー) を隠す。案: 「『サファイア練習』に名前を変えました」に替え、帯はタブの列にかぶらない所へ。
8. **エミュから戻ると 1 ベースに着き、「3 ツリー」が灰色** — どこで: 上のタブ エミュレーター → 上のタブ シミュレーター。迷い: ツリーでなく「0 完成形の設定」に着き、手順の帯の「3 ツリー」が押せない (ベース・狙いは入っている)。戻れるのは左の「← ツリーに戻る」だけ。右上の「×」もあってどれで戻るか迷う。案: 作っていた木がある時はシミュのタブでツリーへ戻す、「3 ツリー」も押せるように。
- 確かめの窓: 保存した後 (1 つ戻す → やり直しで保存した形に戻った後) はエミュへ出ても聞かれなかった。決め (保存済みのまま = 聞かない) どおり。

## 375 幅 (猿 B)

9. **フラクチャーの説明に「カードの右クリック」** — どこで: 2 完成の MOD の説明の箇条書き。迷い: スマホに右クリックは無い。案: 375 幅では「長押し」など、または消す。
10. **2 完成の MOD の行がすぐ見えない** — どこで: 2 完成の MOD。迷い: 上は説明・カード・検索・タブで埋まり、MOD の行は画面の下の外。下には「決めた (ツリーへ)」がかぶる。狙わずに「決めた」を押しがち (猿も行を見つけられずに進んだ)。案: 説明は畳んで、行を上に。
11. **「残りの道 1 · 答えた 1」と「決めた (残り 1)」の意味が分からない** — どこで: 手を 1 つ使った後のツリー。迷い: 「答えていない結果は『決めた』で次の手の質問へ」とあるが、何に答えるのか・決めたを押すと何が起きるのか分からない。「次の手を決める / 始めに戻る」と「決めた」が並んで、どれを押すか迷う。案: 「結果ごとに次をどうするか選ぶ」の 1 行と、決めたは「次の結果へ」。
12. **名前を変える欄が画面の右にはみ出す** — どこで: 保存 → 名前を押した時。迷い: 名前の欄が広がって「レシピ ▾」が右の外へ (開発版の赤い枠、警告 `[overflow-guard] 画面の幅 375px からはみ出し 1 件`)。保存しましたの帯が完成形の行にかぶる。案: 名前の欄は保存・レシピの行の下に開く。
13. **エミュから戻ると 1 ベースに着く (PC の 8 と同じ)** — 手順の帯の「1 ベース」にベース名が出ず「2 完成の MOD 0」で、狙いが消えたように見える (PC は「1 ベース サファイアの指輪」「2 完成の MOD 1」)。案: 8 と同じ。
14. **ヘッダーの右の 3 つの絵だけのボタン** — どこで: 375 幅の上。迷い: 本・? ・吹き出しの絵だけで、どれが「使い方・コツ」「要望」かは押すまで分からない。案: 下に小さな文字。
