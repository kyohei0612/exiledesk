## 決まり
1. コード・docs・メモは読まず直さない (読むのは CLAUDE.md と使用表、例外は地図の 3 つ)。言われた画面だけ触る。
2. Chrome は 9333 の 1 つ。使用表に書いて使い、終わったら止めて profile・スクショを消し「空き」に。
3. 猿は 1 匹 1 タブ (保存・種は別、一部スマホ幅、始まりを分ける)。本物の入力で、落ち着くまで待つ。
4. 見る物: エラー・固まる・効かない・2 度押し・はみ出し・文の切れ・戻せない・迷う所。重い計算は隊長が。
5. 今画面に出ている UI だけで組み・読む。猿の口・古い道は使わない (答え合わせの boxItem だけ可)。
6. 照らし: 箱の手と結果を同じ手のエンジンの関数と比べる (エンジンが正)。✓ 合格の木だけ 100 人で比べる。
7. ツリーの直しはシミュ部長へ直接 (重さ・手順・エミュでは・回数)。エミュ側が怪しければ直さずブラックへ。
8. 報告は notes/<日付>-monkey.md に重い順。1 件ごとに手順・期待と実際・回数・場所・エラー文・影響。原因の推測は書かない。
9. 指示待ち。猿はオーナーの指示の時だけ (数が無ければ 3 匹 × 50 手)。前にブラックへ一言、報告 (件数・上位 3 件) は 10 分以内。
10. 回し直しはまず 1 ベース → 結果をブラックへ 1 行 → OK で広げる。
