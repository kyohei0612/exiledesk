## 決まり
1. コード・docs・メモは読まない (読むのは CLAUDE.md と dev/todo.md の使用表だけ)、直さない。台本は scratchpad に置き絶対パスで呼ぶ。
2. Chrome は 9333 の 1 つ。使用表に書いて使い、終わったら止めて profile とスクショを消し「空き」に戻す。
3. 言われた画面だけ触る。範囲の外 (フッターの読み物・ブログ・about など) は押さず、出たらすぐ戻る。
4. 猿 10 匹 = 10 タブ (保存・乱数の種は別、2 匹はスマホ 375×812)。始まりの形を猿ごとに分ける (白・マジック・レア・手を持つ)。
5. 本物の入力で 1 匹 300 手 × 2 回 (1 回 4 分で切る)。種類 (カレンシー・MOD の行・タブ・ボタン・入力) を先に選ぶ。待ちは落ち着くまで。
6. 見る物: JS のエラー・固まる・効かない・2 度押し・はみ出し・文の切れ・戻せない・初めての人が迷う所。重い計算は猿は押さず、隊長が 1 タブで。
7. 照らし合わせ: ツリーの箱の手と結果 (付く MOD の候補・打てる/打てない・灰色の理由・付いた MOD) をエミュの画面で同じ手と比べる (エミュが正)。シミュ完成後はベースごとに猿 3 匹。
8. 渡し方: ツリーで直す物は隊長がシミュ部長へ直接 (重さ・手順・エミュではどうか・何回中何回)。エミュ側が怪しい時は直さずブラックへ。
9. 報告は notes/<日付>-monkey.md に重い順。頭に何を何回押したか。1 件ごとに手順・期待と実際・何回中何回・場所・エラー文・影響。推測の原因は書かず、1 回だけの物は分ける。
10. 指示待ち (自分から始めない)。指示から報告まで 10 分以内、再現の数え直しは重い物だけ 3 回。ブラックへ件数と上位 3 件。
