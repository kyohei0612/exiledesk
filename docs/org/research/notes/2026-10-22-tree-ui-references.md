## 2. おすすめ 3 つ
1. **Vue Flow (土台) + React Flow の見た目の決まり**: ExileDesk が Vue 3 で、部品 (背景・ミニマップ・コントロール・独自ノード / 独自の線) が揃い、暗い画面の見本 (Dark Mode / Turbo Flow) が公式にある。
2. **ComfyUI のキャンバス操作**: 暗い画面の PC 向けで、右下ツールバー・ミニマップ・手モード・フォーカスモードが公式に書いてある。
3. **Make の「線の上の条件」と枝の順番・フォールバック**: 「当たり / 外れ」の枝分かれを線で表すのに、考え方がそのまま使える。

## 3. まねする所の一覧 (シミュ部長がそのまま作れる粒度)

## 4. 避けた方が良い物 (確認できた範囲)
- React Flow の **Edge Routing / Editable Edges** は「Pro」(有料) の印が付いている (例の一覧の表示)。使わない前提で選ぶ。
- n8n のコミュニティで「横向きの接続点だと線が S 字になって見づらい」という要望が出ている。ツリーが横長になる時の注意 (縦向きの木も検討)。
- Blueprint は今回、画面の特徴を確認できていない。まねする所の一覧には「リルート (折り曲げ)」の考え方だけ入れた。
