# 動画 kQROcbbeR1M (金の指輪): 各段の MOD の名前と段 (T)

出どころ: 動画 https://www.youtube.com/watch?v=kQROcbbeR1M の**画面のコマ** (720p、2 秒おき。画面の MOD 名・T はゲーム内の日本語表示そのまま) と、字幕 data-cache/subs/kQROcbbeR1M.ja.txt。前の調べ = 2026-10-21-gold-ring-spam-video.md。
名前・段の確認 = poe2db の指輪ページ (https://poe2db.tw/jp/Rings と /us/Rings の MOD 表。JA と EN を並べて照合)。

## 先に結論 (前の調べの直し)
1. **動画の指輪は 8 段のうち ⑥ (結晶化 + ルーンの合金) をやっていない。** 5:12〜5:46 は「よくある型はこうする」の説明で、完成品に最大ルーンワードは無い (画面で確認)。本編の道は ④ → ⑤ → ⑦ → ⑧。
2. ⑦ は「冷気・雷を足す」ではなく、**左側の抹消 + 完全カオスで回避力をレアリティ(プレフィックス) T1 に替えた** (1 発目で当たり、6:12)。冷気ダメージは ⑧ のアザーワールド (冒涜)。
3. 前の調べの「高貴エッセンス」は誤り。字幕の「上級エグザ / 上級後期」= **高貴なオーブ (上級)** (Greater Exalted Orb)。エッセンスではない。
4. 完成品は 6 MOD + 暗黙 + 品質 40% (キャスター)。下の表。

## 食い違い・未確認 (決めずに書く)
- **完全カオスの最低モッドレベル**: poe2db は「カオスオーブ (完全) = 50」「(上級) = 35」。⑦ で付いた貯蔵者の (プレフィックスのレアリティ) はレベル 47。つまり **poe2db の 50 だと付かないはず**なのに画面では付いている。使ったのが完全でなく上級の聞き違いか、poe2db の表記と実機の差か。画面のホバーでは種類まで読めなかった。シミュレーターに入れる前に確認する。
- **③ の冒涜・フラクチャーの瞬間** と **③ → ④ の間 (3 MOD を 2 MOD に絞る手)** は画面に出ない。
- 字幕の「(消去) 5 MOD なので 2 回」は、この指輪では 4 MOD (1 回)。指輪ごとに違う。
- 「スペルダメージの T」は画面に出ない (poe2db 上は T2/8)。
- 動画の 0:30〜0:56 などに映る別の指輪 (腐敗した渦巻の別の個体、災いを生む変化 など) と、0:45 の完成品の比較 (ルーンワード入り) は、この調べの表からは除いた。

## どの部に何が効くか
| 部 | 効くこと |
|---|---|
| 解析君 (数学) | 手の列は ④ → ⑤ → ⑦ → ⑧ が実際の道。⑥ は不要。④c の「軽快のカタリスト + 触媒の高貴のお告げ + 高貴なオーブ(上級)」と ⑤ の「削減 + カオス」、⑦ の「左側の抹消 + 完全カオス」が、今の手に無い物。 |
| シミュレーター | 「品質」は別の固定費に外出しできる (④c・④d は品質を載せるだけ、MOD の枠は動かさない)。ただし品質の最大値 (+20%) の入れ方 (ブリーチ + 結晶化) と、それを消す削減は手として要る。 |
| 開発 (MOD の置き場) | スペルダメージ等は「創生の樹 キャスター」MOD、嵐乗りの等は「変質した鎖骨で付く異世界 MOD」。エンジンの置き場に両方あるか確認する。レアリティはプレフィックス (貯蔵者の) とサフィックス (考古学の) の 2 系統が別枠で併存 (どちらも T1 が最上位)。 |
| ブラック | 流れ図の幹は ① ② ③ ④ ⑤ ⑦ ⑧ の 7 段。⑥ は外してよい。 |
