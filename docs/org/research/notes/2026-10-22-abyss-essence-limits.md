# アビスのエッセンスが使えない部位・場面 (2026-10-22 夜、リサーチ長 2 本目)

頼み: ブラック 5 代目 (オーナー待ち)。
**出どころ**: https://poe2db.tw/us/Essence_of_the_Abyss ・ https://poe2db.tw/jp/Essence_of_the_Abyss ・ https://poe2db.tw/us/Mark_of_the_Abyssal_Lord (curl で HTML を取って行を確かめた)。うちのエンジンは src/services/craft-stage/spec/essence-specs.ts の ABYSS_ESSENCE_SPEC・src/services/htc/poe2db-abyss-fix.ts を読んだ。

## 名前
- 付く MOD の日本語名は poe2db で **「アビサルロードの紋章」** (英 Mark of the Abyssal Lord)。うちの一部の文・コメントは「深淵の王の印」(src/i18n の辞書・ブログ 2 本・changelog-notes など)。どちらを画面に出しているかは見ていない (メモ feedback-no-guessed-terms では poe2db の名前が正)。

## 1. 打てる部位
poe2db の表の 27 種 (どれもプレフィックスとサフィックスの両方、要る Lv 0): 片手剣・片手斧・片手メイス・両手剣・両手斧・両手メイス・スピア・弓・クォータースタッフ・短剣・兜・鎧・手袋・靴・盾・スタッフ・ワンド・セプター・指輪・アミュレット・ベルト・矢筒・クロスボウ・フレイル・タリスマン・フォーカス・バックラー。
**表に無い = 付く MOD が無い物**: ジュエル・チャーム・フラスコ・レリック・タブレット・ウェイストーンなど。

## 2. 打てない状態
| 状態 | poe2db | うちのエンジン (ABYSS_ESSENCE_SPEC) |
|---|---|---|
| レア以外 | 打てない (「レアアイテムを左クリック」) | 同じ (target rare) |
| MOD が満杯 | 書いていない。効果が「1 個消してから付ける」なので満杯でも打てる形 | 1 個消す (消せる物が無ければ消さない) |
| 紋章がもう付いている | 書いていない | 打てない (noAbyssMark) |
| 発現済みの冒涜 MOD がある | 書いていない | 打てない (noRevealedDesecrated、オーナーが 2026-10-16 にゲームで確認) |
| 未発現の冒涜 MOD がある | 書いていない | 打てて、未発現を先に消し紋章に入れ替わる (同じくオーナー確認) |
| クラフト MOD の枠 | 書いていない | craftedSlot の決まり (ほかのクラフト MOD があると打てない側) |
| フラクチャー・コラプト | このページには書いていない | — (フラクチャーの MOD は消す候補にならない一般の決まり) |
- 紋章のページの決まり: **紋章の付いたアイテムを冒涜すると、必ず紋章を消して、より高いティアの未発現の冒涜 MOD に置き換える**。

## 3. プレ / サフィ
- poe2db: 27 種とも **プレフィックスとサフィックスの両方** に紋章がある。どちらに付くかの決まりは poe2db に書いていない。
- うちのエンジン: 5d585458 でサフィックスの紋章を足した。付け先は **消した MOD の側** (`addEssence: { side: "removedSide" }`、出どころは SaVeQ 0.5.5 / poe2fun の話)。poe2db と食い違う所は無い (poe2db は側の決まりを書いていないだけ)。
- poe2db-abyss-fix.ts の頭のコメント「打つ処理は先に見つかった方」は、今の spec (消した側) と合っていない可能性がある (コメントだけの話か、エンジン部に 1 回見てもらうとよい)。
