**【途中】オーナー 2026-10-21「最新版以外は一旦止めていい」で、ここで中断。道具の一覧・効果の文・相場の読み取りまでは済み。下の「未確認」と「手の組み立て」は未検証のまま (新しい調べ足しはしていない)。**

目的 = サフィックスの「クリティカルダメージボーナス T2 以上」と、冒涜の「アーケインサージ (クルガルの)」を作る (S 枠には投射物スキルのレベル +2 [フラクチャー済み] がある前提)。
出どころ (poe2db の公開ページ、JA。https://poe2db.tw/jp/<英語名>): お告げ一覧 /jp/Omens と各お告げのページ、カレンシーのページ、手袋 (知性) の MOD 表 /jp/Gloves_int、Craft of Exile (https://beta.craftofexile.com/?game=poe2、Gloves INT・Sirenscale・ilvl 82、読むだけ)。
相場 = poe2db の各ページに埋まっている取引レート (取得 2026-10-21)。「1 神 = n 個」は「神のオーブ 1 個で n 個買える」、「n 神 / n 高貴 = 1 個」は 1 個の値段。**向きは表記からの読み取りで推定**、取引数の少ない物は目安として弱い。外の API は叩いていない。下の表では 神のオーブ換算の 1 個の値段も添える (高貴なオーブ 1 個 = 神 1/546 で換算)。

## 2. この道具で作れる手の組み立て (poe2db の文から読めること。割合・費用は未計算)
1. **クリティカルダメージ T2 を確定で付ける** = ヒステリーのエッセンス (1 個で 1 回、値は T2 の範囲)。付ける前にサフィックスに空きが無ければ、ヒステリーが「ランダムな 1 個」を取り除く: 固定済みの投射物 +2 は取り除かれない。右側の結晶化のお告げを併用するとサフィックスだけが対象になりプレフィックスを守れる (サフィックスが「投射物 +2 (固定) + 外れ 1〜2 個」の状態なら、外れを消して入れ替わる)。
2. **T1 (凶暴性の) を狙うなら** 完全 / 上級のカオス・高貴 (最低レベルで T3 以下を弾く、仮説)。右側の抹消のお告げ (サフィックスだけ回す) と削減のお告げ (最低レベルを狙って消す) で外れを消す。
3. **アーケインサージ** = 骨 (保存された / 古代の肋骨) の冒涜 → アンヴェールで選ぶ。選択肢に無ければアビスの反響のお告げで 1 回リロール。入れるサフィックス枠が必要 (空き枠に付くか、紋章を使って「消してから置き換える」ためにアビスのエッセンス + 右側の結晶化のお告げ + 骨の手を使う案が、poe2db の文からは筋が通る (手順としては未確認): エッセンスがサフィックス 1 個を消して紋章を置き、骨が紋章を高ティアの未発現冒涜 MOD に置き換える)。
4. 6 枠 (P 3 つ + S 3 つ) が埋まった状態でアーケインサージを入れたい時は、**アビスのエッセンス (紋章) + 右側の結晶化のお告げ**で外れサフィックスの 1 つを紋章に替えてから冒涜するのが、文の上では唯一の「満杯でも入る」道。紋章が「サフィックス」か「プレフィックス」のどちらの枠に付くかは、お告げ (右側の結晶化) で消した側に入る形か、エッセンスの追加先の決まり方で変わる (poe2db に決まりの文なし。未確認)。
