# 開く・畳むの動きをエミュとシミュで揃える (オーナー 10-23、デザイン部長 2 本目)

オーナー「UI 系の動き、展開した時の動きを (エミュとシミュで) 一緒にして」。エミュの今の動きを正とし、共通の部品に寄せる。
洗い出しは読むだけの調べ係 (10-23) + 自分で読み直した所。行の「→」が直した後。

## 1. ベース選びの部位を開く (BaseCatalog / BaseCardGrid、両方同じ部品)
| 項目 | エミュ (?page=base、StageBasePage) | シミュ (完成形の設定 1 ベース、TreeGoalPage) |
|---|---|---|
| 1 回のクリックで開く | 開く | 同じ |
| 開いた物の位置 | 一覧の下 +24px が切れていれば 260ms で送る (送る先はページ) | 同じ (送る先は窓の本文) |
| 選び直しで開いた時 | 今の部位まで送る (ページが自分で reveal) | 送らない → **BaseCatalog が開いた時に自分で送る (両方)** |
| 開いている物を押す | 畳む (送った分を戻す)。スマホは「← 部位」 | 同じ |
| 別の物を開く | 前を閉じてその行の下に開く (1 つだけ) | 同じ |
| アニメーション | 一覧はぱっと出る、送りは 260ms | 同じ |
| Esc・枠の外 | 一覧は閉じない。Esc はページごと戻る (選び直しの時) | 一覧は閉じない。Esc・枠の外は窓ごと閉じる (窓の決まり) |
| もっと見る | 開いたら下まで送る・たたむで元の位置 | 同じ |
- 人気のベースの段 (エミュの未選択だけ) は中身の違いで、動きではない。そのまま。

## 2. MOD 表の段を開く (ModTable、両方同じ部品)
| 項目 | エミュ (ページの下の欄 / 窓) | シミュ (完成形の設定 2 MOD、窓) |
|---|---|---|
| 1 回のクリックで開く | 開く | 同じ |
| 開いた物の位置 | 押した行を同じ高さに残し、表の下 +24px まで 320ms で送る | 同じ |
| 開いている物を押す | 閉じる | 同じ |
| 別の物を開く | 前を閉じて開く (1 つだけ、押した物にも届く) | 同じ |
| アニメーション | なし (行の色 0.12s) | 同じ |
| 枠の外 | 閉じる | 同じ |
| Esc | ページの欄: 段の表だけ閉じる。窓: 窓ごと閉じた | 窓ごと閉じた → **段の表だけ先に閉じ、もう 1 回で窓 (両方の窓)** |

## 3. 棚の畳んだルーン・段の欄 (CurrencyShelf、両方同じ部品)
| 項目 | エミュ (CraftStage) | シミュ (打つ手の棚 TreeHandShelf) |
|---|---|---|
| その他のルーンを開く | 1 回で開く・もう一度で畳む・複数開ける・送らない・動きなし・Esc/外では閉じない | 同じ |
| エッセンス・ルーンの段の欄 | 押したアイコンに重ねる・もう一度で閉じる・1 つだけ・外で閉じる・Esc で閉じる | Esc は窓ごと閉じた → **段の欄だけ先に閉じる** |

## 4. ほか
| 物 | エミュ | シミュ |
|---|---|---|
| ? の説明 (HelpTip) | 押す・乗せるで開く、外・Esc・もう一度で閉じる | 窓の中で Esc は窓ごと閉じた → **押して開いた説明は Esc で説明だけ先に閉じる** (共通の use-dismiss に寄せた) |
| 段の表の別の作り | (StageAimPicker は送りあり) | TreeModPick: 1 つだけ・もう一度で閉じるが、送り・Esc・枠の外が無い → **シミュ部長に頼む (ModTable と同じ動きに)** |
| 伸び縮みの動き 300ms | アプリ版の StageBasePicker だけ (Web には無い) | — (アプリは触らない) |

## 直した所 (共通、デザイン)
- src/utils/use-dismiss.ts: 開いている物を 1 本の積みに。Esc は一番後に開いた 1 つだけ閉じる (前は 1 つずつ別に聞いていて、2 つ開いていると古い方が閉じていた)。`cancelTopIn(el)` = el の中で開いている一番上の物を閉じる。
- src/components/ui/ModalShell.vue: Esc の時、窓の中に開いている物があればそれを先に閉じ、窓は閉じない。後ろのページの Esc に届かないのは前と同じ。
- src/components/ui/HelpTip.vue: 押して開いた説明の外・Esc を useDismiss に。
- src/components/items/BaseCatalog.vue: 今のベースがある時は開いた時に自分で reveal。

## 画面の側に頼む物
- エミュ部長: StageBasePage.vue 37〜38 行の `catalog.value?.reveal()` を外す (BaseCatalog が自分で送るので二重)。
- シミュ部長: TreeModPick.vue の段の表を ModTable と同じ動きに (開いたら送る・枠の外と Esc で閉じる。useDismiss と keep-place の revealOpened)。今の初期設定の直しの後で。
