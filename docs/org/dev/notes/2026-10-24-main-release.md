## 形
- 元は main。今の本番 (v0.1.595 = b73f5d82 の形 + 当てた物) と**見た目・挙動がそっくり同じ**になるように、本番に出していない物はスイッチで隠す (revert で抜かない)。
- スイッチは 1 か所 (デザイン部長が作る、例 `src/web/release-flags.ts`)。本番のビルドで切れて、開発版 (`preview:prod -- --dev`・dev サーバー) では入る。OK が出たら 1 行で入れる。

## スイッチの使い方 (src/web/release-flags.ts、デザイン部長 3 本目 3d616bd1)
- 名前を FLAGS に 1 行足す (説明と commit)。コードは `import { flag } from "…/web/release-flags"` → `flag("名前") ? 新しい形 : 本番の形`。本番のビルドで切れ、開発版 (--dev)・dev サーバーで入る。
- CSS だけの直しは `:root[data-flag-名前の小文字] …` の下に書く (main.ts が入っているスイッチを <html> に印)。層の外の決まりを戻す時は `cursor: revert-layer` などで。
- OK が出たら RELEASED に名前を足す 1 行で本番にも入る (revert しない)。確かめは本番の作り (preview:prod) で前の形・--dev で新しい形の両方。
