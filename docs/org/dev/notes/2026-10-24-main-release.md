- 名前を FLAGS に 1 行足す (説明と commit)。コードは `import { flag } from "…/web/release-flags"` → `flag("名前") ? 新しい形 : 本番の形`。本番のビルドで切れ、開発版 (--dev)・dev サーバーで入る。
