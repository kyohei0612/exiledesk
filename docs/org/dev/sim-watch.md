## 見る物 (木ごと)
1. 精査の足りない所 (PC の箱の印): done の木は 0 件、ほかは前と同じ。
2. テスト走行と 100 人回す (どちらも種 1 で決まる): 結果の文・止まった箱が前と同じ。費用 (1 個 N 神) は相場で動くので比べない。
3. PC の箱の札: 「↩ n 段目へ戻る」の n = 戻り先の箱の段、同じ手へ戻る時だけ「再度挑戦」、当たりどうしは「同じ MOD 群のため統合 (n 段目)」、木の戻り・手と札のある / 無しが合う。
4. スマホ: 全体図の箱を 1 つずつ押した重ね窓の「n 段目」= 箱の段、「この箱から次に打つ」= PC の札の手、結果ごとの行き先の n = 戻り先の箱の段。「次へ」で進める画面の下の帯の n = 出している箱の段。
5. (自動の戻りの外れ MOD の種類・数は、精査の知らせ (38973f4a) として 1 に入る)
6. sameHand の木: 外れの箱 (お告げの無い手の外れ) に打つ前の手 / 同じ形の箱 (自動の戻り先) の手を選び、箱が増えず、選んだ手の箱へ戻るか (PC)。
7. 箱の中のアイテム枠の札 (10-27 夜足し、見本は種 1 で決まる・フラクチャーの行は数えない): 全部消えてよい消去の箱は全部「外れ MOD」(heldTags)、外れの側の箱 (外れ・狙いが消えた・外れが消えた・打った後) は外れ MOD でない行が道の上の狙いの数まで (junkByCheck。道の上の狙い = 親と戻ってくる箱をたどった狙い、doc.mjs の pathAims で広め)。箱ごとの札の並びも前と比べる。
8. 手の窓で消去を持った時 (既定 = 全部消えてよい) のカードはフラクチャー以外が全部「外れ MOD」(heldTags。手の無い箱 1 つで ＋ → 棚の消去)。消去の直線の途中の箱 (戻りが無く、どの箱も戻ってこない直線の箱) に乗せても線が出ない (heldTags)。直線の終わりの箱では線が出るのも見る (出なければ乗せ方が効いていないので「見られなかった所」)。fg0BCVYy の b22 → b39 → b40。
9. 完成形の品質か途中で消える MOD がある木 (goalQ): 完成形の窓の「品質も狙う」☑ = 木、カードの品質 = 木の %、「途中で消える」が押された行の数 = 木の途中で消える MOD の数、札が 2 つ以上 (クラフト MOD 2 つ以上)。札の並び (残る / 消える と行) も前と比べる。

## どの木でも成り立つ決まり (rules.mjs、10-28 ブラックの対策 3 番。前と比べず、その場の画面と木だけで合う / 合わないが決まる)
- (A) つながった箱どうし (↩ 戻り・統合) は同じ形。形は開発版の `window.__simMonkey` の形の関数 (sameShape / shapeOf、シミュ部長が出す) を呼ぶ。本番の作り (1460) には口が無いので 1461 (--dev) だけ。始めに戻る・形の合う箱へ (行き先は回し方しだい) は比べない。
- (B) 子の箱 (手も戻りも無い箱、木ごとに 2 つまで) に ＋ → 棚 (カオス・高貴・消去… の打てる物) → カードで手を足しても、ほかの箱の題・戻りの札・次の手の札・カードの行が変わらない (親か、ほかの箱かを分けて書く)。
- (C) 結果の箱の題と、その箱の見本の行: 「〇〇が付いた」= 〇〇の行がある、「〇〇がフラクチャーされた場合 / が固定された」= 〇〇がフラクチャーされた行、「外れ MOD (側) が…」= フラクチャーの行 (側も)、「未発現の冒涜が付いた」= 未発現の行。題と行は文字で比べる (数・括弧を落とす = tree-names の modShort と同じ落とし方)。 この道では作れない箱 (data-sample-note="cant:unreachable"、S-74) は比べず「作れない箱 (見本の印)」で数える。
- (D) 名前: 箱の次の手の札・棚 (aria-label) のカレンシー・お告げ・骨の名前 = src/services/htc/price-keys.json (骨は部位で変わるので骨のどれか)、同じ鍵は箱ごと・棚・持った時の手の窓の題で同じ。エッセンス・発現はデータに無いので揃っているかだけ。

## 線の見張り (lines.mjs、10-28 深夜ブラック。線を直すたびに回し、0 になってから返す)
- 「線を全部表示」の PC の画面で、木の線と戻り・統合の線を数える: (L1) 両端が箱・手の札・ほかの線につながる (L2) 戻り・統合の札がある箱に線か印 (始めに戻る・作り直しは除く) (L3) 出元・行き先でない箱や手の札を横切らない (L4) 木の外 (左右は全部の箱の外へ 12、下は 40) を回らない。線の印 (data-edge-id) の無い前の版では数えない。
- 単独でも回せる: `node scripts/sim-watch/lines.mjs http://localhost:1440 [--only amuB] [--codes <1 行 1 レシピのファイル>]` (開発版は /web.html で開く)。見本の木は小さいので、L4 は木を育てた時にしか出ない (シミュ部長は手の無い箱にカオスを足して 2 回育てた木でも回す)。

## 見られない所 (足すなら)
- 1460 (本番の作り) の見本は 0.3 秒の打ち切りで作るので、1460 と 1461 を同時に回すと機械が重くて見本・決まり (B) がぶれることがある。1460 で見本の違い・(B) が出たら `--only <木>` で 1 本ずつ回し直す (release.md ⑦)。
- 決まり (A) は 1461 だけ (形の関数が開発版の口にしか無い)。(B) は子の箱が 1 つも無い木 (完成まで組んだ木) では見られない。(C) は「外れ」「狙いが消えた」「打った後」の題は見ていない (何が無いかは題に書いていない)。
- スマホの結果の画面 (外れた場合・当たった場合の 1 枚ずつ) は、答えの無い結果がある時しか「次へ」で出ないので、決まり切った木では下の帯を少ししか比べられない。
- 7〜9 (アイテム枠の札・消去・完成形の窓) は PC だけ。スマホのカード・完成形の窓は見ていない。外れの箱の札は「外れ MOD でない行の数 ≤ 道の上の狙いの数」までで、どの行が狙いかは文と MOD の id を結べないので比べていない (前との並びの比べで拾う)。
- 外れの種類 (普通 / エッセンス / 冒涜) は木の数字に無い (回し方が決める) ので、doc.mjs では答えを作らず精査の知らせを読む。
