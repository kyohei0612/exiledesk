# シミュの見張り (scripts/sim-watch/、最終チェック長の持ち物)

10-27 夕オーナー「リリース時に全部集まるから、決まりつくならコイツ」、ブラック 14 代目の頼み。出す前に、見本の木を窓なし Chrome の PC 幅 (1660×860) とスマホ幅 (390×844) で開き、決まりと合わない箱・画面の文と木の中身の食い違いを数える。
これは見張り (前と変わっていないか・文と中身が合っているか)。外の正解 (poe2db・CoE) と突き合わせる物ではない。ツリーのコードも木も直さない。見つけたらシミュ部長へ直接回し、ブラックにも 1 行。

## 回し方
- 出す前: 出す中身で手元の本番の作りを立てて (`pnpm preview:prod`、作業場で作るなら `node ../ExileDesk-preview/scripts/preview-prod.mjs`) → `node scripts/sim-watch/watch.mjs` (既定 http://127.0.0.1:1460)。
- 開発版 (スイッチの下も): `node scripts/sim-watch/watch.mjs --dev` (1461)。開発版の基準が無いので、本番の作りの基準 (出した版) と比べる = 出した後に変わった所が「前と違う」で出る。
- `--only <key>` で木 1 つ、`--shots <dir>` で絵 (見たらすぐ消す)、`--update` で今の数を baseline.json に書く (わざと動きを変えた時だけ。書いたら commit)。
- 1 回 5〜8 分 (100 人回す・テスト走行を木ごとに 1 回)。終わると Chrome ごと閉じる。合わない所があれば終わりの値 1。

## 置き場
- watch.mjs (本体) / cdp.mjs (窓なし Chrome) / doc.mjs (木の側の答え: 段 = 箱の高さ ÷ 360 + 1、戻り先、再度挑戦・統合)。doc.mjs は画面の作りの関数を呼ばない (同じ関数で答えを作ると、関数が違っていても合う)。
- trees.json: 見本の木 (code = 共有 URL の #recipe= の後ろ)。done = 完成まで組んだ木 (精査の足りない所は 0 のはず)、sameHand = (6) も見る木。
- baseline.json: 木ごとの前の数 (prod = v0.1.634 の作りで 10-27 に取った)。

## 見る物 (木ごと)
1. 精査の足りない所 (PC の箱の印): done の木は 0 件、ほかは前と同じ。
2. テスト走行と 100 人回す (どちらも種 1 で決まる): 結果の文・止まった箱が前と同じ。費用 (1 個 N 神) は相場で動くので比べない。
3. PC の箱の札: 「↩ n 段目へ戻る」の n = 戻り先の箱の段、同じ手へ戻る時だけ「再度挑戦」、当たりどうしは「同じ MOD 群のため統合 (n 段目)」、木の戻り・手と札のある / 無しが合う。
4. スマホ: 全体図の箱を 1 つずつ押した重ね窓の「n 段目」= 箱の段、「この箱から次に打つ」= PC の札の手、結果ごとの行き先の n = 戻り先の箱の段。「次へ」で進める画面の下の帯の n = 出している箱の段。
5. (自動の戻りの外れ MOD の種類・数は、精査の知らせ (38973f4a) として 1 に入る)
6. sameHand の木: 外れの箱 (お告げの無い手の外れ) に打つ前の手 / 同じ形の箱 (自動の戻り先) の手を選び、箱が増えず、選んだ手の箱へ戻るか (PC)。

## 見られない所 (足すなら)
- スマホの結果の画面 (外れた場合・当たった場合の 1 枚ずつ) は、答えの無い結果がある時しか「次へ」で出ないので、決まり切った木では下の帯を少ししか比べられない。
- 外れの種類 (普通 / エッセンス / 冒涜) は木の数字に無い (回し方が決める) ので、doc.mjs では答えを作らず精査の知らせを読む。
