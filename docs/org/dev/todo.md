## 触っている (部長ごとのファイル docs/org/dev/touching/<部>.md、オーナー 10-22)
各部長は自分のファイルだけを書き、自分の commit で消す (dev/todo.md に書かない。1 つの表だと他人の commit に混ざった)。全部を見る: `cat docs/org/dev/touching/*.md`。同じファイルは順に、ぶつかる時はブラックが順番を決める。
