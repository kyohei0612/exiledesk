## J10 の片付け (10-20 夜、決まり「写しで決まらない食い違いは poe2db に」)
1. 出どころの分からなかった重み: ES リチャージ (鎧 3 部位)・矢筒の追加の矢は weight-overrides の「同じ系統の MOD から借りる」決まり (09-23 オーナー OK)、弓・クロスボウのリーチは「一部の段だけ仮置きの所を同じ MOD の段から借りる」決まり (09-29) で埋めた値 (読み込みの後 OVERRIDDEN に入っている、台本で確かめた)。出どころがあるので変えない。
2. 意図して持っている物 (変えない): ルーンで付く MOD 825 (CoE の Krakenbul 実測)・ジュエル 692 (poe2db・CoE とも全部 1、jewel-bases.json)・グラスピングメイル 328 (指輪の MOD)・poe2db が 1 の 229 (借りた値・CoE の値、全能力値の鎧 203 は poe2db のページの重みが全部 1)。
3. エンジンにだけあるベース 102: poe2db の us のベースのページを 1 つずつ読んだ (1.2 秒おき)。99 はベースのページがある (ルーンフォージ品・ルーンマスター品・黄金の・全能力値・Garment など、部位のページの一覧に出ないだけ) ので外さない。ページが無いのは [DNT] の 3 つ (Cragbreaker Staff・Driftwood Oar・Venerable Defender) だけで、src/services/items/removed-bases.json に入れてベースの一覧から外した (後で戻せる)。
4. Crossbows_cannon の 18 件: poe2db の Trarthan Cannon のページ (/jp/Trarthan_Cannon、ModsView あり) にグレネードのクールダウン使用回数・クールダウン解消レート・破壊のルーンの「明示 … MOD の強さ」が全部ある → 外さない。照らしで「poe2db に無い」と出たのは、台本 (pageOf) が Crossbows_cannon をクロスボウのページと比べていたため。見本 5 (シージクロスボウ) にこの行が付くかは poe2db のシージクロスボウのページに書いていない (未確認のまま)。
- 見張り: currency-spec-golden・held-odds-parity は変わらず通る。
