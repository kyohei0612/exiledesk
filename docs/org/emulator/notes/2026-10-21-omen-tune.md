# お告げの下の設定 (2026-10-21、オーナー依頼「分からない所を使う人にいじらせたい」、開発版だけ)

commit 55cb342c・d800197f。本番はオーナーの OK の後 (TUNING_ON = dev / VITE_DEV_PREVIEW だけ)。

## 調べ (今のエンジン)
- 触媒の高貴のお告げは **元から入っている**: 対応する MOD (catalystBoosts、指輪・アミュレットは MOD のタグ) の重みに倍率を掛け、品質を使い切る (spec/parts.ts の add、確率の表は spec/odds.ts・outcomes.ts)。
- 倍率の既定 = Craft of Exile の式 `1 + 0.2 × 品質` (20% で ×5)、20% を超えた分は 1% ごと +0.12 (htc/catalysing-multiplier.ts、2026-10-16 オーナー「CoE に合わせて」)。
  - 根拠: CoE (package_poe2.js の exaltedParams)。poe2db の説明文は「確率を上げる」だけで数字は無い。実測は reddit の 2 点 (1.5% で 42/100、40% で 77/100) で、式はその 95% 区間の中。ゲーム内の数字は **未確認**。
- 聖別: 神のオーブと同じく段の範囲で振り直してから MOD ごとに 0.78〜1.22 (0.01 刻み) のランダム (apply-vaal.ts)。

## 作り
- エンジン: services/craft-stage/stage-tuning.ts (`setStageTuning` / `stageTuning` / `tunedCatalysingMultiplier`、入口 engine.ts から)。null = 既定。
  - 触媒: 品質 1% ごとの倍率 r (既定 0.2)。倍率 = 1 + r × min(品質, 20) + 0.6r × (20 を超えた分) (CoE の形のまま傾きだけ変える)。打つ処理と確率の表の 3 か所が同じ関数を読む。
  - 聖別: 倍率 ×100 を決めたらその値 (乱数は同じだけ引く = 後ろの手の乱数がずれない)。
- 画面: views/craft-stage/StageOmenTune.vue をお告げのボタン (持った物の下・お告げのタブ) の直下に。状態 state/emulator/stage-tuning.ts (ブラウザに覚える、変えたらお告げの一覧を入れ直して表を出し直す)。
- 手順 JSON (10-22): 打った手に設定を持たせ (PlayedStep.tune、その手で使ったお告げに効く物・既定から変えた物だけ)、手順の手の追加キー `tune: { catalysing_per_pct?, sanctify_k? }` に写す (stage-steps.ts の planStepOf)。再生 (playPlan) は手ごとに `withStepTune` でその設定、書いていない手は既定 (画面で今決めている値は使わず、打った後に戻す)。共有の縮めた形は手の 5 番目に tune (share.ts)。
- シミュレーター (止めている) は htc の catalysingMultiplier のまま。

## 確かめ
- 台本 (エンジンの入口、金の指輪 品質 (ライフ) 20%、高貴 + 触媒の高貴): ライフの MOD の割合 お告げ無し 13.3% / 既定 0.2 で 43.4% / 0 で 13.3% / 0.5 で 62.8% / 1 で 76.3%。打った 2,000 回も 43.4・13.2・63.8・78.0% で表と同じ (見張りの台本、外の正解ではない)。
- 聖別: 既定は MOD ごとにばらばら (0.8・1.09・0.96・0.88)、×1.22 / ×0.90 に決めると全部その値。
- 画面 (手元の dev、窓なし Chrome 1660×860): 触媒の下「1% ごと + [0.2] 重み ×5.0」、0.5 にすると ×11.0 で MOD 一覧のライフの付く確率 18% → 25%。聖別のお告げの下にチェック → ×1.22 を選んで打つと聖別の帯が ×1.22 にそろう。英語「Per 1% + / Weight ×11.0」。スナップは共有メモ omen-tune/。
- 型チェック 0、入口の見張り (check-engine-entry) 増え無し。golden・held-odds-parity は回していない (既定の値と乱数の引き方は同じ)。

## 確かめ (10-22、手順 JSON)
