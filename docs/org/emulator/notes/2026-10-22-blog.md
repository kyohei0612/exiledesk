## 作り
- 記事の元: src/data/blog/<slug>.<ja|en>.md (書き方 src/data/blog/README.md、見本 sample = 下書き)。絵は src/data/blog/img/ → /blog/img/。
- 読み方と Markdown → HTML: src/services/blog/blog-md.ts (部品を足さない小さな変換。README に書いた書き方だけ)。
- 静的なページ: scripts/build-blog-pages.mjs → /blog/<slug>/・/en/blog/<slug>/ (JS 無しで読める)、一覧 /blog/・/en/blog/、/blog/index.json (右の列用)、サイトマップへ追記 (下書きは入れない)。OGP (article・summary_large_image)・構造化データ Article (一覧は Blog)・hreflang。両脇に 160×600 の枠 (開発版は場所だけ)。
- OGP の絵: 記事の image → 本文の 1 枚目の図 → 題を描いた絵 (scripts/_blog-og.mjs、手元の Chrome を窓なしで撮る 1200×630、/blog/og/<言語>-<slug>.png) → /web/og.png。
- シェア: X (intent)・Reddit (submit) はただのリンク、リンクのコピー・Discord 用のコピー (題 + 改行 + URL) は JS がある時だけ出る。URL は記事の自前の URL (https://exiledesk.com/blog/<slug>/、英語は /en/blog/)。
- 数える: scripts/_blog-client.js (→ /blog/blog.js)。開いた時に visit (entry path:/blog/<slug>/) と screen (to blog:<slug>、言語つき)、シェアのボタンで blog_share {slug, lang, to: x|reddit|copy|discord}。送り方は Web 版の log-sender と同じ (同じ uid・1 時間に 1 回・それまで端末に溜める、POST /log → D1)。記録しない端末と開発版は送らない (window.__blogLog に溜めるだけ)。記事のページは別の訪問として「来た 1 回 = 1 PV」に入る。
- 日報: scripts/analyze-logs.py (分析君) の PAGE と画面の切り替えに blog:<slug>・blog_share の行を足すと出る (まだ足していない)。
- コメント欄: 記事の下に <section id="comments" data-slug data-lang> の置き場だけ (前の掲示板 archive/board-2026-10-16 の作りを戻す予定)。
- 右の列: src/web/BlogLatest.vue (チャンネルの下、/blog/index.json の新しい 3 本、英語の画面は英語の記事)。出す印は state/web-page.ts の BLOG_ON (= TREE_ON、dev / 開発版だけ)。
- 開発版のデプロイ (scripts/deploy-web-dev.mjs) の中だけで `build-blog-pages.mjs <出力> --drafts` を回す。本番の build:web にはまだ入れていない。
