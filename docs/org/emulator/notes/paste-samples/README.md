## ハイブリッドの見本 (オーナー 10-25「このマナ＋スピリットが検知されないな忍者だと」、n6・t3)
読み方 (10-25 ジン 10 本目、item-text-solve.ts): 明示の行全部を「そのベースの MOD の池の組み合わせ」で説明できる割り当てを探す。MOD 1 つは自分の能力値ごとに同じ印の行へ値を足す (ハイブリッドは 2 行にまたがる)。同じ能力値の MOD が 2 つ以上なら行の値はその和 (トレード・ゲームのコピーは同じ文の行を 1 行に足して出す。✦・冒涜など印の違う行は分かれて出る)。守る事: 系統 1 つまで・プレ/サフィの枠・各値がその段の幅 (上乗せ込み)・印 (crafted はエッセンス系だけ、トレードの段 0 はエッセンス・合金・冒涜専用だけ)。① 1 通り → それで読む ② 複数通り → 一番もっともらしい物 (読めない行 < 和の行 < 2 行にまたがる MOD < 印どおりの出どころ の少ない順) を mods に、行の組み方が違う読み方を readings に (普通 ⇄ エッセンスの出どころだけの違いは候補にしない) ③ どの組み合わせでも説明できない行 → skipped の unexplained (コラプトした物は今までどおり段に収まらないの印)。

## ルーン (オーグメント) の値を明示の行から引くか (決着: 引かない、オーナー 10-25「引かないままでいい」)
- ルーンの値は明示の行から引かない (どの部位も、トレードも poe.ninja も)。セプターの t3・t4・t6 は属性のスピリットの検算でもトレードは足していない (t6 162 = 100 × (1 + 0.47 + 0.15)、足していれば 147)。

## 絆 (Bonded) の行は全部のルーンに付くか (オーナー 10-25「絶対絆ってつくっけルーンに全ての」)
- 付かない。poe2db (10-24 の写し) のセプターのはめる物 76 のうち、絆の行があるのは 46 (アイドルなど)、無いのが 30 (頑強・熟練・決意などの普通のルーン、ジクアニのソウルコア、名前付きのルーン)。エンジンのルーンの表 (stage-runes.json 305 件) には絆の効果がほとんど入っていない。
- 貼り付けの読み: 印の無いトレードのコピーは、最後の絆の行までに加えて「スキルを付与」の行より前もルーン側にした (前は絆の行が無いとルーンの行が明示の MOD に混ざった: t6 から絆の行を抜くと「スピリットが15%増加する」と明示の 47% が 2 行とも読めない行になっていた)。スキルを付与の行が無い部位 (防具・装飾品) は、頭から続く行のうち、そのベースに差せるルーンの効果と同じ文で値がその和 (ソケットの数まで) に合い、同じ文の行が後ろにもある物をルーンに (作った文: 胴の「筋力 +9」+ 明示の「筋力 +24」で 9 がルーン、ルーンの無い「筋力 +24」だけなら明示のまま)。poe2db (10-24) の全部位で、絆の無いはめる物は全部エンジンのルーンの表にある (表にも無く絆も無い物は 0)。残る穴: 同じ能力値の明示が無い、絆の無いルーンの行だけの形は明示に混ざりうる (見本が来たら見る)。見本 20 個の答えは変わらない
