## ハイブリッドの見本 (オーナー 10-25「このマナ＋スピリットが検知されないな忍者だと」、n6・t3)
読み方: ハイブリッド (能力値 2 つで 1 つの MOD) が 2 行に分かれた物は、そのままだと有り得ない形 (同じ MOD が 2 行・側の枠を超える) の時だけ、同じ印・同じ側で両方の値が同じ段に収まる 2 行を 1 つにまとめる。別々の 2 つとも読める時と、合算された 1 行は推し量らない (段に収まらないの印)。
