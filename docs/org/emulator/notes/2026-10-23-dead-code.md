# エンジンの持ち場の死蔵の洗い出し (2026-10-23、ジン部長 6 本目。ブラック 8 代目の頼み、オーナー OK)

範囲: owners.txt の「ジン」の src (services/craft-stage・htc・mods・items・vendor/poe2htc) と、それを作る台本。画面の部長の持ち物には触れていない。窓口 (engine.ts・engine-emu.ts・engine-sim.ts) の export は消していない (シミュ部長・解析君が付け替え中)。

## 見方 (台本は scratchpad に置いて消した)
- import のグラフ: 入口 web.html → src/web/main.ts (Web)・index.html → src/main.ts (アプリ)・scripts/ の全部・tests/ の全部から、import / export from / import() / new URL(…, import.meta.url) / import.meta.glob を辿る。
- export の名前: ほかのファイル (src・scripts・tests・html・json、コメントの中も) に同じ単語が 1 つも無い物。コメントも数えるので、取りこぼしはあっても「使っている物を使っていない」とは言わない側。
- 結果: ジンのファイル 158 のうち、Web から辿れないのは 13 (下の表)。関数ごと使われていない export は 0、自分のファイルの中だけで使う export は 96。
