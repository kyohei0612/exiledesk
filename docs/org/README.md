# AI の組織 (ExileDesk)

オーナーと話すのはブラックだけ。仕事は 1 件 1 セッションで部長・係へ。コード (src/ など) の置き場は docs/ARCHITECTURE.md の「部ごとの持ち場」。

```
オーナー
└─ ブラック (司令塔)              black/
   └─ 開発部長 (土台・境目)        dev/        … 全部の部の決まり
      ├─ エミュ部長 (クラフト台)    emulator/
      ├─ シミュ部長 (シミュレーター) simulator/
      ├─ 解析君 (計算の係)          math/
      ├─ 分析君 (要望・バグ・記録)  analytics/
      └─ 動画部長 (POE2Tube)        video/
```

## 各フォルダーの中
- `README.md` … 決まり (10 行まで) と地図。始める前にここを読む (dev/README.md の決まりが先)。
- `todo.md` … やる事・OK 待ち。
- `notes/` … 終わった仕事の記録 (設計・調べ)。裏セッションの共有メモも終わったらここへ写す。
