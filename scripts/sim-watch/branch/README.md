# 枝の突き合わせ (S-210)

木の「決められた枝」(枠の形 × 手 → どの箱に入るか) を、エンジンで同じ品に同じ手を何度も打った結果と突き合わせる見張り。決まりの正は設計図 `docs/spec/sim-tree.md` の S-210。

- 回す時: エンジンの挙動 (`src/services/craft-stage/`) か木の分け方 (`src/services/simulator/tree/`) を変えた時だけ。画面・push・出しでは回らない (tests/ の外)。
- 見る物: (a) どの箱にも入らない結果 (b) 1 度も入らない箱 (c) 箱ごとの割合。エンジンの紙の一覧 E-100〜E-106 に行がある上書きは「わざと」として別に数える。
- 枠の形は始まりの形で作れる 8 つ (白・青・黄 × 狙い / 外れ / ✦)。未発現・腐食などは段 A (`tests/step-outcomes-all/`) の持ち場。

## 回し方 (作業場の根で)

変えた手だけ (既定の使い方):

```bash
KEY=chaos,annul node node_modules/vitest/vitest.mjs run -c scripts/sim-watch/branch/vitest.config.ts
```

- `KEY=` カレンシーの鍵をコンマで (`essence:` のように `:` で終えると前方一致)。無ければ棚の全部。
- `BASE=` 部位の名前の一部 (例 `Gold Ring`)、`SHAPE=` 枠の形の名前の一部 (例 `満杯`)、`N=` 1 手の打つ回数 (既定 400)。
- `PART=i/n` 部位を n に割った i 番目 (全部を裏で並べて回す時)。
- `OUT=<file>` 食い違いの一覧を JSON で書く、`LOG=<file>` 区切りごとに 1 行足す (裏で回す時の run.log)。

全部は長いので裏で回し、run.log を Monitor で見る (G-45)。目安 (11-12): 1 部位で 2 分強、全部の部位は `PART=0/8` 〜 `PART=7/8` を 4 つずつ並べて 12 分ほど。

読み方: 「食い違い」が 0 でなければ落ちる。「わざとの上書き」は落ちない (11-12 の全部の回しでは、削減のお告げを掛けたカオスの箱 = E-102 だけ)。

## 食い違いが出たら

直す前に 3 つに分ける: エンジンが違う (エミュで同じ手を打った結果がゲームと違う) / 木の表が違う (エミュは合っているが箱に入らない) / わざとの上書き (設計図に本文、エンジンの紙の一覧 E-100〜 に 1 行)。
