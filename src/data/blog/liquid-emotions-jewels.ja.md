PoE2 の液化した感情 (デリリウム) は、レアのジュエルの MOD を**ランダムに 1 つ消して、その感情で決まったクラフト MOD を 1 つ付ける**カレンシーです。中でも強力な液化した軽蔑は片側に 3 つ目の MOD を許し、強力な液化した獰猛は反対側の MOD の数値を伸ばします。

:::zundamon normal
ジュエルのクラフトって、指輪や防具ほど話題にならないのだ。
:::

:::metan normal
そうね。でも液化した感情を使うと、決まった MOD を狙って足せるの。軽蔑なら MOD の枠そのものを増やせるわ。
:::

:::zundamon surprised
枠が増えるのだ！？ それはすごいのだ。
:::

:::metan troubled
ただ、プレの版とサフィの版のどちらが付くかが分かりにくいの。ExileDesk も最初はここを間違えて作って、後から直したのよ。
:::

:::summary この記事で分かる事
- 液化した感情は、ジュエルの MOD を 1 つ消してから、決まったクラフト MOD を 1 つ付ける
- 強力な液化した軽蔑は「プレフィックスモッド +1個」などで片側に 3 つ目、続けて高貴なオーブで 5 つ目の MOD を足せる。強力な液化した獰猛は反対側の MOD の数値を伸ばす
- 軽蔑・獰猛のプレの版かサフィの版かは、ExileDesk では**ランダム** (説明文に決め方が無いため、v0.1.533)
:::

:::tip はじめての人へ: この記事の言葉
- **液化した感情**: デリリウムのカレンシー。ジュエルに決まったクラフト MOD を付ける
- **クラフト MOD**: 液化した感情などで付けた、決まった MOD
- **プレフィックス・サフィックス**: MOD の側 (プレフィックスとサフィックス)
- **版**: 同じ感情でも、プレフィックスに付く物とサフィックスに付く物がある
- **高貴なオーブ**: レアのアイテムに MOD を 1 つ足すカレンシー
- **弾かれる**: 上限を超えた側に当たって、何も変わらないこと
:::

## 液化した感情はジュエルに何をするのか

液化した感情は、1 回の使用で「消す」と「付ける」が同時に起きるカレンシーです。

:::zundamon normal
液化した感情の説明文には、何て書いてあるのだ？
:::

:::metan normal
強力な液化した軽蔑なら「ランダムなモッドを1個取り除き、レア基本ジュエルに確定でクラフトモッドを追加する」よ。ExileDesk のホバーに出している文ね。
:::

:::zundamon normal
古代の強力な液化した軽蔑というのも見たのだ。
:::

:::metan normal
古代の版は、同じ文の「タイムロストジュエル」用なの。
:::

:::zundamon happy
消すのはランダムで、付くのは確定なのだ。
:::

:::metan normal
そう。何が付くかは感情の種類で決まっているわ。名前の頭に、希釈された・普通・濃縮された・強力な、が付いた物があるのよ。
:::

:::metan normal
ExileDesk では v0.1.485 で、ジュエルに液化した感情を使えるようにしたわ。
:::

| 説明文の部分 | 何が起きるか | 決まり方 |
|---|---|---|
| ランダムなモッドを1個取り除き | 今ある MOD が 1 つ消える | ランダム |
| 確定でクラフトモッドを追加する | 感情ごとに決まった MOD が 1 つ付く | 確定 |
| 古代の版 | 同じ動きを、タイムロストジュエルに | 同じ |

1 回で消す・付けるが同時に起きる、と覚えておけば十分です。

## 軽蔑・獰猛の版はなぜランダムなのか

軽蔑と獰猛には、プレフィックスに付く版とサフィックスに付く版があります。どちらが付くかで、ジュエルの形が大きく変わります。

### 最初は「消えた MOD の側」で決めていた

:::zundamon normal
最初の ExileDesk は、どうやって版を決めていたのだ？
:::

:::metan normal
v0.1.485 で作った時は、**消えた MOD の側の版が付く**ようにしていたの。サフィックスが消えたらサフィックスの版、という形よ。
:::

:::zundamon happy
空いた所にそのまま入るのだ。自然なのだ！
:::

:::metan troubled
そう見えたのよね。でも、それが間違いだったの。
:::

### 説明文に無いので、ランダムに直した

:::zundamon surprised
何がいけなかったのだ？
:::

:::metan normal
説明文を読み直したら、どちらの版を付けるかの決め方はどこにも書いていなかったの。
:::

:::metan normal
ExileDesk は「説明文に書いてある効果どおりに動かし、書いていない決まりは足さない」作りなのよ。詳しくは [例外を書かない作り方](/blog/crafting-simulator-no-exceptions/) にあるわ。
:::

:::zundamon normal
じゃあ「消えた側に付く」は……。
:::

:::metan normal
根拠の無い決まりを、自分で足していたことになるわ。だから v0.1.533 で、プレの版とサフィの版の**どちらが付くかをランダム**に直したの。
:::

| 版 | 版の決め方 | なぜか |
|---|---|---|
| v0.1.485 (最初) | 消えた MOD の側の版が付く | 空いた所に入るので自然に見えた |
| v0.1.533 (今) | プレの版かサフィの版かがランダム | 説明文に決め方が書いていない |

書いていない決まりを足さないのが、ExileDesk の作りです。

## 強力な軽蔑・獰猛でジュエルはどう変わるか

強力な版の軽蔑と獰猛は、どちらも片側の形を大きく変えます。

### 強力な液化した軽蔑で枠を増やす

:::zundamon normal
強力な液化した軽蔑では、何が付くのだ？
:::

:::metan normal
「プレフィックスモッド +1個」か「サフィックスモッド +1個」よ。
:::

:::metan normal
ExileDesk では、書いてある側に 3 つ目の MOD を持てるの (v0.1.485)。「プレフィックスモッド +1個」ならプレフィックスね。
:::

:::zundamon surprised
前の更新内容で「侮蔑」と書いてあった気がするのだ。
:::

:::metan troubled
以前の ExileDesk の更新内容では、そう書いていたの。アイテムの名前は「強力な液化した軽蔑」よ。
:::

:::zundamon normal
枠を増やしたら、その後はどうするのだ？
:::

:::metan happy
v0.1.561 のチュートリアル「液化した感情を学ぶ」では、軽蔑で枠を増やした後に、高貴なオーブで 5 つ目の MOD を足す所まで打てるわ。
:::

| 強力な液化した軽蔑 | ExileDesk の動き | 何に気を付けるか |
|---|---|---|
| 使った時 | MOD を 1 つ消して、「プレフィックスモッド +1個」か「サフィックスモッド +1個」を付ける | 版はランダム |
| 付いた後 | 書いてある側に 3 つ目の MOD を持てる。高貴なオーブで 5 つ目 | どちらの側が増えるかは選べない |
| 軽蔑を外した後 | 3 つ残った側にカオスオーブが当たると弾かれる | 当たり所しだい |

軽蔑は、MOD の数そのものを増やせる珍しい手です。

### 強力な液化した獰猛は反対側を伸ばす

:::zundamon normal
強力な液化した獰猛はどうなのだ？
:::

:::metan normal
付くのは「サフィックスの効果が増加する」か「プレフィックスの効果が増加する」よ。この MOD で、**反対側の MOD の数値が伸びる**の (v0.1.485)。
:::

:::zundamon troubled
反対側って、どういうことなのだ？
:::

:::metan normal
たとえばサフィックスの枠に「プレフィックスの効果が増加する」が付けば、伸びるのはプレフィックスの数字なの。
:::

:::zundamon normal
じゃあ、伸ばしたい側を選べばいいのだ。
:::

:::metan troubled
それが選べないの。どちらの版が付くかは軽蔑と同じくランダムだから、狙った側が伸びるとは限らないわ。
:::

| 付いた獰猛の MOD | 付く側 | 伸びる側 |
|---|---|---|
| プレフィックスの効果が増加する | サフィックス | プレフィックスの数字 |
| サフィックスの効果が増加する | プレフィックス | サフィックスの数字 |

獰猛は数を増やさず、反対側の数字を押し上げます。

## 使えない時・弾かれる時はどうなるか

液化した感情には、使えない時と、押しても弾かれる時があります。

:::zundamon normal
感情を何回も重ねて打てばいいのだ。
:::

:::metan troubled
それができないの。**クラフト MOD が付いている間は使えない**のよ (v0.1.493)。液化した感情で付けた MOD が残っていると、次の感情は打てないわ。
:::

:::zundamon normal
弾かれる時というのは何なのだ？
:::

:::metan normal
当たり所で弾かれることがあるの。たとえば軽蔑を外した後、3 つ残った側にカオスオーブが当たると弾かれるわ。
:::

:::zundamon troubled
弾かれたら、カレンシーが減ってしまうのだ？
:::

:::metan normal
ExileDesk では、こうした「当たり所で弾かれるだけの物」は棚から消さないの。押して弾かれたら、**数を減らさずに工程に残す**わ (v0.1.493)。
:::

:::metan happy
ゲームと同じく、自由に押せるようにするためよ。
:::

| 場面 | 何が起きるか | なぜか |
|---|---|---|
| クラフト MOD が付いている | 次の感情は使えない | 感情のクラフト MOD が残っている間は打てない |
| 軽蔑を外した後、3 つ残った側にカオス | 弾かれる | その側が上限を超えている (軽蔑を外した後の 3 つ目) |
| 弾かれた時の ExileDesk | 数を減らさずに工程に残す | 棚から消さず、自由に押せるようにする |

:::tip 感情を重ねる時の順番
液化した感情は、クラフト MOD が付いている間は使えません (v0.1.493)。軽蔑や獰猛を付けた後は、そのクラフト MOD が残っている限り次の感情は打てないので、どの感情を使うかを先に決めておくと迷いません。
:::

:::note fold 確かめていない所 (2 件)
- この記事の動きは、ExileDesk のエンジンでの作りです。poe2db の説明文はこの記事のために読み直していません (引用はサイトのホバーの文)。
- 軽蔑・獰猛の版が等しい確率で選ばれるかは、ゲームの数字が公開されていません。説明文に書いていないためにランダムにした、エンジンの前提です。
:::

液化した感情は、1 つ消してから決まった MOD を 1 つ付けます。軽蔑は片側の枠を増やし、獰猛は反対側を伸ばしますが、どちらの版が付くかはランダムです。
