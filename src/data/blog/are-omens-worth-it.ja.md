PoE2 のお告げは高いけれど使うべきか。最善手の計算の答えは「**ほとんどの場面では使わず、0.44 神の普通の消去のオーブで足りる**」でした (神 = 神のオーブ、ディバイン)。左側の消去のお告げ 14.9 神・左側の抹消のお告げ 16 神 (poe2db の取引レート) のような高いお告げが得になるのは、**外れの無い側に狙いが付いている時だけ**です。

お告げの値段を並べてみると、1 個 0.44 神の消去のオーブに対して、10 神を超える物がいくつもあります。それでも「狙いを巻き込みたくないから」と、つい外れのある側だけを消すお告げに手が伸びますよね。

ところが手袋のクラフトで、場面ごとに一番安い手を計算すると、高いお告げの出番はかなり限られていました。逆に、値段が 1 神もしない安いお告げは、最善手の中に何度も出てきます。

この記事では、お告げの値段の一覧と、計算が「使う」「使わない」を分けた場面を並べます。

:::summary この記事で分かる事
- 消す側を選ぶお告げ (消去・抹消) は 1 個 12.9〜19.4 神、削減のお告げも 13.1 神。左右の高貴・結晶化・ネクロマンシーのお告げは 1 神もしない
- 最善手の計算は、外れを普通の消去のオーブで消し、高いお告げはほぼ使わなかった
- 高いお告げが得になるのは、外れの無い側に狙いが揃っている時。普通の消去だと T1 狙いで +740〜3,300 神、T3 以上で +120〜1,580 神の損
- 自分で判断する時の見当の式と、その限界
:::

## お告げの値段: 高い物と安い物

poe2db の各ページにある取引レート (2026-10-21 に取得) を並べました。「1 神 = n 個」は神のオーブ 1 個で n 個買える、という意味です。どちらが値段かの向きは表記からの読み取りで、推定です。

| お告げ (Omen) | 効果 | 1 個の値段 |
|---|---|---:|
| 右側の抹消のお告げ (Omen of Dextral Erasure) | 次のカオスオーブはサフィックスだけ取り除く | 19.4 神 |
| 左側の抹消のお告げ (Omen of Sinistral Erasure) | 次のカオスオーブはプレフィックスだけ取り除く | 16 神 |
| 左側の消去のお告げ (Omen of Sinistral Annulment) | 次の消去のオーブはプレフィックスだけ取り除く | 14.9 神 |
| 削減のお告げ (Omen of Whittling) | 次のカオスオーブは最もレベルの低いモッドを取り除く | 13.1 神 |
| 右側の消去のお告げ (Omen of Dextral Annulment) | 次の消去のオーブはサフィックスだけ取り除く | 12.9 神 |
| 光のお告げ (Omen of Light) | 次の消去のオーブは冒涜モッドだけ取り除く | 6.42 神 |
| 左側の結晶化のお告げ (Omen of Sinistral Crystallisation) | 次のパーフェクト / コラプトエッセンスはプレフィックスだけ取り除く | 0.51 神 |
| 右側の結晶化のお告げ (Omen of Dextral Crystallisation) | 同じくサフィックスだけ | 0.29 神 |
| アビスの反響のお告げ (Omen of Abyssal Echoes) | 次の冒涜の発現で選択肢をもう一度リロールできる | 0.09 神 |
| 右手のネクロマンシーのお告げ (Omen of Dextral Necromancy) | 次の冒涜はサフィックスだけ追加 | 0.049 神 |
| 左側の高貴なお告げ (Omen of Sinistral Exaltation) | 次の高貴なオーブはプレフィックスだけ追加 | 1 神 = 9.87 個 |
| 右側の高貴なお告げ (Omen of Dextral Exaltation) | 次の高貴なオーブはサフィックスだけ追加 | 約 0.017 神 |

比べる相手の消去のオーブ (Orb of Annulment) は、同じ取引レートで 0.45 神、計算に使った ExileDesk の相場では 0.44 神です。

つまり「お告げは高い」は、**消す側を選ぶお告げ (消去・抹消)** と、消す MOD をレベルで寄せる削減のお告げの話です。付ける側を選ぶお告げは、むしろ安い部類です。

## 最善手はどのお告げを使ったか

題材は、配信で作られていた知性の手袋です。形ごとに「完成までの期待費用が一番小さい手」を後ろから計算しました (計算の仕方は [クラフトの期待値は勘と違う](/blog/optimal-move-vs-intuition/) に書いています)。

計算が選んだお告げと、選ばなかったお告げはこう分かれました。

| | お告げ | 使い方 |
|---|---|---|
| 使った | 左側の高貴なお告げ | 高貴なオーブ (上級) と合わせて、プレフィックスの狙いを足す |
| 使った | 結晶化のお告げ (0.4 神) | エッセンスを付ける時に、外れのある側を消させる |
| 使った | 光のお告げ (9.3 神) | 冒涜で付いた外れだけを外す。冒涜ありの計算で 1 本あたり 1.4 回 |
| 使った | アビスの反響のお告げ | 冒涜の発現と合わせる |
| 使わなかった | 抹消・消去のお告げ (14〜21 神) | 外れは普通の消去のオーブで消す |

値段の欄の 0.4 神・9.3 神・14〜21 神は、計算に使った ExileDesk の相場 (2026-10-21) で、上の poe2db の表とは少し違います。

光のお告げは 6〜9 神と安くはありませんが、冒涜の外れを外す時だけは選ばれました (それ以外の外れは普通の消去)。高いから使わない、ではなく「その場面で何を守れるか」で選ばれている、ということです。

## 高いお告げが得になるのはどんな場面か

別の計算で、狙いを 5 つにした手袋 (フラクチャー済みのマナ T1 に、プレフィックス 2 つ・サフィックス 3 つの狙い) を場面 27 個に分け、手ごとの損を出しました。狙いを全部 T1 にした場合と、T3 以上で良しとした場合の 2 通りで、合わせて 54 場面です。

| 場面 (狙いの数 / プレの外れ / サフィの外れ) | 最善の手 | 普通の消去の損 (T1 / T3 以上) | 側の消去の損 (T1 / T3 以上) |
|---|---|---:|---:|
| 0 / 0 / 2 | 普通の消去 | 0 / 0 | +14 / +14 神 |
| 0 / 1 / 0 | カオスオーブ | 0 / 0 | +21 / +21 神 |
| 1 / 1 / 1 | 普通の消去 | 0 / 0 | +14 / +14 神 |
| 2 / 1 / 0 | 冒涜 (保存された肋骨) + 右手のネクロマンシーのお告げ | +1,004 / +185 神 | +1 / 0 神 |
| 3 / 1 / 0 | カオスオーブ (上級) + 左側の抹消のお告げ | +3,335 / +1,581 神 | +1 / +1 神 |
| 3 / 2 / 0 | 消去 + 左側の消去のお告げ | +2,655 / +1,252 神 | 0 / 0 |
| 4 / 1 / 0 | 消去 + 左側の消去のお告げ | +2,723 / +1,354 神 | 0 / 0 |

「側の消去」は外れのある側を選んで消すお告げ付きの手です。

序盤 (狙いが 0〜1 個で、外れと同じ側にしか狙いが無い) では、側の消去の損はお告げの値段ぶん (計算に入れた値段で +14〜21 神) だけ。守る物が無いので、お告げ代がそのまま無駄になります。

ところが、サフィックスに狙いが揃い、外れがプレフィックスだけにある場面では逆転します。普通の消去は揃えたサフィックスを巻き込むので、外れの無い側に狙いがある場面の普通の消去の損は、T1 狙いで +740〜3,300 神、T3 以上でも +120〜1,580 神です。ここでは計算に入れた値段で 1 個 21.0 神の左側の抹消・消去のお告げも安い買い物です。

最善手が「2 / 1 / 0」でネクロマンシーのお告げ (0.049 神) を選んでいるのも面白い所です。消すのではなく、冒涜の付く側をサフィックスに寄せて狙いを足す手が、ほぼ只で選ばれています。

## 使うかどうかの見当の式

計算の答えを手で当てる式も作りました。

:::tip 見当の式
(普通の消去で狙いに当たる確率 − 側の消去で当たる確率) × 付け直しの費用 > お告げの値段 なら、お告げを使う。
:::

計算に入れたお告げの値段は、場面によって 13.6 神か 21.0 神です。たとえば T1 の「3 / 1 / 0」では左辺が 2,592.7 神で、21.0 神を大きく超えます。序盤の場面は左辺が 0 (巻き込む狙いが無い) なので、お告げは要りません。

この式は 54 場面とも、最善手の向き (お告げを使うか、普通の消去か) と合いました。ただし合うのは向きだけです。「4 / 1 / 0」では左辺 67.8 神に対して、実際の普通の消去の損は 2,723 神でした。損の大きさを測る物差しではありません。

付け直しが安い狙いなら左辺は小さくなります。前の記事の手袋で外れを普通の消去で消してよかったのは、投射物 +2 をカオスオーブで付け直せて (平均約 31 神)、巻き込みの損が小さかったからです。

:::note 計算に入っていない物
- 削減のお告げ (13.1 神) は、手として計算に入れていません。使うべき場面があるかは、この計算からは言えません。
- 54 場面の結果は計算の中での比べで、ゲームの実測や Craft of Exile とは突き合わせていません。境目の場面から始めて、エンジンで残りの費用を測ることもまだです。
- poe2db の取引レートの向き (どちらが値段か) は表記からの読み取りで推定です。取引数の少ない物は目安として弱いです。
:::

## 数字の出どころ

- お告げ・消去のオーブの値段の一覧: poe2db の各ページの取引レート (2026-10-21 取得)。向きは推定 (poe2db・推定)。
- 最善手が使ったお告げ・0.44 神・0.4 神・9.3 神・14〜21 神・付け直し約 31 神: 手袋の最善手の計算 (2026-10-21、相場は ExileDesk のサーバー、1 神 = 高貴 718 個)。最善手はエンジン 1,000 本で計算と 1 割以内 (エンジン)。付け直しの 1 回 0.32% はエンジンで実測。
- 54 場面の表・見当の式: 狙い 5 つの手袋の計算 (2026-10-20、T1 は始めから 5,285 神、T3 以上は 2,577 神)。計算の中の比べで、外の正解ではありません (エンジンの計算)。
