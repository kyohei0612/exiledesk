PoE2 のお告げは高いけれど使うべきか。最善手の計算の答えは「**ほとんどの場面では使わず、0.44 神の普通の消去のオーブで足りる**」でした (神 = 神のオーブ、ディバイン)。左側の消去のお告げ 14.9 神・左側の抹消のお告げ 16 神 (poe2db の取引レート) のような高いお告げが得になるのは、**外れの無い側に狙いが付いている時だけ**です。

:::

:::metan normal
気持ちは分かるわ。でも消去のオーブは 1 個 0.44 神、お告げには 10 神を超える物がいくつもあるの。
:::

:::zundamon surprised
そんなに差があるのだ！？ それでも使うべきなのだ？
:::

:::metan happy
手袋で一番安い手を計算したら、高いお告げの出番はかなり限られていたわ。逆に 1 神もしない安いお告げは、何度も出てきたのよ。
:::

:::summary この記事で分かる事
- 消す側を選ぶお告げ (消去・抹消) は 1 個 12.9〜19.4 神、削減のお告げも 13.1 神。左右の高貴・結晶化・ネクロマンシーのお告げは 1 神もしない
- 最善手の計算は外れを普通の消去のオーブで消し、高いお告げはほぼ使わなかった。得になるのは外れの無い側に狙いが揃っている時で、普通の消去だと T1 狙いで +740〜3,300 神、T3 以上で +120〜1,580 神の損
- 自分で判断する時の見当の式と、その限界
:::

:::tip はじめての人へ: この記事の言葉
- **神**: 神のオーブ (ディバイン)。この記事の値段の単位
- **お告げ**: 持っておくと、次に使うカレンシーの効き方を変える物
- **消去のオーブ**: アイテムの MOD を 1 つランダムに取り除くカレンシー
- **側**: MOD の置き場。左側がプレフィックス、右側がサフィックス
- **狙い・外れ**: 完成に要る MOD が狙い、要らない MOD が外れ
- **最善手**: 完成までの期待費用が一番小さくなる手
:::

## お告げの値段: 高い物と安い物

poe2db の各ページにある取引レート (2026-10-21 に取得) を並べました。どちらが値段かの向きは表記からの読み取りで、推定です。

| お告げ | 効果 | 1 個の値段 | 高いか安いか |
|---|---|---:|---|
| 右側の抹消のお告げ | 次のカオスオーブはサフィックスだけ取り除く | 19.4 神 | 高い |
| 左側の抹消のお告げ | 次のカオスオーブはプレフィックスだけ取り除く | 16 神 | 高い |
| 左側の消去のお告げ | 次の消去のオーブはプレフィックスだけ取り除く | 14.9 神 | 高い |
| 削減のお告げ | 次のカオスオーブは最もレベルの低いモッドを取り除く | 13.1 神 | 高い |
| 右側の消去のお告げ | 次の消去のオーブはサフィックスだけ取り除く | 12.9 神 | 高い |
| 光のお告げ | 次の消去のオーブは冒涜モッドだけ取り除く | 6.42 神 | 中くらい |
| 左側の結晶化のお告げ | 次のパーフェクト / コラプトエッセンスはプレフィックスだけ取り除く | 0.51 神 | 安い |
| 右側の結晶化のお告げ | 同じくサフィックスだけ | 0.29 神 | 安い |
| アビスの反響のお告げ | 次の冒涜の発現で選択肢をもう一度リロールできる | 0.09 神 | 安い |
| 右手のネクロマンシーのお告げ | 次の冒涜はサフィックスだけ追加 | 0.049 神 | ほぼ只 |
| 左側の高貴なお告げ | 次の高貴なオーブはプレフィックスだけ追加 | 1 神 = 9.87 個 | 安い |
| 右側の高貴なお告げ | 次の高貴なオーブはサフィックスだけ追加 | 約 0.017 神 | ほぼ只 |

:::zundamon normal
「1 神 = 9.87 個」って、どういう意味なのだ？
:::

:::metan normal
神のオーブ 1 個で 9.87 個買える、という意味よ。
:::

:::zundamon normal
比べる相手の消去のオーブは、いくらなのだ？
:::

:::metan normal
同じ取引レートで 0.45 神、計算に使った ExileDesk の相場では 0.44 神よ。
:::

:::zundamon surprised

:::

## 最善手はどのお告げを使ったか

題材は、投射物 +2 を狙いに入れた知性の手袋です。形ごとに「完成までの期待費用が一番小さい手」を後ろから計算しました (計算の仕方は [クラフトの期待値は勘と違う](/blog/optimal-move-vs-intuition/) に書いています)。

| 使ったか | お告げ | 使い方 |
|---|---|---|
| 使った | 左側の高貴なお告げ | 高貴なオーブ (上級) と合わせて、プレフィックスの狙いを足す |
| 使った | 結晶化のお告げ (0.4 神) | エッセンスを付ける時に、外れのある側を消させる |
| 使った | 光のお告げ (9.3 神) | 冒涜で付いた外れだけを外す。冒涜ありの計算で 1 本あたり 1.4 回 |
| 使った | アビスの反響のお告げ | 冒涜の発現と合わせる |
| 使わなかった | 抹消・消去のお告げ (14〜21 神) | 外れは普通の消去のオーブで消す |

:::zundamon normal
表の値段が、さっきの poe2db の表と少し違うのだ。
:::

:::metan normal
0.4 神・9.3 神・14〜21 神は、計算に使った ExileDesk の相場 (2026-10-21) の値なの。
:::

:::zundamon normal
光のお告げは 6〜9 神もするのに、使われているのだ？
:::

:::metan normal
冒涜の外れを外す時だけ選ばれたの。それ以外の外れは普通の消去よ。
:::

:::metan happy
高いから使わない、ではないの。「その場面で何を守れるか」で選ばれているのよ。
:::

## 高いお告げが得になるのはどんな場面か

別の計算で、狙いを 5 つにした手袋 (フラクチャー済みのマナ T1 に、プレフィックス 2 つ・サフィックス 3 つの狙い) を場面 27 個に分け、手ごとの損を出しました。狙いを全部 T1 にした場合と、T3 以上で良しとした場合の 2 通りで、合わせて 54 場面です。

| 場面 (狙いの数 / プレの外れ / サフィの外れ) | 最善の手 | 普通の消去の損 (T1 / T3 以上) | 側の消去の損 (T1 / T3 以上) | どちらが得か |
|---|---|---:|---:|---|
| 0 / 0 / 2 | 普通の消去 | 0 / 0 | +14 / +14 神 | お告げ無し (守る狙いが無い) |
| 0 / 1 / 0 | カオスオーブ | 0 / 0 | +21 / +21 神 | お告げ無し (守る狙いが無い) |
| 1 / 1 / 1 | 普通の消去 | 0 / 0 | +14 / +14 神 | お告げ無し |
| 2 / 1 / 0 | 冒涜 (保存された肋骨) + 右手のネクロマンシーのお告げ | +1,004 / +185 神 | +1 / 0 神 | 側を選ぶ手 |
| 3 / 1 / 0 | カオスオーブ (上級) + 左側の抹消のお告げ | +3,335 / +1,581 神 | +1 / +1 神 | 側を選ぶ手 |
| 3 / 2 / 0 | 消去 + 左側の消去のお告げ | +2,655 / +1,252 神 | 0 / 0 | 側を選ぶ手 |
| 4 / 1 / 0 | 消去 + 左側の消去のお告げ | +2,723 / +1,354 神 | 0 / 0 | 側を選ぶ手 |

:::

## 使うかどうかの見当の式

計算の答えを手で当てる式も作りました。

:::tip 見当の式
(普通の消去で狙いに当たる確率 − 側の消去で当たる確率) × 付け直しの費用 > お告げの値段 なら、お告げを使う。
:::

:::zundamon normal
お告げの値段には、いくらを入れたのだ？
:::

:::metan normal
計算に入れた値段は、場面によって 13.6 神か 21.0 神よ。
:::

| 場面 | 左辺 | お告げの値段 | 式の答え | 実際の普通の消去の損 |
|---|---:|---:|---|---:|
| T1 の「3 / 1 / 0」 | 2,592.7 神 | 21.0 神 | お告げを使う (大きく超える) | +3,335 神 |
| T1 の「4 / 1 / 0」 | 67.8 神 | 21.0 神 | お告げを使う | +2,723 神 |
| 序盤の場面 | 0 (巻き込む狙いが無い) | 13.6 神か 21.0 神 | お告げは要らない | 0 |

:::zundamon happy
この式があれば、計算しなくても分かるのだ！
:::

:::metan normal
54 場面とも、最善手の向き (お告げを使うか、普通の消去か) とは合ったわ。
:::

:::metan troubled
でも合うのは向きだけ。「4 / 1 / 0」では左辺 67.8 神に対して、実際の損は 2,723 神だったの。損の大きさを測る物差しではないのよ。
:::

:::zundamon normal
付け直しの費用が安いと、どうなるのだ？
:::

:::metan normal
左辺が小さくなるわ。前の記事の手袋で外れを普通の消去で消してよかったのは、投射物 +2 をカオスオーブで付け直せたからなの。
:::

:::metan normal
付け直しは平均約 31 神で、巻き込みの損が小さかったのよ。
:::

:::note fold 確かめていない所 (3 件)
- 削減のお告げ (13.1 神) は、手として計算に入れていません。使うべき場面があるかは、この計算からは言えません。
- 54 場面の結果は計算の中での比べで、ゲームの実測や Craft of Exile とは突き合わせていません。境目の場面から始めて、エンジンで残りの費用を測ることもまだです。
- poe2db の取引レートの向き (どちらが値段か) は表記からの読み取りで推定です。取引数の少ない物は目安として弱いです。
:::

高いお告げは、外れの無い側に守る狙いがある時だけ使えば十分です。それ以外は 0.44 神の普通の消去のオーブで足ります。

## 数字の出どころ

:::fold 出どころを見る (3 件)
- お告げ・消去のオーブの値段の一覧: poe2db の各ページの取引レート (2026-10-21 取得)。向きは推定 (poe2db・推定)。
- 最善手が使ったお告げ・0.44 神・0.4 神・9.3 神・14〜21 神・付け直し約 31 神: 手袋の最善手の計算 (2026-10-21、相場は ExileDesk のサーバー、1 神 = 高貴 718 個)。最善手はエンジン 1,000 本で計算と 1 割以内 (エンジン)。付け直しの 1 回 0.32% はエンジンで実測。
- 54 場面の表・見当の式: 狙い 5 つの手袋の計算 (2026-10-20、T1 は始めから 5,285 神、T3 以上は 2,577 神)。計算の中の比べで、外の正解ではありません (エンジンの計算)。
:::
