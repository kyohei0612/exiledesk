PoE2 の金の指輪のクラフト手順を、動画の字幕の聞き違い (「ち性」= 知性、「上級後期」= 高貴なオーブ (上級) など) ごと poe2db の名前に直しました。途中で付ける「品質の最大値 +20%」は、**品質を 40% にする足場であり、削減のお告げで確実に消える餌**です。

レアリティを盛ったキャスター向けの金の指輪を作る動画を見ていて、字幕で手が止まりました。「ち性」「歴体勢」「上級後期」。何のことか分かりますか?

自動字幕は聞き違いが多く、そのままでは手順を真似できません。そこで動画のコマ (画面に出たゲームの表示) と poe2db の名前で、1 段ずつ全部確かめ直しました。

名前が分かると、途中で「品質の最大値 +20%」を付けてはわざわざ消している理由も見えてきます。

:::summary この記事で分かる事
- 字幕の聞き違い 9 個の正体 (「ち性」= 知性、「上級後期」= 高貴なオーブ (上級) など)
- 完成までの 8 段の手順と、使った物の正しい名前
- 「品質の最大値 +20%」は**品質 40% の足場**で、**削減のお告げで確実に消える餌**
- 完全のカオスでレベル 47 の MOD が付いた理由
:::

## 字幕の聞き違いを直す

| 字幕 | 正体 | 確かめた所 |
|---|---|---|
| ち性 | 知性 (碩学の、T2) | 画面 |
| 歴体勢 / レキ体制 | 冷気耐性 (氷の T2 / ホッキョクグマの T3) | 画面 |
| 上級エグザ / 上級後期 | 高貴なオーブ (上級) | poe2db |
| 冒ト / 冒徳 | 冒涜 (指輪は鎖骨の骨) | poe2db |
| マ消 | 左側の抹消のお告げ | poe2db |
| 削減 | 削減のお告げ | poe2db |
| ブリーチエッセンス | ブリーチのエッセンス | poe2db |
| アザーワールド | 異世界の MOD (変質した鎖骨で冒涜すると付く) | poe2db |
| 高貴エッセンス (前の読み) | 誤り。高貴なオーブ (上級) のこと | 字幕と画面 |

完成品は 6 枠で、オーナーの手元の完成品のスクリーンショットとも全部一致しました。プレフィックスはスペルダメージ (グリフの、フラクチャー)・見つかるアイテムのレアリティ (貯蔵者の、T1)・追加冷気ダメージ (嵐乗りの、冒涜)。サフィックスは全ての元素耐性 (虹の、T1)・見つかるアイテムのレアリティ (考古学の、T1)・キャストスピード (手品の、T1) です。

## 手順を段ごとにたどる

| 段 | 使った物 | 何をしたか |
|---|---|---|
| ① ② | 消去のオーブ | スペルダメージ付きのベースから余計な MOD を消す |
| ③ | 神のオーブ → 冒涜 → フラクチャーオーブ | スペルダメージを 34 まで振ってからフラクチャー (4 MOD 以上が条件) |
| ④a | カオスオーブ | 2 MOD の形でサフィックスのレアリティ T1 が出るまでスパム |
| ④b | 左側の高貴のお告げ + 高貴 (上級) → 左側の結晶化のお告げ + ブリーチのエッセンス | 餌のプレフィックスを付け、それを「品質の最大値 +20%」に入れ替える |
| ④c | 軽快のカタリスト → 触媒の高貴のお告げ + 右側の高貴のお告げ + 高貴 (上級) | 品質 40% でキャストスピードを狙う |
| ④d | 歯擦音のカタリスト | 品質をキャスターモッドの 40% に入れ替える |
| ⑤ | 削減のお告げ + カオスオーブ | 品質の最大値を消して、別の MOD を 1 つ足す |
| ⑦ | 左側の抹消のお告げ + カオスオーブ (完全) | プレフィックスの回避力をレアリティ T1 に替える |
| ⑧ | 変質した鎖骨 | 冒涜して嵐乗りの (冷気) を選ぶ |

動画の途中で説明される「左側の結晶化 + ルーンの合金」(⑥) は、この指輪では使っていません。完成品に最大ルーンワードの MOD が無いことを画面で確かめました。

## 「品質の最大値 +20%」をわざわざ消す理由

④b〜⑤ は、一見すると遠回りです。わざわざ MOD を 1 枠使って「品質の最大値 +20%」を付け、品質を載せ終わったらすぐに消しています。理由は 3 つの性質の組み合わせです。

1. **品質は MOD が消えても残る**。品質の上限は素の 20% ですが、「品質の最大値 +20%」があれば 40% まで載せられます。載せた後でこの MOD を消しても、40% の品質はそのまま残ります。
2. **この MOD は MOD レベル 1**。ブリーチのエッセンスで付く「品質の最大値 +20%」は、MOD レベル 1 です。
3. **削減のお告げは「最もレベルの低い MOD」を消す**。次のカオスオーブが、フラクチャー以外で一番 MOD レベルの低い MOD を取り除きます。レベル 1 の MOD があれば、ほぼ確実にそれが選ばれます。

つまり「品質の最大値 +20%」は、品質を 40% にするための足場であり、同時に削減のお告げの的になる餌でもあります。

:::tip 餌の MOD の考え方
「消したい時に確実に消える MOD」を先に置いておくと、削減のお告げの行き先を選べます。MOD レベル 1 の物が餌に向きます。
:::

動画では⑤で削減 + カオスを打ち、品質の最大値が消えて、代わりに回避力 T2 が付きました。

### 品質 40% で費用は下がるのか

ちなみに、品質 40% にするとサフィックスを揃える費用が下がるかも、エンジンで回してみました。サフィックスの 3 つを揃える計算 (外れを 3 つまで埋めてから消去する打ち方、触媒の高貴に完全・素の高貴に上級) で、品質 20% は 1 個 528 神、40% (餌・結晶化・ブリーチの代金込み) は 492 神でした。50 人ずつの比べで誤差は ±25% あるので、差は誤差の中です。40% の値打ちは、費用よりも完成品の数字が伸びる所にあります (同じ計算の別の打ち方は [外れは溜めるな](/blog/dont-hoard-misses/) に書きました)。

## 完全のカオスでレベル 47 の MOD が付いた謎

⑦ では、カオスオーブ (完全) で貯蔵者の (レアリティ T1、MOD レベル 47) が付いています。poe2db では完全のカオスの最低モッドレベルは 50 なので、字面どおりなら付かないはずです。

これはゲームの用語の説明 (最低モッドレベルのキーワード) にある「その種類のモッドが完全に除外される場合を除く」で説明がつきます。貯蔵者の はレアリティ (プレフィックス) の一番上の段で、レベル 50 以上の段がありません。下限で全部消えてしまう系統は、一番上の段だけが残ります。ExileDesk のエンジンもこの扱いで作ってあります。

## 数字と名前の出どころ

- 名前・段・MOD レベルは poe2db の指輪のページ (日本語・英語)。段ごとの手順は動画のコマ (画面の表示) と字幕。冒涜とフラクチャーの瞬間は画面に出ず、未確認です。
- 品質 20% と 40% の比べは ExileDesk のエンジンで 50 人ずつ。Craft of Exile とは突き合わせていません。

:::note 確かめていない所
冒涜とフラクチャーの瞬間は動画の画面に出ておらず、そこの手順は字幕だけが頼りです。
:::
