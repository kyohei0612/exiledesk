PoE2 の冒涜 MOD には陣営 (アマナム・ウラマン・クルガル) がありますが、ExileDesk では**メイスの余震・亀裂など一部の MOD が違う陣営に入っていました**。poe2db の 9,455 段とタグを全部照らし合わせ、v0.1.572 で 93 MOD (部位ごとに数えた数) を poe2db に合わせています。

:::

:::metan normal
そう。poe2db と全部照らし合わせて、v0.1.572 で直したわ。
:::

:::summary この記事で分かる事
- 冒涜の陣営が poe2db と違っていた MOD (メイスの余震・亀裂・強化アタック、ワンドのフルマナ時のキャストスピードなど)
- 照らし合わせた範囲 (通常・冒涜・エッセンスの 9,455 段) と、食い違いの 34 種類の内訳
- v0.1.572 で 93 MOD を poe2db に合わせたこと、まだ決まっていない 1 つ
:::

:::tip はじめての人へ: この記事の言葉
- **冒涜**: アイテムに冒涜 MOD を付けるクラフト
- **陣営**: 冒涜 MOD の持ち主。アマナム・ウラマン・クルガルの 3 つ
- **陣営のお告げ**: 掛けて冒涜すると、その陣営の MOD だけが候補に入るお告げ
- **タグ**: MOD に付いた印。品質で伸びるか・一覧の絞り込みなどに使う
- **段**: 同じ MOD でも数字の強さで分かれる 1 つ 1 つ
:::

### 陣営のお告げとの関係

ExileDesk のエンジンでは、陣営のお告げは MOD に付いた陣営のタグで候補を選びます。

:::zundamon normal
陣営がずれると、何が困るのだ？
:::

:::metan normal
陣営のお告げを掛けた時に、どの MOD が候補に入るかが変わるの。
:::

:::zundamon normal
防具でも困るのだ？
:::

:::metan normal
防具には効かないわ。お告げを掛けられるのは武器・装飾品・矢筒だけなの。
:::

:::metan normal
だから効くのは、メイスやワンドのような武器・装飾品の MOD よ。
:::

| お告げ | 陣営 | 直す前のメイスの余震・亀裂 | 今 |
|---|---|---|---|
| 君主のお告げ | アマナム | 出ない | 出る |
| 支配者のお告げ | ウラマン | 出る | 出ない |
| ブラックブラッドのお告げ | クルガル | 出ない | 出ない |

直す前は、メイスの余震や亀裂は支配者のお告げの候補に入っていました。今は poe2db どおり、君主のお告げの側です。

:::zundamon troubled
君主のお告げで余震を狙っても、出なかったのだ……。
:::

:::metan troubled
そういうこと。メイスで陣営のお告げを試していた人には、違う候補を見せていたの。
:::

## ほかに何が違っていたのか

陣営のほかに、画面に出すタグも比べました。食い違いは陣営と合わせて 34 種類です。

:::zundamon normal
陣営のほかにも、まだあったのだ？
:::

:::metan normal
タグの中身の違いもあったわ。表を見て。
:::

| 食い違いの種類 | 数 | 例 | どう直したか |
|---|---:|---|---|
| 冒涜の陣営が違う | 9 MOD | メイスの余震・亀裂 | poe2db の陣営に合わせた |
| 冒涜のタグの中身が違う | 4 MOD | 鎧の被クリティカル率: poe2db はクリティカル、こちらはスピード | poe2db のタグに合わせた |
| こちらにだけブロック・フラスコのタグがある | 16 MOD | ブロック系・ベルトのフラスコ系 | タグを外した |
| エッセンス | 5 MOD | パーフェクトエッセンスのタグの有る無し | poe2db に合わせた (3 種類の防御の鎧の防御 % だけ今のまま) |

いちばん多いのは、こちらで足していたブロック・フラスコのタグでした。

:::zundamon normal
ブロックとフラスコは、なんで外したのだ？
:::

:::metan normal
poe2db には、そのタグ自体が無いの。poe2db のタグは 27 種類よ。
:::

:::metan normal
こちらで足していた物だから、外して poe2db に合わせたわ。
:::

## タグがずれると何が困るのか

タグは陣営のお告げだけでなく、いくつかの所で使っています。

:::zundamon normal
タグって、お告げのほかにも使うのだ？
:::

:::metan normal
使うわ。表にすると、こうなるの。
:::

| タグを使う所 | ずれると何が起きるか |
|---|---|
| カタリストの品質で伸びる MOD (指輪・アミュレット・ジュエル) | 品質で伸びるかどうかが変わる |
| MOD 一覧の札と検索 | 一覧で絞り込めるかどうかが変わる |
| 陣営のお告げ (陣営のタグ) | お告げの候補に入るかどうかが変わる |

:::zundamon surprised
小さなずれでも、打った結果に出るのだ！
:::

:::metan normal
そうなの。だから全部 poe2db に合わせたのよ。
:::

## どうやって確かめて、何を直したのか

poe2db は 2026-10-18 に取り直し、こちらのデータと 1 段ずつ比べるスクリプトを回しました。

:::zundamon normal
どうやって全部比べたのだ？
:::

:::metan normal
通常・冒涜・エッセンス (パーフェクトを含む) の 9,455 段を、1 段ずつスクリプトで比べたの。
:::

:::zundamon normal
タグは全部比べたのだ？
:::

:::metan normal
こちらのタグは、画面に出す物だけよ。冒涜の陣営は別に比べたわ。
:::

:::metan normal

:::

:::zundamon normal
見つけたきっかけは何だったのだ？
:::

:::metan normal
オーナーの「db みてタグフルチェックして相違ないか調べて」の一言よ。
:::

:::metan happy
その後、オーナーの「db に全て合わせてくれ」で、v0.1.572 に全部を poe2db に合わせたわ。部位ごとに数えると 93 MOD よ。
:::

:::note fold 確かめていない所 (4 件)
- 3 種類の防御の鎧のエッセンスの防御 % は、poe2db に 3 種類全部の行が無いので今のまま (アーマー・回避・ES) です。
- エッセンスの防御 % の食い違いは、突き合わせ方の取り違えの可能性もあり、記録では要確認になっています。
- 今回はゲームの中で陣営のお告げを打って確かめてはいません。正は poe2db に置いています。
- 直したことで陣営のお告げの結果がどれだけ変わったかは、数字では測っていません。
:::

:::zundamon normal
前にメイスで試していたら、どうすればいいのだ？
:::

:::metan normal
もう一度見直してほしいの。余震と亀裂は君主のお告げ (アマナム) の側よ。
:::

:::tip メイスで陣営を狙う時
v0.1.572 より前に ExileDesk でメイスの陣営のお告げを試していたなら、もう一度見直してください。余震と亀裂は君主のお告げ (アマナム) の側です。
:::

冒涜の陣営とタグは、v0.1.572 で全部 poe2db に合わせました。メイスで陣営を狙う時は、余震・亀裂は君主のお告げの側と覚えておいてください。
