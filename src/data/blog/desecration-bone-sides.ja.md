PoE2 の冒涜で、骨の MOD が左右どちらに付くかの答えは、**両側が空いていれば半々 (50%)、両側が埋まっていれば固定 (フラクチャー) 以外の MOD から等しく 1 つ消えて、消えた側に付く**です。側を自分で決めたい時は、左手 / 右手のネクロマンシーのお告げを使います。ExileDesk は v0.1.525 でこの形に直しました。

:::zundamon normal
骨を打つ時、どっちの側に付くかなんて気にしたことないのだ。
:::

:::metan normal
でも手袋みたいに、狙いの冒涜 MOD がサフィックスにしか無い部位もあるの。側が外れたら、その時点で狙いが候補に出ないのよ。
:::

:::zundamon surprised
それは困るのだ！ どうやって側が決まるのだ？
:::

:::metan troubled
実は ExileDesk も、少し前までここを独自の形で動かしていたの。Craft of Exile と照らし合わせて初めて気付いた話よ。
:::

:::summary この記事で分かる事
- 骨の側は、両側が空いていれば半々。両側が埋まっていれば、固定以外の MOD から等しく 1 つ消えてその側に付く
- 前の ExileDesk は側を MOD の重みの合計で選んでいた。「書いてなければランダム」の原則で v0.1.525 で直した
- 側を決めたい時は左手 / 右手のネクロマンシーのお告げ。アビサルロードの紋章がある時は使われない
:::

:::tip はじめての人へ: この記事の言葉
- **冒涜**: 骨を打って、未発現の冒涜 MOD を 1 つ付けるクラフト
- **プレフィックス・サフィックス**: MOD の 2 つの側。左側・右側とも言う
- **固定 (フラクチャー)**: 固定された MOD。骨で両側が埋まっている時も消える対象に入らない
- **ネクロマンシーのお告げ**: 次の冒涜の側を決めるお告げ。左手はプレフィックス、右手はサフィックス
- **重み**: MOD ごとの出やすさの数字。大きいほど出やすい
- **高貴**: 高貴なオーブ。この記事の値段の単位
:::

## 骨はどちらの側に付くのか

両側 (プレフィックス・サフィックス) に空きがあれば、どちらに付くかは半々です。

:::zundamon normal
半々って、どこで決まっているのだ？
:::

:::metan normal
Craft of Exile (CoE) の冒涜の作りは、ここを 0 か 1 の乱数で決めているの。
:::

:::zundamon normal
ゲームの説明文には書いてないのだ？
:::

:::metan normal
骨の説明文にも、ネクロマンシーのお告げの説明文にも、お告げが無い時の側の決め方は書いていないわ。
:::

:::metan normal
書いていない所は等しくランダム。これが今の ExileDesk の読み方よ。
:::

## 両側が埋まっていたら何が消えるのか

両側が埋まったレアに骨を打つと、固定以外の MOD の中から等しく 1 つが消えます。新しい未発現の MOD は、その消えた側に付きます。

:::zundamon normal
先にどっちの側か決めて、その側から 1 つ消すのだ？
:::

:::metan normal
逆よ。先に消す物を決めて、空いた側に付く順番なの。
:::

| 場面 | 付く側 | 何が起きるか |
|---|---|---|
| 両側が空いている | 半々 | CoE の作りでは 0 か 1 の乱数 |
| 両側が埋まっている | 消えた MOD の側 | 固定以外の MOD から等しく 1 つ消え、空いた側に付く |

「側を選んでから消す」のではなく、「消す物を選んでから側が決まる」と覚えておけば十分です。

### 前の作りはどこが違っていたのか

前の ExileDesk は、どちらの場面も CoE と違っていました。

| 場面 | 前の ExileDesk | 今 (v0.1.525 から、CoE と同じ) | なぜ直したか |
|---|---|---|---|
| 両側が空いている | 両側の MOD の重みの合計で側を選ぶ | 半々 | 重みで選ぶ決まりはゲームのどこにも無い |
| 両側が埋まっている | 側を重みで選んでから、その側の 1 つを消す | 固定以外の全部から等しく 1 つ消し、消えた側に付く | 10-10 のメモ「固定以外から等しく 1 つ消す」と食い違っていた |

:::zundamon normal
重みで選ぶのも、それらしく見えるのだ。
:::

:::metan normal
候補の多い側に寄るから、それらしくは見えるの。でも、ゲームのどこにもそう書いていないのよ。
:::

:::metan troubled
両側が埋まった時は、10-10 に残したメモとも食い違っていたわ。メモが正しくて、作りの方がずれていたの。
:::

:::zundamon normal
いつ気付いたのだ？
:::

:::metan normal
2026-10-16 よ。決まりを総点検した時の「公開の情報では決まらない物」を、CoE の作りと 1 つずつ比べたの。
:::

:::metan normal
API は叩かず、CoE のページが自分で読み込む作りのファイルだけを読んだわ。その中にこの 2 つがあったのよ。
:::

## なぜ半々に決めたのか

決め手は、オーナーの原則「書いてなければランダム」でした。

:::zundamon normal
オーナーは何て言ったのだ？
:::

:::metan normal
「普通なんも書いてなかったらそのまま効果発動だから、書いてないやつはランダム」よ。
:::

:::metan normal
書いていない所に、こちらで理屈を足さない。重みで側を選ぶのは、その「足した理屈」だったの。
:::

:::zundamon normal
それで、いつ直したのだ？
:::

:::metan normal
v0.1.525 (10-16) で CoE の形に直したわ。同じ日の夜に半々のままでよいとオーナーが確かめて、10-17 に OK が出たの。
:::

:::zundamon happy
じゃあ、全部 CoE に合わせたのだ？
:::

:::metan normal
全部ではないの。触媒の高貴のお告げの倍率などは CoE に合わせたけど、違う方に決めた物もあるわ。
:::

| 項目 | ExileDesk の今 | CoE と比べると | いつから |
|---|---|---|---|
| 骨の側 (半々・等しく 1 つ消す) | CoE と同じ形 | 合っている | v0.1.525 |
| 光のお告げと左側 / 右側の消去のお告げ | 一緒には掛けられない | 違う (10-17 にオーナーが「光使ってるから」と決めた) | v0.1.544 (v0.1.525 では一緒に掛けられた) |
| アビサルロードの紋章がある時の骨 | 骨は紋章と入れ替わり、ネクロマンシーのお告げは使わず減らない | 合っている | v0.1.545 |

CoE に合わせるかどうかは、1 つずつ決めています。

## 側を選びたい時はネクロマンシーのお告げ

側を自分で決めたい時は、ネクロマンシーのお告げを掛けてから骨を打ちます。

:::zundamon normal
お告げで、側はどう変わるのだ？
:::

:::metan normal
説明文どおりよ。左手のネクロマンシーのお告げなら、次の冒涜はプレフィックスだけ。右手ならサフィックスだけになるわ。
:::

:::zundamon normal
その側が満杯だったらどうなるのだ？
:::

:::metan normal
その側の 1 つと置き換わるの。ExileDesk では v0.1.511 から「1 つ置き換える」と出しているわ。
:::

:::zundamon normal
お告げはいくらするのだ？
:::

:::metan normal
右手のネクロマンシーのお告げは 7.29 高貴だったわ (ExileDesk のサーバーの相場、2026-10-20)。
:::

:::metan normal
手袋の冒涜専用 MOD はサフィックスにしか無いの。[アーケインサージの冒涜](/blog/arcane-surge-desecrated-gloves/) で数えたわ。手袋の骨 (肋骨) の値段も並べるわね。
:::

| 骨 | 使える条件 | 相場 (高貴) | ひとこと |
|---|---|---:|---|
| 噛み切られた肋骨 | アイテムレベル 64 まで | 6.39 | 条件つきで安い |
| 保存された肋骨 | ― | 6.75 | 制限の表示なし |
| 古代の肋骨 | 最低モッドレベル 40 | 4,702 | 桁違いに高い |

:::zundamon surprised
古代の肋骨だけ、桁が違うのだ！
:::

:::tip サフィックスだけの部位は側を先に決める
手袋のように冒涜専用 MOD がサフィックスにしか無い部位では、両側が空いたまま骨を打つと半分はプレフィックスに付きます。右手のネクロマンシーのお告げで側を決めてから打つと、側の外れがなくなります。
:::

:::note fold 確かめていない所 (3 件)
- 半々・等しく 1 つ消える、はどちらも CoE の作りとオーナーの原則「書いてなければランダム」に合わせた物です。ゲームで何百回も打って数えた物ではありません。
- ゲームの説明文にも、側の割合は書いてありません。
- 片側だけ空いている時の扱いや、両側が埋まった時に未発現・冒涜の MOD も消える対象に入るかは、この記事の出どころでは確かめていません。
:::

:::metan normal
冒涜を含むクラフトの費用も、この側の決め方の上に乗っているの。費用を後ろから計算する話は [クラフトの期待値は勘と違う](/blog/optimal-move-vs-intuition/) にあるわ。
:::

骨の側は、両側が空いていれば半々、両側が埋まっていれば固定以外から等しく 1 つ消えた側です。狙いが片側にしか無い時は、ネクロマンシーのお告げで側を決めてから打つのが近道です。

## 数字の出どころ

:::fold 出どころを見る (6 件)
- 半々・固定以外から等しく 1 つ消してその側: CoE の作り (poe2_desecrate、2026-10-16 の突き合わせ)・更新内容 v0.1.525 (poe2db・CoE / エンジン)。
- 前の作り (重みの合計・側を重みで選んでから消す): Craft of Exile との突き合わせの記録 (2026-10-16) (エンジン)。
- オーナーの原則とその後の確認 (10-16 夜・10-17 OK): 同じ記録とクラフトの決まりのチェックリスト (2026-10-17)。
- 光のお告げと左右の消去 (v0.1.525 → v0.1.544)・印がある時のネクロマンシー (v0.1.545)・「1 つ置き換える」(v0.1.511): 更新内容 (エンジン)。
- ネクロマンシーのお告げの効果: ゲームの説明文。
- 値段 (右手のネクロマンシーのお告げ 7.29 高貴・肋骨 6.39 / 6.75 / 4,702 高貴): ExileDesk のサーバーの相場 (2026-10-20)。肋骨の使える条件 (アイテムレベル 64 まで・最低モッドレベル 40) は解析君の引き継ぎの記録から (出どころの画面は記録に無い)。
:::
