PoE2 の上級・完全のオーブの違いは、**最低モッドレベル** (それより低い MOD レベルの段が付かない下限) です。poe2db では王者・高貴・カオスが上級 35・完全 50、ExileDesk のエンジンでは変成・増強のオーブが上級 44・完全 70 です。下限が高いほど低い段の外れは減りますが、値段も上がります。

:::zundamon normal
「完全」って付いてたら、一番いいオーブなのだ？
:::

:::metan normal
そう見えるわよね。でも ES の手袋で作り比べたら、一番安かったのは上級だったの。
:::

:::zundamon surprised
完全じゃないのだ！？ 理由が知りたいのだ。
:::

:::summary この記事で分かる事
- 上級・完全のオーブは「低い段を付けない」オーブ。その下限の早見表
- ES 手袋では上級の高貴が 1 個 105 神で、完全 (201 神) より安かった
- 下限が高すぎると、狙いの段まで付かなくなることがある
:::

:::tip はじめての人へ: この記事の言葉
- **高貴なオーブ**: レアのアイテムに MOD を 1 つ足すカレンシー
- **MOD の段 (T1・T2…)**: 同じ MOD でも数字の強さで段が分かれる。T1 が一番強い
- **MOD レベル**: 段ごとに決まっている数字。強い段ほど高い
- **上級・完全**: カレンシーの格。通常・上級・完全の 3 つ
- **最低モッドレベル**: これより低い MOD レベルの段は付かない、という下限
- **神**: 神のオーブ (ディバイン)。この記事の値段の単位
:::

:::metan normal
強いというより「弱い段を付けない」オーブなの。
:::

:::metan normal

:::

:::metan normal

:::

## 完全が一番安いとは限らない: ES 手袋では上級が最安

左側の高貴のお告げで、ES の手袋のプレフィックス 3 つ (上の表の 3 つ、全部 T2 以上) を揃える費用を、エンジンで 300 人ずつ比べました。

:::zundamon normal
外れが一番減る完全を打てば、一番安いのだ？
:::

:::metan happy
それが違うの。図を見て。
:::

:::chart bar 1 個あたりの費用 (神、エンジンで 300 人ずつ)
unit: 神
labels: 通常の高貴, 上級の高貴, 完全の高貴
ルーン無し: 423, 105, 201
セールの凱旋 + コルの狩り: 598, 194, 307
:::

| 左側の高貴のお告げ + (ルーン無し) | 1 個あたり | 使った高貴 | カオス | 狙いが全部消えた |

| 高貴なオーブ | 423 神 | 244 個 | 2,682 個 | 111 回 |

上級が 105 神で一番安いのだ！

:::

## 下限が高すぎて損をする場面

同じ手袋のサフィックス (コルの狩りを差した形) では、完全の下限が裏目に出ました。

:::zundamon troubled
完全だと損をすることもあるのだ？
:::

:::metan normal
あるの。クリティカルダメージボーナスの T2 は MOD レベル 45 なのよ。
:::

:::zundamon normal
完全の下限は 50 だから……。
:::

:::metan normal
そう、50 より低いから、エンジンでは T2 が付かないの。残るのは T1 (MOD レベル 59、重み 250) だけよ。
:::

:::chart bar サフィックスの費用 (神、右側の高貴で狙う形)
unit: 神
labels: 上級, 完全

:::metan troubled

:::

:::metan troubled
完成の割合も 83% から 53% に下がっているの。
:::

:::zundamon normal
ほかにも損をする場面はあるのだ？
:::

:::metan normal
削減のお告げ (一番 MOD レベルの低い MOD を消す) と組み合わせた時ね。
:::

:::metan normal
下限の高いカオスほど、付く外れのサフィックスの MOD レベルが高くなるの。
:::

:::metan troubled
すると削減が、外れより MOD レベルの低いプレフィックスの狙いを消してしまうのよ。
:::

:::chart bar 削減のお告げがプレフィックスの狙いを消した割合

:::

:::zundamon troubled
完全のカオスだと、半分近く狙いが消えるのだ……。
:::

:::note 確かめていない所
- 高貴・カオスの最低モッドレベルは 2026-10-21 に poe2db で読んだ値、変成・増強はエンジンの値 (POE2Tube とオーナーの話が元) です。ゲーム内で 1 つずつ確かめてはいません。
- 「完全では下限より下の段が付かず、T1 だけになる」はエンジンの動きで、ゲームで確かめるまでは仮説です。
- 「上級が一番安い」は、ES の手袋 1 つをエンジンで回した結果です。Craft of Exile とは突き合わせておらず、ほかの部位・狙いでも同じ順位になるかは分かりません。
- 値段は ExileDesk のサーバーの相場 (2026-10-20 16:00 UTC) です。相場が動けば、上級と完全の差も変わります。
- 変成・増強の取り違えの「2 倍」は記録に残っている見積もりで、直した後の費用は出し直していません。
:::

:::zundamon normal
結局、どのオーブを選べばいいのだ？
:::

:::metan happy
狙いの段の MOD レベルを先に見て、それを切らない一番安い下限を選ぶのが基本よ。
:::

:::tip 迷った時の考え方
狙いの段の MOD レベルを先に見て、それを切らない一番安い下限を選ぶのが基本です。完全は「狙いの段がすべて下限より上にあり、外れの多さが値段の差を上回る時」だけ検討すれば十分です。
:::

上級・完全のオーブの違いは、最低モッドレベルという下限だけです。完全が一番いいとは限らず、狙いの段の MOD レベルと値段を並べて選ぶのが近道です。

## 数字の出どころ

- 最低モッドレベル (王者・高貴・カオス 通常無し・上級 35・完全 50): poe2db の各オーブのページ、2026-10-21 の読み (poe2db)
- 最低モッドレベル (変成・増強 44・70): ExileDesk のエンジンの `CURRENCY_FLOOR`、元は POE2Tube (2026-10-06) とオーナーの話 (2026-09-10)。0.5.0 より前の上級は 55 (エンジン)
- カードの「MOD レベル ◯ 以上だけ付く」: ExileDesk の更新内容 v0.1.515
- ES 手袋のプレフィックスの費用 (ルーン無し 105 / 201 / 423 神と個数、セールの凱旋 + コルの狩り 194 / 307 / 598 神)・T2 の MOD レベル・クリティカルダメージボーナスの T2 が完全で出ない話 (コルの狩りを差した形のサフィックス 1,158 / 2,683 神)・削減の 37% / 48%: docs/org/math/notes/2026-10-21-es-gloves-ev.md、ExileDesk のエンジンで 300 人ずつ (エンジン。ゲームでは未確認)
- 高貴の値段 (上級 13.38 高貴・完全 2,045.74 高貴、1 神 = 696.93 高貴): ExileDesk のサーバーの相場、2026-10-20 16:00 UTC
- 変成・増強の下限の取り違えで「マジックを 2 倍に見積もった」: 期待値の計算の試しの記録 (推定。直した後の値は出し直していない)

## 自分で試してみる

上級・完全のオーブを選ぶと、カードの頭に「MOD レベル ◯ 以上だけ付く」が出ます。[クラフト台](/?base=Sirenscale%20Gloves) でサイレーンスケイルの手袋に、高貴なオーブ (上級) と (完全) を打ち比べてみてください。
