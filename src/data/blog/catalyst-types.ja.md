PoE2 のカタリストの種類は 13 個で、**どれも「指輪またはアミュレット」専用**です。それぞれ強化する MOD のタグが決まっていて、マナの MOD なら神経のカタリスト、キャスターなら歯擦音のカタリスト、スピードなら軽快のカタリストが効きます。品質は 1 種類しか載らず、別の種類を入れると 0 からやり直しです。

:::zundamon troubled
「歯擦音のカタリスト」って、何に効くのか全然分からないのだ。
:::

:::metan normal
名前からは想像しにくいわよね。歯擦音はキャスター、甲羅はアーマー・回避力・エナジーシールドなの。
:::

:::zundamon normal
どうやって調べたのだ？
:::

:::metan normal
マナ系の金の指輪を調べた時に、狙いの MOD ごとに poe2db のタグを 1 つずつ見たの。その結果を 13 種類まとめて表にしたわ。
:::

:::summary この記事で分かる事
- 13 種類のカタリストと、それぞれが強化する MOD のタグ
- マナ系の指輪の狙い (最大マナ・キャストスピードなど) に効くカタリスト
- 品質は 1 種類だけで、別の種類を入れると 0 から。手袋には使えず、ジュエルは「精製された」カタリスト
:::

:::tip はじめての人へ: この記事の言葉
- **カタリスト**: 指輪・アミュレットに品質を足すカレンシー
- **品質**: 決まったタグの MOD の数字を伸ばす値
- **MOD のタグ**: MOD に付いている分類 (マナ・キャスターなど)
- **精製されたカタリスト**: ジュエル用のカタリスト
- **神**: 神のオーブ。この記事の値段の単位
:::

## PoE2 のカタリストは何種類? 13 種類で全部が宝飾品用

poe2db の説明文は 13 種類とも同じ形です。違うのは、強化する MOD のタグだけです。

:::zundamon normal
説明文はどんな形なのだ？
:::

:::metan normal
「◯◯モッドを強化する品質を指輪またはアミュレットに追加する。他の品質タイプを置き換える」よ。
:::

:::metan normal
「◯◯」の所が種類ごとに違うの。表にするとこうなるわ。
:::

| カタリスト | 強化する MOD |
|---|---|
| 肉体のカタリスト | ライフ |
| 神経のカタリスト | マナ |
| 甲羅のカタリスト | アーマー・回避力・エナジーシールド |
| ウール・ネトルのカタリスト | 物理 |
| ゾフのカタリスト | 火 |
| トゥルのカタリスト | 冷気 |
| エシュのカタリスト | 雷 |
| チャユラのカタリスト | 混沌 |
| 強奪者のカタリスト | アタック |
| 歯擦音のカタリスト | キャスター |
| 軽快のカタリスト | スピード |
| 適応のカタリスト | 能力値 |
| 死霊術のカタリスト | ミニオン |

:::zundamon normal
MOD の名前を見れば、効くかどうか分かるのだ？
:::

:::metan normal
いいえ、決め手は**MOD に付いているタグ**なの。名前ではないわ。
:::

:::metan normal
タグを 2 つ以上持つ MOD なら、どのタグのカタリストでも効くのよ。
:::

## マナ系の指輪には神経・歯擦音・軽快のどれが効く?

金の指輪 (アイテムレベル 82) でマナ系の狙いを調べた結果です。タグは poe2db の指輪の MOD 表で確かめました。

| 狙いの MOD | タグ | 効くカタリスト | どう選ぶか |
|---|---|---|---|
| 最大マナ (藍色をした ほか) | マナ | 神経 | 神経だけ |
| 最大マナが(4–6)%増加する | マナ | 神経 | 神経だけ |
| マナ自動回復レート (涅槃の) | マナ | 神経 | 神経だけ |
| スペルのマナコスト効率 (計算高い) | マナ・キャスター | 神経と歯擦音の両方 | どちらでも乗る |
| キャストスピード | キャスター・スピード | 歯擦音と軽快の両方 | どちらでも乗る |
| 全ての元素耐性 | 元素・火・冷気・雷・耐性 | 神経・歯擦音・軽快は効かない | トゥル・ゾフ・エシュで (エンジンの扱い) |

:::zundamon happy
キャストスピードは、歯擦音でも軽快でもいいのだ！
:::

:::metan normal
そう、2 つのタグを持つからどちらでも品質が乗るわ。
:::

:::metan troubled
でも神経で伸ばしたいマナの MOD もある時は、どの MOD を伸ばすかで 1 種類を選ぶことになるの。
:::

:::zundamon normal
全ての元素耐性には、何が効くのだ？
:::

:::metan normal
火・冷気・雷のタグを持つから、ExileDesk ではトゥル・ゾフ・エシュのカタリストが効く扱いよ。
:::

:::metan normal
マナ系の指輪の計算でも、全耐性はトゥルのカタリストで狙ったわ。
:::

:::metan troubled
ただ、これはタグで判定するエンジンの動きなの。ゲームではまだ確かめていないわ。
:::

:::zundamon normal
スペルのマナコスト効率も、クラフトで付けるのだ？
:::

:::metan normal
それは違うの。指輪の普通の MOD 表には無く、創生の樹の表にだけある MOD よ。
:::

## 品質は何 % まで? 別の種類を入れると 0 から

カタリストの品質は、指輪・アミュレットに 1 種類しか載りません。別の種類を入れると、前の品質は消えます。

:::zundamon normal
2 種類のカタリストを重ねて入れられないのだ？
:::

:::metan normal
入れられないわ。説明文の「他の品質タイプを置き換える」のとおり、0 から積み直しよ。
:::

:::zundamon normal
1 個でどれくらい品質が上がるのだ？
:::

:::metan normal
ExileDesk では、**手で打つと 1 個で品質 +1% か +2% (半々)** にしているの。
:::

:::metan normal
これはオーナーの決め (2026-10-17) で、v0.1.540 からよ。上限は普通 20% ね。
:::

:::zundamon surprised
前は違ったのだ？
:::

:::metan normal
v0.1.509 では、種類を選ぶと 1 回で上限まで上がっていたわ。
:::

| 入れ方 | 何が起きるか | どうなるか |
|---|---|---|
| 同じ種類を足す | 品質が積み上がる | 上限 (普通 20%) まで伸ばせる |
| 別の種類を入れる | 前の品質が消える | 0 から積み直し、積んだ分は無駄 |

:::zundamon troubled
途中で狙いが変わったら、もったいないのだ。
:::

:::metan troubled
そうなの。マナ系の指輪の計算では、費用の大きな部分が 2 つあったわ。
:::

:::metan normal
完全な高貴 (376〜418 神) と、キャストスピード用の軽快のカタリストの入れ直し (228〜391 神) よ。詳しくは [マナ系の指輪のクラフト](/blog/mana-ring-craft/) にあるわ。
:::

:::tip 品質は数字を伸ばすだけではない
品質で伸びる MOD の数字は、表示の時に切り捨てられます ([品質の丸めは切り捨て](/blog/quality-rounding-down/))。もう 1 つの使い道が触媒の高貴のお告げで、品質のタグに合う MOD を引きやすくします ([倍率の話](/blog/catalysing-exaltation-multiplier/))。
:::

### 手袋やジュエルにはカタリストを使えない?

手袋とジュエルでは、事情がそれぞれ違います。

:::zundamon normal
ES 手袋にも、甲羅や神経のカタリストを入れたいのだ。
:::

:::metan troubled
**手袋に使えるカタリストはありません。** 狙いに合うタグの物はあっても、置き場が指輪・アミュレットだけなの。
:::

:::metan normal
手袋の品質は、防具用の別のカレンシーで上げるのよ。
:::

:::zundamon normal
ジュエルはどうなのだ？
:::

:::metan normal
ジュエルは「精製された」カタリストになるわ。例えば精製された神経のカタリストね。
:::

:::metan normal
ExileDesk でも v0.1.508 で、ジュエルの触媒を精製された方に直したの。普通のカタリストは指輪・アミュレット用よ。
:::

## カタリストの値段の目安は?

poe2db の各カレンシーのページに載っている取引レートです (2026-10-21 に読んだ値)。

| カタリスト | poe2db の表記 | 24 時間の取引数 | 安さ (私たちの読み) |
|---|---|---:|---|
| 神経のカタリスト | 1 神のオーブ = 21.5 個 | 279 | 向きが合えば 3 つで一番安い |
| 歯擦音のカタリスト | 1 神のオーブ = 3.02 個 | 935 | 向きが合えば神経より高い |
| 軽快のカタリスト | 1 神のオーブ = 3.93 個 | 267 | 向きが合えば神経より高い |

:::zundamon happy
神経のカタリストが、ずっと安いのだ！
:::

:::metan troubled
この読み方ならね。表記の向き (「1 神 = n 個」か「n 神 = 1 個」か) は私たちの読みなの。
:::

:::note fold 確かめていない所 (3 件)
- 全ての元素耐性にトゥル・ゾフ・エシュが効くのは、タグで判定するエンジンの扱いです。ゲームでは確かめていません。
- 1 個で +1% か +2% は ExileDesk の決めで、ゲームの値は確かめていません。
- 値段の向きは推定です。使う前に poe2db のページで向きを確かめてください。
:::

カタリストは、狙いの MOD のタグを先に見て 1 種類を選ぶのが基本です。種類を替えると品質は 0 からなので、途中で替えない形を考えておくと無駄が出ません。
