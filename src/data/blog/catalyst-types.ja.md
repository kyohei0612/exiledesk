PoE2 のカタリストの種類は 13 個で、**どれも「指輪またはアミュレット」専用**です。それぞれ強化する MOD のタグが決まっていて、マナの MOD なら神経のカタリスト、キャスターなら歯擦音のカタリスト、スピードなら軽快のカタリストが効きます。品質は 1 種類しか載らず、別の種類を入れると 0 からやり直しです。

カタリストは名前から効き目が想像しにくいですよね。「歯擦音」がキャスター、「甲羅」がアーマー・回避力・エナジーシールドだと、名前だけで分かる人は少ないと思います。

私たちもマナ系の金の指輪を調べた時、狙いの MOD ごとに poe2db のタグを 1 つずつ見て、どのカタリストが効くかを確かめました。その結果を、13 種類まとめて表にしておきます。

:::summary この記事で分かる事
- 13 種類のカタリストと、それぞれが強化する MOD のタグ (日本語名・英語名つき)
- マナ系の指輪の狙い (最大マナ・キャストスピードなど) に効くカタリスト
- 品質は 1 種類だけ。別の種類を入れると 0 から (ExileDesk では 1 個で +1% か +2%)
- 手袋には使えず、ジュエルは「精製された」カタリストになる
:::

## PoE2 のカタリストは何種類? 13 種類で全部が宝飾品用

poe2db の説明文は 13 種類とも同じ形で、「◯◯モッドを強化する品質を指輪またはアミュレットに追加する。他の品質タイプを置き換える」です。違うのは「◯◯」の部分、つまり強化する MOD のタグだけです。

| カタリスト | 英語名 | 強化する MOD |
|---|---|---|
| 肉体のカタリスト | Flesh Catalyst | ライフ |
| 神経のカタリスト | Neural Catalyst | マナ |
| 甲羅のカタリスト | Carapace Catalyst | アーマー・回避力・エナジーシールド |
| ウール・ネトルのカタリスト | Uul-Netol's Catalyst | 物理 |
| ゾフのカタリスト | Xoph's Catalyst | 火 |
| トゥルのカタリスト | Tul's Catalyst | 冷気 |
| エシュのカタリスト | Esh's Catalyst | 雷 |
| チャユラのカタリスト | Chayula's Catalyst | 混沌 |
| 強奪者のカタリスト | Reaver Catalyst | アタック |
| 歯擦音のカタリスト | Sibilant Catalyst | キャスター |
| 軽快のカタリスト | Skittering Catalyst | スピード |
| 適応のカタリスト | Adaptive Catalyst | 能力値 |
| 死霊術のカタリスト | Necrotic Catalyst | ミニオン |

効くかどうかは MOD の名前ではなく、**MOD に付いているタグ**で決まります。タグを 2 つ以上持つ MOD なら、どのタグのカタリストでも効きます。

## マナ系の指輪には神経・歯擦音・軽快のどれが効く?

金の指輪 (アイテムレベル 82) でマナ系の狙いを調べた時の、MOD ごとのタグと効くカタリストです。タグは poe2db の指輪の MOD 表で確かめました。

| 狙いの MOD | タグ | 効くカタリスト |
|---|---|---|
| 最大マナ (藍色をした ほか) | マナ | 神経 |
| 最大マナが(4–6)%増加する | マナ | 神経 |
| マナ自動回復レート (涅槃の) | マナ | 神経 |
| スペルのマナコスト効率 (計算高い) | マナ・キャスター | 神経と歯擦音の両方 |
| キャストスピード | キャスター・スピード | 歯擦音と軽快の両方 |
| 全ての元素耐性 | 元素・火・冷気・雷・耐性 | 神経・歯擦音・軽快は効かない |

キャストスピードのように 2 つのタグを持つ MOD は、歯擦音でも軽快でも品質が乗ります。同じ指輪に神経で伸ばしたいマナの MOD もある時は、どの MOD を伸ばすかで 1 種類を選ぶことになります。

全ての元素耐性は火・冷気・雷のタグを持つので、ExileDesk はタグで判定して、トゥル (冷気)・ゾフ (火)・エシュ (雷) のカタリストが効く扱いにしています。マナ系の指輪の計算でも、全耐性はトゥルのカタリストで狙いました。これはエンジンの動きで、ゲームではまだ確かめていません。

なお、スペルのマナコスト効率 (計算高い) は、指輪の普通の MOD 表には無く、創生の樹の表にだけある MOD です。後からクラフトで付ける物ではありません。

## 品質は何 % まで? 別の種類を入れると 0 から

カタリストの品質は、指輪・アミュレットに 1 種類しか載りません。説明文の「他の品質タイプを置き換える」のとおり、別の種類を入れると前の品質は消え、0 から積み直しです。

ExileDesk では、カタリストは**手で打つと 1 個で品質 +1% か +2% (半々)** にしています。これはオーナーの決めで (2026-10-17)、v0.1.540 からです。前は種類を選ぶと 1 回で上限まで上がっていました (v0.1.509)。上限は普通 20% です。

途中で狙いが変わってカタリストの種類を替えると、積んだ品質は無駄になります。マナ系の指輪の計算では、費用の大きな部分が 2 つあり、完全の高貴 (376〜418 神) と並んで、キャストスピード用の軽快のカタリストの入れ直し (228〜391 神) が重くなりました ([マナ系の指輪のクラフト](/blog/mana-ring-craft/))。

:::tip 品質は数字を伸ばすだけではない
品質で伸びる MOD の数字は、表示の時に切り捨てられます ([品質の丸めは切り捨て](/blog/quality-rounding-down/))。もう 1 つの使い道が触媒の高貴のお告げで、品質のタグに合う MOD を引きやすくします ([倍率の話](/blog/catalysing-exaltation-multiplier/))。
:::

### 手袋やジュエルにはカタリストを使えない?

**手袋に使えるカタリストはありません。** 甲羅のカタリスト (エナジーシールド)・神経のカタリスト (マナ) のように ES 手袋の狙いに合うタグの物はあっても、置き場が指輪・アミュレットだけです。手袋の品質は防具用の別のカレンシーで上げます。

ジュエルは「精製された」カタリストになります (例: 精製された神経のカタリスト / Refined Neural Catalyst)。ExileDesk でも v0.1.508 で、ジュエルの触媒を精製された方に直しました。普通のカタリストは指輪・アミュレット用です。

## カタリストの値段の目安は?

poe2db の各カレンシーのページに載っている取引レートです (2026-10-21 に読んだ値)。

| カタリスト | poe2db の表記 | 24 時間の取引数 |
|---|---|---:|
| 神経のカタリスト | 1 神のオーブ = 21.5 個 | 279 |
| 歯擦音のカタリスト | 1 神のオーブ = 3.02 個 | 935 |
| 軽快のカタリスト | 1 神のオーブ = 3.93 個 | 267 |

この読み方なら、神経のカタリストは歯擦音・軽快よりずっと安いことになります。ただし、表記の向き (「1 神 = n 個」か「n 神 = 1 個」か) は私たちの読みです。

:::note 確かめていない所
- 全ての元素耐性にトゥル・ゾフ・エシュが効くのは、タグで判定するエンジンの扱いです。ゲームでは確かめていません。
- 1 個で +1% か +2% は ExileDesk の決めで、ゲームの値は確かめていません。
- 値段の向きは推定です。使う前に poe2db のページで向きを確かめてください。
:::

## 数字の出どころ

- 13 種類の名前と強化するタグ: poe2db の各カタリストの説明文 (ExileDesk のカレンシーの説明と同じ文)。名前の日英は ExileDesk の catalysts.json — poe2db・CoE
- マナ系の指輪の MOD のタグと効くカタリスト: research/notes/2026-10-21-mana-ring-mods.md (poe2db の指輪の MOD 表) — poe2db・CoE
- 全耐性をトゥルで狙う扱いと、マナ系の指輪の費用の内訳: math/notes/2026-10-21-gold-ring-suffix-ev.md・2026-10-21-mana-ring-ev.md — エンジン
- 手袋にカタリストが使えない事: research/notes/2026-10-21-es-gloves-mods.md (poe2db の説明文) — poe2db・CoE
- 品質 1 個 +1% か +2%: ExileDesk の更新内容 v0.1.540 (オーナーの決め)。前の形は v0.1.509、砥石などの品質の変え方は v0.1.529 — エンジン
- 種類を変えると 0 から・13 種類: チュートリアル「カタリストと品質を学ぶ」(v0.1.561) と poe2db の文 — poe2db・CoE
- ジュエルは精製されたカタリスト: v0.1.508 — poe2db・CoE
- 値段: poe2db のページ内の取引レート (2026-10-21)。向きは推定 — 推定
